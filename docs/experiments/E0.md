# E0 — Text2Schema from gold NL

Maps dataset-authored natural-language requirements to relational schemata
(MySQL DDL + metadata). Evaluates structural fidelity only (no BLEU/ROUGE/SCR).

## Entry points

| Role | Command |
|---|---|
| Offline Tables V+VI | `python3 experiments/E0/reproduce_genuine_tables.py --pred-root "$PRED_ROOT" --write-gpm --strict` |
| Gold / protocol checks | `python3 experiments/E0/reproduce_genuine_tables.py --validate-only` |
| Closed Direct inference | `python3 experiments/E0/run_direct_api.py --confirm-paid` |
| Dry-run inference | `python3 experiments/E0/run_direct_api.py --dry-run` |
| PaperMethods baselines | `python3 experiments/E0/original_benchmarks/run_baselines.py --dry-run` |

Full CLI and private prediction layout: [`experiments/E0/README.md`](../../experiments/E0/README.md).

## Metrics

- Micro F1 on T/A/D/E/R (RSchema 518 structural / 381 Domain; SchemaBench 239).
- Hallucination: 4-dim micro mean over T/A/E/R (Domain excluded).
- nGED: type-independent names-only mean; empty prediction → 1.
- Domain uses genuine typed gold with known nullability only (never synthetic VARCHAR gold for canonical Domain).
- Coverage (`COMPLETE` / `INCOMPLETE` / `INVALID` / `BLOCKED`) is separate from scored population size.
- Direct rows of Table VI equal Table V exactly when both are computed from the same dumps.
