## Protocol

| Item | Value |
|---|---|
| Basic prompt | `prompts/describer_basic.txt` (schema2text1 short summary; SHA256 strip `e1422bc8…`) |
| Detailed prompt | `prompts/describer_detailed.txt` (schema2text2 exhaustive paragraph; SHA256 strip `f09fc8ca…`) |
| Enterprise-145 | N=145, **SCR only** (no gold NL) |
| RSchema | N=**381** DDL-matched IDs from `datasets/rschema/annotation_ddl.jsonl` |
| SchemaBench | N=239 |
| BLEU-4 | `sacrebleu.corpus_bleu(hyps, [refs])` — **not** `[[r] for r in refs]` |
| ROUGE-L | `RougeScorer(["rougeL"], use_stemmer=True)` mean F1 |
| BERTScore-F1 | `bert_score` `lang="en"` (RoBERTa-large), mean F1 |
| SCR | Macro mean identifier coverage (tables ∪ columns) |
