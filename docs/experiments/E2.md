# E2 - Round trip Schema -> Text -> Schema

**Paper table:** `tab:e2_roundtrip` (Table VIII). **Code:** `experiments/E2/` (`run.py`, `evaluate.py`,
`generate_table_viii.py`). **Guide:** [REPRODUCE_E1_E2.md](../REPRODUCE_E1_E2.md).

Pipeline: E1 description -> GPT-4o-mini constructor (`prompts/constructor.txt`, sha256 `392a396f...84ad4`) ->
reconstructed DDL + metadata -> structural comparison with the **genuine** gold DDL (RSchema: the 381
DDL-matched schemas, not the synthetic 518).
Metrics: micro-F1 for Tables / Attributes / Domain / Entity / Referential and mean nGED; failed
reconstructions score gold counts with recreated = matched = 0 and nGED = 1 (`--fail-policy score`).

**Paid constructor.** Dry-run is the default. A real GPT-4o-mini run works with `--execute --confirm-paid`
(both required) and `OPENAI_API_KEY` in the environment; it is billed per token, so try `--limit 1` first.

**Provenance.** E1 descriptions must carry the requested describer (`llm`, `model_id`), `prompt_style` and
describer-prompt sha256; mismatches are rejected, never relabelled; duplicate ids / mixed prompt styles
abort the run; `--allow-legacy-e1` tolerates only *missing* fields (with a warning).

**Empty schemas.** `{"ddl": "", ...}` is a valid reconstruction. Statuses in `per_schema.csv`: `ok`,
`valid_empty` (gold empty too, nGED 0), `incorrect_empty` (gold non-empty, natural nGED), `scored_failure`
(nGED 1), `skipped`. A missing file is never a valid empty schema.

```bash
python experiments/E2/run.py --dataset rschema --describer-model llama31 --prompt detailed \
    --e1-pred-dir experiments/E1/outputs/rschema_detailed_llama31                      # dry-run
python experiments/E2/run.py --dataset rschema --describer-model llama31 --prompt detailed \
    --e1-pred-dir experiments/E1/outputs/rschema_detailed_llama31 --execute --confirm-paid   # paid
python experiments/E2/evaluate.py --dataset rschema --describer-model llama31 --prompt detailed \
    --pred-dir experiments/E2/outputs/rschema_detailed_llama31
python experiments/E2/generate_table_viii.py --metrics-dir experiments/E2/outputs/metrics
```
