# E3 — Constructor isolation

**Paper table:** `tab:e3_overall` (Table IX). **Code:** `experiments/E3/` (`prepare_inputs.py`, `run.py`,
`validate_inputs.py`, `evaluate.py`, `generate_table_ix.py`). **Guide:** [REPRODUCE_E3.md](../REPRODUCE_E3.md).

Hold the natural-language description fixed (GPT-5.4-mini, Detailed prompt) and vary only the
constructor. Populations: Enterprise-145 (N=145), SchemaBench (N=239), RSchema (N=381 genuine DDL).
Constructors: CodeLlama-13B, Llama-3.1-8B, DeepSeek-Coder, Claude Sonnet 4.6, GPT-5.4-mini.
Metrics: mean nGED, five-dimension micro Hallucination, micro-F1 for T/A/D/E/R.

```bash
python experiments/E3/prepare_inputs.py --dataset rschema \
    --descriptions-dir experiments/E1/outputs/rschema_detailed_gpt54mini
python experiments/E3/run.py --dataset rschema --constructor llama31 \
    --descriptions-dir experiments/E1/outputs/rschema_detailed_gpt54mini            # dry-run
python experiments/E3/evaluate.py --dataset rschema --constructor llama31 \
    --pred-dir experiments/E3/outputs/rschema_detailed_llama31
python experiments/E3/generate_table_ix.py --metrics-dir experiments/E3/outputs/metrics
```
