## Pipeline

Gold schema → frozen GPT-5.4-mini detailed NL (identical per schema across constructors) → five constructors → predicted DDL → locked E2 vendor metrics.

Constructor isolation is hash-verified for **765/765** PRIMARY schemata.

## Metrics

- **nGED:** type-dependent `(col, type_family, nullability)` — same Exp4/E2 vendor definition (**not** E0 names-only).
- **Hall.:** mean of micro FP rates on Tables / Attributes / Entity / Referential (Domain excluded).
- **F1:** micro-averaged T / A / D / E / R.

## Public reproducibility limit

Frozen descriptions and Exp4 prediction JSON are **not** in git (private dumps). Checksums and path manifests are published under `E3_AUDIT/provenance/`. External users with only the public repo **cannot** fully re-run the numerical evaluation without those inputs.
