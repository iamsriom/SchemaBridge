ZERO-SCORE POLICY (updated):
  Failed / missing / empty predictions are NOT excluded.
  They are included in every mean over all 518 gold schemas as:
    F1 (Tables / Attrs / Domain / Entity / Ref) = 0.0
    nGED                                         = 1.0   (worst)
    Hallucination                                = 1.0   (worst)
  Eval = 518 for every method.
  Zero = count of cases scored under this policy.
  Reported F1 / nGED / Halluc = macro mean over all gold schemas.

NOTE (Domain Integrity on PaperMethods):
  PaperMethods emit structured schemas (no SQL types). Predictions are converted
  with the same synthetic DDL helper as gold, so Domain F1 == Attributes F1 in
  our runs. Table V baselines used real DDL types, so Domain is lower there.
