This database schema, named "rschema_0015," is used to store information about plots, pest and disease status, employees, and monitoring records. The schema consists of four tables: "plot," "pest_and_disease," "employee," and "monitoring_record."
The "plot" table contains information about each plot, including its number, area, soil type, current pest and disease status, and geographic location. The primary key for this table is the "plot_number" column.
The "pest_and_disease" table contains information about each pest or disease, including its number, name, degree of harm, prevention and control methods, and season of occurrence. The primary key for this table is the "pest_and_disease_number" column.
The "employee" table contains information about each employee, including their number, name, gender, age, and contact information. The primary key for this table is the "employee_number" column.
The "monitoring_record" table contains information about each monitoring record, including the plot number, pest or disease number, monitoring time, monitoring results, and the employee number who conducted the monitoring. The primary key for this table is the combination of the "plot_number," "pest_and_disease_number," and "monitoring_time" columns.
The "monitoring_record" table has two foreign key constraints: one that references the "pest_and_disease" table and one that references the "plot" table. The "pest_and_disease" table is referenced by the "pest_and_disease_number" column, and the "plot" table is referenced by the "plot_number" column. The foreign key constraints have the ON DELETE CASCADE and ON UPDATE CASCADE options, which means that if a record in the "pest_and_disease" or "plot" table is deleted or updated, the corresponding records in the "monitoring_record" table will be deleted or updated as well.
