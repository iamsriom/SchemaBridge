The database name is rschema_0035, and it contains three tables: Customer, Project, and Customer_Project_Relationship. The Customer table has five columns: Address, Customer_ID (primary key), Email, Name, and Phone. The Project table has seven columns: Actual_Completion_Date, Estimated_Completion_Date, Project_Budget, Project_ID (primary key), Project_Name, Start_Date, and Satisfaction_Rating. The Customer_Project_Relationship table has five columns: Customer_ID (foreign key referencing Customer), Feedback, Project_ID (foreign key referencing Project), Satisfaction_Rating, and a composite primary key (Customer_ID, Project_ID). The foreign keys in this table reference the primary keys in the Customer and Project tables, and the update and delete rules are CASCADE.
