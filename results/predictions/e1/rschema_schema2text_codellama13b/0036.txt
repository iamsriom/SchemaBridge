The database name is rschema_0036, and it contains four tables: Project, Contract, Project_Includes_Contract, and Contract_Change_Record.
The Project table has the following columns: Actual_Completion_Date, Budget, Expected_Completion_Date, Location, Project_Name, Project_Number (primary key), and Start_Date. The Project_Number column is an integer and is the primary key.
The Contract table has the following columns: Contract_Amount, Contract_Name, Contract_Number (primary key), Contract_Status, Project_Number (not null), Signing_Date. The Contract_Number column is an integer and is the primary key. The Project_Number column is an integer and is not null.
The Project_Includes_Contract table has the following columns: Contract_Number (not null), Project_Number (not null), and a composite primary key consisting of Project_Number and Contract_Number. The Contract_Number column is an integer and is not null. The Project_Number column is an integer and is not null.
The Contract_Change_Record table has the following columns: Change_Amount, Change_Content, Change_Date, Change_Number (primary key), Contract_Number (not null). The Change_Number column is an integer and is the primary key. The Contract_Number column is an integer and is not null.
The foreign keys in the schema are:
* Project_Includes_Contract.Contract_Number references Contract.Contract_Number
* Project_Includes_Contract.Project_Number references Project.Project_Number
* Contract_Change_Record.Contract_Number references Contract.Contract_Number
The update and delete rules for the foreign keys are:
* Project_Includes_Contract.Contract_Number has an update rule of CASCADE and a delete rule of RESTRICT
* Project_Includes_Contract.Project_Number has an update rule of CASCADE and a delete rule of RESTRICT
* Contract_Change_Record.Contract_Number has an update rule of CASCADE and a delete rule of RESTRICT
There are no other indexes or constraints in the schema.
