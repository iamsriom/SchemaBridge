This database schema, named rschema_0039, contains five tables that are used to store information about sales personnel, project managers, civil engineering projects, buildings, and building sales. The tables are designed to enforce data integrity through the use of primary keys, foreign keys, and unique constraints.
The Sales_Personnel table contains information about the sales personnel, including their contact information, name, position, and a unique identifier for each sales personnel. The table has a primary key on the Sales_Personnel_ID column.
The Project_Manager table contains information about the project managers, including their contact information, name, position, and a unique identifier for each project manager. The table has a primary key on the Project_Manager_ID column.
The Civil_Engineering_Project table contains information about the civil engineering projects, including the project name, location, start and expected completion dates, and a unique identifier for each project. The table has a primary key on the Project_ID column and a foreign key on the Project_Manager_ID column that references the Project_Manager table.
The Building table contains information about the buildings, including the building ID, number of floors, area, price, and a unique identifier for each building. The table has a primary key on the Building_ID column and a foreign key on the Project_ID column that references the Civil_Engineering_Project table.
The Building_Sale table contains information about the sales of buildings, including the building ID, customer contact information, customer name, price, sales date, and a unique identifier for each sale. The table has a primary key on the Building_ID, Sales_Personnel_ID, and Sales_Date columns, and foreign keys on the Building_ID and Sales_Personnel_ID columns that reference the Building and Sales_Personnel tables, respectively.
Overall, this schema is designed to store and manage information about sales personnel, project managers, civil engineering projects, buildings, and building sales in a way that ensures data integrity through the use of primary keys, foreign keys, and unique constraints.
