The database schema rschema_0043 is used to store information about loan applications, approvals, and approval officers. It consists of three tables: loan_application, loan_approval, and approval_officer.
The loan_application table contains information about each loan application, including the application number, property number, loan amount, loan term, approval status, applicant name, applicant phone number, applicant ID number, and application time. The primary key of this table is the application number.
The loan_approval table contains information about each loan approval, including the approval officer number, loan application number, approval time, approval result, and the foreign keys that reference the approval officer number and loan application number. The primary key of this table is a composite key consisting of the approval time, loan application number, and approval officer number.
The approval_officer table contains information about each approval officer, including the approval officer number, approval officer name, and approval officer phone number. The primary key of this table is the approval officer number.
The foreign keys in the loan_approval table reference the approval officer number and loan application number in the approval_officer and loan_application tables, respectively. The ON DELETE CASCADE and ON UPDATE CASCADE clauses in the foreign key constraints ensure that if an approval officer or loan application is deleted or updated, the corresponding records in the loan_approval table are also deleted or updated.
In summary, the rschema_0043 database schema is used to store information about loan applications, approvals, and approval officers. It consists of three tables that are related through foreign keys, and the schema ensures data integrity through the use of primary keys, foreign keys, and constraints.
