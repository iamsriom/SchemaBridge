This schema, named rschema_0045, is a database for managing inventory and outgoing records for a warehouse. It consists of five tables: warehouse, good, warehouse_good_record, inventory, and outgoing_record.
The warehouse table contains information about each warehouse, including its number, name, address, inventory accuracy, and outbound efficiency. The good table contains information about each product, including its name, model, barcode, and price.
The warehouse_good_record table contains information about the inventory of each product in each warehouse, including the quantity of each product in each warehouse. This table has a composite primary key consisting of the good barcode and warehouse number. It also has foreign key constraints referencing the good and warehouse tables.
The inventory table contains information about the inventory of each product in each warehouse, including the time and person who recorded the inventory, the quantity of each product, and the receiving unit. This table has a composite primary key consisting of the inventory time, product barcode, and warehouse number. It also has foreign key constraints referencing the good and warehouse tables.
The outgoing_record table contains information about the outgoing records of each product in each warehouse, including the time, quantity, and receiving unit of each product. This table has a composite primary key consisting of the outbound time, good number, and warehouse number. It also has foreign key constraints referencing the good and warehouse tables.
In summary, this schema is designed to manage the inventory and outgoing records of a warehouse, with each table representing a different aspect of the data. The tables are connected through foreign key constraints, ensuring referential integrity and data consistency.
