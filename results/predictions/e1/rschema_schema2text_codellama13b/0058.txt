The database name is rschema_0058. It contains three tables: Equipment, Inspection_Personnel, and Inspection_Record.
The Equipment table has five columns: Equipment_ID, Equipment_Model, Equipment_Name, Installation_Date, and Installation_Location. The Equipment_ID column is the primary key and is an integer. The Equipment_Model, Equipment_Name, Installation_Date, and Installation_Location columns are all strings. The Installation_Date column is a datetime.
The Inspection_Personnel table has four columns: Contact_Information, Department, Inspection_Personnel_ID, and Name. The Inspection_Personnel_ID column is the primary key and is an integer. The Contact_Information, Department, and Name columns are all strings.
The Inspection_Record table has five columns: Equipment_ID, Inspection_Content, Inspection_Date, Inspection_Personnel_ID, and PRIMARY KEY (Equipment_ID, Inspection_Personnel_ID, Inspection_Date). The Equipment_ID column is an integer and is not null. The Inspection_Content column is a string. The Inspection_Date column is a datetime. The Inspection_Personnel_ID column is an integer and is not null. The PRIMARY KEY constraint is a composite key made up of the Equipment_ID, Inspection_Personnel_ID, and Inspection_Date columns.
The Inspection_Record table has two foreign key constraints: one referencing the Equipment table and the other referencing the Inspection_Personnel table. The foreign key constraints have update and delete rules of CASCADE.
