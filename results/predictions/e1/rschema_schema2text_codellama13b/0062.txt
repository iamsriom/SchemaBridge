The database name is rschema_0062, and it contains three tables: Document, Author, and Modification_Record. The Document table has four columns: Creation_Date, Document_ID (primary key), Title, and Version_Number. The Author table has six columns: Author_ID (primary key), Date_of_Birth, Gender, Name, Phone_Number, and Position. The Modification_Record table has five columns: Document_ID (foreign key referencing Document.Document_ID), Modification_Content, Modification_Date, Modifying_Author_ID (foreign key referencing Author.Author_ID), and Version_Number. The primary key of the Modification_Record table is a composite key consisting of Document_ID, Modification_Date, and Modifying_Author_ID. The foreign keys in the Modification_Record table reference the Document and Author tables, and the update and delete rules are CASCADE and RESTRICT, respectively.
