The database schema rschema_0064 is used to store information about projects and their reviews by experts. The schema consists of three tables: project, expert, and project_review_record.
The project table contains information about each project, including its number, name, application date, and application unit. The primary key for this table is the project number, which is a unique identifier for each project.
The expert table contains information about each expert, including their number, name, unit, and title. The primary key for this table is the expert number, which is a unique identifier for each expert.
The project_review_record table contains information about each review of a project by an expert. It includes the project number, expert number, review date, and review opinion. The primary key for this table is a composite key consisting of the project number and expert number. The table also contains foreign keys referencing the project and expert tables, with ON DELETE CASCADE and ON UPDATE CASCADE rules. This means that if a project or expert is deleted, any associated reviews will also be deleted.
