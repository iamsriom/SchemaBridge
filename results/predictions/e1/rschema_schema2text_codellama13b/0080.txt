The Repair_Worker table contains information about repair workers, including their ID, name, and address. The Part table contains information about parts, including their description, inventory quantity, serial number, price, and supplier.
The Repair_Task table contains information about repair tasks, including the customer ID, task ID, task start and completion dates, task status, vehicle model, and foreign keys to the Customer and Repair_Worker tables. The Repair_Worker_Task table contains information about the repair worker assigned to a repair task, including the repair task ID and the repair worker ID.
The Part_Usage table contains information about the parts used in repair tasks, including the part serial number, repair task ID, usage quantity, and foreign keys to the Part and Repair_Task tables.
Each table has primary keys and foreign keys that enforce entity and referential integrity. The foreign keys in the Repair_Task table reference the Customer table, and the foreign keys in the Repair_Worker_Task and Part_Usage tables reference the Repair_Task and Part tables, respectively. The foreign keys have update and delete rules of CASCADE, which means that if a customer or repair task is deleted, the corresponding records in the Repair_Worker_Task and Part_Usage tables are also deleted.
The Part table has a unique constraint on the Part_Serial_Number column, which ensures that each part has a unique serial number. The Repair_Task table has a unique constraint on the Repair_Task_ID column, which ensures that each repair task has a unique ID.
