The database name is rschema_0089, and it contains three tables: Block, Account, and Transaction. The Block table has the following columns: Block_Hash (primary key, VARCHAR(255)), Height (INTEGER), Merkle_Root (VARCHAR(255)), Previous_Block_Hash (NOT NULL, VARCHAR(255)), Timestamp (DATETIME), and a foreign key referencing the Block table itself. The Account table has the following columns: Address (primary key, VARCHAR(255)), Balance (FLOAT). The Transaction table has the following columns: Block_Hash (NOT NULL, VARCHAR(255)), Fee (FLOAT), Input_Address (NOT NULL, VARCHAR(255)), Output_Address (NOT NULL, VARCHAR(255)), Timestamp (DATETIME), Transaction_Hash (primary key, VARCHAR(255)), and foreign keys referencing the Block and Account tables. The foreign keys are set to CASCADE on update and delete.
