This database schema, named "rschema_0100," contains five tables: Customer, User, Order, Quotation, and Order_Item. Each table represents a different entity in the system, with columns that define its attributes and relationships with other tables.
The Customer table contains information about customers, including their name, email, and creation and deletion dates. The User table contains information about users, including their username, email, and password, as well as creation and deletion dates.
The Order table contains information about orders, including the order number, customer ID, creation and deletion dates, and the user who created the order. The Quotation table contains information about quotations, including the quotation number, customer ID, creation and deletion dates, and the user who created the quotation.
The Order_Item table contains information about the items in an order, including the order ID, item description, quantity, unit, and unit price.
Each table has primary keys, which are used to uniquely identify each row in the table. The Customer and User tables have a primary key of Customer_ID and User_ID, respectively, while the Order, Quotation, and Order_Item tables have a primary key of Order_ID, Quotation_ID, and Order_Item_ID, respectively.
The Order and Quotation tables also have foreign keys, which reference the primary keys of the User and Customer tables. This ensures that the orders and quotations are associated with the correct users and customers.
In addition to the primary and foreign keys, the Order_Item table has a composite key of Order_ID and Order_Item_ID, which ensures that each item in an order is uniquely identified.
Overall, this schema provides a comprehensive and well-structured way to store and manage customer, user, order, quotation, and order item data in a relational database.
