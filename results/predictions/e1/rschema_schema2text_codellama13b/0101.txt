This schema is for a database that stores information about employees, departments, and their performance evaluations. The database is called "rschema_0101" and it contains five tables: employee, department, employee_department_transfer, employee_attendance, and performance_evaluation.
The employee table contains information about each employee, including their ID, name, gender, date of birth, phone number, ID number, place of origin, age, department ID, position, level, and contract type. The employee ID is the primary key for this table.
The department table contains information about each department, including its ID, name, responsibilities, department head ID, total number of people in the department, and department location. The department ID is the primary key for this table.
The employee_department_transfer table contains information about transfers between departments, including the employee ID, the department ID they are transferring into, the department ID they are transferring out of, the transfer time, and the post-transfer position. The employee ID and transfer time are the primary key for this table.
The employee_attendance table contains information about each employee's attendance, including their ID, punch-in time, punch-in type, and punch-out time. The punch-in time and employee ID are the primary key for this table.
The performance_evaluation table contains information about each employee's performance evaluation, including their ID, evaluation time, evaluation content, evaluation result, and evaluator ID. The employee ID and evaluation time are the primary key for this table.
The foreign keys in this schema are used to establish relationships between the tables. For example, the employee_department_transfer table references the employee and department tables to link each employee to their transfer information. The employee_attendance table references the employee table to link each employee to their attendance information. The performance_evaluation table references the employee and evaluator tables to link each employee to their performance evaluation information.
