The database name is rschema_0105. It is used for storing information about users, their dynamic information, and their social activities. The database has four tables: User, User_dynamic_information, Add_Contact, and Social_Activity.
The User table contains information about each user, including their account, birthday, email, gender, nickname, password, phone number, registration time, and user ID. The user ID is the primary key.
The User_dynamic_information table contains information about each user's dynamic information, such as the dynamic content, number of comments, number of favorites, number of likes, publisher ID, publishing time, and dynamic ID. The dynamic ID is the primary key. The publisher ID is a foreign key that references the user ID in the User table.
The Add_Contact table contains information about each user's contact list, including the time the contact was added, the added user ID, the relationship type, the remarks, and the user ID. The user ID and added user ID are the primary key. The user ID and added user ID are foreign keys that reference the user ID in the User table.
The Social_Activity table contains information about each user's social activities, such as whether the activity was a collection, the comment, the creation time, the dynamic ID, whether the activity was a like, and the user ID. The user ID and dynamic ID are the primary key. The dynamic ID is a foreign key that references the dynamic ID in the User_dynamic_information table. The user ID is a foreign key that references the user ID in the User table.
In summary, the rschema_0105 database stores information about users, their dynamic information, and their social activities. The database has four tables, each with its own set of columns and constraints. The tables are related through foreign keys, which ensure referential integrity and prevent orphaned data.
