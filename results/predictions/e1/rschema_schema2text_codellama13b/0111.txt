The database name is rschema_0111 and it is used to store information about users, companies, employees, and credit records. The database has four tables: User, Company, Employee, and Credit_Record.
The User table has the following columns: Email, Password, Phone_Number, Registration_Time, Role, Update_Time, User_ID (primary key), and Username. The Company table has the following columns: Company_Address, Company_ID (primary key), Company_Name, and Creation_Time. The Employee table has the following columns: Affiliated_Company_ID (not null), Employee_ID (primary key), Employee_Name, Employee_Position, and FOREIGN KEY (Affiliated_Company_ID) referencing Company(Company_ID). The Credit_Record table has the following columns: Application_Date, Creation_Time, Credit_Number (primary key), Credit_Status, Credit_Type, Deletion_Time, Employee_ID (not null), Monthly_Factor, Number_of_Applications, Update_Time, User_ID (not null), and FOREIGN KEY (Employee_ID) referencing Employee(Employee_ID) and FOREIGN KEY (User_ID) referencing User(User_ID).
Each table has primary keys and foreign keys to enforce entity and referential integrity. The primary keys are unique identifiers for each row in the table, while the foreign keys reference the primary keys of other tables. The foreign keys are used to establish relationships between tables and ensure data consistency.
The database also has indexes and constraints to optimize query performance and enforce data integrity. For example, the Credit_Record table has indexes on the Employee_ID and User_ID columns to improve query performance when searching for credit records by employee or user. The database also has a unique constraint on the Credit_Number column to ensure that each credit record has a unique identifier.
Overall, the database schema is designed to store and manage information about users, companies, employees, and credit records in a structured and organized manner, with clear relationships between the different tables and constraints to enforce data integrity and consistency.
