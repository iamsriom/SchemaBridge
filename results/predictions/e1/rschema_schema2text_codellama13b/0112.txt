The database schema "rschema_0112" is used to store information about a company's employees, products, orders, and customers. The schema consists of eight tables: Employee, Product, Order, Office_location, Customer, Sales_performance_record, Order_detail, and Payment_record.
The Employee table contains information about the company's employees, including their base salary, commission rate, email, employee ID, employee number, hire date, name, office phone, position, and supervisor ID. The table has a primary key on the employee ID column and a foreign key on the supervisor ID column that references the employee ID column in the same table.
The Product table contains information about the company's products, including their brand, cost price, description, inventory quantity, model, name, product ID, specification, suggested retail price, and supplier. The table has a primary key on the product ID column.
The Order table contains information about the company's orders, including the actual shipping date, notes, order ID, order date, order status, required delivery date, and special instructions. The table has a primary key on the order ID column.
The Office_location table contains information about the company's office locations, including the city, contact phone, country, fax, manager employee ID, office location ID, postal code, street address, and foreign key on the manager employee ID column that references the employee ID column in the Employee table.
The Customer table contains information about the company's customers, including their city, contact person name, contact person phone, contact person position, country, credit limit, customer ID, customer company name, dedicated sales rep employee ID, postal code, state/province, street, and foreign key on the dedicated sales rep employee ID column that references the employee ID column in the Employee table.
The Sales_performance_record table contains information about the company's sales performance, including the record ID, sales person ID, total sales, and year. The table has a primary key on the record ID column and a foreign key on the sales person ID column that references the employee ID column in the Employee table.
The Order_detail table contains information about the company's order details, including the line number, order ID, product ID, quantity, and unit price. The table has a primary key on the order ID and product ID columns and foreign keys on the order ID column that references the order ID column in the Order table and the product ID column that references the product ID column in the Product table.
The Payment_record table contains information about the company's payment records, including the check clearing date, check number, customer accounts receivable, invoice amount, paying customer ID, payment date, record ID, and foreign key on the paying customer ID column that references the customer ID column in the Customer table.
In summary, the schema "rschema_0112" is used to store information about a company's employees, products, orders, and customers, with each table containing relevant information about each entity. The schema includes primary keys, foreign keys, and composite keys to ensure data integrity and referential integrity.
