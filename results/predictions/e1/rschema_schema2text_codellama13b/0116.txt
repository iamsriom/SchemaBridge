The database name is rschema_0116, and it contains four tables: Customers_Table, Airlines_Table, CustomerReviews_Table, and CustomerBankAccounts_Table.
The Customers_Table contains the following columns: CustomerID (primary key), Name (VARCHAR(255)), and Phone (INTEGER).
The Airlines_Table contains the following columns: AirlineID (primary key), AirlineName (VARCHAR(255)), Route (VARCHAR(255)), and Time (DATETIME).
The CustomerReviews_Table contains the following columns: AirlineID (foreign key referencing Airlines_Table), CustomerID (foreign key referencing Customers_Table), ReviewContent (VARCHAR(255)), ReviewGrade (FLOAT), and ReviewID (primary key).
The CustomerBankAccounts_Table contains the following columns: AccountID (primary key), AccountNumber (null), Balance (null), and CustomerID (foreign key referencing Customers_Table).
The primary keys in each table are indicated by the PRIMARY KEY constraint. The foreign keys in the CustomerReviews_Table reference the primary keys in the Airlines_Table and Customers_Table, respectively. The foreign keys in the CustomerBankAccounts_Table reference the primary key in the Customers_Table. The update and delete rules for the foreign keys are CASCADE and RESTRICT, respectively.
There are no indexes or constraints in this schema.
