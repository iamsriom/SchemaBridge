The rschema_0117 database is a schema that contains three tables: user, data_record, and operation_data. The user table contains information about users, including their ID, name, password, phone number, and creation time. The data_record table contains information about data records, including their ID, name, data content, user ID of the creator, creation time, user ID of the most recent operator, and last operation time. The operation_data table contains information about data record operations, including the user ID, data record ID, operation type, operation time, remarks, and operation content. The user ID in the operation_data table is a foreign key that references the user table, and the data record ID is a foreign key that references the data_record table. The operation_data table has a composite primary key consisting of the data record ID, user ID, and operation time.
