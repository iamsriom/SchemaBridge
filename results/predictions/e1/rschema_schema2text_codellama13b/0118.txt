The database schema "rschema_0118" is used to store information about employees, their departments, and their attendance, transfers, leaves, and overtime. The schema consists of six tables: "department," "employee_attendance," "employee," "employee_transfer_department," "employee_leave," and "employee_overtime."
The "department" table contains information about each department in the company, including its location, name, responsibilities, and the person in charge. The "department_ID" column is the primary key, and the "person_in_charge_ID" column references the "employee" table. The "total_number_of_department_employees" column is a foreign key that references the "employee" table.
The "employee_attendance" table contains information about each employee's attendance, including their ID, punch time, punch type, and clock-in time. The "employee_ID" column is the primary key, and the "punch_time" column is a foreign key that references the "employee" table.
The "employee" table contains information about each employee, including their age, contact information, date of birth, department, ID, gender, name, position, salary, time of employment, and transfer-in and transfer-out departments. The "employee_ID" column is the primary key, and the "department_ID" column is a foreign key that references the "department" table. The "transfer-in_department_ID" and "transfer-out_department_ID" columns are foreign keys that reference the "department" table.
The "employee_transfer_department" table contains information about each employee's transfer between departments, including their ID, transfer time, transfer-in department, and transfer-out department. The "employee_ID" column is the primary key, and the "transfer_time" column is a foreign key that references the "employee" table. The "transfer-in_department_ID" and "transfer-out_department_ID" columns are foreign keys that reference the "department" table.
The "employee_leave" table contains information about each employee's leave, including their ID, leave time, and leave type. The "employee_ID" column is the primary key, and the "leave_time" column is a foreign key that references the "employee" table.
The "employee_overtime" table contains information about each employee's overtime, including their ID, overtime time, and overtime type. The "employee_ID" column is the primary key, and the "overtime" column is a foreign key that references the "employee" table.
In summary, the schema "rschema_0118" is used to store information about employees, their departments, and their attendance, transfers, leaves, and overtime. The schema consists of six tables, each with its own unique columns and foreign keys that reference other tables in the schema.
