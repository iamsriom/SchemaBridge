The database schema rschema_0122 is used to store information related to customer inquiries and conversations. It consists of six tables: conversation, message, inquiry, organization, security_base_record, and customer.
The conversation table stores information about each conversation, including the conversation ID, customer ID, creation time, last update time, and a foreign key reference to the security_base_record table. The message table stores information about each message in a conversation, including the message ID, conversation ID, content, send time, and status. The inquiry table stores information about each customer inquiry, including the customer ID, inquiry category, inquiry content, status, creation time, and end time. The organization table stores information about each organization, including the organization ID, organization name, phone number, avatar, location, email, description, homepage link, and image link. The security_base_record table stores encrypted information related to the organization, including the base ID, encrypted information, record creation time, and record update time. The customer table stores information about each customer, including the customer ID, name, contact information, and foreign key reference to the organization table.
Each table has its own primary key, and some tables have foreign key constraints that reference other tables. For example, the conversation table has a foreign key constraint that references the security_base_record table, and the message table has a foreign key constraint that references the conversation table. The inquiry table has a composite primary key consisting of creation time and customer ID, and the customer table has a foreign key constraint that references the organization table.
Overall, the schema is designed to store and manage customer inquiries and conversations, as well as information about the organizations and customers involved.
