The database name is rschema_0123, and it contains six tables. The first table is Customer, which has five columns: Address, Contact, Gender, ID (primary key), and Name. The second table is Supplier, which has four columns: Address, Contact, ID (primary key), and Name. The third table is Product, which has four columns: Description, ID (primary key), Inventory_Quantity, and Name. The fourth table is Staff, which has four columns: ID (primary key), Name, Phone, and Position. The fifth table is Purchase_from_Supplier, which has eight columns: Operator_ID (foreign key referencing Staff), Product_ID (foreign key referencing Product), Purchase_Product_Unit_Price, Purchase_Quantity, Purchase_Time, Supplier_ID (foreign key referencing Supplier), and a composite primary key consisting of Supplier_ID, Product_ID, and Purchase_Time. The sixth table is Sales_Product, which has eight columns: Customer_ID (foreign key referencing Customer), Operator_ID (foreign key referencing Staff), Product_ID (foreign key referencing Product), Quantity_of_Sales_Product, Sales_Time, Unit_Price_of_Sales_Product, and a composite primary key consisting of Product_ID, Customer_ID, and Sales_Time.
