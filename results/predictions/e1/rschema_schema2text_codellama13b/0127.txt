The database name is rschema_0127, and it contains three tables: User, Match, and User_Match_Record. The User table stores information about users, including their avatar, balance, gender, password, registration time, user ID, and user name. The Match table stores information about matches, including the match ID, match name, and match time. The User_Match_Record table stores information about the results of matches played by users, including the match ID, match result, user ID, and primary key (combination of user ID and match ID). The primary key in the User_Match_Record table is a composite key consisting of the user ID and match ID, and it is a unique constraint. The foreign keys in the User_Match_Record table reference the match ID and user ID columns in the Match and User tables, respectively. The update and delete rules for the foreign keys are CASCADE and RESTRICT, respectively.
