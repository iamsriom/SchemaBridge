The database name is rschema_0141 and it is used to store information about students and their identifications. The database contains two tables: Identification and Student.
The Identification table has five columns: Address, Age, Gender, Identification_Number, and Name. The Address column is a string of up to 255 characters, the Age column is an integer, the Gender column is also an integer, the Identification_Number column is a string of up to 255 characters and is the primary key, and the Name column is also a string of up to 255 characters.
The Student table has eight columns: Department, Gender, Identification_Number, Major, Name, School, Student_ID, and FOREIGN KEY (Identification_Number). The Department column is a string of up to 255 characters, the Gender column is also a string of up to 255 characters, the Identification_Number column is a string of up to 255 characters and is not null, the Major column is also a string of up to 255 characters, the Name column is also a string of up to 255 characters, the School column is also a string of up to 255 characters, the Student_ID column is an integer and is the primary key, and the FOREIGN KEY (Identification_Number) column references the Identification_Number column in the Identification table.
The Identification_Number column in the Student table is a foreign key that references the Identification_Number column in the Identification table. The update and delete rules for this foreign key are CASCADE.
The database also contains a unique constraint on the Identification_Number column in the Identification table, and a composite primary key on the Student_ID and Identification_Number columns in the Student table.
