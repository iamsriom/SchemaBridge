This schema is for a database named rschema_0151, which contains three tables: Customer, Savings_Institution, and Transaction_Record.
The Customer table has four columns: Address, Identity_Card_Number (primary key), Name, and Phone_Number. The Identity_Card_Number column is unique and cannot be null.
The Savings_Institution table has four columns: Address, Name, Phone_Number, and Savings_Institution_ID (primary key). The Savings_Institution_ID column is unique and cannot be null.
The Transaction_Record table has nine columns: Identity_Card_Number (foreign key referencing Customer), Interest_Rate, Maturity_Date, Password, Savings_Institution_ID (foreign key referencing Savings_Institution), Transaction_Amount, Transaction_Time, Type, and PRIMARY KEY (Identity_Card_Number, Savings_Institution_ID, Transaction_Time). The Identity_Card_Number and Savings_Institution_ID columns are foreign keys that reference the corresponding columns in the Customer and Savings_Institution tables, respectively. The Transaction_Time column is the primary key, which is a composite key made up of the Identity_Card_Number, Savings_Institution_ID, and Transaction_Time columns.
In summary, this schema is for a database that stores information about customers, savings institutions, and transactions between them. The Customer table contains information about customers, including their address, identity card number, name, and phone number. The Savings_Institution table contains information about savings institutions, including their address, name, phone number, and savings institution ID. The Transaction_Record table contains information about transactions between customers and savings institutions, including the identity card number of the customer, the savings institution ID, the transaction amount, the transaction time, and the type of transaction.
