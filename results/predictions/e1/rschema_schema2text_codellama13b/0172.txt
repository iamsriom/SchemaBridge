The database name is rschema_0172, and it has three tables: Patient, Medical_Record, and Alert_Record. The Patient table contains information about patients, including their name, age, contact number, and emergency contact number. The Medical_Record table contains information about medical records, including the patient's ID, record ID, record time, temperature, and blood pressure. The Alert_Record table contains information about alerts, including the alert ID, alert content, alert time, and the ID of the abnormal record. The Patient table has a primary key of Patient_ID, which is an integer. The Medical_Record table has a primary key of Record_ID, which is an integer. The Alert_Record table has a primary key of Alert_ID, which is an integer. The Medical_Record table has a foreign key of Patient_ID that references the Patient table. The Alert_Record table has a foreign key of Abnormal_Record_ID that references the Medical_Record table. The foreign keys have update and delete rules of CASCADE.
