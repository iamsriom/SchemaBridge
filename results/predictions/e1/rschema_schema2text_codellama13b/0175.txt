This schema is for a database that tracks alumni donations and their impact on various units within the university. The database is called "rschema_0175" and it contains six tables: "alumni," "donation_record," "project," "benefit_detail," "unit," and "donation_project."
The "alumni" table contains information about each alumnus, including their name, employer, job title, department, class, enrollment year, and ID number. The table has a primary key on the "alumni_id" column, which is a unique identifier for each alumnus. The "employer" column is a foreign key that references the "unit" table, which contains information about the different units within the university.
The "donation_record" table contains information about each donation made by an alumnus, including the donation amount, type, and usage. The table has a primary key on the "donation_id" column, which is a unique identifier for each donation. The "donating_alumni" column is a foreign key that references the "alumni" table, which contains information about the alumnus who made the donation.
The "project" table contains information about each donation project, including the project name, start and end time, and total donation amount. The table has a primary key on the "project_id" column, which is a unique identifier for each project.
The "benefit_detail" table contains information about the benefits provided by each donation project, including the beneficiary unit and the benefit percentage. The table has a primary key on the "donation_project_id" and "beneficiary_unit" columns, which together form a composite key. The "beneficiary_unit" column is a foreign key that references the "unit" table, which contains information about the different units within the university.
The "unit" table contains information about each unit within the university, including the unit name and address. The table has a primary key on the "unit_id" column, which is a unique identifier for each unit.
The "donation_project" table contains information about the relationship between donation projects and alumni donations. The table has a primary key on the "donation_id" column, which is a foreign key that references the "donation_record" table. The "project_id" column is a foreign key that references the "project" table.
Overall, this schema is designed to track and analyze the impact of alumni donations on various units within the university. The tables are interconnected through foreign keys, which ensure data consistency and integrity across the database.
