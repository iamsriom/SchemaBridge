This schema, named rschema_0178, is a database for a pharmacy management system. It contains seven tables, each representing a different entity or relationship in the system.
The first table, Customer, stores information about the customers of the pharmacy, including their address, agreement status, contact information, customer ID, email, name, and password. The customer ID is the primary key, and the other columns allow null values.
The second table, Medication, stores information about the medications available in the pharmacy, including the dosage, medication ID, medication name, price, and stock quantity. The medication ID is the primary key, and the other columns allow null values.
The third table, Payment_Method, stores information about the payment methods accepted by the pharmacy, including the customer ID, payment details, payment method ID, payment type, and primary key (payment method ID, customer ID). The customer ID is a foreign key that references the customer table, and the payment method ID is the primary key.
The fourth table, Prescription, stores information about the prescriptions written by doctors for customers, including the customer ID, doctor contact information, doctor hospital, doctor name, prescription ID, prescription status, submission time, and primary key (prescription ID). The customer ID is a foreign key that references the customer table, and the prescription ID is the primary key.
The fifth table, Prescription_Medication_Association, stores information about the medications prescribed for each customer, including the medication ID, prescription ID, quantity, and primary key (prescription ID, medication ID). The medication ID is a foreign key that references the medication table, and the prescription ID is a foreign key that references the prescription table.
The sixth table, Order, stores information about the orders placed by customers, including the customer ID, mailing address, order ID, order status, order time, prescription ID, total price, and primary key (order ID). The customer ID is a foreign key that references the customer table, the prescription ID is a foreign key that references the prescription table, and the order ID is the primary key.
The seventh table, Verification_Log, stores information about the verification results for each prescription, including the log ID, prescription ID, verification result, verification time, and primary key (log ID). The prescription ID is a foreign key that references the prescription table.
In summary, this schema represents a comprehensive database for a pharmacy management system, with tables for customers, medications, payment methods, prescriptions, prescription-medication associations, orders, and verification logs. Each table has its own set of columns, with primary keys and foreign keys to ensure data integrity and referential integrity.
