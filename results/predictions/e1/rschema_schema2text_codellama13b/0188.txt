The "department" table contains information about the company's departments, including their ID, name, manager, and contact information. The "employee" table contains information about the company's employees, including their ID, name, gender, phone number, job position, and department ID. The "employee_id" column is the primary key and is used to uniquely identify each employee. The "department_id" column is a foreign key that references the "department_id" column in the "department" table.
The "production_record" table contains information about the company's production records, including the product ID, producer, production time, and production quantity. The primary key is a composite key consisting of the product ID, producer, and production time. The "producer" column is a foreign key that references the "employee_id" column in the "employee" table.
The "inventory_record" table contains information about the company's inventory records, including the product ID, stock-in time, and stock quantity. The primary key is the product ID. The "product_id" column is a foreign key that references the "product_id" column in the "product" table.
The "sales_record" table contains information about the company's sales records, including the salesperson, customer, sales time, product ID, and sales quantity. The primary key is a composite key consisting of the product ID, salesperson, and sales time. The "product_id" column is a foreign key that references the "product_id" column in the "product" table, and the "salesperson" column is a foreign key that references the "employee_id" column in the "employee" table.
The "performance_evaluation" table contains information about the company's performance evaluations, including the department ID, evaluation time, and evaluation score. The primary key is a composite key consisting of the evaluation time and department ID. The "department_id" column is a foreign key that references the "department_id" column in the "department" table.
In summary, the schema is designed to store information about a company's products, departments, employees, production records, inventory records, sales records, and performance evaluations.
