This database schema, named rschema_0197, contains three tables: Personnel, Project, and Construction_Cost_Record. The Personnel table stores information about the personnel involved in the construction project, including their email, name, personnel ID, phone number, and role. The Personnel table has a primary key of Personnel_ID, which is an integer. The Personnel table also has a foreign key of Project_Manager_ID, which references the Project table.
The Project table stores information about the construction project, including the project ID, project name, project location, and project manager ID. The Project table has a primary key of Project_ID, which is an integer. The Project table also has a foreign key of Recording_Staff_ID, which references the Personnel table.
The Construction_Cost_Record table stores information about the construction costs, including the cost amount, expense type, project ID, record date, record ID, and recording staff ID. The Construction_Cost_Record table has a primary key of Record_ID, which is an integer. The Construction_Cost_Record table also has foreign keys of Project_ID and Recording_Staff_ID, which reference the Project and Personnel tables, respectively. The foreign keys have update and delete rules of CASCADE and RESTRICT, respectively.
In summary, this schema stores information about personnel, projects, and construction costs, with relationships between the tables established through foreign keys. The schema ensures domain integrity, entity integrity, and referential integrity through the use of primary keys, foreign keys, and constraints.
