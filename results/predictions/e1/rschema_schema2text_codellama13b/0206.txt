The database name is rschema_0206, and it contains three tables: Region, Flora_and_Fauna_Record, and Environmental_Change_Record. The Region table has four columns: Administrator, Geographical_Location, Name, and Region_ID, with Region_ID being the primary key. The Flora_and_Fauna_Record table has seven columns: Quantity, Record_ID, Record_Time, Recorder, Region_ID, Type, and FOREIGN KEY (Region_ID) REFERENCES Region(Region_ID). The Environmental_Change_Record table has eight columns: Change_ID, Change_Time, Humidity, Location, Rainfall, Region_ID, Temperature, and FOREIGN KEY (Region_ID) REFERENCES Region(Region_ID). The Region_ID column in both tables is a foreign key that references the Region table's Region_ID column.
