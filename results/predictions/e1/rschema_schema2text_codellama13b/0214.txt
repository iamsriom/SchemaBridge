The database named rschema_0214 is a schema used to store information about employees, their assessments, and their monthly assessment statistics. It contains three tables: Employee, Assessment_Record, and Employee_Monthly_Assessment_Statistics.
The Employee table has five columns: Employee_ID, Gender, Name, Phone_Number, and Position. The Employee_ID column is the primary key and is used to uniquely identify each employee. The Gender, Name, Phone_Number, and Position columns contain information about each employee.
The Assessment_Record table has five columns: Assessment_Content, Assessment_Date, Assessment_ID, Assessment_Score, and Employee_ID. The Assessment_ID column is the primary key and is used to uniquely identify each assessment. The Assessment_Content, Assessment_Date, Assessment_Score, and Employee_ID columns contain information about each assessment. The Employee_ID column is a foreign key that references the Employee table.
The Employee_Monthly_Assessment_Statistics table has three columns: Average_Score, Employee_ID, and Month. The Employee_ID column is the primary key and is used to uniquely identify each employee. The Average_Score column contains the average score for each employee in a given month. The Month column contains the date of the month for which the average score is calculated. The Employee_ID column is a foreign key that references the Employee table.
In summary, this schema stores information about employees, their assessments, and their monthly assessment statistics. It uses primary keys and foreign keys to ensure data integrity and consistency.
