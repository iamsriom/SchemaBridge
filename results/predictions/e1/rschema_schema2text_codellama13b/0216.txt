The rschema_0216 database is used to store information about credit card transactions and repayments. It contains five tables: Credit_Card_Type, Customer, Credit_Card, Transaction, and Repayment.
The Credit_Card_Type table stores information about different types of credit cards, including their annual fees, card type codes, and card type names. The table has three columns: Annual_Fee, Card_Type_Code (primary key), and Card_Type_Name.
The Customer table stores information about customers, including their contact numbers, customer IDs, ID numbers, and names. The table has four columns: Contact_Number, Customer_ID (primary key), ID_Number, and Name.
The Credit_Card table stores information about credit cards, including their account opening dates, card numbers, card types, credit limits, and customer IDs. The table has seven columns: Account_Opening_Date, Card_Number (primary key), Card_Type_Code (foreign key referencing Credit_Card_Type), Credit_Limit, Customer_ID (foreign key referencing Customer), and FOREIGN KEY (Card_Type_Code) and FOREIGN KEY (Customer_ID).
The Transaction table stores information about credit card transactions, including the card number, customer ID, transaction amount, transaction location, transaction time, and transaction type. The table has seven columns: Card_Number (foreign key referencing Credit_Card), Customer_ID (foreign key referencing Customer), Transaction_Amount, Transaction_Location, Transaction_Time, Transaction_Type, and PRIMARY KEY (Customer_ID, Card_Number, Transaction_Time).
The Repayment table stores information about credit card repayments, including the card number, customer ID, repayment amount, repayment time, and PRIMARY KEY (Customer_ID, Card_Number, Repayment_Time). The table has six columns: Card_Number (foreign key referencing Credit_Card), Customer_ID (foreign key referencing Customer), Repayment_Amount, Repayment_Time, PRIMARY KEY (Customer_ID, Card_Number, Repayment_Time), and FOREIGN KEY (Card_Number) and FOREIGN KEY (Customer_ID).
In summary, the rschema_0216 database is a relational database that stores information about credit card transactions and repayments, with five tables that are linked by foreign keys. The tables store information about credit card types, customers, credit cards, transactions, and repayments, and each table has its own set of columns with specific data types and constraints.
