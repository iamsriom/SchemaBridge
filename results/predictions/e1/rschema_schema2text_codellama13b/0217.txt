This schema is for a school management system, which includes information about courses, students, teachers, tools, and system settings. The database name is rschema_0217.
The course table contains information about the courses offered at the school, including the course ID, teacher, class hours, description, and schedule. The primary key is the course ID.
The student table contains information about the students enrolled in the courses, including the student ID, name, grade, class, and user ID. The primary key is the student ID, and there is a foreign key constraint on the user ID, which references the user table.
The user table contains information about the users of the system, including the user ID, email, password, username, and role. The primary key is the user ID.
The tool table contains information about the tools used in the school, including the name, asset number, and holder. The primary key is the asset number, and there is a foreign key constraint on the holder, which references the user table.
The tool loan record table contains information about the loans of tools by students, including the record ID, borrower, asset number, and time. The primary key is the record ID, and there are foreign key constraints on the borrower and asset number, which reference the user and tool tables, respectively.
The system settings table contains information about the system, including the system name, theme, page configuration, and version information. The primary key is the setting ID.
The course enrollment table contains information about the enrollment of students in courses, including the student ID and course ID. The primary key is the combination of student ID and course ID, and there are foreign key constraints on the student ID and course ID, which reference the student and course tables, respectively.
