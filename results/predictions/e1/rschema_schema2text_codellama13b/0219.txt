The database name is rschema_0219, and it contains five tables. The first table, Card, has the following columns: Card_Artist, Card_Effect, Card_Endurance, Card_ID (primary key), Card_Intelligence, Card_Name, Card_Power, and Card_Type. The second table, Card_Collection, has the columns Collection_ID (primary key) and Collection_Name. The third table, User, has the columns Email, Password, Phone, User_ID (primary key), and Username. The fourth table, Card_Collection_Association, has the columns Card_ID (foreign key referencing Card), Card_Rarity, Collection_ID (foreign key referencing Card_Collection), Collection_Number, and primary key (Card_ID, Collection_ID). The fifth table, User_Card_Exchange, has the columns Exchange_Time, Exchanged_Card_ID (foreign key referencing Card), User_1_ID (foreign key referencing User), User_2_ID (foreign key referencing User), and primary key (User_1_ID, User_2_ID, Exchange_Time).
