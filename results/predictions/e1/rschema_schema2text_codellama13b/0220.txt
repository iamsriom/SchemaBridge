The database name is rschema_0220, and it contains seven tables. The tables are:
1. Product: This table stores information about the products sold by the company. It has columns for the product brand, click count, image link, price, product ID (primary key), product title, and product type.
2. Address: This table stores information about the addresses of customers and the postal codes used in the database. It has columns for the city, postal code (primary key), and state.
3. Customer: This table stores information about the customers who have placed orders with the company. It has columns for the customer ID (primary key), email, name, and phone number.
4. Product_Description: This table stores information about the descriptions of the products sold by the company. It has columns for the description content, description ID (primary key), description type, and product ID (foreign key referencing the Product table).
5. Tax_Rate: This table stores information about the tax rates for different postal codes. It has columns for the postal code (foreign key referencing the Address table), tax rate, tax rate ID (primary key), and tax rate type.
6. Order: This table stores information about the orders placed by customers. It has columns for the customer ID (foreign key referencing the Customer table), order date, order ID (primary key), order price, payment method, postal code (foreign key referencing the Address table), shipping method, tax, and total price.
7. Order_Detail: This table stores information about the details of the orders placed by customers. It has columns for the detail ID (primary key), order ID (foreign key referencing the Order table), product ID (foreign key referencing the Product table), quantity, and total price.
