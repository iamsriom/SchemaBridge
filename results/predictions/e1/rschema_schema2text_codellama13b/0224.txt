This schema is for a task management system that allows users to create and manage tasks, as well as evaluate and rate other users' performance on those tasks. The schema consists of five tables: user, task, task_execution_status, user_quote, and user_evaluation.
The user table contains information about each user, including their user ID, name, avatar URL, contact information, number of failed tasks, and number of completed tasks. The user ID is the primary key for this table.
The task table contains information about each task, including its task ID, title, description, budget, deadline, category, and address. The task ID is the primary key for this table.
The task_execution_status table contains information about the progress of each task, including the task ID, task executor (the user who is working on the task), and the progress of the task. The task ID is the primary key for this table, and the task executor is a foreign key that references the user table.
The user_quote table contains information about each user's quote for a task, including the user ID, task ID, quote, and additional comments. The user ID and task ID are the primary key for this table, and the user ID is a foreign key that references the user table, while the task ID is a foreign key that references the task table.
The user_evaluation table contains information about each user's evaluation of another user's performance on a task, including the evaluation record ID, evaluator (the user who evaluated the performance), executor (the user who performed the task), and the rating given. The evaluation record ID is the primary key for this table, and the evaluator and executor are foreign keys that reference the user table.
Overall, this schema provides a comprehensive system for managing tasks and evaluating user performance, with clear relationships between the different tables and columns.
