The database name is rschema_0225 and it contains four tables: Company, User, Request_Log, and User_Feedback. The Company table has the following columns: Authorization_Token, Company_ID (primary key), Company_Name, Creation_Time, Modification_Time, and Token_Hash_Value. The User table has the following columns: Company_ID (foreign key referencing Company), Creation_Time, Modification_Time, Password_Hash_Value, Password_Salt_Value, Permission_Level, User_ID (primary key), and User_Name. The Request_Log table has the following columns: Compression_Result, Probe_Information, Request_Data, Request_ID (primary key), Status, Timestamp, and User_ID (foreign key referencing User). The User_Feedback table has the following columns: Comment, Creation_Time, Feedback_ID (primary key), Rating, and User_ID (foreign key referencing User). The primary keys for each table are indicated in parentheses. Foreign keys are indicated with the name of the table they reference. The User_ID column in the User table and the Request_ID column in the Request_Log table are foreign keys referencing the User_ID column in the User table and the User_ID column in the User_Feedback table, respectively.
