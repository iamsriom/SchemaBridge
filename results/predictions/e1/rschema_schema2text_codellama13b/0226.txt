The database name is rschema_0226, and it contains five tables: Branch, Customer, Category, Book, and Order. The Branch table has two columns: Branch_ID, which is the primary key, and Location. The Customer table has six columns: Address, Customer_ID, which is the primary key, Email, First_Name, Last_Name, and Phone. The Category table has two columns: Category_ID, which is the primary key, and Category_Name. The Book table has six columns: Book_ID, which is the primary key, Book_Name, Category_ID, Price, Stock_Quantity, and FOREIGN KEY (Category_ID) REFERENCES Category(Category_ID). The Order table has eight columns: Book_ID, Branch_ID, Customer_ID, Order_Date, Order_ID, which is the primary key, Purchase_Quantity, and FOREIGN KEY (Book_ID) REFERENCES Book(Book_ID), FOREIGN KEY (Branch_ID) REFERENCES Branch(Branch_ID), and FOREIGN KEY (Customer_ID) REFERENCES Customer(Customer_ID).
