The rschema_0231 database is used to store information about users and their experiences. It contains two tables: User and Experience.
The User table has the following columns: Email, Password, Phone_Number, Registration_Time, User_ID (primary key), and Username. The Email and Username columns are strings, while the Password and Phone_Number columns are strings. The Registration_Time column is a datetime, and the User_ID column is an integer that serves as the primary key.
The Experience table has the following columns: Code_Content, Creation_Time, Creator_ID (not null), Experience_Description, Experience_ID (primary key), Language, Modification_Time, Status. The Code_Content, Experience_Description, and Language columns are strings, while the Creation_Time, Modification_Time, and Status columns are datetimes. The Experience_ID column is an integer that serves as the primary key, and the Creator_ID column is an integer that references the User_ID column in the User table. The Creator_ID column has a foreign key constraint that references the User table and has an update rule of CASCADE and a delete rule of RESTRICT.
