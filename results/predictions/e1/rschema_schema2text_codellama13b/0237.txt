The rschema_0237 database contains six tables that represent various aspects of a real estate market. The User table stores information about users, including their email, password, user ID, and username. The Area table contains information about different areas, including their area ID and area name. The House_Type table stores information about different types of houses, including their type ID and type name. The Street table contains information about different streets, including their street ID, street name, and the area they belong to. The House table contains information about individual houses, including their house ID, description, price, type, and the street they belong to. The Lease table contains information about leases, including the description, house ID, lease date, price, and user ID. The primary keys for each table are highlighted, and foreign keys are used to establish relationships between tables. For example, the Street table has a foreign key referencing the Area table, and the House table has foreign keys referencing both the Street and House_Type tables. The Lease table has a composite primary key consisting of the user ID, house ID, and lease date.
