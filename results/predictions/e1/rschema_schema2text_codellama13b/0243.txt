The database name is rschema_0243 and it is used for storing information about a library's readers, books, and borrowing records. The database contains three tables: Reader, Book, and Borrowing.
The Reader table has the following columns: Reader_Email, Reader_ID (primary key), Reader_Name, Reader_Phone, Registration_Date, and Update_Time. The Reader_Email column is a string that represents the reader's email address, the Reader_ID column is an integer that serves as the primary key, the Reader_Name column is a string that represents the reader's name, the Reader_Phone column is a string that represents the reader's phone number, the Registration_Date column is a datetime that represents the date and time the reader registered, and the Update_Time column is a datetime that represents the last time the reader's information was updated.
The Book table has the following columns: Book_Author, Book_ID (primary key), Book_ISBN, Book_Publication_Date, Book_Stock, Book_Title, Book_Type, and Update_Time. The Book_Author column is a string that represents the book's author, the Book_ID column is an integer that serves as the primary key, the Book_ISBN column is a string that represents the book's International Standard Book Number, the Book_Publication_Date column is a datetime that represents the date and time the book was published, the Book_Stock column is an integer that represents the number of copies of the book in stock, the Book_Title column is a string that represents the book's title, the Book_Type column is a string that represents the book's type, and the Update_Time column is a datetime that represents the last time the book's information was updated.
The Borrowing table has the following columns: Book_ID (foreign key), Borrow_Date, Overdue_Fine, Reader_ID (foreign key), Renewal_Count, Return_Date, and PRIMARY KEY (Reader_ID, Book_ID, Borrow_Date). The Book_ID column is an integer that references the Book table's Book_ID column, the Borrow_Date column is a datetime that represents the date and time the book was borrowed, the Overdue_Fine column is a float that represents the fine for overdue books, the Reader_ID column is an integer that references the Reader table's Reader_ID column, the Renewal_Count column is an integer that represents the number of times the book was renewed, the Return_Date column is a datetime that represents the date and time the book was returned, and the PRIMARY KEY constraint ensures that each combination of Reader_ID, Book_ID, and Borrow_Date is unique.
The foreign key constraints ensure that the Borrowing table's Book_ID and Reader_ID columns reference the Book and Reader tables' primary keys, respectively. The update and delete rules for the foreign keys are CASCADE, which means that if a book or reader is deleted, all related borrowing records are also deleted.
