The database name is rschema_0244, and it contains five tables: user, bus_route, station, announcement, and question. The user table stores information about the users, including their account, password, name, phone number, and user role. The bus_route table stores information about the bus routes, including the route ID, route name, start station, end station, passing stations, and departure time. The station table stores information about the bus stations, including the station ID, station name, and station location. The announcement table stores information about the announcements, including the announcement ID, announcement title, announcement content, publisher, and publish time. The question table stores information about the questions, including the questioner account, question content, question time, answer content, responder account, and answer time. The primary keys for each table are account, route_id, station_id, announcement_id, and question_time. The foreign keys for the question table are responder_account and questioner_account, which reference the account column in the user table. The update and delete rules for the foreign keys are CASCADE and RESTRICT, respectively.
