The database name is rschema_0245, and it consists of five tables: User, Novel, Bookshelf, Book_review, and Novel_added_to_Bookshelf. The User table contains information about users, including their email, password, username, and creation and update times. The Novel table contains information about novels, including their title, description, author, ISBN, publication date, and creation and update times. The Bookshelf table contains information about bookshelves, including the user who created it, the novel it contains, and the time it was added. The Book_review table contains information about book reviews, including the user who wrote it, the novel it is about, the rating, and the review content. The Novel_added_to_Bookshelf table contains information about which novels have been added to which bookshelves, including the time they were added. Each table has a primary key, and there are foreign key constraints between the tables to ensure referential integrity.
