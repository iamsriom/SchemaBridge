The database schema "rschema_0250" is used to store information about users, products, orders, and order details. It contains eight tables: User, Product, Order, User_Shopping_Cart, Admin_Product_Management, Order_Product, User_Order, and Admin_Order_Management.
The User table contains information about registered users, including their username, password, phone number, registration time, and role. The User_ID column is the primary key and is used to identify each user.
The Product table contains information about the products available for purchase, including the product name, description, price, category, and shelving time. The Product_ID column is the primary key and is used to identify each product.
The Order table contains information about orders placed by users, including the delivery address, order status, order time, payment time, total amount, and user ID. The Order_ID column is the primary key and is used to identify each order.
The User_Shopping_Cart table contains information about the products added to the shopping cart by each user, including the product ID, quantity, and user ID. The primary key is a composite key consisting of the User_ID and Product_ID columns.
The Admin_Product_Management table contains information about the management of products by administrators, including the admin ID, operation time, operation type, and product ID. The primary key is a composite key consisting of the Admin_ID and Product_ID columns.
The Order_Product table contains information about the products included in each order, including the order ID, product ID, quantity, subtotal, and unit price. The primary key is a composite key consisting of the Order_ID and Product_ID columns.
The User_Order table contains information about the orders placed by each user, including the delivery address, order status, order time, payment time, total amount, and user ID. The primary key is a composite key consisting of the Order_ID and User_ID columns.
The Admin_Order_Management table contains information about the management of orders by administrators, including the admin ID, operation time, operation type, and order ID. The primary key is a composite key consisting of the Admin_ID and Order_ID columns.
Each table has foreign keys that reference the primary keys of other tables, ensuring referential integrity and maintaining the relationships between the tables. For example, the User_ID column in the Order table references the User_ID column in the User table, ensuring that each order is associated with a specific user. Similarly, the Product_ID column in the Order_Product table references the Product_ID column in the Product table, ensuring that each order includes specific products.
