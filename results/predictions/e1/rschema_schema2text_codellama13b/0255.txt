The database schema, rschema_0255, is used to store data related to a production facility. It consists of 11 tables, each representing a different entity or aspect of the production process.
The first table, production_report, stores information about production reports, including the report ID, report type, date, production data, production indicators, completion status, metal recovery rate, and grade. The primary key is the report ID.
The second table, equipment, stores information about the equipment used in the production process, including the equipment ID, equipment name, model, main category, subcategory, location, and operation status. The primary key is the equipment ID.
The third table, equipment_inspection, stores information about equipment inspections, including the equipment ID, inspector ID, inspection plan, execution progress, and any related foreign keys. The primary key is the equipment ID and inspector ID, and there are foreign key constraints on the inspector ID and equipment ID referencing the user and equipment tables.
The fourth table, equipment_failure_reporting, stores information about equipment failures, including the equipment ID, failure reporter ID, failure type, failure time, and processing status. The primary key is the equipment ID and failure reporter ID, and there are foreign key constraints on the failure reporter ID and equipment ID referencing the user and equipment tables.
The fifth table, equipment_repair, stores information about equipment repairs, including the equipment ID, repair person ID, repair progress, repair time, and any related foreign keys. The primary key is the repair ID, and there are foreign key constraints on the repair person ID and equipment ID referencing the user and equipment tables.
The sixth table, quality_report, stores information about quality reports, including the report ID, metal recovery rate, warehouse sample, metal grade, recovery rate daily report, grade daily report, and any related foreign keys. The primary key is the report ID.
The seventh table, equipment_monitoring, stores information about equipment monitoring, including the equipment ID, equipment type, collected data, status, monitoring data, fault alarm, data visualization, and administrator ID. The primary key is the equipment ID and administrator ID, and there are foreign key constraints on the administrator ID and equipment ID referencing the user and equipment tables.
The eighth table, user, stores information about users, including the user ID, username, role, permissions, status, and operation history. The primary key is the user ID.
The ninth table, announcement, stores information about announcements, including the announcement ID, announcement content, release time, publisher ID, and announcement status. The primary key is the announcement ID, and there is a foreign key constraint on the publisher ID referencing the user table.
The tenth table, job_position, stores information about job positions, including the job ID, job name, job description, job responsibilities, and job requirements. The primary key is the job ID.
The eleventh table, user_job_application, stores information about user job applications, including the user ID, job ID, job match rate, and any related foreign keys. The primary key is the job ID and user ID, and there are foreign key constraints on the job ID and user ID referencing the job position and user tables.
Overall, the schema is designed to store and manage data related to a production facility, including production reports, equipment, inspections, failures, repairs, quality reports, monitoring, users, announcements, job positions, and job applications. The schema is well-structured and organized, with clear primary and foreign key constraints, and appropriate data types for each column.
