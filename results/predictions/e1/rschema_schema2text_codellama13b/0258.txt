The database name is rschema_0258, and it contains three tables: Donor, Fundraising_Event, and Donation_Record. The Donor table has the following columns: Address, Date_of_Birth, Donor_ID (primary key), Gender, Identity_Card_Number, Name, Phone, and Type. The Fundraising_Event table has the following columns: Current_Event_Amount, Event_Address, Event_End_Time, Event_ID (primary key), Event_Name, Event_Start_Time, Event_Status, and Event_Type. The Donation_Record table has the following columns: Donation_Amount, Donation_Message, Donation_Method, Donation_Time, Donor_ID (foreign key referencing Donor.Donor_ID), Event_ID (foreign key referencing Fundraising_Event.Event_ID), and a primary key consisting of Donor_ID, Event_ID, and Donation_Time. The Donor_ID and Event_ID columns are foreign keys that reference the primary keys of the Donor and Fundraising_Event tables, respectively. The Donation_Record table also has a composite primary key consisting of Donor_ID, Event_ID, and Donation_Time.
