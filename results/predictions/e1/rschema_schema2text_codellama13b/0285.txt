The database name is rschema_0285. It is used to store information about advertisements and their viewership. The database contains three tables: Advertisement, Client, and Play_Advertisement.
The Advertisement table has four columns: Advertisement_Content, Advertisement_Duration, Advertisement_ID, and Advertisement_Name. Advertisement_Content is a string of up to 255 characters, Advertisement_Duration is a date and time, Advertisement_ID is an integer that serves as the primary key, and Advertisement_Name is a string of up to 255 characters.
The Client table has four columns: Client_Email, Client_ID, Client_Name, and Client_Phone. Client_Email is a string of up to 255 characters, Client_ID is an integer that serves as the primary key, Client_Name is a string of up to 255 characters, and Client_Phone is a string of up to 255 characters.
The Play_Advertisement table has seven columns: Advertisement_ID, Client_ID, End_Time, Play_Duration, Start_Time, Viewership_Rating, and PRIMARY KEY (Advertisement_ID, Client_ID). Advertisement_ID and Client_ID are integers that reference the Advertisement and Client tables, respectively. End_Time, Play_Duration, and Start_Time are date and time values, and Viewership_Rating is a floating-point number. The PRIMARY KEY constraint ensures that each combination of Advertisement_ID and Client_ID is unique.
The foreign key constraints ensure that the Advertisement_ID and Client_ID columns in the Play_Advertisement table reference the Advertisement and Client tables, respectively. The update and delete rules for the foreign keys are CASCADE and RESTRICT, respectively.
In summary, the rschema_0285 database stores information about advertisements and their viewership, with three tables: Advertisement, Client, and Play_Advertisement. Each table has its own set of columns, and the foreign key constraints ensure that the data is consistent and accurate.
