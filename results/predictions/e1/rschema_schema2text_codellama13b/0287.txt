The database name is rschema_0287 and it is used to store information about parks, plants, and their maintenance and growth records. The database has five tables: Park, Plant, Park_Maintenance, Park_Ecological_Record, and Plant_Growth_Record.
The Park table contains information about the parks, including the park area, park ID, park location, park name, and responsible person. The Park ID is the primary key and is used to identify each park.
The Plant table contains information about the plants, including the plant category, plant ID, and plant name. The Plant ID is the primary key and is used to identify each plant.
The Park_Maintenance table contains information about the maintenance activities performed in each park, including the maintenance content, maintenance cost, maintenance personnel, and maintenance time. The maintenance ID is the primary key and is used to identify each maintenance activity. The Park ID is a foreign key that references the Park table.
The Park_Ecological_Record table contains information about the ecological records of each park, including the park ID, record number, recorder, and recording time. The record number is the primary key and is used to identify each ecological record. The Park ID is a foreign key that references the Park table.
The Plant_Growth_Record table contains information about the growth of each plant, including the growth status, plant ID, quantity, and record number. The record number and plant ID are the primary key and are used to identify each growth record. The Plant ID is a foreign key that references the Plant table, and the Record Number is a foreign key that references the Park_Ecological_Record table.
In summary, the rschema_0287 database stores information about parks, plants, and their maintenance and growth records, with each table containing relevant information about the parks, plants, and maintenance activities. The database uses primary keys and foreign keys to ensure data integrity and consistency.
