The database name is rschema_0291 and it is used to store information about reagents, laboratories, personnel, and reagent usage records. The database has four tables: Reagent, Laboratory, Personnel, and Reagent_Usage_Record.
The Reagent table has five columns: Expiration_Date, Inventory_Quantity, Reagent_ID (primary key), Reagent_Name, and Reagent_Specifications. The Laboratory table has four columns: Laboratory_ID (primary key), Laboratory_Location, Laboratory_Name, and Laboratory_Person_in_Charge_ID. The Personnel table has six columns: Affiliated_Laboratory_ID (not null), Age, Gender, Name, Personnel_ID (primary key), and FOREIGN KEY (Affiliated_Laboratory_ID) referencing Laboratory(Laboratory_ID). The Reagent_Usage_Record table has six columns: Reagent_ID (not null), Usage_Duration, Usage_Personnel_ID (not null), Usage_Quantity, Usage_Start_Time, and PRIMARY KEY (Reagent_ID, Usage_Personnel_ID, Usage_Start_Time).
The Reagent table stores information about the reagents used in the laboratory, including their expiration date, inventory quantity, and specifications. The Laboratory table stores information about the laboratory, including its location, name, and the person in charge. The Personnel table stores information about the personnel working in the laboratory, including their age, gender, name, and affiliated laboratory. The Reagent_Usage_Record table stores information about the usage of reagents in the laboratory, including the reagent ID, usage duration, personnel ID, usage quantity, and start time.
The primary keys in the Reagent, Laboratory, and Personnel tables are Reagent_ID, Laboratory_ID, and Personnel_ID, respectively. The foreign keys in the Reagent_Usage_Record table reference the primary keys in the Reagent, Personnel, and Laboratory tables. The update and delete rules for the foreign keys are CASCADE and RESTRICT, respectively. There are no other indexes or constraints in the schema.
