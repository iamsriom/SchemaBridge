The database name is rschema_0295, and it contains three tables: Trader, Client, and Transaction. The Trader table has four columns: Contact_Number, Hire_Date, Name, and Trader_ID, which is the primary key. The Client table has six columns: Client_ID, Client_Name, Contact_Number, ID_Number, Risk_Level, and Client_ID is the primary key. The Transaction table has eight columns: Client_ID, Futures_Code, Trader_ID, Transaction_Price, Transaction_Quantity, Transaction_Time, Transaction_Type, and the primary key is a composite of Trader_ID, Client_ID, and Futures_Code. The Client_ID and Trader_ID columns are foreign keys that reference the Client and Trader tables, respectively. The Transaction table also has a foreign key constraint that references the Client table, and the update and delete rules are set to CASCADE.
