The database schema named "rschema_0300" contains four tables, each with its own unique purpose. The first table, "Material_Table," stores information about the materials used in the project. It has three columns: "Material_ID," which serves as the primary key and is used to identify each material; "Name," which contains the name of the material; and "Unit_Price," which holds the price of each material. The second table, "Project_Table," keeps track of the projects that are being worked on. It has three columns: "Close_Date," which indicates when the project was completed; "Creation_Date," which shows when the project was initiated; and "Project_ID," which serves as the primary key and identifies each project. The third table, "Bill_Table," contains information about the bills that have been generated for each project. It has six columns: "Bill_ID," which serves as the primary key and identifies each bill; "Creation_Time," which indicates when the bill was created; "Modification_Time," which shows when the bill was last modified; "Project_ID," which references the project that the bill is associated with; "Total_Sale_Amount," which holds the total amount of the sale; and "Unit," which indicates the unit of measurement for the sale. The fourth and final table, "Bill_Details_Table," contains information about the materials used in each bill. It has five columns: "Bill_ID," which references the bill that the material is associated with; "Material_ID," which references the material used in the bill; "Quantity," which indicates the quantity of the material used; "Selling_Price," which holds the price of each material; and "Primary Key," which serves as the primary key and identifies each combination of "Bill_ID" and "Material_ID."
