The database schema "rschema_0315" is used to store information about borrowers, books, and book borrowings. It consists of four tables: Borrower, Book, Book_Borrowing, and Book_Return.
The Borrower table contains information about the borrowers, including their ID, email, gender, name, and phone number. The Borrower_ID is the primary key, and the other columns are not null.
The Book table contains information about the books, including the author, book ID, category, price, publication year, publisher, and title. The Book_ID is the primary key, and the other columns are not null.
The Book_Borrowing table contains information about the borrowings, including the book ID, borrow duration, borrow quantity, borrow time, borrower ID, expected return time, and primary key (Borrower_ID, Book_ID, Borrow_Time). The Book_ID and Borrower_ID are foreign keys that reference the Book and Borrower tables, respectively. The update and delete rules for these foreign keys are CASCADE.
The Book_Return table contains information about the returns, including the book ID, borrow duration, borrower ID, is overdue return, overdue penalty amount, return quantity, and return time. The Book_ID and Borrower_ID are foreign keys that reference the Book and Borrower tables, respectively. The update and delete rules for these foreign keys are CASCADE.
In summary, the rschema_0315 database schema is used to store information about borrowers, books, and book borrowings, with each table representing a different aspect of the data. The tables are connected through foreign keys, and the schema enforces entity and referential integrity.
