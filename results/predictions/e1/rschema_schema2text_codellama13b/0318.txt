The database schema rschema_0318 contains three tables: Role, Menu, and User. The Role table has two columns: Role_ID, which is the primary key, and Role_name. The Menu table has five columns: Label, Menu_ID, which is the primary key, Parent_menu_ID, Relative_URL, and Foreign Key (Parent_menu_ID) that references the Menu_ID column in the Menu table. The User table has six columns: First_name, Last_name, Password, Role_ID, which is a foreign key that references the Role_ID column in the Role table, User_ID, which is the primary key, and Username.
