The Customer table has two columns: Customer_ID, which is an integer that serves as the primary key, and Name, which is a string of up to 255 characters. The Sales_record table has seven columns: Customer_ID, which is an integer that references the Customer table, Sales_amount, which is a floating-point number, Sales_date, which is a date and time, Salesperson_ID, which is an integer that references the Salesperson table, Transaction_quantity, which is an integer, and Visit_count, which is also an integer. The primary key for the Sales_record table is a composite of Salesperson_ID, Customer_ID, and Sales_date. The Sales_record table also has two foreign keys: one referencing the Customer table and one referencing the Salesperson table. The foreign keys are set to cascade on update and delete.
