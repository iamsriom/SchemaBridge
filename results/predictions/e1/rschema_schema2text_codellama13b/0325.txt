The Class table has two columns: Class_ID, which is an integer primary key, and Class_Name, which is a string with a maximum length of 255 characters. The Character table has six columns: Character_ID, which is an integer primary key, Character_Name, which is a string with a maximum length of 255 characters, Class_ID, which is an integer that references the Class table, Rarity_ID, which is an integer, Star_Level, which is a string with a maximum length of 255 characters, and a foreign key constraint that references the Class table.
