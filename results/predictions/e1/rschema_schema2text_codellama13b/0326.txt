The database schema, rschema_0326, is used to store information about users, tasks, and task files. The schema consists of three tables: User, Task, and Task_File.
The User table contains information about each user, including their avatar file, date of birth, full name, password, user ID, and user name. The User_ID column is the primary key, and the User_Name column is unique.
The Task table contains information about each task, including the assignee's user ID, completion date, creation date, creator's user ID, task ID, task name, task priority, task remarks, and task status. The Task_ID column is the primary key, and the Creator_User_ID and Assignee_User_ID columns are foreign keys that reference the User table.
The Task_File table contains information about each task file, including the file name, task file ID, and task ID. The Task_File_ID column is the primary key, and the Task_ID column is a foreign key that references the Task table.
The schema also includes foreign key constraints that enforce referential integrity, ensuring that the values in the foreign key columns match the values in the referenced columns in the parent table. For example, the Assignee_User_ID and Creator_User_ID columns in the Task table are foreign keys that reference the User_ID column in the User table.
In summary, the rschema_0326 database schema is used to store information about users, tasks, and task files, with each table containing relevant information about each entity. The schema includes primary keys, foreign keys, and other constraints to ensure data integrity and consistency.
