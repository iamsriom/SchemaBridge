The database schema "rschema_0328" is used to store information about a survey system. It consists of six tables: Administrator, Survey, Question, Option, Text_answer_record, and Choice_answer_record.
The Administrator table contains information about the users who have access to the survey system, including their account names, IDs, names, passwords, and phone numbers. The Administrator_ID column is the primary key.
The Survey table contains information about the surveys themselves, including their access restrictions, access rules, anonymity, background image URLs, descriptions, start and end times, survey statuses, survey titles, and survey logos. The Survey_ID column is the primary key.
The Question table contains information about the questions in the surveys, including their descriptions, display orders, display styles, evaluation scores, for evaluations, question IDs, question titles, question types, required statuses, and validation types. The Question_ID column is the primary key.
The Option table contains information about the options for each question, including their display orders, correct answer statuses, option IDs, option contents, and question IDs. The Option_ID column is the primary key.
The Text_answer_record table contains information about the answers given by respondents to text questions, including their answer contents, question IDs, respondent information, submission times, and answer IDs. The Answer_ID column is the primary key.
The Choice_answer_record table contains information about the answers given by respondents to choice questions, including their answer types, option IDs, respondent information, submission times, and answer IDs. The Answer_ID column is the primary key.
The foreign key constraints ensure that the data in the tables is consistent and accurate, and that the relationships between the tables are properly maintained. For example, the foreign key constraint in the Question table ensures that the Survey_ID column in the Question table references a valid Survey_ID in the Survey table. Similarly, the foreign key constraint in the Option table ensures that the Question_ID column in the Option table references a valid Question_ID in the Question table.
