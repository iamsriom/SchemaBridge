The database name is rschema_0331. It is used to store information about players, matches, and battles in a video game. The database has four tables: Player, Match_Information, Match_Result, and Battle.
The Player table has the following columns: Contact_Information, Gender, Nickname, Player_ID (primary key), Registration_Time. The Player_ID column is a foreign key that references the Player table.
The Match_Information table has the following columns: End_Time, Match_ID (primary key), Name, Start_Time, Total_Participants, Type. The Match_ID column is a foreign key that references the Match_Information table.
The Match_Result table has the following columns: Match_ID, Player_ID, Ranking, Total_Score. The primary key is a composite key consisting of Player_ID and Match_ID.
The Battle table has the following columns: Battle_Duration, Match_End_Time, Match_ID (primary key), Match_Start_Time, Player_1_ID, Player_2_ID, Result. The primary key is a composite key consisting of Match_ID, Player_1_ID, Player_2_ID, and Match_Start_Time. The Match_ID column is a foreign key that references the Match_Information table, and the Player_1_ID and Player_2_ID columns are foreign keys that reference the Player table.
