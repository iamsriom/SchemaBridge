The database name is rschema_0341 and it contains three tables: Anonymous_Comment, User_Information, and Normal_Comment. The Anonymous_Comment table has five columns: Comment_Content, Comment_ID (primary key), Contact_URL, Publication_Time, and Storage_Format. The Comment_Content column is a string with a maximum length of 255 characters, the Comment_ID column is an integer that serves as the primary key, the Contact_URL column is a string with a maximum length of 255 characters, the Publication_Time column is a datetime, and the Storage_Format column is a string with a maximum length of 255 characters. The User_Information table has four columns: Address, Contact_Information, Name, and User_ID (primary key). The Address column is a string with a maximum length of 255 characters, the Contact_Information column is a string with a maximum length of 255 characters, the Name column is a string with a maximum length of 255 characters, and the User_ID column is an integer that serves as the primary key. The Normal_Comment table has five columns: Comment_Content, Comment_ID (primary key), Publication_Time, Storage_Format, and User_ID (foreign key). The Comment_Content column is a string with a maximum length of 255 characters, the Comment_ID column is an integer that serves as the primary key, the Publication_Time column is a datetime, the Storage_Format column is a string with a maximum length of 255 characters, and the User_ID column is an integer that references the User_Information table's User_ID column. The foreign key constraint is set up so that when a row is deleted from the User_Information table, all the related rows in the Normal_Comment table are also deleted.
