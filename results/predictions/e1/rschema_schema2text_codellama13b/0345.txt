The database schema "rschema_0345" contains eight tables that represent various aspects of a university course catalog. The tables are:
1. Subject: This table contains information about the courses offered at the university, including the subject code, subject name, and the number of credits required to complete the course. The subject code is the primary key.
2. Professor: This table contains information about the professors who teach courses at the university, including their name, email, and professor ID. The professor ID is the primary key.
3. Student: This table contains information about the students enrolled in courses at the university, including their name, email, date of birth, average grade, and the number of credits completed. The student ID is the primary key.
4. Subject_Equivalence: This table contains information about the equivalent subjects offered at the university. Each row represents a subject that is equivalent to another subject, and the primary key is a combination of the subject code and the equivalent subject code.
5. Subject_Prerequisites: This table contains information about the prerequisites for a course. Each row represents a prerequisite for a course, and the primary key is a combination of the prerequisite subject and the related subject.
6. Course: This table contains information about the courses offered at the university, including the course code, name, responsible professor, total credits, and the subject code. The course code is the primary key.
7. Course_Assignment: This table contains information about the assignments for a course, including the course code, semester, subject code, and the responsible professor. The primary key is a combination of the course code, subject code, and semester.
8. Student_Course_Enrollment: This table contains information about the courses enrolled by students, including the course code, course grade, and the student ID. The primary key is a combination of the student ID and the course code.
The tables are related to each other through foreign keys, which ensure referential integrity and prevent orphaned records. For example, the Course table references the Subject table through the subject code, and the Student_Course_Enrollment table references the Course table through the course code. The foreign keys also specify the update and delete rules, such as CASCADE or RESTRICT, which determine what happens to the related records when a record is updated or deleted.
Overall, the schema provides a comprehensive view of the university course catalog, including the courses offered, the professors who teach them, the students enrolled, and the prerequisites and equivalents for each course.
