The database named "rschema_0347" contains 12 tables that store information about machine learning models, their performance, and the data they were trained on. The tables are:
1. "leaderboard_metadata" stores information about the runs of the models, including the run ID, the model execution time, the start and end times, the run time, the run path, the maximum number of models, the model species, and the primary key, which is the run ID.
2. "leaderboard" stores information about the models themselves, including the model ID, the model name, the root mean squared error (RMSE), the mean squared error (MSE), the mean absolute error (MAE), the root mean squared logarithmic error (RMSLE), and the presence of a stacked ensembled best of family, and the primary key, which is the model ID.
3. "model_map" stores information about the types of models, including the model type ID and the model type name, and the primary key, which is the model type ID.
4. "dataset_variable_details" stores information about the variables in the datasets, including the variable ID, the name of the variable, the data type of the variable, the number of unique values in each column, the number of null values in each column, and the dataset ID, and the primary key, which is the variable ID, and the foreign key, which is the dataset ID.
5. "tags" stores information about the tags associated with the models, including the tag ID and the tag name, and the primary key, which is the tag ID.
6. "hyperparameter_value" stores information about the hyperparameters of the models, including the model ID, the hyperparameter ID, and the value of the hyperparameter, and the primary key, which is the hyperparameter ID and the model ID, and the foreign key, which is the hyperparameter ID and the model ID.
7. "model_run" stores information about the runs of the models, including the run ID and the model ID, and the primary key, which is the run ID and the model ID, and the foreign key, which is the model ID and the run ID.
8. "data_map" stores information about the datasets used in the runs, including the dataset ID and the run ID, and the primary key, which is the run ID and the dataset ID, and the foreign key, which is the dataset ID and the run ID.
9. "hyperparameter_def_values" stores information about the default values of the hyperparameters of the models, including the model type ID, the hyperparameter ID, and the default value, and the primary key, which is the model type ID and the hyperparameter ID, and the foreign key, which is the hyperparameter ID and the model type ID.
10. "id_map" stores information about the mapping of model IDs to model types, including the model ID and the model type ID, and the primary key, which is the model ID, and the foreign key, which is the model ID and the model type ID.
11. "hyperparameter" stores information about the hyperparameters of the models, including the hyperparameter ID and the name of the hyperparameter, and the primary key, which is the hyperparameter ID.
12. "dataset_metadata" stores information about the datasets, including the dataset ID, the name of the dataset, the dataset owner, the license, the visibility, the URL, the date created, the last updated, the data size, the number of rows, and the number of columns, and the primary key, which is the dataset ID.
The schema is designed to store information about machine learning models, their performance, and the data they were trained on. The tables are interconnected through foreign keys, which ensure referential integrity and prevent orphaned data. The schema is organized in a way that allows for efficient querying and analysis of the data.
