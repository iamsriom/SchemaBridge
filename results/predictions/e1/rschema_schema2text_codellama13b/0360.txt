The database schema "rschema_0360" is used to store information about system logs, operators, and operations. It contains three tables: "Log", "Operator", and "Operation_Log".
The "Log" table stores information about system logs, including the category, content, creation time, deletion time, ID, last modified time, and level. The ID column is the primary key, and the other columns are not nullable.
The "Operator" table stores information about operators, including the account, contact information, ID, and password. The ID column is the primary key, and the other columns are not nullable.
The "Operation_Log" table stores information about operations, including the execution content, log ID, operation time, operation type, and user ID. The primary key is a composite of the log ID, user ID, and operation time, and the foreign keys reference the "Log" and "Operator" tables. The update and delete rules for the foreign keys are set to CASCADE.
