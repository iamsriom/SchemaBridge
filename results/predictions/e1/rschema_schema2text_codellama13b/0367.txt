This schema, named rschema_0367, is used to store information about users, medical institutions, and operators. The user table contains information about each user, including their name, email, phone number, birth date, gender, password, address, insurance status, and a unique identifier. The medical institution table contains information about each medical institution, including its name, address, opening and closing times, and a unique identifier. The operator table contains information about each operator, including their username, password, and a unique identifier. The user table has a primary key on the user_id column, and the medical institution and operator tables have primary keys on their respective unique identifiers. The medical institution table has a foreign key on the operator_id column that references the operator table, and the operator table has a foreign key on the affiliated_institution_id column that references the medical institution table. The foreign key relationships are set to cascade on update and delete, meaning that if a user or medical institution is deleted, any associated operators or medical institutions will also be deleted.
