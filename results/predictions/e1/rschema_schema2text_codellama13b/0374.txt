The database name is rschema_0374, and it contains eight tables. The tables are:
1. Role: This table stores information about the roles that users can have in the organization. Each row represents a role, and the columns include the role name, role ID, and operation permissions. The role ID is the primary key.
2. Supervisory department: This table stores information about the supervisory departments in the organization. Each row represents a department, and the columns include the department ID, department name, and responsibility description. The department ID is the primary key.
3. Resource: This table stores information about the resources that can be acquired by users. Each row represents a resource, and the columns include the resource name, resource code, and storage location. The resource code is the primary key.
4. Approval document: This table stores information about the approval documents that need to be submitted for resource acquisition. Each row represents an approval document, and the columns include the document ID, document name, and document content. The document ID is the primary key.
5. User: This table stores information about the users in the organization. Each row represents a user, and the columns include the user ID, username, email, password, and role ID. The user ID is the primary key.
6. Work unit: This table stores information about the work units in the organization. Each row represents a work unit, and the columns include the work unit ID, work unit name, responsibility description, and supervisory department ID. The work unit ID is the primary key.
7. Operation: This table stores information about the operations that users can perform in the organization. Each row represents an operation, and the columns include the operation ID, operation content, operation time, and operating user ID. The operation ID is the primary key.
8. Resource transaction record: This table stores information about the resource transactions that have been made in the organization. Each row represents a resource transaction, and the columns include the record ID, resource acquisition value, resource code, storage location, receiver user ID, and work unit ID. The record ID is the primary key.
The tables are related to each other through foreign keys. For example, the user table has a foreign key to the role table, and the work unit table has a foreign key to the supervisory department table. The resource transaction record table has foreign keys to the resource table, user table, and work unit table. The foreign keys ensure that the data in the tables is consistent and accurate.
