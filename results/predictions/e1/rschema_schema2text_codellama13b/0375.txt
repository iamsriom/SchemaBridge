The database name is rschema_0375 and it contains seven tables. The first table is called Device and it has the following columns: Device_Status, ID (primary key), IP_Address, Installation_Location, Installation_Time, Name, and Type. The second table is called User and it has the following columns: ID (primary key), User_Account, and User_Password. The third table is called Staff and it has the following columns: Contact_Information, ID (primary key), and Name. The fourth table is called Network_Traffic and it has the following columns: Device_ID (foreign key referencing Device), Download_Traffic, Timestamp, Total_Traffic, Traffic_Status, Upload_Traffic, and a composite primary key (Device_ID, Timestamp). The fifth table is called Device_Failure_Record and it has the following columns: Device_ID (foreign key referencing Device), Failure_Description, Failure_Occurrence_Time, Failure_Type, Handling_Status, Remarks, and a composite primary key (Device_ID, Failure_Occurrence_Time). The sixth table is called User_Connection_Device and it has the following columns: Connection_Time, Device_ID (foreign key referencing Device), Disconnection_Time, Used_Bandwidth, User_ID (foreign key referencing User), User_IP, and a composite primary key (User_ID, Device_ID, Connection_Time). The seventh table is called Device_Maintenance_Record and it has the following columns: Device_ID (foreign key referencing Device), Maintenance_Content, Maintenance_Result, Maintenance_Time, Remarks, Staff_ID (foreign key referencing Staff), and a composite primary key (Device_ID, Staff_ID, Maintenance_Time).
