The database name is rschema_0378, and it contains five tables. The first table is User, which stores information about the users of the system. It has three columns: Email_Address, Name, and User_ID, which is the primary key. The second table is Article, which stores information about the articles published on the system. It has seven columns: Article_ID, Author_ID, Body_Content, Creation_Time, Summary, Title, and Foreign Key (Author_ID) that references the User table. The third table is Comment, which stores information about the comments left on articles. It has five columns: Article_ID, Comment_Content, Creation_Time, User_ID, and Primary Key (User_ID, Article_ID, Creation_Time). The fourth table is Operation_Record, which stores information about the operations performed on articles. It has three columns: Article_ID, Operation_Type, and Timestamp, and the primary key is (Article_ID, Timestamp). The fifth table is User_Manage_Article, which stores information about the articles managed by users. It has three columns: Article_ID, User_ID, and Primary Key (User_ID, Article_ID).
