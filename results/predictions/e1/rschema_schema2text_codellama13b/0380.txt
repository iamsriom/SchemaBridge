The database name is rschema_0380 and it contains four tables: Customer, Airline, Flight, and Flight_Reservation. The Customer table has four columns: Customer_ID (primary key), Email, Name, and Phone. The Airline table has four columns: Airline_ID (primary key), Address, Name, and Phone. The Flight table has six columns: Airline_ID (foreign key referencing Airline), Arrival_Time, Departure_Location, Departure_Time, Destination, and Flight_ID (primary key). The Flight_Reservation table has five columns: Customer_ID (foreign key referencing Customer), Flight_ID (foreign key referencing Flight), Number_of_Tickets, Reservation_Time, and a composite primary key consisting of Customer_ID, Flight_ID, and Reservation_Time. The foreign keys in the Flight_Reservation table reference the primary keys in the Customer and Flight tables.
