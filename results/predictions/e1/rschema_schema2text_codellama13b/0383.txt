The database name is rschema_0383, and it contains four tables: Student, Professor, Course, and Course_Registration. The Student table has columns for address, date of birth, department ID, enrollment year, name, and student ID, with the student ID being the primary key. The Professor table has columns for name, office duration, office number, office start time, and professor ID, with the professor ID being the primary key. The Course table has columns for class day, course duration, course ID, name, semester, teaching professor ID, year, and foreign key referencing the Professor table. The Course_Registration table has columns for course ID, grade, registration time, student ID, and primary key consisting of student ID, course ID, and registration time, with foreign keys referencing the Course and Student tables.
