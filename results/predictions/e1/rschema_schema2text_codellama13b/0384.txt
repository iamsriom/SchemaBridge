The database named rschema_0384 contains six tables that store information about tasks, parameters, organisms, and their relationships. The Task table contains information about each task, including the algorithm used, the creation and end dates, the executable file, options, query statement, status reason, task ID, task owner, task status, and task title. The Parameter table contains information about each parameter, including the parameter ID and parameter name. The Organism table contains information about each organism, including the organism ID and organism name. The Task_Parameter table contains information about the parameters associated with each task, including the parameter ID, parameter value, and task ID. The Task_Related_Organism table contains information about the organisms related to each task, including the creation time, organism ID, and task ID. The Task_Excluded_Organism table contains information about the organisms excluded from each task, including the creation time, organism ID, and task ID. The foreign keys in the Task_Parameter, Task_Related_Organism, and Task_Excluded_Organism tables reference the primary keys in the Task, Parameter, and Organism tables, respectively. The primary keys in the Task_Parameter, Task_Related_Organism, and Task_Excluded_Organism tables are composite keys consisting of the task ID, parameter ID, and parameter value, respectively. The foreign keys in the Task_Related_Organism and Task_Excluded_Organism tables have update and delete rules of CASCADE, which means that if a task or organism is deleted, the related records in the Task_Related_Organism or Task_Excluded_Organism tables will also be deleted.
