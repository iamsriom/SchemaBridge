The database name is rschema_0386 and it contains three tables: User, Block, and Transaction_Record. The User table has five columns: Address, Creation_Time, ID (primary key), Public_Key, and Username. The Block table has five columns: Block_Hash, Block_ID (primary key), Block_Size, Creation_Time, and Previous_Block_ID. The Transaction_Record table has eight columns: Block_ID (foreign key referencing Block), Operation_Content, Operation_Type, Receiver_ID (foreign key referencing User), Sender_ID (foreign key referencing User), Transaction_Amount, Transaction_Time, and a composite primary key consisting of Sender_ID, Receiver_ID, Transaction_Time, and Block_ID. The foreign keys in the Transaction_Record table reference the primary keys in the Block and User tables, and the update and delete rules for these foreign keys are CASCADE and RESTRICT, respectively.
