1. Supplier_Table: This table stores information about suppliers, including their ID, information, relationship management, and update time. The primary key is Supplier_ID, and the columns are Creation_Time, Supplier_ID, Supplier_Information, Supplier_Relationship_Management, and Update_Time.
2. Project_Table: This table stores information about projects, including their ID, information, progress management, and update time. The primary key is Project_ID, and the columns are Creation_Time, Project_ID, Project_Information, Project_Progress_Management, and Update_Time.
3. Salary_Table: This table stores information about salaries, including their calculation, distribution, ID, and update time. The primary key is Salary_ID, and the columns are Creation_Time, Salary_Calculation, Salary_Distribution, Salary_ID, and Update_Time.
4. Supplier_Supply_Project: This table stores information about the relationship between suppliers and projects, including the supplier ID and project ID. The primary key is a composite key of Supplier_ID and Project_ID, and the columns are Project_ID, Supplier_ID, and Update_Time.
5. Employee_Table: This table stores information about employees, including their ID, information, performance evaluation, position allocation, salary ID, and update time. The primary key is Employee_ID, and the columns are Creation_Time, Employee_ID, Employee_Information, Performance_Evaluation, Position_Allocation, Salary_ID, Update_Time.
6. Attendance_Record_Table: This table stores information about attendance records, including the attendance ID, record, creation time, employee ID, employee punch-in time, update time, and employee ID. The primary key is Attendance_ID, and the columns are Attendance_ID, Attendance_Record, Creation_Time, Employee_ID, Employee_Punch_In, Update_Time.
7. Employee_Project_Allocation: This table stores information about the allocation of employees to projects, including the employee ID and project ID. The primary key is a composite key of Employee_ID and Project_ID, and the columns are Employee_ID, Project_ID, and Update_Time.
Each table has its own set of columns, and some of the columns are foreign keys that reference other tables. For example, the Supplier_Supply_Project table has foreign keys to the Supplier_Table and Project_Table, while the Employee_Table has a foreign key to the Salary_Table.
