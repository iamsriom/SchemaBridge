The database name is rschema_0394, and it contains four tables: User, Administrator, Menu, and Order. The User table has the following columns: Address, Last_Login_Time, Password, Phone_Number, Registration_Time, User_ID (primary key), and Username. The Administrator table has the following columns: Administrator_ID (primary key), Administrator_Name, Last_Login_Time, Login_IP, Password. The Menu table has the following columns: Description, Dish_Name, Image, Menu_ID (primary key), and Price. The Order table has the following columns: Creation_Time, Menu_ID (not null), Order_Amount, Order_Modification_Time, Order_Status, Remarks, User_ID (not null), and a composite primary key consisting of User_ID, Menu_ID, and Creation_Time. The Order table also has foreign keys to the Menu and User tables, with update and delete rules of CASCADE and RESTRICT, respectively.
