The database name is rschema_0401, and it contains four tables: students, classes, departments, and teachers. The students table has the following columns: student_id, name, gender, grade, department, home_address, date_of_birth, and enrollment_time. The student_id column is the primary key, and the department column has a foreign key constraint that references the departments table. The classes table has the following columns: class_id, class_name, grade, major, head_teacher, department_id, and class_monitor. The class_id column is the primary key, and the head_teacher and class_monitor columns have foreign key constraints that reference the teachers and students tables, respectively. The departments table has the following columns: department_id, department_name, department_size, and subordinate_majors. The department_id column is the primary key. The teachers table has the following columns: teacher_id, name, gender, grade, department, home_address, date_of_birth, and entry_time. The teacher_id column is the primary key, and the department column has a foreign key constraint that references the departments table.
