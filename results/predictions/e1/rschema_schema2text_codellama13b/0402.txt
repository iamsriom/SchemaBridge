The database schema named rschema_0402 is used to store information about a hospital. It has nine tables, each representing a different entity or relationship in the hospital.
The first table, Department, stores information about the different departments in the hospital, including their address, department ID, department name, department phone number, and staff. The Department_Address column is a string that represents the physical address of the department, while the Department_ID column is an integer that serves as the primary key for the table. The Department_Name column is a string that represents the name of the department, and the Department_Phone column is an integer that represents the phone number of the department. The Staff column is a string that represents the names of the staff members working in the department.
The second table, Patient, stores information about the patients who visit the hospital. The table has columns for the patient's age, contact information, diagnosis description, gender, name, patient ID, and visit date. The Age column is an integer that represents the patient's age, while the Contact_Information column is a string that represents the patient's contact information. The Diagnosis_Description column is a string that represents the patient's diagnosis, and the Gender column is a string that represents the patient's gender. The Name column is a string that represents the patient's name, and the Patient_ID column is an integer that serves as the primary key for the table. The Visit_Date column is a datetime that represents the date and time of the patient's visit.
The third table, Ward, stores information about the wards in the hospital. The table has columns for the number of beds in the ward, ward level, and ward number. The Number_of_Beds column is an integer that represents the number of beds in the ward, while the Ward_Level column is a string that represents the level of the ward. The Ward_Number column is an integer that serves as the primary key for the table.
The fourth table, Registration_Category, stores information about the different categories of patients who can be registered in the hospital. The table has columns for the category ID and category name. The Category_ID column is an integer that serves as the primary key for the table, while the Category_Name column is a string that represents the name of the category.
The fifth table, Medicine, stores information about the medicines that are used in the hospital. The table has columns for the medicine barcode, medicine ID, medicine name, price, and quantity. The Barcode column is a string that represents the barcode of the medicine, while the Medicine_ID column is an integer that serves as the primary key for the table. The Name column is a string that represents the name of the medicine, and the Price column is a float that represents the price of the medicine. The Quantity column is an integer that represents the quantity of the medicine.
The sixth table, Prescription, stores information about the prescriptions that are written for patients in the hospital. The table has columns for the medicine information and prescription ID. The Medicine_Information column is a string that represents the information about the medicine, while the Prescription_ID column is an integer that serves as the primary key for the table.
The seventh table, Doctor, stores information about the doctors who work in the hospital. The table has columns for the date of birth, doctor ID, gender, name, title, work certificate, and years of employment. The Date_of_Birth column is a datetime that represents the date of birth of the doctor, while the Doctor_ID column is an integer that serves as the primary key for the table. The Gender column is a string that represents the gender of the doctor, and the Name column is a string that represents the name of the doctor. The Title column is a string that represents the title of the doctor, and the Work_Certificate column is a string that represents the work certificate of the doctor. The Years_of_Employment column is an integer that represents the number of years the doctor has been employed in the hospital.
The eighth table, Treatment, stores information about the treatments that are provided to patients in the hospital. The table has columns for the case number, patient ID, treatment content, and foreign key to the Patient table. The Case_Number column is an integer that serves as the primary key for the table, while the Patient_ID column is an integer that references the Patient table. The Treatment_Content column is a string that represents the content of the treatment, and the Foreign key to the Patient table is used to link the Treatment table to the Patient table.
The ninth table, Prescription_Medicine, stores information about the medicines that are prescribed to patients in the hospital. The table has columns for the medicine ID, prescription ID, quantity, and foreign keys to the Medicine and Prescription tables. The Medicine_ID column is an integer that references the Medicine table, while the Prescription_ID column is an integer that references the Prescription table. The Quantity column is an integer that represents the quantity of the medicine, and the Foreign keys to the Medicine and Prescription tables are used to link the Prescription_Medicine table to the Medicine and Prescription tables.
In summary, the rschema_0402 database schema is used to store information about a hospital, including information about departments, patients, wards, registration categories, medicines, prescriptions, doctors, treatments, and prescription medicines.
