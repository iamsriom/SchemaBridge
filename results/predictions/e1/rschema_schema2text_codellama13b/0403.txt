The rschema_0403 database is a collection of six tables that store information about students, administrators, books, and the borrowing and returning of books. The tables are:
1. Student: This table contains information about students, including their contact number, email, grade, major, name, student ID, and student number. The student ID is the primary key, and the student number is unique.
2. Administrator: This table contains information about administrators, including their administrator ID, contact number, email, job number, name, and position. The administrator ID is the primary key.
3. Book: This table contains information about books, including the author, book ID, borrowed quantity, category, publication date, publisher, stock quantity, and title. The book ID is the primary key.
4. Student_Borrow_Book: This table contains information about the borrowing of books by students, including the borrow date, borrowed book ID, return date, review status, and student ID. The primary key is the combination of student ID and borrowed book ID.
5. Student_Return_Book: This table contains information about the returning of books by students, including the book ID, return date, returned book ID, review status, and student ID. The primary key is the combination of student ID and returned book ID.
6. Administrator_Audit: This table contains information about the auditing of books by administrators, including the administrator ID, audit date, audit result, book ID, borrowing status, and review status. The primary key is the combination of administrator ID and book ID.
The tables are related to each other through foreign keys, which ensure referential integrity and prevent orphaned records. For example, the Student_Borrow_Book and Student_Return_Book tables have foreign keys that reference the Book table, ensuring that the book IDs in those tables are valid. Similarly, the Administrator_Audit table has foreign keys that reference the Book and Student tables, ensuring that the book IDs and student IDs in that table are valid.
