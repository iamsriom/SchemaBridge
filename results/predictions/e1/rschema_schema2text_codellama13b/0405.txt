3. Patient: This table stores information about the patients who visit the clinic. It has four columns: patient_id, name, address, and phone_number. The patient_id column is the primary key, and the other columns are not nullable.

The outpatient_id column is the primary key, and the other columns are not nullable. The doctor_number column is a foreign key that references the doctor table.
6. Patient Outpatient Consultation: This table stores information about the consultations between patients and doctors in the outpatient clinics. It has four columns: patient_number, outpatient_number, consultation_time, and consultation_content. The primary key is a composite key consisting of the patient_number, outpatient_number, and consultation_time columns. The prescription_number column is a foreign key that references the prescription table, and the patient_number column is a foreign key that references the patient table.
8. Prescription Contains Drug: This table stores information about the drugs included in each prescription. It has three columns: prescription_number, drug_number, and quantity. The primary key is a composite key consisting of the prescription_number and drug_number columns. The prescription_number column is a foreign key that references the prescription table, and the drug_number column is a foreign key that references the drug table.
