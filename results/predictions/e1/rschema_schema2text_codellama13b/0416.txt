The rschema_0416 database is used to store information about users, companies, jobs, and conversations. It contains 10 tables, each with its own set of columns and constraints.
The User table contains information about each user, including their avatar, email, nickname, password, registration time, role, and user ID. The User_ID column is the primary key and is used to uniquely identify each user.
The Company table contains information about each company, including their company address, company ID, company name, company profile, and contact information. The Company_ID column is the primary key and is used to uniquely identify each company.
The Conversation table contains information about each conversation, including the conversation ID, message content, receiver user ID, send time, and sender user ID. The Conversation_ID column is the primary key and is used to uniquely identify each conversation. The Receiver_User_ID and Sender_User_ID columns are foreign keys that reference the User table.
The Message_Board table contains information about each message, including the message content, message ID, message time, and user ID. The Message_ID column is the primary key and is used to uniquely identify each message. The User_ID column is a foreign key that references the User table.
The Job_Info table contains information about each job, including the company ID, content, education level, job category, job info ID, requirements, salary, title, and work location. The Job_Info_ID column is the primary key and is used to uniquely identify each job. The Company_ID column is a foreign key that references the Company table.
The User_and_Conversation table contains information about each conversation that a user is involved in, including the conversation ID, message content, receiver user ID, send time, and sender user ID. The Conversation_ID, Receiver_User_ID, and Sender_User_ID columns are foreign keys that reference the Conversation, User, and User tables, respectively.
The User_and_Message table contains information about each message that a user has sent, including the message content, message ID, message time, and user ID. The Message_ID and User_ID columns are foreign keys that reference the Message_Board and User tables, respectively.
The Resume_Submission table contains information about each resume submission, including the job info ID, submission time, and user ID. The Job_Info_ID and User_ID columns are foreign keys that reference the Job_Info and User tables, respectively.
The Resume_Save table contains information about each resume that a user has saved, including the job info ID, save time, and user ID. The Job_Info_ID and User_ID columns are foreign keys that reference the Job_Info and User tables, respectively.
The Company_and_Job_Info table contains information about each job that a company has posted, including the company ID, content, education level, job category, job info ID, requirements, salary, title, and work location. The Job_Info_ID and Company_ID columns are foreign keys that reference the Job_Info and Company tables, respectively.
In summary, the rschema_0416 database is used to store information about users, companies, jobs, and conversations. It contains 10 tables, each with its own set of columns and constraints, and is used to manage the relationships between these entities.
