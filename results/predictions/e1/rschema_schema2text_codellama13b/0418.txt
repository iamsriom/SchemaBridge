The database named rschema_0418 contains four tables: User, Announcement, Type, and Income_Expense_Record. The User table contains information about users, including their address, age, answer to a security question, contact information, email, gender, login name, name, password, security question, status, user ID, and user type. The Announcement table contains information about announcements, including the announcement ID, content, publication time, status, and title. The Type table contains information about types, including the type ID and type name. The Income_Expense_Record table contains information about income and expense records, including the amount, record ID, record name, remark, status, time, type ID, and user ID. The Type ID and User ID columns in the Income_Expense_Record table are foreign keys that reference the Type and User tables, respectively. The foreign key constraints are set to CASCADE on update and delete, which means that if a record in the Type or User table is updated or deleted, the corresponding records in the Income_Expense_Record table will also be updated or deleted.
