The database name is rschema_0421, and it contains three tables: User, Property, and Rental_Transaction_Record.
The User table has the following columns: Account_Creation_Time, Account_Update_Time, Email, Password, Phone_Number, Role, and User_ID. The User_ID column is the primary key, and the other columns are not null.
The Property table has the following columns: Images, Owner, Property_Area, Property_Creation_Time, Property_Description, Property_ID, Property_Location, Property_Title, Property_Update_Time, Rent, Status. The Property_ID column is the primary key, and the Owner column is a foreign key that references the User_ID column in the User table.
The Rental_Transaction_Record table has the following columns: Lease_End_Date, Lease_Start_Date, Property_ID, Total_Rent, Transaction_Creation_Time, Transaction_Status, Transaction_Update_Time, User_ID. The primary key is a composite key consisting of User_ID, Property_ID, and Lease_Start_Date. The Property_ID column is a foreign key that references the Property_ID column in the Property table, and the User_ID column is a foreign key that references the User_ID column in the User table.
