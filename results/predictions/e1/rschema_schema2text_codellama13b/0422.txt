The database schema rschema_0422 is used to store information about users, projects, project versions, code submissions, and tasks. The schema consists of five tables: User, Project, Project_Version, Code_Submission, and Task.
The User table contains information about each user, including their email, last login time, password, phone number, registration time, role, and user ID. The User ID is the primary key for this table.
The Project table contains information about each project, including its creation time, introduction, name, project ID, project status, and responsible person ID. The Project ID is the primary key for this table.
The Project_Version table contains information about each project version, including whether it is a stable version, the project ID, release date, version description, version ID, and version name. The primary key for this table is a composite key consisting of Version ID and Project ID.
The Code_Submission table contains information about each code submission, including the code path, project ID, submission description, submission time, user ID, and primary key consisting of User ID, Project ID, and Submission Time. The foreign keys for this table are Project ID and User ID, which reference the Project and User tables, respectively.
The Task table contains information about each task, including the assigned-to user ID, end time, project ID, start time, task description, task name, task status, and primary key consisting of Project ID, Assigned-To User ID, and Start Time. The foreign keys for this table are Assigned-To User ID and Project ID, which reference the User and Project tables, respectively.
In summary, the rschema_0422 schema is used to store information about users, projects, project versions, code submissions, and tasks, with each table containing relevant information about each entity. The schema is designed to enforce entity integrity, referential integrity, and domain integrity through the use of primary keys, foreign keys, and data types.
