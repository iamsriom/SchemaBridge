The database schema "rschema_0423" is used to store information about online courses, instructors, and students. It consists of seven tables: Course, Chapter, Instructor, Student, Course_material, Instructor_teaching, and Viewing_record.
The Course table contains information about each course, including its category, description, name, difficulty level, number of lessons, recommended status, target audience, and total duration. The Course_ID column is the primary key, and the table has a foreign key reference to the Chapter table.
The Chapter table contains information about each chapter in a course, including its description, name, duration, and video URL. The Chapter_ID column is the primary key, and the table has foreign key references to the Course and Chapter tables.
The Instructor table contains information about each instructor, including their avatar, name, personal profile, professional field, and teaching experience. The Instructor_ID column is the primary key, and the table has a foreign key reference to the Instructor_teaching table.
The Student table contains information about each student, including their account status, age, avatar, contact information, gender, membership level, name, points, registration time, and student ID. The Student_ID column is the primary key, and the table has foreign key references to the Viewing_record and Instructor_teaching tables.
The Course_material table contains information about each course material, including its course ID, material ID, material URL, and material name. The Course_ID column is the primary key, and the table has a foreign key reference to the Course table.
The Instructor_teaching table contains information about each instructor's teaching performance, including their course ID, instructor ID, rating, and student feedback. The primary key is a composite of the instructor ID and course ID, and the table has foreign key references to the Course and Instructor tables.
The Viewing_record table contains information about each student's viewing record, including their chapter ID, completion status, student ID, view count, and viewing duration. The primary key is a composite of the student ID and chapter ID, and the table has foreign key references to the Chapter and Student tables.
Overall, this schema provides a comprehensive database for an online learning platform, allowing for the storage of course information, instructor information, student information, course materials, and viewing records.
