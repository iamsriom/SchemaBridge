The database schema "rschema_0424" is used to store information about users, systems, and their interactions. It consists of four tables: User, System, Login_record, and System_authorization.
The User table contains information about individual users, including their account status, email, last login time, login IP, password, phone number, user ID, and username. The User ID is the primary key, and the username is unique.
The System table contains information about systems, including their access time, approval required, callback URL, enabled status, secret key, system ID, system domain, system name, and token validity period. The system ID is the primary key.
The Login_record table contains information about user login records, including the expiration time, login IP, login time, logout time, system ID, token, user ID, validity, and primary key (user ID and system ID). The system ID and user ID are foreign keys that reference the System and User tables, respectively.
The System_authorization table contains information about system authorizations, including the authorization time, effective status, expiration time, system ID, user ID, and primary key (user ID and system ID). The system ID and user ID are foreign keys that reference the System and User tables, respectively.
In summary, the schema stores information about users, systems, and their interactions, with each table representing a different aspect of the data. The primary keys and foreign keys ensure referential integrity, while the unique constraints ensure entity integrity.
