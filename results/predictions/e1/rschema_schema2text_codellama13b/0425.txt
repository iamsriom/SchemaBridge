This database schema, named rschema_0425, is used to store information about a university dormitory and its residents. It consists of seven tables: User, Building, Announcement, Dormitory, Student, Maintenance_Record, and Application.
The User table contains information about the users of the system, including their passwords, roles, and usernames. The Role column specifies whether the user is an administrator, a dormitory supervisor, or a student. The User_ID column is the primary key for the table.
The Building table contains information about the dormitories, including their names, descriptions, locations, and types. The Building_ID column is the primary key for the table, and the Dormitory_Supervisor_ID column references the User table to specify the dormitory supervisor.
The Announcement table contains information about announcements made by the dormitory supervisor, including the title, content, and release time. The Administrator_ID column references the User table to specify the announcement author, and the Announcement_ID column is the primary key for the table.
The Dormitory table contains information about the dormitories, including their names, numbers of beds, and facilities. The Dormitory_ID column is the primary key for the table, and the Building_ID column references the Building table to specify the dormitory's building.
The Student table contains information about the students who live in the dormitories, including their names, genders, and classes. The Student_ID column is the primary key for the table, and the Dormitory_ID column references the Dormitory table to specify the student's dormitory.
The Maintenance_Record table contains information about maintenance requests made by students or dormitory supervisors, including the fault description, report time, completion time, and maintenance status. The Maintenance_ID column is the primary key for the table, and the Dormitory_ID column references the Dormitory table to specify the maintenance request's dormitory.
The Application table contains information about applications made by students, including the application type, content, application time, processing status, and processing opinion. The Application_ID column is the primary key for the table, and the Student_ID column references the Student table to specify the application's student.
In summary, this schema stores information about a university dormitory and its residents, including users, buildings, announcements, dormitories, students, maintenance requests, and applications. The schema enforces domain integrity by specifying data types for each column and ensuring that certain columns cannot be null. It also enforces entity integrity by specifying primary keys and foreign keys, and ensures referential integrity by specifying update and delete rules for foreign keys.
