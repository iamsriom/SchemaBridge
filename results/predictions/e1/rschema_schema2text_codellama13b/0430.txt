The rschema_0430 database contains six tables, each with its own unique purpose. The user table stores information about the users of the system, including their email, full name, password, and other personal details. The attraction table contains information about the attractions available for booking, including their name, details, era, region, type, and reference price. The message table stores messages sent between users, along with the time they were sent and the user who sent them. The ticket_booking table tracks the bookings made by users for specific attractions, including the attraction ID, booking date, order status, and ticket quantity. The attraction_comment table stores comments left by users about specific attractions, along with the user ID and comment content. Finally, the attraction_favorite table stores information about which attractions are favorited by users, including the attraction ID, favorite creation time, and user ID. Each table has its own set of columns, with some columns serving as primary keys, foreign keys, or unique constraints. The database is designed to ensure data integrity and referential integrity, with each table referencing other tables through foreign keys and constraints.
