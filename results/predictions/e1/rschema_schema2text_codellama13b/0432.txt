The database name is rschema_0432, and it contains five tables: student, professor, course, course_registration, and department. The student table has the following columns: student_id, name, address, enrollment_year, date_of_birth, and belonging_department. The professor table has the following columns: professor_id, name, office_number, office_start_time, and belonging_department. The course table has the following columns: course_id, name, semester, year, teaching_professor_id, class_day, course_duration, and course_belonging_department. The course_registration table has the following columns: student_id, course_id, registration_time. The department table has the following columns: department_id, department_name.
The student table has a primary key on the student_id column and a foreign key on the belonging_department column that references the department table. The professor table has a primary key on the professor_id column and a foreign key on the belonging_department column that references the department table. The course table has a primary key on the course_id column and foreign keys on the teaching_professor_id and course_belonging_department columns that reference the professor and department tables, respectively. The course_registration table has a primary key on the student_id, registration_time, and course_id columns and foreign keys on the student_id and course_id columns that reference the student and course tables, respectively. The department table has a primary key on the department_id column.
The schema enforces entity integrity by ensuring that each student, professor, course, and department has a unique identifier, and that each course is taught by a professor and belongs to a department. It also enforces referential integrity by ensuring that the foreign keys in the course_registration table reference the primary keys in the student and course tables.
