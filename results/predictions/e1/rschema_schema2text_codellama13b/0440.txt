The database schema "rschema_0440" contains six tables, each representing a different entity or concept. The tables are:
1. Device: This table stores information about the devices in the system, including their creation time, department, device ID, device image, device model, group, IP address, person in charge, product name, QR code, type, update time, and usage location. The device ID is the primary key, and the table has no foreign keys.
2. User: This table stores information about the users in the system, including their account status, contact information, name, role, and user ID. The user ID is the primary key, and the table has no foreign keys.
3. Device_Status: This table stores information about the status of the devices in the system, including their current status, last update time, remarks, and device ID. The device ID is the primary key, and the table has a foreign key referencing the Device table.
4. Device_Maintenance: This table stores information about the maintenance records of the devices in the system, including the device ID, maintenance content, maintenance person ID, maintenance result, maintenance time, remarks, user satisfaction, and primary key (device ID, maintenance person ID, maintenance time). The device ID and maintenance person ID are foreign keys referencing the Device and User tables, respectively.
5. Device_Repair_Request: This table stores information about the repair requests for the devices in the system, including the device ID, handling personnel, handling status, handling time, remarks, request content, request time, and requester ID. The device ID and requester ID are foreign keys referencing the Device and User tables, respectively.
6. Device_Inventory: This table stores information about the inventory of the devices in the system, including the device ID, device location, inventory person ID, and inventory time. The device ID and inventory person ID are foreign keys referencing the Device and User tables, respectively.
In summary, the schema "rschema_0440" is a comprehensive database that stores information about devices, users, device status, maintenance records, repair requests, and inventory in a relational database management system. The schema is designed to ensure data consistency and integrity across the different tables, with foreign keys and primary keys used to enforce referential and entity integrity.
