The database name is "rschema_0442" and it is used to store information about medical waste management in a hospital. The database has seven tables:
1. "medical_institution" table: This table stores information about the medical institution, including its name, address, and contact information. The table has a primary key of "medical_institution_id".
2. "department" table: This table stores information about the departments within the medical institution, including the department name, description, and the medical institution it belongs to. The table has a primary key of "department_id" and a foreign key of "medical_institution_id" that references the "medical_institution" table.
3. "medical_waste" table: This table stores information about the medical waste, including the waste type, weight, generation time, collector, collection time, traceability code, and current status. The table has a primary key of "medical_waste_id" and foreign keys of "medical_institution_id", "department_id", "collector_id", and "traceability_code_id" that reference the "medical_institution", "department", "schema_7", and "traceability_code" tables respectively.
4. "traceability_code" table: This table stores information about the traceability code, including the traceability code number, generation time, and the medical waste it belongs to. The table has a primary key of "traceability_code_id" and a foreign key of "medical_waste_id" that references the "medical_waste" table.
5. "medical_waste_inbound" table: This table stores information about the inbound medical waste, including the batch number, expected quantity, actual quantity, expected weight, actual weight, inbound time, collector, and confirmer. The table has a primary key of "medical_waste_id" and "medical_institution_id" and foreign keys of "collector_id", "confirmer_id", "medical_institution_id", and "medical_waste_id" that reference the "schema_7", "medical_institution", "medical_waste", and "medical_waste" tables respectively.
6. "medical_waste_temporary_storage_outbound" table: This table stores information about the outbound medical waste from temporary storage, including the batch number, outbound quantity, outbound weight, outbound time, transporter, and confirmer. The table has a primary key of "medical_waste_id" and "medical_institution_id" and foreign keys of "confirmer_id", "medical_institution_id", "medical_waste_id", and "transporter_id" that reference the "schema_7", "medical_institution", "medical_waste", and "schema_7" tables respectively.
7. "transport_vehicle" table: This table stores information about the transport vehicle, including the vehicle ID, transport start time, transport end time, and the receiver. The table has a primary key of "medical_waste_id" and "vehicle_id" and foreign keys of "collector_id" and "medical_waste_id" that reference the "schema_7" and "medical_waste" tables respectively.
In summary, the database stores information about medical waste management in a hospital, including medical institutions, departments, medical waste, traceability codes, inbound and outbound medical waste, transport vehicles, and personnel involved in the process. The database uses foreign keys to enforce referential integrity and ensure data consistency.
