The database schema "rschema_0445" is a comprehensive database for a security system that manages personnel, access points, and appointments. The schema consists of 13 tables, each representing a different entity or relationship in the system.
The "personnel" table stores information about the personnel, including their ID, name, type, contact information, health status, entry permission, and the ID of the unit they are affiliated with. The "unit" table stores information about the units, including their ID, name, type, and the ID of the administrator in charge.
The "health_record_entry" table stores information about the health records of the personnel, including the ID of the personnel, the ID of the record, and the time of entry and exit. The "access_personnel" table stores information about the access points that personnel have access to, including the ID of the personnel, the ID of the record, and the time of entry and exit.
The "access_point_entry" table stores information about the access points, including the ID of the access control, the ID of the record, and the time of entry and exit. The "administrator" table stores information about the administrators, including their ID, name, and management role.
The "appointment" table stores information about the appointments, including the ID, scheduled entry and exit times, status, visitor name, and the ID of the personnel being visited. The "health_record" table stores information about the health records of the personnel, including the ID of the appointment, scheduled entry and exit times, status, and the ID of the personnel.
The "access_record" table stores information about the access records, including the ID of the record, entry and exit times, the ID of the personnel, and the ID of the access control. The "access_control" table stores information about the access controls, including their ID, name, location, and status.
The "affiliation" table stores information about the affiliation between personnel and units, including the ID of the personnel and the ID of the unit. The "management" table stores information about the management of the units, including the ID of the unit and the ID of the administrator in charge.
The "visit_appointment" table stores information about the appointments that personnel visit, including the ID of the appointment and the ID of the personnel being visited.
The schema is designed to enforce entity integrity, referential integrity, and domain integrity by using primary keys, foreign keys, and constraints. The primary keys ensure that each table has a unique identifier, while the foreign keys establish relationships between tables. The constraints ensure that the data in the tables is consistent and valid.
