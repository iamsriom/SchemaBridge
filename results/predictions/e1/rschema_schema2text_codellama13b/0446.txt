This database schema, named rschema_0446, is used to store information related to an agricultural monitoring and management system. It contains nine tables, each representing a different entity or aspect of the system.
The first table, "user," stores information about the users of the system, including their usernames, passwords, phone numbers, registration times, last login times, and roles. The primary key for this table is the user ID.
The second table, "sensor," stores information about the sensors used to collect data in the system, including their IDs, data collection times, soil moisture, temperature, rainfall, light intensity, sensor location, and burial depth. The primary key for this table is the sensor ID, and it has a foreign key constraint referencing the "meteorology" table.
The third table, "meteorology," stores information about the meteorological conditions in the area where the sensors are located, including timestamps, temperatures, humidity, rainfall, wind speed, and light intensity. The primary key for this table is the meteorological ID.
The fourth table, "crop," stores information about the crops being monitored, including their IDs, names, types, and associated growth models. The primary key for this table is the crop ID, and it has foreign key constraints referencing the "meteorology" and "growth_model" tables.
The fifth table, "growth_model," stores information about the growth models used to predict crop growth, including their IDs, names, parameters, and creation times. The primary key for this table is the model ID.
The sixth table, "user_water_and_fertilizer_supply," stores information about the water and fertilizer supplies provided to crops, including the admin ID, crop type, supply time, location, water supply, fertilizer supply, and associated sensor ID. The primary key for this table is the associated sensor ID and admin ID, and it has foreign key constraints referencing the "sensor" and "user" tables.
The seventh table, "user_operation," stores information about the operations performed on crops, including the admin ID, crop ID, operation time, type, location, and details. The primary key for this table is the admin ID and crop ID, and it has foreign key constraints referencing the "crop" and "user" tables.
The eighth table, "system_performance_evaluation," stores information about the performance of the system, including the admin ID, crop ID, evaluation time, metric name, value, and location. The primary key for this table is the admin ID and crop ID, and it has foreign key constraints referencing the "crop" and "user" tables.
The ninth table, "model_performance_evaluation," stores information about the performance of the growth models, including the model ID, crop ID, evaluation metric name, value, and location. The primary key for this table is the model ID and crop ID, and it has foreign key constraints referencing the "crop" and "growth_model" tables.
Overall, this schema provides a comprehensive and detailed representation of the agricultural monitoring and management system, with tables for users, sensors, meteorology, crops, growth models, water and fertilizer supplies, user operations, system performance evaluation, and model performance evaluation.
