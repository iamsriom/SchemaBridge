The database name is rschema_0447, and it contains five tables. The first table, User, has the following columns: Associated_Unit, Password, Phone_Number, Role, User_ID (primary key), and Username. The second table, Financial_Document, has the following columns: Attachment_Path, Document_Category, Document_Content, Document_ID (primary key), Document_Level, Document_Number, Document_Title, Issue_Date, Issuing_Unit, Remarks, and Validity_Status. The third table, Notification, has the following columns: Issue_Date, Notification_Content, Notification_ID (primary key), Notification_Status, Notification_Title, and User_ID (foreign key referencing User.User_ID). The fourth table, System_Configuration, has the following columns: Admin_ID (foreign key referencing User.User_ID), Configuration_ID (primary key), Data_Type, Database_Directory, File_Upload_Directory, and System_Name. The fifth table, Document_Management, has the following columns: Admin_ID (foreign key referencing User.User_ID), Document_ID (foreign key referencing Financial_Document.Document_ID), Operation_Time, Operation_Type, and PRIMARY KEY (Admin_ID, Document_ID).
