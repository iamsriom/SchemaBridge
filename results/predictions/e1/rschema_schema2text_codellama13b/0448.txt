This database schema, named rschema_0448, is used to store information about a laboratory environment. It consists of nine tables: User, Experimental_Equipment, Experimental_Consumables, Hazardous_Chemicals, Experimental_Course, User_Usage_of_Equipment, User_Purchase_Consumables, User_Purchase_Hazardous_Chemicals, and User_Participation_in_Course.
The User table contains information about the users of the laboratory, including their associated unit, password, phone number, role, user ID, and username. The Experimental_Equipment table contains information about the experimental equipment used in the laboratory, including the acquisition time, device category, device ID, device model, device name, manufacturer, and status. The Experimental_Consumables table contains information about the consumables used in the laboratory, including the category, consumable ID, consumable name, inventory quantity, and status. The Hazardous_Chemicals table contains information about the hazardous chemicals used in the laboratory, including the chemical ID, chemical name, inventory quantity, issuance time, and status.
The Experimental_Course table contains information about the experimental courses offered in the laboratory, including the class location, class time, course ID, course name, participants, and teacher ID. The User_Usage_of_Equipment table contains information about the usage of experimental equipment by users, including the device ID, usage purpose, usage time, and user ID. The User_Purchase_Consumables table contains information about the purchase of consumables by users, including the consumable ID, purchase time, and user ID. The User_Purchase_Hazardous_Chemicals table contains information about the purchase of hazardous chemicals by users, including the chemical ID, purchase time, and user ID.
The User_Participation_in_Course table contains information about the participation of users in experimental courses, including the course ID, experimental course grade, participation status, and user ID. The tables are related to each other through foreign keys, which ensure referential integrity and entity integrity. For example, the User_Usage_of_Equipment table references the Experimental_Equipment table through the device ID, and the User_Purchase_Consumables table references the Experimental_Consumables table through the consumable ID. The User_Participation_in_Course table references the Experimental_Course table through the course ID and the User table through the user ID.
Overall, this schema provides a comprehensive and structured way to store and manage information about a laboratory environment, including users, equipment, consumables, and courses. It ensures data consistency and integrity through the use of foreign keys, primary keys, and unique constraints.
