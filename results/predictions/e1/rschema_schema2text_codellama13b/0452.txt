The rschema_0452 database is used to store information about users, students, and certificates. The user table contains information about each user, including their username, password, email, role, and account creation and update times. The student table contains information about each student, including their name, major, information creation and update times, and the user ID of the student. The certificate table contains information about each certificate, including the certificate name, issuing institution, issuance date, certificate description, certificate status, information creation and update times, hash value, and the associated student. The user ID in the student table is a foreign key that references the user table, and the associated student in the certificate table is a foreign key that references the student table. The foreign key constraints are set to cascade on update and delete, meaning that if a user or student is deleted, all associated certificates will also be deleted or updated. Additionally, there are primary keys set for each table, including the user ID, student ID, and certificate ID.
