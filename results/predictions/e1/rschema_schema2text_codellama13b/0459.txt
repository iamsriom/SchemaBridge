The department table contains information about each department, including its department ID, department name, and manager's employee ID. The project table contains information about each project, including its project ID, project name, department ID, responsible person's employee ID, and project participation time. The employee_project_participation table contains information about the participation of each employee in each project, including the employee's ID, project ID, and project participation time.
Each table has primary keys that uniquely identify each row, and foreign keys that reference other tables. For example, the employee table has a foreign key that references the department table, and the project table has foreign keys that reference the employee and department tables. The employee_project_participation table has foreign keys that reference the employee and project tables.
The schema also includes constraints that ensure the integrity of the data, such as the primary keys and foreign keys.
