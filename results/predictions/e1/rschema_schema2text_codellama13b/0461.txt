The database name is rschema_0461, and it contains six tables. The first table, Product, has columns for category, description, location, name, product ID (primary key), stock quantity, unit price, and unit of measurement. The second table, Delivery_Personnel, has columns for delivery personnel ID (primary key), gender, name, phone, and position. The third table, Customer, has columns for address, age, customer ID (primary key), gender, name, and phone. The fourth table, Order, has columns for customer ID (foreign key referencing Customer), delivery address, order creation time, order number (primary key), order status, and total order price. The fifth table, Order_Product, has columns for order ID (foreign key referencing Order), product ID (foreign key referencing Product), product quantity, and primary key (order ID and product ID). The sixth table, Order_Delivery, has columns for delivery personnel ID (foreign key referencing Delivery_Personnel), estimated delivery time, order ID (foreign key referencing Order), and primary key (order ID and delivery personnel ID).
