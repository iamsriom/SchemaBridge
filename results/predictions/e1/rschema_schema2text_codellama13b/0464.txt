This database schema, named rschema_0464, contains four tables: Employee, Department, Project, and Participation. The Employee table has columns for Department_ID, Education_level, Employee_ID (primary key), Name, Position, Salary, and a foreign key referencing the Department table. The Department table has columns for Department_ID (primary key), Department_name, Manager_employee_ID (not null), and a foreign key referencing the Employee table. The Project table has columns for Department_ID, Manager_employee_ID, Project_ID (primary key), Project_name, and foreign keys referencing the Department and Employee tables. The Participation table has columns for Employee_ID, Project_ID (primary key), and foreign keys referencing the Employee and Project tables. The primary keys for each table are indicated by the PRIMARY KEY constraint, and the foreign keys are indicated by the FOREIGN KEY constraint. The update and delete rules for each foreign key are CASCADE or RESTRICT, depending on the constraint.
