The rschema_0476 database is a schema for a pizza production and sales system. It contains 11 tables, each representing a different aspect of the system.
The Customer table contains information about customers, including their address, contact number, customer ID, and name. The Customer ID is the primary key for this table.
The Raw_Material table contains information about raw materials used in pizza production, including their ID, name, and specification. The Raw Material ID is the primary key for this table.
The Financial_Record table contains information about financial transactions, including the amount, date, status, transaction ID, and transaction type. The Transaction ID is the primary key for this table.
The Supplier table contains information about suppliers, including their contact information, supplier ID, and supplier name. The Supplier ID is the primary key for this table.
The Pizza_Recipe table contains information about pizza recipes, including the raw material ID, recipe ID, and usage amount. The Recipe ID is the primary key for this table.
The Sales_Order table contains information about sales orders, including the customer ID, expected delivery date, order ID, order status, and foreign key to the Customer table. The Order ID is the primary key for this table.
The Purchase_Order table contains information about purchase orders, including the order quantity, order status, purchase order ID, raw material ID, supplied quantity, and supplier ID. The Purchase Order ID is the primary key for this table.
The Product table contains information about products, including the product ID, product name, recipe ID, and foreign key to the Pizza_Recipe table. The Product ID is the primary key for this table.
The Production_Plan table contains information about production plans, including the order ID, production plan ID, production status, and foreign key to the Sales_Order table. The Production Plan ID is the primary key for this table.
The Delivery_Record table contains information about delivery records, including the delivery location, delivery record ID, delivery time, order ID, status, and foreign key to the Sales_Order table. The Delivery Record ID is the primary key for this table.
The Inventory_Management table contains information about inventory management, including the inventory ID, product ID, quantity, status, and foreign key to the Product table. The Inventory ID is the primary key for this table.
In summary, the rschema_0476 database schema is a comprehensive system for managing pizza production and sales, with tables for customers, raw materials, financial transactions, suppliers, recipes, sales orders, purchase orders, products, production plans, delivery records, and inventory management. Each table has its own primary key and foreign keys to other tables as necessary, ensuring referential integrity and entity integrity throughout the system.
