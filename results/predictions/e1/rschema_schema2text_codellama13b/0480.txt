The database name is rschema_0480 and it contains four tables: Property, Agent, User, and Responsibility. The Property table has the following columns: Address, Built_area, Construction_year, Is_apartment, Property_ID (primary key), Property_certificate, Property_photos, Sale_price, and Sales_status. The Agent table has the following columns: Agent_ID (primary key), Contact_number, Home_address, and Name. The User table has the following columns: Password, Role, User_ID (primary key), and Username. The Responsibility table has the following columns: Agent_ID (foreign key referencing Agent), Property_ID (foreign key referencing Property), Responsibility_end_time, Responsibility_start_time, and a composite primary key consisting of Agent_ID and Property_ID. The Responsibility table also has foreign key constraints referencing the Agent and Property tables, with update and delete rules of CASCADE and RESTRICT, respectively.
