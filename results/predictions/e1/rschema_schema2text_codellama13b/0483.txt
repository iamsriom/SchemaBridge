2. User: This table stores information about the users of the system. It has four columns: Contact_Information, Name, Registration_Method, and User_ID (primary key).
3. Operation: This table stores information about the operations performed in the system. It has five columns: Operation_Amount, Operation_ID (primary key), Operation_Time, Operation_Type, and Platform_ID (foreign key referencing Payment_Platform).
4. Intermediary: This table stores information about the intermediaries involved in the payment process. It has four columns: Intermediary_ID (primary key), Intermediary_Name, Intermediary_Status, and Operation_ID (foreign key referencing Operation).
5. User_Payment_Operation: This table stores information about the payments made by users in the system. It has five columns: Operation_ID (foreign key referencing Operation), Payment_Status, Payment_Time, User_ID (foreign key referencing User), and a composite primary key consisting of Operation_ID and User_ID.
