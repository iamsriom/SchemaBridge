The database name is rschema_0499 and it contains five tables. The first table is called Class and it has four columns: Class_ID, Class_name, Classroom, and Major. The Class_ID column is the primary key and the other columns are not null. The second table is called Sports_team and it has four columns: Activity_time, Coach, Team_ID, and Team_name. The Team_ID column is the primary key and the other columns are not null. The third table is called Dormitory and it has five columns: Administrator, Building_number, Dormitory_number, Number_of_residents, and PRIMARY KEY (Dormitory_number, Building_number). The fourth table is called Student and it has eight columns: Age, Building_number, Class_ID, Dormitory_number, Gender, Name, Student_ID, and FOREIGN KEY (Building_number) REFERENCES Dormitory(Building_number), FOREIGN KEY (Class_ID) REFERENCES Class(Class_ID), FOREIGN KEY (Dormitory_number) REFERENCES Dormitory(Dormitory_number). The Student_ID column is the primary key and the other columns are not null. The fifth table is called Team_membership and it has three columns: Student_ID, Team_ID, and PRIMARY KEY (Student_ID, Team_ID). The Student_ID and Team_ID columns are not null and the FOREIGN KEY (Student_ID) REFERENCES Student(Student_ID) and FOREIGN KEY (Team_ID) REFERENCES Sports_team(Team_ID) constraints are in place.
