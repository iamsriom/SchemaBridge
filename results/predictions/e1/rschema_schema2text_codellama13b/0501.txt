The database name is rschema_0501 and it contains six tables. The first table is Aircraft, which has columns for the affiliated airline, aircraft ID, aircraft model, aircraft status, manufacture date, and maximum passenger capacity. The second table is Crew_Member, which has columns for crew member ID, gender, name, phone, and position. The third table is Passenger, which has columns for gender, identification number, name, passenger ID, and phone. The fourth table is Flight, which has columns for aircraft ID, departure airport, departure time, flight ID, landing airport, landing time, responsible captain ID, and foreign keys for aircraft ID and responsible captain ID. The fifth table is Maintenance_Record, which has columns for aircraft ID, maintenance date, maintenance description, maintenance personnel ID, maintenance type, and foreign keys for aircraft ID and maintenance personnel ID. The sixth table is Ticket_Order, which has columns for booking time, flight ID, passenger ID, seat number, ticket price, and foreign keys for flight ID and passenger ID.
