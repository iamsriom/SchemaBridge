The database name is rschema_0508, and it contains five tables: Member, Book, Order, Order_book, and Place_order. The Member table has the following columns: Address, Consumption_amount, Member_ID (primary key), Name, Password, Phone, Points, Postal_code, and Username. The Book table has the following columns: Author, Book_ID (primary key), Book_title, Category_name, ISBN, Price, Publication_date, and Publisher. The Order table has the following columns: Member_ID (foreign key referencing Member), Order_ID (primary key), Order_date, Sales_amount, Shipping_date, and a foreign key referencing Member. The Order_book table has the following columns: Book_ID (foreign key referencing Book), Order_ID (foreign key referencing Order), Quantity, and a composite primary key consisting of Order_ID and Book_ID. The Place_order table has the following columns: Member_ID (foreign key referencing Member), Order_ID (foreign key referencing Order), and a composite primary key consisting of Member_ID and Order_ID. The foreign keys in the Order_book and Place_order tables reference the primary keys in the Book and Order tables, respectively.
