The rschema_0509 database is used to store information about a hospital's patients, doctors, nurses, departments, and wards. The database contains seven tables: Patient, Department, Doctor, Ward, Hospitalization_Record, Registration_Record, and Nurse.
The Patient table contains information about each patient, including their name, age, gender, medical record number, identity card number, and phone number. The table also has a primary key, Patient_ID, which is an integer that uniquely identifies each patient.
The Department table contains information about each department in the hospital, including its name, location, contact phone number, and department head ID. The table also has a primary key, Department_ID, which is an integer that uniquely identifies each department.
The Doctor table contains information about each doctor in the hospital, including their name, gender, title, and contact phone number. The table also has a primary key, Doctor_ID, which is an integer that uniquely identifies each doctor.
The Ward table contains information about each ward in the hospital, including its location, bed count, remaining bed count, and head ID. The table also has a primary key, Ward_ID, which is an integer that uniquely identifies each ward.
The Hospitalization_Record table contains information about each patient's hospitalization, including their patient ID, ward ID, hospitalization start time, discharge time, and attending physician ID. The table also has a primary key, which is a composite key consisting of the patient ID, ward ID, and hospitalization start time.
The Registration_Record table contains information about each patient's registration, including their patient ID, doctor ID, consultation time, and diagnosis result. The table also has a primary key, which is a composite key consisting of the patient ID, doctor ID, and consultation time.
The Nurse table contains information about each nurse in the hospital, including their name, gender, duties, and department ID. The table also has a primary key, Nurse_ID, which is an integer that uniquely identifies each nurse.
The database also has foreign key constraints that ensure referential integrity, such as the foreign key from the Department table to the Doctor table, and the foreign key from the Ward table to the Doctor table. The database also has composite primary keys and unique constraints to ensure entity integrity.
