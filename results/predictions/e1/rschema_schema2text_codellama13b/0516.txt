The rschema_0516 database is used to store information about a pizza restaurant's customers, pizzas, sales orders, income and expenditure, production plan, and delivery content. The database has six tables: Customer, Pizza, Sales_Order, Income/Expenditure, Production_Plan, and Delivery_Content.
The Customer table has four columns: Address, Customer_ID (primary key), Name, and Phone. The Pizza table has four columns: Flavor, Ingredients, Pizza_ID (primary key), and Stock. The Sales_Order table has five columns: Customer_ID (foreign key referencing Customer), Expected_Delivery_Date, Order_ID (primary key), Status, and FOREIGN KEY (Customer_ID) referencing Customer.
The Income/Expenditure table has six columns: Amount, Description, Pizza_ID (foreign key referencing Pizza), Record_ID (primary key), Time, and Type. The Production_Plan table has five columns: Order_ID (foreign key referencing Sales_Order), Pizza_ID (foreign key referencing Pizza), Production_Quantity, Production_Sequence, and PRIMARY KEY (Order_ID, Pizza_ID). The Delivery_Content table has four columns: Delivery_Time, Order_ID (foreign key referencing Sales_Order), Record_ID (primary key), and Status.
The database enforces entity integrity by using primary keys and foreign keys to ensure that each table has a unique identifier and that the relationships between tables are consistent. The database also enforces domain integrity by specifying the data types of each column and whether they allow null values. Finally, the database enforces referential integrity by specifying the update and delete rules for foreign keys, such as CASCADE and RESTRICT.
