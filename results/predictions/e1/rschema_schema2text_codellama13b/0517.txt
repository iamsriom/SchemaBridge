The rschema_0517 database is a relational database that stores information about a supermarket and its employees, departments, products, and sales. The database has nine tables, each representing a different entity or relationship in the system.
The Product table contains information about the products sold in the supermarket, including the product model, name, quantity, and unit price. The Product_ID column is the primary key for this table.
The Supermarket table contains information about the supermarkets, including the address, manager's employee ID, phone number, and supermarket name. The Supermarket_ID column is the primary key for this table.
The Department table contains information about the departments within the supermarkets, including the department name, responsibility, employee count, establishment time, manager's employee ID, and supermarket ID. The Department_ID column is the primary key for this table.
The Employee table contains information about the employees, including their name, position, salary, and contact information. The Employee_ID column is the primary key for this table.
The Allocation table contains information about the allocation of products to employees, including the allocation quantity, allocation time, product ID, and sales employee ID. The primary key for this table is a composite of the sales employee ID, allocation time, and product ID.
The Establish table contains information about the establishment of departments within supermarkets, including the department ID and supermarket ID. The primary key for this table is a composite of the supermarket ID and department ID.
The Manage_supermarket table contains information about the managers of supermarkets, including the manager's employee ID and supermarket ID. The primary key for this table is a composite of the manager's employee ID and supermarket ID.
The Manage_department table contains information about the managers of departments, including the department ID and manager's employee ID. The primary key for this table is a composite of the manager's employee ID and department ID.
The Work table contains information about the employees working in departments, including the department ID and employee ID. The primary key for this table is a composite of the employee ID and department ID.
In summary, the rschema_0517 database is a relational database that stores information about a supermarket and its employees, departments, products, and sales.
