The database schema for the database named 'rschema_0002' consists of 6 tables. The database is designed to manage and track multimodal transportation tasks.
The 'transportation_mode' table represents the different modes of transportation. It has two columns: 'mode_id' which is a unique identifier for each transportation mode and 'schema_name' which represents the name of the schema. The 'mode_id' column is the primary key of this table.
The 'carrier' table is used to store information about the transport carriers. It has three columns: 'carrier_id' which is a unique identifier for each carrier, 'name' which represents the name of the carrier, and 'contact_phone_number' which stores the contact phone number of the carrier. The 'carrier_id' column is the primary key of this table.
The 'multimodal_transportation_task' table is used to store information about the multimodal transportation tasks. It has seven columns: 'task_number' which is a unique identifier for each task, 'origin' which represents the origin location of the task, 'destination' which represents the destination location of the task, 'cargo_name' which represents the name of the cargo, 'weight' which represents the weight of the cargo, 'transportation_time' which represents the estimated transportation time, 'start_time' which represents the start time of the task, and 'end_time' which represents the end time of the task. The 'task_number' column is the primary key of this table.
The 'task_detail' table is used to store detailed information about each task. It has six columns: 'task_number', 'mode_id', 'carrier_id', 'transportation_time', 'start_time', and 'end_time'. The columns 'task_number', 'carrier_id', and 'mode_id' are foreign keys referencing the 'multimodal_transportation_task', 'carrier', and 'transportation_mode' tables respectively. The combination of 'carrier_id', 'task_number', and 'mode_id' is the primary key of this table.
The 'task_transportation_mode' table is used to store information about the transportation modes used in each task. It has two columns: 'task_number' and 'mode_id'. Both columns are foreign keys referencing the 'multimodal_transportation_task' and 'transportation_mode' tables respectively. The combination of 'task_number' and 'mode_id' is the primary key of this table.
Finally, the 'task_carrier' table is used to store information about the carriers involved in each task. It has two columns: 'task_number' and 'carrier_id'. Both columns are foreign keys referencing the 'multimodal_transportation_task' and 'carrier' tables respectively. The combination of 'carrier_id' and 'task_number' is the primary key of this table. The database schema is designed to maintain referential integrity by setting up cascading delete and update operations on foreign keys.
