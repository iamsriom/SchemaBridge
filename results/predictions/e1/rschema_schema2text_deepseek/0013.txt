The database schema named 'rschema_0013' consists of three tables: 'Weather_Station', 'Meteorological_Data', and 'Subscription_Data'.
The 'Weather_Station' table contains information about various weather stations. It has an integer primary key 'Weather_Station_ID', along with columns for 'Contact_Information', 'Location', 'Name', and 'Person_in_Charge'.
The 'Meteorological_Data' table contains meteorological data related to the weather stations. It has an integer primary key 'Data_ID', along with columns for 'Humidity', 'Precipitation', 'Recording_Date', 'Temperature', and 'Wind_Direction' and 'Wind_Speed'. The 'Weather_Station_ID' column is a foreign key referencing the 'Weather_Station_ID' in the 'Weather_Station' table, ensuring referential integrity.
The 'Subscription_Data' table contains subscription data related to the weather stations. It has columns for 'Farm_Name', 'Subscription_Date', 'Unsubscription_Date', and 'Weather_Station_ID'. The combination of 'Farm_Name' and 'Weather_Station_ID' forms the primary key, ensuring entity integrity. The 'Weather_Station_ID' column is a foreign key referencing the 'Weather_Station_ID' in the 'Weather_Station' table, ensuring referential integrity.
