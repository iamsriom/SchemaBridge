The database schema named 'rschema_0015' consists of four tables: 'plot', 'pest_and_disease', 'employee', and 'monitoring_record'.
The 'plot' table represents the plots of land in a farm. It has five columns: 'plot_number', 'area', 'soil_type', 'current_pest_and_disease_status', and 'geographic_location'. All these columns allow null values.
The 'pest_and_disease' table represents the pests and diseases that can be found in the plots. It has five columns: 'pest_and_disease_number', 'name', 'degree_of_harm', 'prevention_and_control_methods', and 'season_of_occurrence'. All these columns allow null values.
The 'employee' table represents the employees who monitor the pests and diseases. It has five columns: 'employee_number', 'name', 'gender', 'age', and 'contact_information'. All these columns allow null values.
The 'monitoring_record' table represents the records of pest and disease monitoring. It has five columns: 'plot_number', 'pest_number', 'monitoring_time', 'monitoring_results', and 'monitoring_employee_number'. The primary key of this table is a composite key of 'pest_and_disease_number', 'monitoring_time', and 'plot_number'. The 'pest_and_disease_number' column references the 'pest_and_disease' table, and the 'plot_number' column references the 'plot' table. The 'monitoring_record_ibfk_pest_and_disease_number' and 'monitoring_record_ibfk_plot_number' are foreign keys with ON DELETE CASCADE and ON UPDATE CASCADE options, which means if a record in the 'pest_and_disease' or 'plot' table is deleted or updated, the corresponding records in the 'monitoring_record' table will also be deleted or updated.
