The database schema named rschema_0017 comprises eight tables. The primary function of this database is to manage the production process of a workshop.
The Worker table represents the workers involved in the production process. It contains columns for the contact number, name, and a unique identifier for each worker.
The Workshop table represents the workshop where the production takes place. It contains columns for the workshop ID, address, and name.
The Raw_material table represents the raw materials used in the production process. It contains columns for the raw material ID and name.
The Product table represents the products produced by the workshop. It contains columns for the product ID and name.
The Workshop_raw_material_management table represents the inventory of raw materials at each workshop. It contains columns for the inventory quantity, raw material ID, and workshop ID. The primary key is a composite of workshop ID and raw material ID. The foreign keys reference the Raw_material and Workshop tables.
The Product_processing_task table represents the tasks involved in processing a product. It contains columns for the processing task ID, processing time, product ID, product quality rating, and production quantity. The foreign key references the Product table.
The Worker_processing_product table represents the assignment of workers to processing tasks. It contains columns for the processing task ID and worker ID. The primary key is a composite of processing task ID and worker ID. The foreign keys reference the Product_processing_task and Worker tables.
Finally, the Raw_materials_involved_in_product_processing table represents the raw materials involved in each processing task. It contains columns for the processing task ID and raw material ID. The primary key is a composite of processing task ID and raw material ID. The foreign keys reference the Product_processing_task and Raw_material tables. This schema ensures referential integrity by linking all tables together through the foreign keys.
