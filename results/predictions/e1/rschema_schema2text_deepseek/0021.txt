The database schema named 'rschema_0021' consists of three tables: Employee, Shift, and Schedule.
The Employee table represents the employees of an organization. It has five columns: Date_of_Birth (which is a DATETIME type), Employee_ID (which is an INTEGER type and is the primary key), Employee_Name (which is a VARCHAR(255) type), Gender (which is also a VARCHAR(255) type), and Phone_Number (which is a VARCHAR(255) type). All these columns allow null values.
The Shift table is used to represent the different shifts in the organization. It has four columns: End_Time (which is a DATETIME type), Shift_ID (which is an INTEGER type and is the primary key), Shift_Name (which is a VARCHAR(255) type), and Start_Time (which is also a DATETIME type). All these columns allow null values.
The Schedule table is used to represent the schedule of the employees. It has three columns: Employee_ID (which is an INTEGER type and is not null), Scheduled_Time (which is a DATETIME type), and Shift_ID (which is an INTEGER type and is not null). The combination of Employee_ID, Shift_ID, and Scheduled_Time forms the primary key of this table. The Employee_ID and Shift_ID columns are foreign keys referencing the Employee and Shift tables respectively.
The Schedule table ensures referential integrity by ensuring that the Employee_ID and Shift_ID values exist in the Employee and Shift tables respectively. The Schedule table also ensures entity integrity by ensuring that the combination of Employee_ID, Shift_ID, and Scheduled_Time is unique.
