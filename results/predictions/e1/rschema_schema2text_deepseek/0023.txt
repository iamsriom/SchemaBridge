The database schema named 'rschema' consists of five tables: 'donor', 'recipient', 'donated_item', 'donation_record', and 'donation_record_details'.
The 'donor' table represents donors with attributes such as donor_number, name, gender, date_of_birth, and contact_information. The primary key for this table is 'donor_number'.
The 'recipient' table holds information about recipients, including attributes such as recipient_number, name, gender, date_of_birth, and contact_information. The primary key for this table is 'recipient_number'.
The 'donated_item' table contains information about the items donated, including attributes such as item_number, name, quantity, and description. The primary key for this table is 'item_number'.
The 'donation_record' table records the donations made, with attributes such as donation_record_id, recipient_number, donation_time, and item_number. The primary key for this table is 'donation_record_id'. It has two foreign keys, 'donor_number' and 'recipient_number', referencing the 'donor' and 'recipient' tables respectively.
Lastly, the 'donation_record_details' table holds details about the donations, with attributes such as donation_record_id and item_number. The primary key for this table is a composite key of 'item_number' and 'donation_record_id'. It has two foreign keys, 'donation_record_id' and 'item_number', referencing the 'donation_record' and 'donated_item' tables respectively. The delete and update rules for these foreign keys are set to CASCADE, meaning that if a record in the referenced table is deleted or updated, the corresponding records in this table will also be deleted or updated.
