The database schema named 'rschema' consists of seven tables.
The 'Textile' table is used to store information about different types of textiles. It includes columns for 'Name', 'Price', 'Production_Date', 'Textile_ID', and 'Type'. The 'Textile_ID' is the primary key for this table.
The 'Department' table holds information about different departments within the company. It includes columns for 'Contact_Information', 'Department_ID', 'Department_Name', and 'Manager'. The 'Department_ID' is the primary key for this table.
The 'Inventory' table keeps track of the inventory of different textiles. It includes columns for 'Inventory_ID', 'Quantity', 'Stock-in_Time', and 'Textile_ID'. The 'Textile_ID' is a foreign key referencing the 'Textile' table.
The 'Employee' table contains information about the employees of the company. It includes columns for 'Department_ID', 'Employee_ID', 'Gender', 'Name', 'Phone', and 'Position'. The 'Department_ID' is a foreign key referencing the 'Department' table and 'Employee_ID' is the primary key for this table.
The 'Production_Relationship' table is used to track the production of textiles. It includes columns for 'Producer_ID', 'Production_Time', 'Quantity', and 'Textile_ID'. The combination of 'Textile_ID', 'Producer_ID', and 'Production_Time' forms the primary key for this table. The 'Producer_ID' is a foreign key referencing the 'Employee' table and 'Textile_ID' is a foreign key referencing the 'Textile' table.
Finally, the 'Sales_Relationship' table is used to track sales of textiles. It includes columns for 'Customer', 'Quantity', 'Sales_Personnel_ID', 'Sales_Time', and 'Textile_ID'. The combination of 'Textile_ID', 'Sales_Personnel_ID', and 'Sales_Time' forms the primary key for this table. The 'Sales_Personnel_ID' is a foreign key referencing the 'Employee' table and 'Textile_ID' is a foreign key referencing the 'Textile' table.
The 'Performance_Evaluation' table is used to evaluate the performance of employees. It includes columns for 'Employee_ID', 'Evaluation_Date', 'Performance_ID', and 'Score'. The 'Employee_ID' is a foreign key referencing the 'Employee' table and 'Performance_ID' is the primary key for this table.
This schema provides a comprehensive overview of the company's textile production, inventory, sales, and employee performance.
