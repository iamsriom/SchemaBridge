The database schema for the database named 'rschema_0030' consists of 6 tables. The tables are described as follows:
1. 'raw_material_table': This table contains information about the raw materials used in the production process. The table has five columns: 'raw_material_id', 'name', 'production_date', 'shelf_life', and 'price'. The 'raw_material_id' is the primary key of this table.
2. 'product_table': This table contains information about the products produced. The table has six columns: 'product_id', 'name', 'composition', 'production_date', 'shelf_life', 'price', and 'raw_material_id'. The 'product_id' is the primary key of this table and 'raw_material_id' is a foreign key referencing the 'raw_material_table'.
3. 'production_record_table': This table contains records of the production process. The table has four columns: 'product_id', 'quantity', 'producer', and 'production_time'. The combination of 'production_time', 'product_id', and 'producer' is the primary key of this table and 'product_id' and 'producer' are foreign keys referencing the 'product_table' and 'employee_department_table' respectively.
4. 'inventory_record_table': This table contains records of the inventory. The table has four columns: 'product_id', 'stocking_person', 'quantity', and 'stocking_time'. The combination of 'stocking_person', 'product_id', and 'stocking_time' is the primary key of this table and 'stocking_person' and 'product_id' are foreign keys referencing the 'employee_department_table' and 'product_table' respectively.
5. 'sales_record_table': This table contains records of the sales. The table has four columns: 'product_id', 'quantity', 'salesperson', and 'sale_time'. The combination of 'product_id', 'salesperson', and 'sale_time' is the primary key of this table and 'product_id' and 'salesperson' are foreign keys referencing the 'product_table' and 'employee_department_table' respectively.
6. 'employee_department_table': This table contains information about the employees and their departments. The table has seven columns: 'employee_id', 'name', 'gender', 'phone', 'department_id', 'position', and 'supervisor_id'. The 'employee_id' is the primary key of this table and 'employee_id' and 'department_id' are foreign keys referencing the 'employee_department_table' and 'production_record_table' respectively. The 'supervisor_id' is also a foreign key referencing the 'employee_id' in the same table.
All the tables are set up with InnoDB engine and utf8mb3 character set. The tables are interconnected with foreign keys and primary keys ensuring referential integrity and entity integrity. The DELETE and UPDATE rules are set to CASCADE, which means if a record in the referenced table is deleted or updated, the corresponding records in the referencing table will automatically be deleted or updated as well.
