The database schema named 'rschema_0033' consists of seven tables. The main purpose of this schema is to manage sales tasks, personnel, customers, and electronic products.
The 'Electronic_Product' table represents electronic products for sale. It has four columns: Model, Name, Price, and Product_ID. The Product_ID is the primary key, which ensures entity integrity as it uniquely identifies each record in the table.
The 'Sales_Team' table is used to manage sales teams. It has four columns: Contact_Information, Manager, Team_ID, and Team_Name. The Team_ID is the primary key, which uniquely identifies each team.
The 'Customer' table is used to store customer information. It has three columns: Customer_ID, Customer_Name, and Customer_Phone. The Customer_ID is the primary key, which uniquely identifies each customer.
The 'Sales_Task' table is used to manage sales tasks. It has four columns: Sales_Cost, Sales_Date, Sales_Quantity, and Sales_Task_ID. The Sales_Task_ID is the primary key, which uniquely identifies each sales task.
The 'Sales_Personnel' table is used to manage sales personnel. It has six columns: Gender, Name, Phone, Position, Sales_Personnel_ID, and Team_ID. The Sales_Personnel_ID is the primary key, which uniquely identifies each sales personnel member. The Team_ID is a foreign key referencing the Sales_Team table, ensuring referential integrity.
The 'Sales_Task_Customer' table is used to link sales tasks to customers. It has four columns: Customer_ID, Feedback, Rating, and Sales_Task_ID. The combination of Sales_Task_ID and Customer_ID forms the primary key, which uniquely identifies each record in the table. The Customer_ID and Sales_Task_ID are foreign keys referencing the Customer and Sales_Task tables, respectively, ensuring referential integrity.
Finally, the 'Sales_Task_Product' table is used to link sales tasks to products. It has three columns: Product_ID and Sales_Task_ID. The combination of Sales_Task_ID and Product_ID forms the primary key, which uniquely identifies each record in the table. The Product_ID and Sales_Task_ID are foreign keys referencing the Electronic_Product and Sales_Task tables, respectively, ensuring referential integrity.
