The database schema for the database named 'rschema_0038' contains three tables: 'designer', 'customer', and 'project'.
The 'designer' table represents the designers working in the company. It has five columns: 'designer_id', 'designer_name', 'phone', 'email', and 'department'. The 'designer_id' column is the primary key for this table.
The 'customer' table represents the customers who are using the services of the company. It has four columns: 'customer_id', 'name', 'phone', and 'email'. The 'customer_id' column is the primary key for this table.
The 'project' table represents the projects managed by the company. It has eleven columns: 'project_id', 'designer_id', 'customer_id', 'project_manager', 'project_name', 'start_date', 'estimated_completion_date', 'actual_completion_date', 'project_budget', 'design_plan_date', and 'design_plan_name', 'design_plan_content'. The 'project_id' column is the primary key for this table. The 'customer_id' and 'designer_id' columns are foreign keys referencing the 'customer' and 'designer' tables respectively. The ON DELETE CASCADE and ON UPDATE CASCADE options are set on these foreign keys to ensure referential integrity.
This schema allows for a clear and efficient tracking of the relationships between designers, customers, and projects.
