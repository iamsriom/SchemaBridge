4. **Building**: This table contains information about the buildings. The columns include `Area` (a float), `Building_ID` (an integer, the primary key), `Number_of_Floors` (an integer), `Price` (a float), `Project_ID` (an integer, not null, foreign key referencing `Civil_Engineering_Project`), and `Project_ID` (an integer, not null, foreign key referencing `Civil_Engineering_Project`).
5. **Building_Sale**: This table contains information about the sales of the buildings. The columns include `Building_ID` (an integer, not null, foreign key referencing `Building`), `Customer_Contact_Information` (a string of up to 255 characters), `Customer_Name` (a string of up to 255 characters), `Price` (a float), `Sales_Date` (a date and time), and `Sales_Personnel_ID` (an integer, not null, foreign key referencing `Sales_Personnel`).
