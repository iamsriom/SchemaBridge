The database schema named 'rschema_0046' contains three tables: 'Member', 'Shopping_Record', and 'Point_Redemption_Record'.
The 'Member' table represents a member of the club with columns for 'Current_Points', 'Member_ID', 'Name', and 'Phone_Number'. 'Current_Points' is an integer type column that stores the current points of each member. 'Member_ID' is the primary key for this table. 'Name' is a varchar type column that stores the name of each member, and 'Phone_Number' is an integer type column that stores the phone number of each member.
The 'Shopping_Record' table represents the shopping records of the members. It has columns for 'Member_ID', 'Points_Change', 'Shopping_Time', and 'Total_Price_of_Goods'. 'Member_ID' is a foreign key referencing the 'Member_ID' in the 'Member' table, indicating which member made the shopping. 'Points_Change' is an integer type column that shows how many points the member earned or spent. 'Shopping_Time' is a datetime type column that records the time of the shopping. 'Total_Price_of_Goods' is a float type column that records the total price of the goods bought. 'Member_ID' and 'Shopping_Time' form the primary key of this table.
The 'Point_Redemption_Record' table represents the point redemption records of the members. It has columns for 'Member_ID', 'Points_Consumed', 'Redeemed_Product_Name', 'Redemption_Quantity', and 'Redemption_Time'. 'Member_ID' is a foreign key referencing the 'Member_ID' in the 'Member' table, indicating which member made the redemption. 'Points_Consumed' is an integer type column that shows how many points the member consumed. 'Redeemed_Product_Name' is a varchar type column that records the name of the product redeemed. 'Redemption_Quantity' is an integer type column that records the quantity of the product redeemed. 'Redemption_Time' is a datetime type column that records the time of the redemption. 'Member_ID' and 'Redemption_Time' form the primary key of this table.
This schema ensures referential integrity by linking the 'Member' table with the 'Shopping_Record' and 'Point_Redemption_Record' tables through the 'Member_ID' foreign key. It also ensures entity integrity by ensuring that each member has a unique 'Member_ID' and that the 'Member_ID' in the 'Shopping_Record' and 'Point_Redemption_Record' tables exists in the 'Member' table.
