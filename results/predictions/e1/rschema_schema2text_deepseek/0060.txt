The database schema named 'rschema_0060' contains four tables: 'project', 'researcher', 'research_result', and 'fund_usage'.
The 'project' table represents a project with columns for 'project_id', 'name', 'start_date', 'end_date', 'project_leader', and 'budget'. The 'project_id' column is the primary key.
The 'researcher' table represents a researcher with columns for 'employee_number', 'name', 'date_of_birth', 'gender', 'phone_number', 'position', and 'project_id'. The 'employee_number' column is the primary key and the 'project_id' column is a foreign key referencing the 'project' table.
The 'research_result' table represents a research result with columns for 'result_id', 'name', 'publication_date', and 'researcher_employee_number'. The 'result_id' column is the primary key and the 'researcher_employee_number' column is a foreign key referencing the 'researcher' table.
Finally, the 'fund_usage' table represents the usage of funds with columns for 'fund_id', 'project_id', 'purpose', 'amount', and 'usage_date'. The 'fund_id' column is the primary key and the 'project_id' column is a foreign key referencing the 'project' table. The 'fund_usage' table has ON DELETE CASCADE and ON UPDATE CASCADE rules for both foreign keys, meaning that if a project or researcher is deleted or updated, the corresponding entries in the 'fund_usage' table will also be deleted or updated.
