The database schema named 'rschema_0069' comprises three tables: 'customer', 'rental_item', and 'rental_record'.
The 'customer' table is used to store information about customers. It includes fields for 'customer_id', 'customer_name', 'customer_phone', 'customer_age', 'customer_gender', 'customer_address', and 'customer_email'. The 'customer_id' field is the primary key, ensuring entity integrity as no two customers can have the same ID.
The 'rental_item' table is used to store information about the items that can be rented. It includes fields for 'rental_item_id', 'item_name', 'item_category', 'single_rental_fee', 'total_inventory', and 'remaining_inventory'. The 'rental_item_id' field is the primary key, ensuring entity integrity for each rental item.
The 'rental_record' table is used to store information about the rentals. It includes fields for 'customer_id', 'rental_item_id', 'rental_start_time', 'rental_end_time', 'number_of_rented_items', and 'rental_payment_fee'. The combination of 'rental_start_time' and 'customer_id' and 'rental_item_id' form the primary key, ensuring entity integrity for each rental record. The 'customer_id' and 'rental_item_id' fields are foreign keys referencing the 'customer' and 'rental_item' tables respectively. The ON DELETE CASCADE and ON UPDATE CASCADE options ensure referential integrity. This means if a customer or rental item is deleted or updated, the corresponding rental records will also be deleted or updated.
