The database schema named 'rschema_0070' consists of six tables: 'Ore', 'Working_Employees', 'Mine', 'Processing_Plant', 'Output_Ore', and 'Processing_Plant_Processing_Ore'.
The 'Ore' table represents the characteristics of the ore and is used to store information about the type and name of the ore. It has three columns: 'Characteristics', 'Name', and 'Ore_ID', where 'Ore_ID' is the primary key.
The 'Working_Employees' table stores information about the employees. It includes columns for 'Age', 'Email', 'Employee_ID', 'Gender', and 'Name'. 'Employee_ID' is the primary key.
The 'Mine' table contains information about the mines. It has columns for 'Location', 'Mine_ID', 'Name', and 'Person_In_Charge_ID'. 'Mine_ID' is the primary key and 'Person_In_Charge_ID' is a foreign key referencing 'Employee_ID' in the 'Working_Employees' table.
The 'Processing_Plant' table contains information about the processing plants. It has columns for 'Location', 'Name', 'Person_In_Charge_ID', and 'Processing_Plant_ID'. 'Processing_Plant_ID' is the primary key and 'Person_In_Charge_ID' is a foreign key referencing 'Employee_ID' in the 'Working_Employees' table.
The 'Output_Ore' table stores information about the output of the ore from the mines. It has columns for 'Mine_ID', 'Ore_ID', 'Output_Quantity', and 'Output_Time'. 'Mine_ID' and 'Ore_ID' are foreign keys referencing 'Mine_ID' and 'Ore_ID' in the 'Mine' and 'Ore' tables respectively, and 'Mine_ID' and 'Ore_ID' together form the primary key.
Finally, the 'Processing_Plant_Processing_Ore' table stores information about the processing of the ore by the processing plants. It has columns for 'Ore_ID', 'Processing_Cost', 'Processing_Date', 'Processing_Plant_ID', 'Processing_Quantity'. 'Ore_ID' and 'Processing_Plant_ID' are foreign keys referencing 'Ore_ID' and 'Processing_Plant_ID' in the 'Ore' and 'Processing_Plant' tables respectively, and 'Ore_ID' and 'Processing_Plant_ID' together form the primary key. This schema ensures referential integrity by linking all the tables together through the primary and foreign keys.
