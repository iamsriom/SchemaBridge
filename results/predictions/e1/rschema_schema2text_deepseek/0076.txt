The database schema named rschema_0076 consists of five tables. The Beer_Manufacturer table represents the manufacturer of the beer. It contains columns for Country (a string with a maximum length of 255 characters), Manufacturer_Name (a string with a maximum length of 255 characters), and Manufacturer_Number (an integer) which serves as the primary key.
The Bar table represents the bars where drinks are sold. It contains columns for Address (a string with a maximum length of 255 characters), Bar_Name (a string with a maximum length of 255 characters), Bar_Number (an integer), License (a string with a maximum length of 255 characters), and Phone (a string with a maximum length of 255 characters) which serves as the primary key.
The Drinker table represents the drinkers who buy the drinks. It contains columns for Address (a string with a maximum length of 255 characters), Age (an integer), Drinker_Number (an integer), Gender (a string with a maximum length of 255 characters), Name (a string with a maximum length of 255 characters), and Phone (a string with a maximum length of 255 characters) which serves as the primary key.
The Beer table represents the beers sold at the bars. It contains columns for Beer_Name (a string with a maximum length of 255 characters), Beer_Number (an integer), Beer_Price (a float), and Manufacturer_Number (an integer) which is a foreign key referencing the Manufacturer_Number in the Beer_Manufacturer table.
Finally, the Sales_Record table represents the sales records. It contains columns for Bar_Number (an integer), Beer_Number (an integer), Price (a float), and Sales_Date (a datetime). Both Bar_Number and Beer_Number are foreign keys referencing the Bar_Number and Beer_Number in the Bar and Beer tables respectively. The combination of Bar_Number and Beer_Number forms the primary key of this table.
