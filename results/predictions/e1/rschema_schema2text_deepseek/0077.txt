The database schema named 'rschema_0077' consists of five tables: User, Product, Order, Announcement, and Order_Detail.
The User table represents a user of the system. It contains columns for Address_Details, Email, ID (which is the primary key), Membership_Number, Name, Password, Phone_Number, and Postal_Code.
The Product table holds information about the products. It includes columns for Category, Manufacturer, Name, Price, Product_ID (which is the primary key), and Product_Image_URL.
The Order table records user orders. It has columns for Delivery_Status, Order_ID (which is the primary key), Purchase_Date, and User_ID. The User_ID column is a foreign key referencing the ID column in the User table.
The Announcement table holds information about system announcements. It includes columns for Announcement_Number (which is the primary key), Content, Publisher_ID, Registration_Date, and Title. The Publisher_ID column is a foreign key referencing the ID column in the User table.
Finally, the Order_Detail table records the details of each order. It includes columns for Order_ID, Product_ID, Purchase_Quantity. Both Order_ID and Product_ID are foreign keys referencing the Order_ID and Product_ID columns in the Order and Product tables respectively.
