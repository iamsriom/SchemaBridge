The database schema named 'rschema_0085' comprises four tables: User, Recipe, Blog, and Collected_Recipe.
The User table represents a user of the application. It contains columns for Avatar, Email, Password, Profile, User_ID (as the primary key), and Username. The User_ID is an integer and cannot be null.
The Recipe table is used to store information about recipes. It includes columns for Bitter_Level, Calories, Creator_ID (which cannot be null), Ingredients, Large_Image_Filename, Meaty_Level, Number_of_Ratings, Portion, Rating, Recipe_ID (as the primary key), Recipe_Name, Salty_Level, Small_Image_Filename, Sour_Level, Spicy_Level, Steps, Sweet_Level, Total_Time. The Recipe_ID is an integer and cannot be null. The Creator_ID is a foreign key referencing the User_ID in the User table.
The Blog table is used to store information about blogs. It includes columns for Author_User_ID (which cannot be null), Blog_ID (as the primary key), Blog_Summary, Blog_Title, and Publication_Time. The Blog_ID is an integer and cannot be null. The Author_User_ID is a foreign key referencing the User_ID in the User table.
Finally, the Collected_Recipe table is used to store information about which recipes have been collected by which users. It includes columns for Collection_Time, Recipe_ID (which cannot be null), and User_ID (which cannot be null). Both Recipe_ID and User_ID are foreign keys referencing the Recipe_ID and User_ID in their respective tables respectively. The combination of User_ID and Recipe_ID forms the primary key of this table.
