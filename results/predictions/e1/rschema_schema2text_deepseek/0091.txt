The database schema named 'rschema_0091' consists of five tables: 'department', 'training', 'employee', 'attendance', and 'employee_training'.
The 'department' table represents the departments within the organization. It has five columns: 'department_id' as the primary key, 'department_name' as the name of the department, 'person_in_charge' as the person in charge of the department, and 'phone_number' as the department's contact information.
The 'training' table holds information about the training programs offered by the organization. It has four columns: 'training_content', 'training_id' as the primary key, 'training_name' as the name of the training program, and 'training_time' as the scheduled date and time of the training.
The 'employee' table contains information about the employees. It has seven columns: 'date_of_birth', 'department_id' as a foreign key referencing the 'department' table, 'employee_id' as the primary key, 'gender', 'name', 'position', and 'salary'.
The 'attendance' table keeps track of the attendance records of the employees. It has six columns: 'attendance_date', 'attendance_id' as the primary key, 'check-in_and_check-out_times' as the check-in and check-out times, 'employee_id' as a foreign key referencing the 'employee' table, and 'whether_late_or_early_departure' as the status of the attendance.
Finally, the 'employee_training' table acts as a junction table that links the 'employee' and 'training' tables. It has three columns: 'employee_id' and 'training_id' as foreign keys referencing the 'employee' and 'training' tables respectively, and they form the primary key of this table.
All columns allow null values except for 'department_id' in the 'employee' table and 'employee_id' in the 'attendance' table. Default values are not set for any columns. The primary keys enforce entity integrity by uniquely identifying each record in their respective tables. The foreign keys enforce referential integrity by ensuring that the values in the foreign key columns of one table match the values in the primary key column of another table.
