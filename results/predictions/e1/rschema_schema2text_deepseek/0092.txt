The database schema named 'rschema_0092' contains four tables: User, Operator, Change_Superior_User, and Change_Subordinate_User.
The User table represents the users of the system. It contains columns for Creation_Time, Email, Expiration_Time, Identity_Status, Identity_Type, Subordinate_User, and Superior_User. The User_ID is the primary key of this table. The Subordinate_User and Superior_User columns are foreign keys referencing the User_ID in the User table.
The Operator table represents the operators of the system. It contains columns for Name, Operator_ID, Permissions, and Phone. Operator_ID is the primary key of this table.
The Change_Superior_User table logs changes in the superior user relationship. It contains columns for Change_Time, Changed_Superior_User, Operator_ID, Previous_Superior_User, Remarks, and User_ID. The combination of Operator_ID, User_ID, and Change_Time forms the primary key of this table. The Changed_Superior_User and Operator_ID, as well as Previous_Superior_User and User_ID are foreign keys referencing the User_ID and Operator_ID in their respective tables.
Finally, the Change_Subordinate_User table logs changes in the subordinate user relationship. It contains columns for Change_Time, Changed_Subordinate_User, Operator_ID, Previous_Subordinate_User, Remarks, and User_ID. The combination of Operator_ID, User_ID, and Change_Time forms the primary key of this table. The Changed_Subordinate_User and Operator_ID, as well as Previous_Subordinate_User and User_ID are foreign keys referencing the User_ID and Operator_ID in their respective tables. This schema ensures referential integrity by maintaining relationships between tables and enforcing constraints on data.
