The database schema named 'rschema_0100' contains five tables: Customer, User, Order, Quotation, and Order_Item.
The Customer table is used to store customer-related information. It includes columns for Creation_Time, Customer_ID (which is the primary key), Deletion_Time, Email, Name, and Update_Time. All columns allow null values.
The User table stores user-related information. It includes columns for Creation_Time, Deletion_Time, Email, Password, Update_Time, User_ID (the primary key), and Username. All columns allow null values.
The Order table contains information about orders. It includes columns for Creation_Time, Creator_User_ID (which is a foreign key referencing the User table), Currency_Type, Customer_ID (a foreign key referencing the Customer table), Deletion_Time, Delivery_Date, Invoice_Number, Order_Description, Order_ID (the primary key), Order_Number, and Update_Time. All columns allow null values.
The Quotation table contains information about quotations. It includes columns for Creation_Time, Creator_User_ID (a foreign key referencing the User table), Customer_ID (a foreign key referencing the Customer table), Deletion_Time, Description, Quotation_ID (the primary key), Quotation_Number, and Update_Time. All columns allow null values.
Finally, the Order_Item table contains information about the items in orders. It includes columns for Creation_Time, Deletion_Time, Description, Order_ID (a foreign key referencing the Order table), Order_Item_ID (the primary key), Quantity, Unit, Unit_Price, and Update_Time. All columns allow null values.
This schema ensures that the data integrity of the database is maintained by enforcing primary and foreign key constraints, and by allowing null values in all columns. It also ensures referential integrity by ensuring that the foreign keys in the Order, Quotation, and Order_Item tables reference the primary keys in the User and Customer tables.
