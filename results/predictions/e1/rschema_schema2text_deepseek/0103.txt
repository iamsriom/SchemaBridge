The database schema named rschema_0103 consists of four tables: Department, Salary_standard, Employee, and Employee_position_change.
The Department table represents the departments within the organization. It has an integer primary key, Department_ID, and several other columns including Department_code, Name, and Person_in_charge.
The Salary_standard table is used to store the standard salaries for different positions within the organization. It has an integer primary key, Salary_standard_ID, and two other columns, Standard_description and Standard_value, which are used to describe the salary standard and its corresponding value, respectively.
The Employee table holds information about the employees within the organization. It has a datetime column for Date_of_birth, an integer column Department_ID which is not null, an integer primary key Employee_ID, a varchar column Gender, a datetime column Hire_date, and several other columns including Name, Position, and Salary_standard_ID. The Department_ID and Salary_standard_ID columns are foreign keys referencing the Department and Salary_standard tables respectively.
The Employee_position_change table keeps track of the position changes of the employees within the organization. It has several varchar columns for the original and current department and position, datetime columns for the entry and departure times, and integer columns for the Employee_ID and Department_ID. The Department_ID and Employee_ID columns are foreign keys referencing the Department and Employee tables respectively. The combination of Employee_ID, Department_ID, and Departure_time forms the primary key of this table.
