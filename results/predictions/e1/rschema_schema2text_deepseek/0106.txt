The database schema named 'rschema_0106' consists of three tables: 'user', 'post', and 'comment'.
The 'user' table is used to store user information. It has seven columns: 'user_id', 'username', 'email', 'password', 'user_type', 'activation_status', and 'creation_time'. The 'user_id' column is the primary key.
The 'post' table is used to store post information. It has eight columns: 'post_id', 'post_title', 'post_description', 'image_path', 'thumbnail_path', 'activation_status', 'creation_time', and 'user_id'. The 'post_id' column is the primary key and 'user_id' is a foreign key referencing the 'user' table.
The 'comment' table is used to store comment information. It has five columns: 'comment_content', 'author_id', 'post_id', 'creation_time', and 'comment_creation_time' is the primary key. The 'author_id' and 'post_id' are foreign keys referencing the 'user' and 'post' tables respectively. The 'comment_creation_time', 'author_id', and 'post_id' are used together as a composite key to ensure entity integrity.
All columns allow null values except for 'user_id' in the 'post' table and 'author_id' and 'post_id' in the 'comment' table. There are no default values set. The database uses the InnoDB engine and the default character set is utf8mb3. The 'post_id' and 'user_id' columns in the 'post' table and 'author_id' and 'post_id' columns in the 'comment' table have cascade delete and update rules.
