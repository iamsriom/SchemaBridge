The database schema named "rschema_0107" contains three tables: Game, Spaceship, and Fighter.
The Game table is used to store information about the games played. It has five columns: Game_ID (integer, primary key), Game_result (varchar with a maximum length of 255 characters), Grid_size (float), Number_of_rounds (integer), and Username (varchar with a maximum length of 255 characters).
The Spaceship table is used to store information about the spaceships in the games. It has five columns: Game_ID (integer, not null, foreign key referencing the Game table), Name (varchar with a maximum length of 255 characters), Position (varchar with a maximum length of 255 characters), Spaceship_ID (integer, primary key), Strength (float), and Type (varchar with a maximum length of 255 characters).
The Fighter table is used to store information about the fighters in the games. It has four columns: Fighter_ID (integer, primary key), Name (varchar with a maximum length of 255 characters), Spaceship_ID (integer, not null, foreign key referencing the Spaceship table), and Strength (float).
These tables are related to each other through foreign keys, ensuring referential integrity. The Game table has a primary key and unique constraint on Game_ID, Spaceship has a primary key and unique constraint on Spaceship_ID, and Fighter has a primary key and unique constraint on Fighter_ID. The foreign key constraints ensure that the data in the Fighter table is validated against the data in the Spaceship and Game tables.
