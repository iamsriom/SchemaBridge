The database schema named 'rschema_0111' consists of four tables: User, Company, Employee, and Credit_Record.
The User table is used to store user information. It includes columns for Email (a string of up to 255 characters), Password (also a string of up to 255 characters), Phone_Number (a string of up to 255 characters), Registration_Time (a date and time), Role (a string of up to 255 characters), Update_Time (a date and time), User_ID (an integer, the primary key), and Username (a string of up to 255 characters).
The Company table stores information about companies. It includes columns for Company_Address (a string of up to 255 characters), Company_ID (an integer, the primary key), Company_Name (a string of up to 255 characters), and Creation_Time (a date and time).
The Employee table contains information about employees. It has columns for Affiliated_Company_ID (an integer, not null), Employee_ID (an integer, the primary key), Employee_Name (a string of up to 255 characters), and Employee_Position (a string of up to 255 characters). The Affiliated_Company_ID is a foreign key referencing the Company_ID in the Company table.
Finally, the Credit_Record table stores credit records. It includes columns for Application_Date (a date and time), Creation_Time (a date and time), Credit_Number (a string of up to 255 characters, the primary key), Credit_Status (a string of up to 255 characters), Credit_Type (a string of up to 255 characters), Deletion_Time (a date and time), Employee_ID (an integer, not null, a foreign key referencing Employee_ID in the Employee table), Monthly_Factor (a string of up to 255 characters), Number_of_Applications (a string of up to 255 characters), Update_Time (a date and time), and User_ID (an integer, not null, a foreign key referencing User_ID in the User table).
