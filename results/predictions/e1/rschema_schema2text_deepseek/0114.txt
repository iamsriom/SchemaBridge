The database schema named 'rschema_0114' consists of five tables: 'user', 'article', 'comment', 'comment_like', and 'log'.
The 'user' table represents a user of the system, with columns for 'user_id', 'username', 'password', 'email', 'creation_time', and 'is_email_public'. The 'user_id' is the primary key of this table.
The 'article' table represents an article published by users, with columns for 'article_id', 'title', 'body', 'type', 'timestamp', 'publisher_id', and 'is_public'. The 'article_id' is the primary key of this table and a foreign key 'publisher_id' references the 'user_id' in the 'user' table.
The 'comment' table represents user comments on articles, with columns for 'comment_id', 'article_id', 'user_id', 'comment_content', and 'timestamp'. The combination of 'user_id' and 'article_id' is the primary key of this table and foreign keys 'article_id' and 'user_id' reference the 'article_id' and 'user_id' in the 'article' and 'user' tables respectively.
The 'comment_like' table represents likes on comments, with columns for 'user_id', 'comment_id', and 'like_time'. The combination of 'user_id', 'comment_id', and 'like_time' is the primary key of this table and foreign keys 'user_id' and 'comment_id' reference the 'user_id' and 'comment_id' in the 'user' and 'comment' tables respectively.
The 'log' table represents system operations, with columns for 'operation_id', 'operation_type', 'operation_time', 'user_id', 'operation_object_id', and 'operation_content'. The 'operation_id' is the primary key of this table and a foreign key 'user_id' references the 'user_id' in the 'user' table. The 'user' table is the referential integrity entity, ensuring that if a user is deleted, all associated data in the 'article', 'comment', 'comment_like', and 'log' tables will be deleted as well due to the CASCADE delete rule.
