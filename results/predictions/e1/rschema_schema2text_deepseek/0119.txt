The database schema named 'rschema_0119' consists of four tables: 'User', 'Indicator', 'User_assigned_indicator', and 'Indicator_data_record'.
The 'User' table is used to store information about users, including their age, email, gender, name, phone number, and unique user ID. Each column is of the appropriate data type, ensuring domain integrity. The User_ID is the primary key, ensuring entity integrity.
The 'Indicator' table stores information about the indicators, including the calculation method, indicator ID, description, name, target, and unit. The Indicator_ID is the primary key.
The 'User_assigned_indicator' table is a junction table that links the 'User' and 'Indicator' tables. It stores information about which user has been assigned which indicator, along with the allocation time. The combination of User_ID, Indicator_ID, and Allocation_time forms the primary key, ensuring entity integrity. The Indicator_ID and User_ID are foreign keys referencing the Indicator and User tables respectively.
Finally, the 'Indicator_data_record' table stores data records for each indicator. It includes information about the improvement relative to the last record, the indicator ID, the recorded indicator value, remarks, submission record time, and the user ID. The combination of User_ID, Indicator_ID, and Submission_record_time forms the primary key, ensuring entity integrity. The Indicator_ID and User_ID are foreign keys referencing the Indicator and User tables respectively.
This schema ensures referential integrity by ensuring that the foreign keys in the 'User_assigned_indicator' and 'Indicator_data_record' tables reference the primary keys in the 'User' and 'Indicator' tables respectively.
