The database schema named 'rschema_0123' contains six tables: Customer, Supplier, Product, Staff, Purchase_from_Supplier, and Sales_Product.
The Customer table represents customers of a retail store. It has columns for Address, Contact, Gender, ID, and Name. The data type for each column is VARCHAR for the Name and Contact fields, and INTEGER for the ID field. The ID field is the primary key of the table.
The Supplier table also represents suppliers of a retail store. It has columns for Address, Contact, ID, and Name. The data type for each column is VARCHAR for the Name and Contact fields, and INTEGER for the ID field. The ID field is the primary key of the table.
The Product table represents the products sold by the retail store. It has columns for Description, ID, Inventory_Quantity, and Name. The data type for each column is VARCHAR for the Name and Description fields, and INTEGER for the ID and Inventory_Quantity fields. The ID field is the primary key of the table.
The Staff table represents the staff members of the retail store. It has columns for ID, Name, Phone, and Position. The data type for each column is VARCHAR for the Name, Phone, and Position fields, and INTEGER for the ID field. The ID field is the primary key of the table.
The Purchase_from_Supplier table represents the purchases made by the store from suppliers. It has columns for Operator_ID, Product_ID, Purchase_Product_Unit_Price, Purchase_Quantity, Purchase_Time, and Supplier_ID. The data type for each column is INTEGER for the Operator_ID, Product_ID, and Supplier_ID fields, and FLOAT for the Purchase_Product_Unit_Price field. The Supplier_ID and Product_ID fields together form the primary key of the table. The Operator_ID and Product_ID fields are foreign keys referencing the Staff and Product tables respectively.
Finally, the Sales_Product table represents the sales made by the store to customers. It has columns for Customer_ID, Operator_ID, Product_ID, Quantity_of_Sales_Product, Sales_Time, and Unit_Price_of_Sales_Product. The data type for each column is INTEGER for the Customer_ID, Operator_ID, and Product_ID fields, and FLOAT for the Unit_Price_of_Sales_Product field. The Product_ID, Customer_ID, and Sales_Time fields together form the primary key of the table. The Customer_ID, Operator_ID, and Product_ID fields are foreign keys referencing the Customer, Staff, and Product tables respectively.
