The database schema named "rschema_0124" consists of three tables: User, User_Follow, and User_Post.
The User table represents the user of the social media platform. It contains five columns: Email (a string of up to 255 characters), Password (also a string of up to 255 characters), Phone (a string of up to 255 characters), Registration_Time (a datetime field to record the user's registration time), and User_ID (an integer primary key).
The User_Follow table is used to track the relationship between users. It contains three columns: Follow_Time (a datetime field to record the follow time), Followed_ID (an integer field representing the ID of the user being followed, which is a foreign key referencing User_ID in the User table), and Follower_ID (an integer field representing the ID of the user who is following, also a foreign key referencing User_ID in the User table).
The User_Post table represents the posts made by users. It contains four columns: Post_Content (a string of up to 255 characters), Post_ID (an integer primary key), Post_Time (a datetime field to record the post time), and User_ID (an integer field representing the ID of the user who made the post, which is a foreign key referencing User_ID in the User table).
This schema ensures referential integrity by enforcing foreign key constraints. When a user is deleted from the User table, the corresponding entries in the User_Follow and User_Post tables will be automatically deleted due to the CASCADE delete rule.
