The database schema named 'rschema_0125' contains three tables: 'page', 'comment', and 'version_record'.
The 'page' table represents a collection of web pages. It has five columns: 'page_id', 'edit_status', 'visibility_status', 'active_version_number', and 'page_id' is the primary key.
The 'comment' table is used to store user comments. It has four columns: 'comment_id', 'belonging_page', 'reply_comment', 'sending_user', and 'comment_id' is the primary key. The 'belonging_page' and 'reply_comment' columns are foreign keys that reference the 'page' and 'comment' tables respectively. The 'comment' table has two cascade delete and update rules.
The 'version_record' table is used to store version information of web pages. It has four columns: 'page_number', 'version_number', 'image_url', and 'description_information'. 'page_number' is a foreign key that references the 'page' table. The 'version_record' table also has cascade delete and update rules.
All columns in all tables allow null values, and they have the default charset of 'utf8mb3'. The tables are created using the InnoDB engine.
