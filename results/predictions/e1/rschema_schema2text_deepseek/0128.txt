The database schema named 'rschema_0128' contains three tables: 'task_execution_record', 'task_parameter', and 'task_batch'.
The 'task_execution_record' table is used to store records of task executions. It contains columns for 'execution_id', 'task_name', 'start_time', 'end_time', 'exit_code', 'exit_message', 'error_message', 'last_update_time', 'external_execution_id', 'parent_task_execution_id', and 'batch_id'. The 'execution_id' column is the primary key and it references 'batch_id' and 'external_execution_id' in the 'task_batch' table, and 'parent_task_execution_id' in the 'task_execution_record' table. The foreign key constraints are set to ON DELETE CASCADE and ON UPDATE CASCADE, which means that when a record in the 'task_batch' or 'task_execution_record' table is deleted or updated, the corresponding records in the 'task_execution_record' table will also be deleted or updated.
The 'task_parameter' table is used to store parameters of task executions. It contains columns for 'execution_id', 'parameter_name', and 'parameter_value'. The 'execution_id' and 'parameter_name' columns form the primary key and it references 'execution_id' in the 'task_execution_record' table. The foreign key constraint is set to ON DELETE CASCADE and ON UPDATE CASCADE, which means that when a record in the 'task_execution_record' table is deleted or updated, the corresponding records in the 'task_parameter' table will also be deleted or updated.
The 'task_batch' table is used to store batch information. It contains columns for 'batch_id', 'batch_name', 'start_time', and 'end_time'. The 'batch_id' column is the primary key. The 'batch_id' in the 'task_execution_record' table references this 'batch_id'.
All columns allow null values and have a default value of an empty string. The database engine is InnoDB and the default character set is utf8mb3.
