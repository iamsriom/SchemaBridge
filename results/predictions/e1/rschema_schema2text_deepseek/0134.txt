The database schema named rschema_0134 consists of four tables: Users, Houses, Demands, and Orders.
The Users table is used to store user information. It includes columns for Email, Password, Phone, User_ID (which is the primary key), User_Role, and Username.
The Houses table is used to store information about properties. It includes columns for Landlord_ID (which is not null), Property_Description, Property_Facilities, Property_ID (which is the primary key), Property_Location, Property_Price, Property_Title, Property_Type, and Publisher. The Landlord_ID is a foreign key referencing the User_ID in the Users table.
The Demands table is used to store information about user demands. It includes columns for Demand_Budget, Demand_Description, Demand_ID (which is the primary key), Demand_Location, Demand_Title, Demand_Type, and User_ID (which is not null and is a foreign key referencing the User_ID in the Users table).
Finally, the Orders table is used to store information about orders. It includes columns for Lease_End_Date, Lease_Start_Date, Order_ID (which is the primary key), Order_Price, Order_Status, Payment_Status, Property_ID (which is not null and is a foreign key referencing the Property_ID in the Houses table), and User_ID (which is not null and is a foreign key referencing the User_ID in the Users table).
This schema ensures that the data is properly related and ensures integrity by enforcing primary and foreign key constraints, and by maintaining referential integrity.
