The database schema named rschema_0136 consists of four tables: student, course, teacher, and course_selection.
The student table represents a collection of students, with each student identified by a unique student_id. The name, gender, birthdate, and class of each student are also recorded. The student_id is the primary key for this table.
The course table represents a collection of courses, with each course identified by a unique course_id. The name and instructor of each course are also recorded. The course_id is the primary key for this table, and the instructor is a foreign key referencing the teacher_id in the teacher table. The deletion and update operations on the course table are set to cascade, meaning that if a course is deleted or updated, the corresponding records in the course_selection table will also be deleted or updated.
The teacher table represents a collection of teachers, with each teacher identified by a unique teacher_id. The name of each teacher is also recorded. The teacher_id is the primary key for this table.
The course_selection table represents the selection of courses by students. It contains two foreign keys: student_id and course_id, which reference the student_id and course_id in the student and course tables respectively. The grade of each course selection is also recorded. The combination of course_id and student_id forms the primary key for this table. The deletion and update operations on the course_selection table are set to cascade, meaning that if a student or a course is deleted or updated, the corresponding records in the course_selection table will also be deleted or updated.
