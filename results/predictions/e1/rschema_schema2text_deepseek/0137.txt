The database schema named 'rschema_0137' contains four tables: User, Product, Order, and Shopping_Cart.
The User table represents a user of the system and contains information such as the user's email, password, registration time, unique user ID, and username. The User_ID is the primary key of this table.
The Product table represents a product in the system and contains information such as the discounted price, original price, unique product ID, and product name. The Product_ID is the primary key of this table.
The Order table represents an order made by a user in the system. It contains information such as the amount paid, order number, order status, order time, payment time, shipping address, and a foreign key User_ID referencing the User table. The Order_Number is the primary key of this table.
The Shopping_Cart table represents a shopping cart of a user. It contains information such as the discount amount, product ID, product quantity, total amount, and a foreign key User_ID referencing the User table. The combination of User_ID and Product_ID forms the primary key of this table. The foreign key Product_ID references the Product table.
All columns in all tables allow null values except for the foreign keys. There are no default values specified. The primary keys enforce entity integrity by uniquely identifying each record in their respective tables. The foreign keys enforce referential integrity by ensuring that the values in the foreign key columns of a child table match the values in the primary key column of a parent table.
The database schema is designed to support a wide range of operations, including user registration, product management, order placement, and shopping cart functionality.
