The database schema named 'rschema_0140' contains five tables: Product, Supplier, Staff, Customer, and Supplier_product.
The Product table represents the inventory of products in the store. It includes columns for Inventory_quantity (an integer representing the number of units in stock), Price (a float representing the price of each product), Product_ID (an integer acting as the primary key), Product_name (a string representing the name of the product), and Supplier (a string representing the supplier of the product).
The Supplier table represents the suppliers of products. It includes columns for Address (a string representing the supplier's address), Name (a string representing the supplier's name), and Supplier_ID (an integer acting as the primary key).
The Staff table represents the employees of the store. It includes columns for Department (a string representing the department the employee works in), Employee_ID (an integer acting as the primary key), Employment_status (a string representing the employee's employment status), Name (a string representing the employee's name), and Position (a string representing the employee's position).
The Customer table represents the customers of the store. It includes columns for Customer_ID (an integer acting as the primary key) and Name (a string representing the customer's name).
The Supplier_product table represents the relationship between suppliers and products. It includes columns for Product_ID and Supplier_ID, which are foreign keys referencing the Product and Supplier tables respectively. The combination of these two columns forms the primary key of this table.
This schema ensures referential integrity by enforcing foreign key constraints. When a product or supplier is deleted, the corresponding entries in the Supplier_product table will be automatically deleted to maintain data integrity.
