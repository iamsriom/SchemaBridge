The database schema named 'rschema_0144' consists of seven tables.
The 'Course' table is used to store information about the courses offered at the school. It includes columns for Class_time (a datetime field), Classroom (a varchar field), Course_ID (an integer primary key), Course_name (a varchar field), and Credits (a float field).
The 'Class' table is used to store information about the classes. It includes columns for Class_ID (an integer primary key), Class_name (a varchar field), and Specialized_direction (a varchar field).
The 'School' table is used to store information about the school. It includes columns for Address (a varchar field), Contact_number (a varchar field), Name (a varchar field), and School_ID (an integer primary key).
The 'Student' table is used to store information about the students. It includes columns for Age (an integer field), Class (an integer field that cannot be null), Gender (a varchar field), Major (a varchar field), Name (a varchar field), and Student_ID (an integer primary key). The Class field is a foreign key referencing the Class table.
The 'Teacher' table is used to store information about the teachers. It includes columns for Age (an integer field), Gender (a varchar field), Major (a varchar field), Name (a varchar field), Professional_title (a varchar field), School_ID (an integer field that cannot be null), and Teacher_ID (an integer primary key). The School_ID field is a foreign key referencing the School table.
The 'Student_course' table is used to store information about which courses each student is enrolled in. It includes columns for Course_ID (an integer field that cannot be null), Score (an integer field), and Student_ID (an integer field that cannot be null). Both Course_ID and Student_ID are foreign keys referencing the Course and Student tables respectively.
The 'Teacher_course' table is used to store information about which courses each teacher is teaching. It includes columns for Course_ID (an integer field that cannot be null), and Teacher_ID (an integer field that cannot be null). Both Course_ID and Teacher_ID are foreign keys referencing the Course and Teacher tables respectively.
