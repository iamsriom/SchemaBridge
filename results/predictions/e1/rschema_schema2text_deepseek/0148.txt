The database schema named 'rschema_0148' consists of 6 tables. The tables are College, Major, Teacher, Student, Course, and Student_Course_Selection.
The College table represents the primary information about the colleges. It has a College_ID as the primary key and College_Name as a variable character field.
The Major table represents the majors offered by the colleges. It has a College_ID as a foreign key referencing the College table, Major_ID as the primary key, and Major_Name as a variable character field.
The Teacher table represents the teachers in the colleges. It has a College_ID as a foreign key referencing the College table, Contact_Information, Gender, Hire_Date, Position, Teacher_ID as the primary key, and Teacher_Name as a variable character field.
The Student table represents the students in the colleges. It has Gender, Major_ID as a foreign key referencing the Major table, Name, and Student_ID as the primary key.
The Course table represents the courses offered by the colleges. It has Class_Hours, Course_ID as the primary key, Course_Name, Credit, Major_ID and Teacher_ID as foreign keys referencing the Major and Teacher tables respectively.
The Student_Course_Selection table represents the course selections made by the students. It has Course_ID as a foreign key referencing the Course table, Course_Selection_Time, Grade, and Student_ID as the primary key. It also has composite primary key consisting of Student_ID and Course_ID.
All tables allow null values except for the ones that have NOT NULL constraint, which ensures data integrity. The foreign keys ensure referential integrity, meaning that the data in the foreign key columns of one table is related to the primary key of another table.
