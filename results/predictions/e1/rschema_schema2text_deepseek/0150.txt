The database schema named 'rschema_0150' consists of 9 tables. The 'Supplier' table is used to store information about suppliers, including their address, phone number, and unique supplier ID. The 'Project' table stores information about projects, including the budget, project ID, and start date. The 'Part' table contains information about parts, including their description, name, part ID, specification, and unit price.
The 'Supplier_Supply_Project' table is a junction table that links suppliers and projects, with each record indicating a supplier's supply of a project. It includes start and end times, as well as foreign keys referencing the 'Project' and 'Supplier' tables.
The 'Supplier_Supply_Part' table is another junction table that links suppliers and parts, with each record indicating a supplier's supply of a part. It includes the supply quantity and foreign keys referencing the 'Part' and 'Supplier' tables.
The 'Project_Requires_Parts' table is a junction table that links projects and parts, with each record indicating a project's requirement for a part. It includes the quantity and foreign keys referencing the 'Part' and 'Project' tables.
The 'Warehouse' table stores information about warehouses, including area, person in charge, phone number, and warehouse ID. The 'Employee' table stores information about employees, including age, employee ID, job title, name, and work location.
The 'Warehouse_Inventory_Parts' table is a junction table that links warehouses and parts, with each record indicating the inventory quantity of a part in a warehouse. It includes foreign keys referencing the 'Part' and 'Warehouse' tables. This schema ensures referential integrity by enforcing foreign key constraints, which prevent invalid data from being entered into the database.
