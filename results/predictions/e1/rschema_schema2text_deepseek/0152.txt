The database schema named 'rschema_0152' consists of four tables: User, Post, Image, and User_post_comment.
The User table represents a user in the social media platform. It has columns for Age, Gender, Interests, Name, Occupation, Password, Personal_profile, User_ID (as the primary key), and Username. All columns allow null values.
The Post table is used to store information about posts made by users. It has columns for Description, Post_ID (as the primary key), and Title.
The Image table contains information about images associated with posts. It has columns for Image_ID (as the primary key), Image_URL, and Post_ID. The Post_ID column is a foreign key referencing the Post table.
The User_post_comment table is used to store comments made by users on posts. It has columns for Comment_content, Comment_time, Post_ID, and User_ID. Both Post_ID and User_ID are foreign keys referencing the Post and User tables respectively. The combination of User_ID, Post_ID, and Comment_time forms the primary key of this table.
The User_post_comment table has update and delete rules set to CASCADE, meaning that if a record in the User or Post table is updated or deleted, the corresponding records in the User_post_comment table will also be updated or deleted.
