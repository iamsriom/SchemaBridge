The database schema for the database 'rschema_0155' consists of 6 tables: 'user', 'admin', 'product', 'order', 'shipping_address_record', and 'order_detail'.
The 'user' table represents a user of the system, storing information about each user such as their unique user_id, username, password, email, and phone number. The user_id is the primary key for this table.
The 'admin' table stores information about the administrators of the system. It includes the admin_id, admin_account, password, and creation_time. The admin_id is the primary key for this table.
The 'product' table represents the products available for purchase in the system. It includes product_id, category, name, description, price, and inventory. The product_id is the primary key for this table.
The 'order' table records all the orders made by users. It includes order_id, ordering_user (a foreign key referencing the user_id in the user table), order_time, and order_status. The order_id is the primary key for this table, and the ordering_user field is a foreign key referencing the user table.
The 'shipping_address_record' table stores the shipping addresses of users. It includes user_id (a foreign key referencing the user_id in the user table), creation_time, and shipping_address. The combination of user_id and creation_time is the primary key for this table.
Finally, the 'order_detail' table records the details of each order, including the order_id (a foreign key referencing the order_id in the order table), product_id (a foreign key referencing the product_id in the product table), and quantity. The combination of product_id and order_id is the primary key for this table. All foreign key references are set to CASCADE on delete and update, meaning that if a referenced record in the referenced table is deleted or updated, the corresponding records in this table will also be deleted or updated.
