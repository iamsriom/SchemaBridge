The database schema named 'rschema_0158' consists of seven tables. The tables are described as follows:
1. **Role**: This table contains information about the roles that users can take in the system. The table has two columns, 'Role_ID' which is an integer and serves as the primary key, and 'Role_Name' which is a variable character field of maximum length 255.
2. **Category**: This table contains information about the categories of questions. It has two columns, 'Category_ID' which is an integer and serves as the primary key, and 'Category_Name' which is a variable character field of maximum length 255.
3. **User**: This table contains information about the users of the system. It has five columns, 'Contact_Information', 'Name', 'Role_ID', 'User_ID', and 'Role_ID' is a foreign key referencing the 'Role' table.
4. **Question**: This table contains information about the questions. It has seven columns, 'Category_ID', 'Content', 'Correct_Answer', 'Difficulty_Level', 'Explanation', 'Options', and 'Question_ID'. The 'Category_ID' is a foreign key referencing the 'Category' table.
5. **Exam**: This table contains information about the exams. It has six columns, 'Creator_ID', 'Description', 'Exam_ID', 'Exam_Name', 'Status', and 'Time_Range'. The 'Creator_ID' is a foreign key referencing the 'User' table.
6. **Exam_Question**: This table contains information about which questions are part of which exams. It has four columns, 'Exam_ID', 'Question_ID', 'Sequence', and 'Exam_ID' and 'Question_ID' are foreign keys referencing the 'Exam' and 'Question' tables respectively.
7. **User_Answer_Sheet**: This table contains information about the answers submitted by the users. It has five columns, 'Exam_ID', 'Score', 'Student_ID', 'Submission_Time', and 'Exam_ID' and 'Student_ID' are foreign keys referencing the 'Exam' and 'User' tables respectively.
All tables allow null values except for the 'Role_ID' in the 'User' table, 'Category_ID' in the 'Question' table, and 'Creator_ID' in the 'Exam' table. The primary keys are 'Role_ID', 'Category_ID', 'User_ID', 'Question_ID', 'Exam_ID', and 'Student_ID' respectively. The foreign keys enforce referential integrity by ensuring that the values in the foreign key columns match the values in the primary key columns of the referenced tables.
