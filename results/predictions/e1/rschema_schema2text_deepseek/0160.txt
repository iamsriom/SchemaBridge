The database schema for the database named rschema_0160 consists of seven tables. The tables are user, countryside_scenic_spot, agricultural_product, scenic_spot_comment, product_comment, order, and order_detail.
The user table represents the users of the system. It has three columns: user_id, username, and password. The user_id is the primary key of this table.
The countryside_scenic_spot table represents the countryside scenic spots. It has five columns: scenic_spot_id, name, location, image_url, and main_scenic_spot_introduction. The scenic_spot_id is the primary key of this table.
The agricultural_product table represents the agricultural products. It has three columns: product_id, product_name, and product_price. The product_id is the primary key of this table.
The scenic_spot_comment table represents the comments on the countryside scenic spots. It has four columns: scenic_spot_id, comment_content, posting_user, and comment_time. The combination of comment_time and scenic_spot_id and posting_user forms the primary key of this table. The posting_user is a foreign key referencing the user table.
The product_comment table represents the comments on the agricultural products. It has four columns: product_id, comment_content, posting_user, and posting_time. The combination of posting_time, product_id, and posting_user forms the primary key of this table. The product_id and posting_user are foreign keys referencing the agricultural_product and user tables respectively.
The order table represents the orders. It has five columns: order_id, ordering_user, order_time, order_amount, and order_status. The order_id is the primary key of this table. The ordering_user is a foreign key referencing the user table.
The order_detail table represents the details of the orders. It has three columns: order_id, product_id, and quantity. The combination of product_id and order_id forms the primary key of this table. The product_id is a foreign key referencing the agricultural_product table, and the order_id is a foreign key referencing the order table.
All columns allow null values except for the ones that are marked NOT NULL. Default values are not specified for any columns. The database schema ensures referential integrity by enforcing foreign key constraints. If a user or an agricultural product is deleted, all the associated comments and orders will be deleted due to the CASCADE delete rule. If an order or an agricultural product is updated, the associated comments and order details will be updated due to the CASCADE update rule.
