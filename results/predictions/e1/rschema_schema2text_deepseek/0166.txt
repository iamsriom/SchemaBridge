The database schema named 'rschema_0166' contains six tables: Patient, Doctor, Medical_Image, Doctor_Operation_on_Image, Doctor_Upload_Image, and Doctor_Share_Image.
The Patient table represents patient information, including Age (an integer), Contact_Information (a string of up to 255 characters), Gender (a boolean), Medical_Records (a string of up to 255 characters), Name (a string of up to 255 characters), and Patient_ID (an integer, the primary key).
The Doctor table contains information about doctors, including Contact_Information (a string of up to 255 characters), Department (a string of up to 255 characters), Doctor_ID (an integer, the primary key), and Name (a string of up to 255 characters).
The Medical_Image table contains information about medical images, including Film_Time (a datetime), Image_Data (a blob), Image_Enhancement_Information (a blob), Image_ID (an integer, the primary key), Image_Resolution (a string of up to 255 characters), and Image_Type (a string of up to 255 characters). The Patient_ID column is a foreign key referencing the Patient table.
The Doctor_Operation_on_Image table records operations performed on images, including Doctor_ID (an integer, not null), Image_ID (an integer, not null), Operation_Remarks (a string of up to 255 characters), Operation_Time (a datetime), and Operation_Type (a string of up to 255 characters). Both Doctor_ID and Image_ID are foreign keys referencing the Doctor and Medical_Image tables respectively.
The Doctor_Upload_Image table records image uploads by doctors, including Doctor_ID (an integer, not null), Image_ID (an integer, not null), Server_Path (a string of up to 255 characters), and Upload_Time (a datetime). Both Doctor_ID and Image_ID are foreign keys referencing the Doctor and Medical_Image tables respectively.
Finally, the Doctor_Share_Image table records image sharing between doctors, including Image_ID (an integer, not null), Shared_Doctor_ID (an integer, not null), Sharing_Time (a datetime), and Target_Institution (a string of up to 255 characters). Both Image_ID and Shared_Doctor_ID are foreign keys referencing the Medical_Image and Doctor tables respectively.
