The database schema named rschema_0186 consists of four tables. The Insured_Person table is used to store information about individuals insured. It includes columns for Contact_Information (a string of up to 255 characters), Date_of_Birth (a date and time), Gender (a string of up to 255 characters), Identity_Card_Number (a string of up to 255 characters), Name (a string of up to 255 characters), and Social_Security_ID (an integer) which serves as the primary key.
The Social_Security_Type table stores information about different types of social security. It includes columns for Description (a string of up to 255 characters), Name (a string of up to 255 characters), and Type_ID (an integer) which serves as the primary key.
The Insured_Person_Payment table stores information about payments made by individuals insured. It includes columns for Payer (a string of up to 255 characters), Payment_Amount (a float), Payment_ID (an integer), Payment_Time (a date and time), Social_Security_ID (an integer, not null), Type_ID (an integer, not null), and serves as the primary key on Payment_ID, Social_Security_ID, and Type_ID. It has foreign key relationships with the Insured_Person table on Social_Security_ID and the Social_Security_Type table on Type_ID.
Finally, the Insured_Person_Receipt table stores information about receipts received by individuals insured. It includes columns for Receipt_Amount (a string of up to 255 characters), Receipt_ID (an integer), Receipt_Time (a date and time), Recipient (a string of up to 255 characters), Social_Security_ID (an integer, not null), and Type_ID (an integer, not null), and serves as the primary key on Receipt_ID, Social_Security_ID, and Type_ID. It also has foreign key relationships with the Insured_Person table on Social_Security_ID and the Social_Security_Type table on Type_ID.
