The database schema "rschema_0187" consists of five tables: Farm, Crop, Plot, Planting_record, and Harvest_record.
The Farm table represents the information about the farms. It has columns for Address, Contact_information, Farm_ID (as the primary key), and Owner_name and Owner_type.
The Crop table contains information about the crops. It has columns for Crop_ID (as the primary key), Crop_name, Growth_cycle, Suitable_climate_conditions, and Suitable_soil_type.
The Plot table holds information about the plots. It has columns for Area, Current_status, Farm_ID (with a foreign key reference to the Farm table), Plot_ID (as the primary key), and Soil_type.
The Planting_record table records the details of crop planting. It has columns for Crop_ID (with a foreign key reference to the Crop table), Expected_harvest_time, Operator, Planting_quantity, Planting_time, and Plot_ID (with a foreign key reference to the Plot table). The primary key for this table is a combination of Plot_ID and Crop_ID along with Planting_time.
Lastly, the Harvest_record table records the details of crop harvest. It has columns for Crop_ID (with a foreign key reference to the Crop table), Harvest_quantity, Harvest_time, Operator, and Plot_ID (with a foreign key reference to the Plot table). The primary key for this table is a combination of Plot_ID and Crop_ID along with Harvest_time. All these tables are interconnected, ensuring referential integrity and maintaining the relationships between the data.
