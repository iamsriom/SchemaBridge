The database schema named 'rschema_0194' consists of five tables: 'Supplier', 'Project', 'Material', 'Supplier_Credit_Assessment', and 'Procurement_Record'.
The 'Supplier' table represents suppliers, with columns for 'Address', 'Email', 'Name', 'Supplier_ID', and 'Telephone'. Each of these columns does not allow null values.
The 'Project' table represents projects, with columns for 'Actual_Completion_Date', 'Expected_Completion_Date', 'Project_Budget', 'Project_ID', 'Project_Location', 'Project_Name', and 'Start_Date'. All columns allow null values.
The 'Material' table represents materials, with columns for 'Material_Description', 'Material_ID', and 'Material_Name'. All columns allow null values.
The 'Supplier_Credit_Assessment' table represents assessments of suppliers' creditworthiness, with columns for 'Assessment_Content', 'Assessment_Date', 'Assessment_ID', 'Assessment_Score', and 'Supplier_ID'. The 'Supplier_ID' column is a foreign key referencing the 'Supplier' table.
Finally, the 'Procurement_Record' table represents procurement records, with columns for 'Material_ID', 'Material_Quantity', 'Material_Unit_Price', 'Procurement_Record_ID', 'Project_ID', 'Purchase_Date', 'Supplier_ID', and 'Total_Price'. The 'Project_ID' and 'Supplier_ID' columns are foreign keys referencing the 'Project' and 'Supplier' tables respectively.
This schema ensures referential integrity by enforcing foreign key constraints between the tables. It also ensures entity integrity by enforcing primary key constraints on each table and unique constraints on the 'Supplier_ID' column in the 'Supplier_Credit_Assessment' table.
