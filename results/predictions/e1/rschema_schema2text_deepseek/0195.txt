The database schema named rschema_0195 consists of four tables: Property, Sales_Personnel, Client, and Sales_Record.

The Sales_Personnel table represents sales personnel. It has columns for Commission_Rate (a float), Contact_Phone (an integer), Employee_ID (an integer that serves as the primary key), and Name (a string of up to 255 characters).
The Client table represents clients. It has columns for Address (a string of up to 255 characters), Client_ID (an integer that serves as the primary key), Contact_Phone (an integer), and Name (a string of up to 255 characters).
The Sales_Record table represents sales records. It has columns for Client_ID (an integer that cannot be null), Property_ID (an integer that cannot be null), Sale_Date (a datetime), Sale_Price (a float), and Sales_Personnel_ID (an integer that cannot be null). The primary key of this table is a composite of Property_ID, Employee_ID, and Client_ID. There are three foreign keys: Client_ID references the Client table, Property_ID references the Property table, and Sales_Personnel_ID references the Sales_Personnel table. The schema ensures referential integrity by enforcing the constraints on foreign keys.
