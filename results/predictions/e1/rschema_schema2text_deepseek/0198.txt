The database schema named 'rschema_0198' consists of four tables: Community_information, Maintenance_staff_information, Property_information, and Maintenance_task.
The Community_information table holds information about different communities. It includes a Community_ID as the primary key, Community_name, Location, and Property_manager.
The Maintenance_staff_information table contains information about the maintenance staff. It includes Contact_information, Maintenance_staff_ID as the primary key, Name, and Position.
The Property_information table holds information about the properties. It includes Address, Area, Community_ID (which is a foreign key referencing the Community_information table), Maintenance_status, and Property_ID as the primary key.
Finally, the Maintenance_task table contains information about the maintenance tasks. It includes Maintenance_content, Maintenance_cost, Maintenance_staff_ID (which is a foreign key referencing the Maintenance_staff_information table), Maintenance_time, and Property_ID (which is a foreign key referencing the Property_information table). The combination of Property_ID and Maintenance_staff_ID, along with Maintenance_time, forms the primary key for this table.
