The database schema named rschema_0199 consists of four tables: store, product, sales_record, and store_performance.
The store table represents a store with various attributes such as store number, name, address, and manager. The primary key for this table is the store number.
The product table holds information about the products, including product number, name, model, barcode, and price. The primary key for this table is the product number.
The sales_record table records sales transactions. It includes store number, product number, sales time, sales quantity, sales amount, and sales personnel. The primary key for this table is a composite of sales time, product number, and store number. It has two foreign key constraints: product_number references the product table, and store_number references the store table. Both are set to CASCADE on delete and update.
Finally, the store_performance table records the performance of the stores. It includes store number, sales amount, and customer satisfaction. The primary key for this table is the store number. It also has a foreign key constraint, store_number, which references the store table. This constraint is set to CASCADE on delete and update.
