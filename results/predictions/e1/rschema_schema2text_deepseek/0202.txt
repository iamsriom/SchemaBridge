The database schema named 'rschema_0202' consists of three tables: 'procured_product', 'supplier', and 'product'.
The 'procured_product' table is used to store information about procured products. It contains columns such as 'procured_product_id', 'supplier_id', 'procurement_time', 'procurement_quantity', 'total_procurement_price', 'payment_method', 'payment_status', 'delivery_address', 'recipient_name', and 'recipient_phone'. The primary key of this table is a composite key consisting of 'procured_product_id', 'procurement_time', and 'supplier_id'.
The 'procured_product_ibfk_procured_product_id' foreign key references the 'supplier_id' in the 'schema_3' table. Similarly, the 'procured_product_ibfk_supplier_id' foreign key references the 'product_id' in the 'schema_4' table. The ON DELETE CASCADE and ON UPDATE CASCADE options are set for these foreign keys, meaning that when a record in the referenced table is deleted or updated, the corresponding records in the 'procured_product' table will also be deleted or updated.
The 'supplier' table stores information about suppliers. It includes columns like 'supplier_id', 'supplier_name', 'supplier_address', 'historical_procurement_quantity', 'historical_procurement_amount', 'credit_rating', 'contact_person', 'phone', 'email', 'fax', and 'company_website'. The primary key of this table is 'supplier_id'.
The 'product' table contains information about products. It includes columns like 'product_id', 'product_name', 'product_model', 'product_price', 'product_category', 'shelf_life', and 'stock_quantity'. The primary key of this table is 'product_id'.
This schema ensures data integrity by enforcing primary and foreign key constraints, and by setting up cascading delete and update operations for the foreign keys. It also allows for efficient data retrieval and manipulation.
