The database schema named 'rschema_0203' consists of seven tables. The tables are:
1. `promotion_activity`: This table represents the promotion activities. It has four columns: `activity_id`, `activity_name`, `activity_time`, and `discount`. The `activity_id` is the primary key of this table.
2. `store`: This table represents the stores. It has three columns: `store_id`, `store_name`, and `store_address`. The `store_id` is the primary key of this table.
3. `product`: This table represents the products. It has five columns: `product_id`, `product_name`, `product_model`, `product_barcode`, and `product_price`. The `product_id` is the primary key of this table.
4. `promotion_effect_record`: This table represents the record of promotion effects. It has five columns: `promotion_effect_record_id`, `activity_id`, `sales_amount`, `sales_quantity`, and `participating_member_count`. The `promotion_effect_record_id` is the primary key of this table. The `activity_id` is a foreign key referencing the `promotion_activity` table.
5. `promotion_effect_evaluation`: This table represents the evaluation of promotion effects. It has three columns: `activity_id`, `sales_growth_rate`, and `customer_engagement`. The `activity_id` is the primary key of this table. The `activity_id` is a foreign key referencing the `promotion_activity` table.
6. `promotion_activity_participating_store`: This table represents the participating stores in promotion activities. It has two columns: `activity_id` and `store_id`. The combination of `store_id` and `activity_id` is the primary key of this table. The `activity_id` and `store_id` are foreign keys referencing the `promotion_activity` and `store` tables respectively.
7. `promotion_activity_participating_product`: This table represents the participating products in promotion activities. It has three columns: `activity_id`, `product_id`, and `discount`. The combination of `product_id` and `activity_id` is the primary key of this table. The `activity_id` and `product_id` are foreign keys referencing the `promotion_activity` and `product` tables respectively.
All columns allow null values and have default charset as utf8mb3. The database engine is InnoDB. The schema is designed to maintain referential integrity by setting up foreign key constraints to ensure the consistency of data. The delete and update rules are set to CASCADE, which means that if a record in the referenced table is deleted or updated, the corresponding records in the referencing table will also be deleted or updated.
