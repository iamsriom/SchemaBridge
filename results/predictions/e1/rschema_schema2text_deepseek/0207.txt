The database schema named 'rschema_0207' contains 4 tables. The 'Facility' table is used to store information about various facilities. It includes columns for Creation_Date, Facility_ID, Facility_Location, Facility_Name, and Facility_Responsible_Person. The primary key for this table is Facility_ID. The 'User' table stores user information, including User_ID and User_Name. The 'Facility_Maintenance' table records the maintenance activities for each facility. It includes columns for Facility_ID, Maintenance_Content, Maintenance_Cost, Maintenance_Time, and User_ID. The primary key for this table is a combination of Facility_ID, User_ID, and Maintenance_Time. The 'Facility_Usage' table records the usage of each facility. It includes columns for Facility_ID, Usage_Frequency, Usage_Time, User_Feedback, and User_ID. The primary key for this table is a combination of Facility_ID, User_ID, and Usage_Time. Both 'Facility_Maintenance' and 'Facility_Usage' tables have foreign keys referencing the 'Facility' and 'User' tables respectively. This schema ensures data integrity by enforcing primary and foreign key constraints, and referential integrity by maintaining the consistency of related data across tables.
```plaintext
CREATE TABLE Facility (
Creation_Date DATETIME,
Facility_ID INTEGER PRIMARY KEY,
Facility_Location VARCHAR(255),
Facility_Name VARCHAR(255),
Facility_Responsible_Person VARCHAR(255)
);
CREATE TABLE User (
User_ID INTEGER PRIMARY KEY,
User_Name VARCHAR(255)
);
CREATE TABLE Facility_Maintenance (
Facility_ID INTEGER NOT NULL,
Maintenance_Content VARCHAR(255),
Maintenance_Cost FLOAT,
Maintenance_Time DATETIME,
User_ID INTEGER NOT NULL,
PRIMARY KEY (Facility_ID, User_ID, Maintenance_Time),
FOREIGN KEY (Facility_ID) REFERENCES Facility(Facility_ID),
FOREIGN KEY (User_ID) REFERENCES User(User_ID)
);
CREATE TABLE Facility_Usage (
Facility_ID INTEGER NOT NULL,
Usage_Frequency FLOAT,
Usage_Time DATETIME,
User_Feedback VARCHAR(255),
User_ID INTEGER NOT NULL,
PRIMARY KEY (Facility_ID, User_ID, Usage_Time),
FOREIGN KEY (Facility_ID) REFERENCES Facility(Facility_ID),
FOREIGN KEY (User_ID) REFERENCES User(User_ID)
);
```
This schema allows for a detailed tracking of facility usage and maintenance activities, facilitating efficient management and maintenance of facilities.
