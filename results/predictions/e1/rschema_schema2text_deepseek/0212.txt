The database schema named 'rschema_0212' contains four tables: Customer, Branch, Vehicle, and Customer_vehicle_rental.
The Customer table represents a customer of a car rental service. It has a primary key 'Customer_ID' which is an integer. The 'Email', 'Name', and 'Phone' columns store the customer's email address, name, and phone number, respectively.
The Branch table represents a branch of the car rental service. It has a primary key 'Branch_ID' which is an integer. The 'Address', 'Branch_income', 'Manager_name', and 'Name' columns store the branch's address, income, manager's name, and name, respectively.
The Vehicle table represents a vehicle available for rental. It has a primary key 'Vehicle_ID' which is an integer. The 'Branch_ID', 'License_plate', 'Model', 'Rental_rate', and 'Year' columns store the branch ID, license plate number, model, rental rate, and manufacturing year of the vehicle, respectively. The 'Branch_ID' column is a foreign key referencing the 'Branch_ID' in the Branch table.
Lastly, the Customer_vehicle_rental table represents a rental transaction. It has a composite primary key 'Customer_ID' and 'Vehicle_ID' which are foreign keys referencing the 'Customer_ID' and 'Vehicle_ID' in the Customer and Vehicle tables, respectively. The 'Rental_fee', 'Rental_time', and 'Return_time' columns store the rental fee, rental time, and return time of the rental, respectively.
This schema ensures entity integrity by ensuring each table has a primary key and foreign key relationship with the other tables. It also ensures referential integrity by maintaining the relationship between the tables and enforcing the rules of foreign key constraints.
