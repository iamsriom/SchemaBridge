The database schema named "rschema_0219" consists of five tables.
The "Card" table represents a collection of cards, each with attributes such as Artist, Effect, Endurance, ID, Intelligence, Name, Power, and Type. The ID is the primary key for this table.
The "Card_Collection" table represents a collection of cards, with attributes such as ID and Name. The ID is the primary key for this table.
The "User" table represents a collection of users, with attributes such as Email, Password, Phone, ID, and Username. The ID is the primary key for this table.
The "Card_Collection_Association" table represents the association between cards and collections. It has attributes such as Card_ID, Rarity, Collection_ID, and Collection_Number. The combination of Card_ID and Collection_ID is the primary key for this table. The Card_ID and Collection_ID are foreign keys referencing the Card and Card_Collection tables respectively.
Finally, the "User_Card_Exchange" table represents the exchange of cards between users. It has attributes such as Exchange_Time, Exchanged_Card_ID, User_1_ID, and User_2_ID. The combination of User_1_ID, User_2_ID, and Exchange_Time is the primary key for this table. The Exchanged_Card_ID, User_1_ID, and User_2_ID are foreign keys referencing the Card and User tables respectively. This schema ensures referential integrity by maintaining the relationships between tables.
