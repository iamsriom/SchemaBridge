The database schema named 'rschema_0224' contains five tables: 'user', 'task', 'task_execution_status', 'user_quote', and 'user_evaluation'.
The 'user' table represents the users of the system, with columns for 'user_id', 'user_name', 'avatar_url', 'contact_information', 'number_of_failed_tasks', and 'number_of_completed_tasks'. All these columns allow null values and have a default charset of utf8mb3. The 'user_id' is the primary key of this table.
The 'task' table represents the tasks that users can execute. It has columns for 'task_id', 'title', 'description', 'budget', 'deadline', 'category', and 'address'. Again, all these columns allow null values. The 'task_id' is the primary key of this table.
The 'task_execution_status' table represents the status of the tasks. It has columns for 'task_id' and 'task_executor'. The 'task_id' and 'task_executor' are both foreign keys referencing the 'task' and 'user' tables respectively. The primary key of this table is 'task_id'.
The 'user_quote' table represents the quotes given by users to tasks. It has columns for 'user_id', 'task_id', 'quote', and 'additional_comments'. Both 'user_id' and 'task_id' are foreign keys referencing the 'user' and 'task' tables respectively. The primary key of this table is a composite of 'user_id' and 'task_id'.
Finally, the 'user_evaluation' table represents the evaluations given by users to other users. It has columns for 'evaluation_record_id', 'evaluator', 'executor', and 'rating'. Both 'evaluator' and 'executor' are foreign keys referencing the 'user' table. The primary key of this table is 'evaluation_record_id'. All these tables have an InnoDB engine and a default charset of utf8mb3.
On delete and update operations, the CASCADE option is used to delete or update the corresponding records in the referenced table.
