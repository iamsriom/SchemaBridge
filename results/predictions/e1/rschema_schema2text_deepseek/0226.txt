The database schema named 'rschema_0226' consists of five tables: Branch, Customer, Category, Book, and Order.
The Branch table contains information about each branch with a Branch_ID as the primary key and a Location as a variable character field of maximum length 255.
The Customer table contains information about each customer with a Customer_ID as the primary key and other fields such as Email, First_Name, Last_Name, and Phone.
The Category table has a Category_ID as the primary key and a Category_Name as a variable character field of maximum length 255.
The Book table represents the books available in the store. It has a Book_ID as the primary key, Book_Name, Category_ID as a foreign key referencing the Category table, Price, and Stock_Quantity.
Finally, the Order table records each purchase made by customers. It contains Book_ID, Branch_ID, Customer_ID as foreign keys referencing the Book, Branch, and Customer tables respectively, Order_Date, Order_ID as the primary key, and Purchase_Quantity. The foreign key constraints ensure referential integrity, meaning that the data in these tables is consistent and valid.
