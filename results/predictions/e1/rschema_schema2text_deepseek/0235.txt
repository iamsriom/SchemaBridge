The database schema named 'rschema_0235' consists of six tables. The main tables are 'User', 'Product', 'Receipt', 'User_Subscribed_Products', 'User_Refunded_Products', and 'User_Purchased_Products'.
The 'User' table represents a user of the system. It contains columns for the user's email, phone number, platform, registration time, update time, user ID, and username. The user ID is the primary key of this table.
The 'Product' table represents a product in the system. It contains columns for the product's creation time, currency, description, inventory unit, platform, price, product ID, product name, and update time. The product ID is the primary key of this table.
The 'Receipt' table represents a receipt in the system. It contains columns for the receipt's creation time, hash value, receipt data, and receipt ID. The receipt ID is the primary key of this table.
The 'User_Subscribed_Products' table represents the products a user has subscribed to. It contains columns for the end date, product ID, promotional period, renewal status, start date, subscription status, subscription time, trial period, user ID, and validity type. The combination of user ID, product ID, and subscription time form the primary key of this table. The product ID is a foreign key referencing the Product table, and the user ID is a foreign key referencing the User table.
The 'User_Refunded_Products' table represents the products a user has refunded. It contains columns for the product ID, refund amount, refund date, refund status, refund time, and user ID. The combination of user ID, product ID, and refund time form the primary key of this table. The product ID is a foreign key referencing the Product table, and the user ID is a foreign key referencing the User table.
The 'User_Purchased_Products' table represents the products a user has purchased. It contains columns for the currency, hash value, order number, product ID, purchase platform, purchase price, purchase time, receipt ID, refund status, subscription status, and user ID. The combination of user ID, product ID, and order number form the primary key of this table. The product ID is a foreign key referencing the Product table, the receipt ID is a foreign key referencing the Receipt table, and the user ID is a foreign key referencing the User table.
