The database schema named 'rschema_0243' contains three tables: 'Reader', 'Book', and 'Borrowing'.
The 'Reader' table represents a collection of readers who have signed up for the library. It has five columns: 'Reader_Email' (a string of up to 255 characters), 'Reader_ID' (an integer, the primary key), 'Reader_Name' (a string of up to 255 characters), 'Reader_Phone' (a string of up to 255 characters), and 'Registration_Date' and 'Update_Time' (datetime fields).
The 'Book' table represents a collection of books in the library. It has seven columns: 'Book_Author' (a string of up to 255 characters), 'Book_ID' (an integer, the primary key), 'Book_ISBN' (a string of up to 255 characters), 'Book_Publication_Date' (a datetime field), 'Book_Stock' (an integer representing the number of copies of the book available), 'Book_Title' (a string of up to 255 characters), and 'Book_Type' (a string of up to 255 characters), and 'Update_Time' (a datetime field).
The 'Borrowing' table represents the borrowing records of books by readers. It has seven columns: 'Book_ID' (an integer, not null, foreign key referencing the 'Book' table), 'Borrow_Date' (a datetime field), 'Overdue_Fine' (a float field), 'Reader_ID' (an integer, not null, foreign key referencing the 'Reader' table), 'Renewal_Count' (an integer field), 'Return_Date' (a datetime field), and 'Reader_ID' and 'Book_ID' (both integers) together form the primary key.
This schema ensures data integrity by enforcing primary key constraints on each table, foreign key constraints on 'Book_ID' and 'Reader_ID' columns in the 'Borrowing' table, and indexing on 'Book_ID' and 'Reader_ID' columns in the 'Book' and 'Reader' tables respectively. It also ensures referential integrity by maintaining the consistency of data across related tables.
