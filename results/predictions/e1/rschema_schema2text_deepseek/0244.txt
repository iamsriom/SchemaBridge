The database schema named 'rschema_0244' consists of five tables: 'user', 'bus_route', 'station', 'announcement', and 'question'.
The 'user' table is used to store user information. It includes columns for 'account', 'password', 'name', 'phone', and 'user_role'. The 'account' column is the primary key, ensuring entity integrity as no two users can have the same account.
The 'bus_route' table is used to store bus route information. It includes columns for 'route_id', 'route_name', 'start_station', 'end_station', 'passing_stations', and 'departure_time'. The 'route_id' column is the primary key.
The 'station' table is used to store station information. It includes columns for 'station_id', 'station_name', and 'station_location'. The 'station_id' column is the primary key.
The 'announcement' table is used to store announcement information. It includes columns for 'announcement_id', 'announcement_title', 'announcement_content', 'publisher', and 'publish_time'. The 'announcement_id' column is the primary key.
The 'question' table is used to store question information. It includes columns for 'questioner_account', 'question_content', 'question_time', 'answer_content', 'responder_account', and 'answer_time'. The 'question_time' and 'questioner_account' columns form a composite primary key. The 'responder_account' and 'questioner_account' columns are foreign keys referencing the 'account' column in the 'user' table. The delete and update rules are set to cascade, meaning if a user is deleted or updated, their associated questions will also be deleted or updated.
This schema provides a comprehensive framework for managing user accounts, bus routes, stations, announcements, and questions, ensuring data integrity and consistency.
