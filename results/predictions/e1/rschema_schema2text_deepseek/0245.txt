The database schema named 'rschema_0245' consists of five tables: User, Novel, Bookshelf, Book_review, and Novel_added_to_Bookshelf.
The User table represents a collection of users, with each user identified by a unique User_ID. It contains columns for Username, Email, Password, Creation_time, and Update_time. The Username column allows null values, while Email and Password are required. The Update_time column is updated every time a user updates their information.
The Novel table contains information about novels, including Novel_ID, Novel_title, Novel_description, Author, Publication_date, Creation_time, and Update_time. The Novel_ID serves as the primary key for this table.
The Bookshelf table represents a collection of bookshelves, with each bookshelf identified by a unique Bookshelf_ID. It contains columns for User_ID and Novel_ID, both of which are foreign keys referencing the User and Novel tables respectively. The Novel_ID column cannot contain null values.
The Book_review table contains reviews for novels, with each review identified by a unique Book_review_ID. It contains columns for User_ID, Novel_ID, Rating, Review_content, and Creation_time. The User_ID and Novel_ID are foreign keys referencing the User and Novel tables respectively.
Finally, the Novel_added_to_Bookshelf table represents the relationship between novels and bookshelves. It contains columns for Novel_ID and Bookshelf_ID, both of which are foreign keys referencing the Novel and Bookshelf tables respectively. The combination of Novel_ID and Bookshelf_ID forms the primary key of this table, ensuring that a novel cannot be added to the same bookshelf more than once.
