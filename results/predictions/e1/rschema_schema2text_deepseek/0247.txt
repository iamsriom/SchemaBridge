The database schema named 'rschema_0247' consists of six tables: User, Class, Sign-in, Course, Control_Flag, and Grade.
The User table represents a collection of users, with columns for Last_Login_Time (datetime), Password (varchar with a maximum length of 255 characters), Registration_Time (datetime), Role (varchar with a maximum length of 255 characters), Student_ID (integer), and User_ID (integer) as primary keys.
The Class table contains information about classes, with columns for Class_ID (integer), Class_Name (varchar with a maximum length of 255 characters), Grade (float), and Major (varchar with a maximum length of 255 characters).
The Sign-in table records user sign-ins, with columns for IP_Address (varchar with a maximum length of 255 characters), Sign-in_Status (varchar with a maximum length of 255 characters), Sign-in_Time (datetime), and User_ID (integer). The User_ID column is the primary key and also a foreign key referencing the User table.
The Course table contains information about courses, with columns for Course_Description (varchar with a maximum length of 255 characters), Course_ID (integer), Course_Name (varchar with a maximum length of 255 characters), and Teacher_ID (integer). The Teacher_ID is a foreign key referencing the User table.
The Control_Flag table is used to control sign-in times, with columns for Sign-in_End_Time (datetime), Sign-in_Start_Time (datetime), and Teacher_ID (integer). The Teacher_ID is the primary key and a foreign key referencing the User table.
Finally, the Grade table records grades, with columns for Course_ID (integer), Final_Grade (float), Grade_ID (integer), Regular_Grade (float), Student_ID (integer), and Total_Grade (float). Both Course_ID and Student_ID are foreign keys referencing the Course and User tables respectively.
