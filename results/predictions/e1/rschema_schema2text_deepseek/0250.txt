The database schema named 'rschema_0250' contains 8 tables. The main tables are 'User', 'Product', 'Order', 'User_Shopping_Cart', 'Admin_Product_Management', 'Order_Product', 'User_Order', and 'Admin_Order_Management'.
The 'User' table represents a user of the system, with columns for the user's last login time, password, phone number, registration time, role, user ID, and username. The user ID is the primary key of this table.
The 'Product' table holds information about the products in the system, including price, product category, product description, product ID, product name, shelving time, and stock quantity. The product ID is the primary key of this table.
The 'Order' table records orders made by users. It includes columns for the delivery address, order ID, order status, order time, payment time, total amount, and user ID. The user ID is a foreign key referencing the User table, and the order ID is the primary key of this table.
The 'User_Shopping_Cart' table maintains a shopping cart for each user. It includes columns for product ID, quantity, and user ID. Both user ID and product ID are foreign keys referencing the User and Product tables respectively, and the combination of user ID and product ID forms the primary key of this table.
The 'Admin_Product_Management' table is used by administrators to manage products. It includes columns for admin ID, operation time, operation type, and product ID. Both admin ID and product ID are foreign keys referencing the User and Product tables respectively, and the combination of admin ID and product ID forms the primary key of this table.
The 'Order_Product' table records the products in each order. It includes columns for order ID, product ID, quantity, subtotal, and unit price. Both order ID and product ID are foreign keys referencing the Order and Product tables respectively, and the combination of order ID and product ID forms the primary key of this table.
The 'User_Order' table records user orders. It includes columns for delivery address, order ID, order status, order time, payment time, total amount, and user ID. Both order ID and user ID are foreign keys referencing the Order and User tables respectively, and the combination of order ID and user ID forms the primary key of this table.
Finally, the 'Admin_Order_Management' table is used by administrators to manage orders. It includes columns for admin ID, operation time, operation type, and order ID. Both admin ID and order ID are foreign keys referencing the User and Order tables respectively, and the combination of admin ID and order ID forms the primary key of this table.
