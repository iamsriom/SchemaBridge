The database schema named 'rschema_0253' contains five tables: User, Group_Chat, Chat_Record, User_Joining_Group_Chat, and User_Leaving_Group_Chat.
The User table represents a user of the system. It has columns for 'Games', 'Password', 'Phone', 'Registration_Time', 'User_ID' (primary key), and 'Username'.
The Group_Chat table is used to store information about group chats. It has columns for 'Creation_Time', 'Creator_ID' (not null), 'Group_Chat_ID' (primary key), 'Group_Chat_Name', and 'Total_Members'. The 'Creator_ID' column is a foreign key referencing the 'User_ID' in the User table.
The Chat_Record table is used to store chat messages. It has columns for 'Message_Content', 'Message_Type', 'Read_Time', 'Send_Time', 'User_1_ID' (not null), and 'User_2_ID' (not null). Both 'User_1_ID' and 'User_2_ID' are foreign keys referencing the 'User_ID' in the User table.
The User_Joining_Group_Chat table is used to store information about users joining group chats. It has columns for 'Application_Information', 'Group_Chat_ID' (not null), 'Join_Time', and 'User_ID' (not null). Both 'Group_Chat_ID' and 'User_ID' are foreign keys referencing the 'Group_Chat_ID' and 'User_ID' in the Group_Chat and User tables respectively.
Finally, the User_Leaving_Group_Chat table is used to store information about users leaving group chats. It has columns for 'Group_Chat_ID' (not null), 'Leaving_Time', and 'User_ID' (not null). Both 'Group_Chat_ID' and 'User_ID' are foreign keys referencing the 'Group_Chat_ID' and 'User_ID' in the Group_Chat and User tables respectively.
This schema ensures referential integrity by enforcing foreign key constraints between tables. It also ensures entity integrity by having primary keys in each table and unique constraints on certain columns.
