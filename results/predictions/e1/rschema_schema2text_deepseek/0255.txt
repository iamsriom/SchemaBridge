The database schema for the database named 'rschema_0255' consists of 11 tables. The database is used for managing various aspects of a manufacturing process, from equipment inspections and failures to quality reports and user management.
The 'production_report' table represents the production reports generated by the production team. It contains columns for the report type, date, production data, production indicators, completion status, metal recovery rate, and grade. The report_id is the primary key.
The 'equipment' table holds information about the various types of equipment used in the manufacturing process. It includes columns for equipment name, model, main category, subcategory, location, and operation status. The equipment_id is the primary key.
The 'equipment_inspection' table records the details of equipment inspections. It includes columns for equipment_id, inspector_id, inspection plan, and execution progress. The combination of inspector_id and equipment_id forms the primary key. The foreign keys are linked to the 'user' and 'equipment' tables respectively.
The 'equipment_failure_reporting' table records the details of equipment failures. It includes columns for equipment_id, failure_reporter_id, failure type, failure time, and processing status. The combination of failure_reporter_id and equipment_id forms the primary key. The foreign keys are linked to the 'user' and 'equipment' tables respectively.
The 'equipment_repair' table records the details of equipment repairs. It includes columns for equipment_id, repair_person_id, repair progress, and repair time. The primary key is repair_id. The foreign keys are linked to the 'user' and 'equipment' tables respectively.
The 'quality_report' table holds the quality reports generated by the quality team. It includes columns for metal recovery rate, warehouse sample, metal grade, recovery rate daily report, and grade daily report. The report_id is the primary key.
The 'equipment_monitoring' table records the details of equipment monitoring. It includes columns for equipment_id, equipment type, collected data, status, monitoring data, fault alarm, data visualization, and administrator_id. The combination of equipment_id and administrator_id forms the primary key. The foreign keys are linked to the 'user' and 'equipment' tables respectively.
The 'user' table holds information about the users of the system. It includes columns for user_id, username, role, permissions, status, and operation history. The user_id is the primary key.
The 'announcement' table holds information about announcements made by users. It includes columns for announcement_id, announcement content, release time, publisher_id, and announcement status. The announcement_id is the primary key. The foreign key is linked to the 'user' table.
The 'job_position' table holds information about job positions available. It includes columns for job_id, job name, job description, job responsibilities, and job requirements. The job_id is the primary key.
The 'user_job_application' table holds information about user job applications. It includes columns for user_id, job_id, and job match rate. The combination of user_id and job_id forms the primary key. The foreign keys are linked to the 'user' and 'job_position' tables respectively.
All tables allow null values except for the NOT NULL constraints. Default values are not specified. Primary keys are unique and not null, and foreign keys are used to link tables together.
