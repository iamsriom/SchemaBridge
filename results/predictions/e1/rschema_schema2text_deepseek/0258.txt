The database schema named rschema_0258 consists of three tables: Donor, Fundraising_Event, and Donation_Record.
The Donor table represents a collection of donors. It contains columns for Address, Date_of_Birth, Donor_ID (which is the primary key), Gender, Identity_Card_Number, Name, Phone, and Type.
The Fundraising_Event table represents a collection of fundraising events. It contains columns for Current_Event_Amount, Event_Address, Event_End_Time, Event_ID (which is the primary key), Event_Name, Event_Start_Time, Event_Status, and Event_Type.
The Donation_Record table represents a collection of donation records. It contains columns for Donation_Amount, Donation_Message, Donation_Method, Donation_Time, Donor_ID, and Event_ID. The primary key of this table is a composite of Donor_ID, Event_ID, and Donation_Time. The Donor_ID and Event_ID columns are foreign keys referencing the Donor and Fundraising_Event tables respectively. This schema ensures referential integrity by maintaining the relationship between the Donor and Fundraising_Event tables based on the foreign keys. It also allows for update and delete rules like CASCADE or RESTRICT to maintain data integrity.
