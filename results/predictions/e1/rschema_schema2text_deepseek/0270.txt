The database schema named 'rschema_0270' contains four tables: Program, Staff, Program_Production, and Program_Review.
The Program table represents a collection of programs, with each program having a unique ID, a name, and a type. It also includes the broadcast start and end times and the duration of the program.
The Staff table contains information about the staff members. Each staff member has a unique ID, name, gender, contact number, and position.
The Program_Production table represents the production team for each program. It has a foreign key referencing the Staff table, indicating the ID of the production staff member. It also has a foreign key referencing the Program table, indicating the ID of the program. The working duration for the production team is also recorded.
The Program_Review table represents the review team for each program. It has a foreign key referencing the Staff table, indicating the ID of the reviewer. It also has a foreign key referencing the Program table, indicating the ID of the program. The working duration for the review team is also recorded. The review result and the working duration for the review team are also recorded.
All columns allow null values except for the Program_ID and Production_Staff_ID in the Program_Production table and Program_ID and Reviewer_ID in the Program_Review table. The primary keys are Program_ID in the Program and Staff tables, and (Program_ID, Production_Staff_ID) and (Program_ID, Reviewer_ID) in the Program_Production and Program_Review tables respectively. The foreign keys enforce referential integrity, ensuring that the referenced data exists in the referenced table.
