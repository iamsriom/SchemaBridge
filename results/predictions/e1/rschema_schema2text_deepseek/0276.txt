The database schema for the database 'rschema_0276' consists of five tables: 'maintenance_technician', 'maintenance_team', 'customer', 'maintenance_task', and 'maintenance_feedback'.
The 'maintenance_technician' table represents the maintenance technicians in the company. It contains columns for technician_id, name, gender, phone, position, employment_date, and team_id. The technician_id is the primary key and a foreign key referencing the team_id in the 'customer' table.
The 'maintenance_team' table represents the maintenance teams in the company. It contains columns for team_id, team_name, team_leader_id, team_responsibilities, and total_team_members. The team_id is the primary key and a foreign key referencing the team_leader_id in the 'maintenance_technician' table.
The 'customer' table represents the customers of the company. It contains columns for customer_id, customer_name, customer_phone, and customer_address. The customer_id is the primary key.
The 'maintenance_task' table represents the maintenance tasks performed by the technicians. It contains columns for maintenance_task_number, customer_id, maintenance_cost, maintenance_duration, maintenance_result, maintenance_time, and maintenance_technician. The maintenance_task_number is the primary key and foreign keys referencing the customer_id and maintenance_technician in the 'customer' and 'maintenance_technician' tables respectively.
Finally, the 'maintenance_feedback' table represents the feedback given by the customers about the maintenance tasks. It contains columns for maintenance_task_number, feedback_content, feedback_resolution_result, and customer_satisfaction. The maintenance_task_number is the primary key and a foreign key referencing the maintenance_task_number in the 'maintenance_task' table. The delete and update rules are set to cascade, meaning that if a maintenance task or a technician is deleted or updated, the corresponding feedback will also be deleted or updated.
