The database schema named "rschema_0287" consists of five tables: Park, Plant, Park_Maintenance, Park_Ecological_Record, and Plant_Growth_Record.
The Park table represents a collection of parks with attributes such as Park_Area, Park_ID, Park_Location, Park_Name, and Responsible_Person. The Park_ID is the primary key and is used to uniquely identify each park.
The Plant table contains information about different plants with attributes such as Plant_Category, Plant_ID, and Plant_Name. The Plant_ID is the primary key, used to identify each plant.
The Park_Maintenance table records the details of park maintenance tasks such as Maintenance_Content, Maintenance_Cost, Maintenance_ID, Maintenance_Personnel, and Maintenance_Time. The Park_ID is a foreign key referencing the Park table, ensuring that each maintenance record is associated with a specific park.
The Park_Ecological_Record table records ecological data about parks. The Park_ID is a foreign key referencing the Park table, allowing each ecological record to be associated with a specific park. The Record_Number is the primary key, used to uniquely identify each record.
Finally, the Plant_Growth_Record table records the growth status and quantity of plants. The Plant_ID is a foreign key referencing the Plant table and the Record_Number is a foreign key referencing the Park_Ecological_Record table. The combination of Record_Number and Plant_ID forms the primary key, ensuring that each growth record is unique.
This schema ensures referential integrity by enforcing foreign key constraints, which ensure that all data in the Park_Maintenance, Park_Ecological_Record, and Plant_Growth_Record tables are valid and correspond to existing data in the Park and Plant tables.
