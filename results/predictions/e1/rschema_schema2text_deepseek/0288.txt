The database schema named 'rschema_0288' consists of five tables.
The 'monitoring_site' table is used to store information about the monitoring sites. It has four columns: 'site_id', 'site_name', 'location', and 'responsible_person'. The 'site_id' column is the primary key of this table.
The 'monitoring_personnel' table stores information about the personnel involved in site monitoring. It has four columns: 'monitoring_personnel_id', 'name', 'contact_information', and 'monitoring_scope'. The 'monitoring_personnel_id' is the primary key of this table.
The 'maintenance_personnel' table contains information about the personnel involved in site maintenance. It has four columns: 'maintenance_personnel_id', 'name', 'contact_information', and 'maintenance_scope'. The 'maintenance_personnel_id' is the primary key of this table.
The 'site_monitoring_data' table holds data related to site monitoring. It has seven columns: 'site_id', 'monitoring_personnel_id', 'record_time', 'air_quality', 'water_quality', 'noise_level', and 'monitoring_result'. The combination of 'record_time', 'site_id', and 'monitoring_personnel_id' forms the primary key of this table. The 'monitoring_personnel_id' and 'site_id' columns are foreign keys referencing the 'monitoring_personnel' and 'monitoring_site' tables respectively. The delete and update rules are set to CASCADE.
Finally, the 'site_maintenance_data' table contains data related to site maintenance. It has five columns: 'site_id', 'maintenance_personnel_id', 'maintenance_time', 'maintenance_content', and 'maintenance_cost'. The combination of 'maintenance_personnel_id' and 'maintenance_time' and 'site_id' form the primary key of this table. The 'site_id' and 'maintenance_personnel_id' columns are foreign keys referencing the 'monitoring_site' and 'maintenance_personnel' tables respectively. The delete and update rules are set to CASCADE.
This schema ensures data integrity by enforcing primary and foreign key constraints, and by setting cascading delete and update rules.
