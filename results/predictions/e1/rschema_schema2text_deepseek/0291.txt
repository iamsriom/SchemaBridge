The database schema named "rschema_0291" consists of four tables: Reagent, Laboratory, Personnel, and Reagent_Usage_Record.
The Reagent table is used to store information about the reagents used in the laboratory. It includes columns for Reagent_ID (an integer primary key), Reagent_Name (a variable character field with a maximum length of 255 characters), Reagent_Specifications (a variable character field with a maximum length of 255 characters), Inventory_Quantity (an integer representing the quantity of the reagent in stock), and Expiration_Date (a datetime field indicating when the reagent is expected to expire).
The Laboratory table stores information about the laboratories. It includes columns for Laboratory_ID (an integer primary key), Laboratory_Name (a variable character field with a maximum length of 255 characters), Laboratory_Location (a variable character field with a maximum length of 255 characters), and Laboratory_Person_in_Charge_ID (an integer referencing the Personnel table).
The Personnel table stores information about the personnel. It includes columns for Personnel_ID (an integer primary key), Name (a variable character field with a maximum length of 255 characters), Age (an integer), Gender (a variable character field with a maximum length of 255 characters), and Affiliated_Laboratory_ID (an integer not null and a foreign key referencing the Laboratory table).
Finally, the Reagent_Usage_Record table records the usage of reagents by personnel. It includes columns for Reagent_ID (an integer not null and a foreign key referencing the Reagent table), Usage_Personnel_ID (an integer not null and a foreign key referencing the Personnel table), Usage_Start_Time (a datetime field indicating when the usage started), Usage_Duration (a variable character field with a maximum length of 255 characters), and Usage_Quantity (an integer representing the quantity of the reagent used). All these columns are part of the primary key, which is a composite key consisting of Reagent_ID, Usage_Personnel_ID, and Usage_Start_Time.
