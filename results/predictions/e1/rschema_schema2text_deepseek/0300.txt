The database schema named 'rschema_0300' consists of four tables: 'Material_Table', 'Project_Table', 'Bill_Table', and 'Bill_Details_Table'.
The 'Material_Table' represents the materials that are used in the projects. It contains three columns: 'Material_ID' which is the primary key, 'Name' which is a string of up to 255 characters, and 'Unit_Price' which is a floating-point number.
The 'Project_Table' is used to store information about the projects. It contains three columns: 'Close_Date' which is a date and time, 'Creation_Date' which is a date and time, and 'Project_ID' which is the primary key.
The 'Bill_Table' contains information about the bills. The 'Project_ID' column is a foreign key referencing the 'Project_Table' table.
Finally, the 'Bill_Details_Table' contains details about the bills. It has five columns: 'Bill_ID' and 'Material_ID' which are both integers and cannot be null, 'Quantity' which is an integer, 'Selling_Price' which is a floating-point number. Both 'Bill_ID' and 'Material_ID' are primary keys, and they are foreign keys referencing the 'Bill_Table' and 'Material_Table' tables respectively.
All columns allow null values, and there are no default values. The primary keys are unique and cannot be null. The foreign keys ensure referential integrity, meaning that the values in the foreign key columns must correspond to the primary key values in the referenced tables.
