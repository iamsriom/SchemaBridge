The database schema named 'rschema_0302' consists of five tables: Patient, Doctor, Medicine, Consultation_Record, and Patient_Medication_Record.
The Patient table represents a collection of patients, with columns for Address (VARCHAR(255)), Age (INTEGER), Date_of_Birth (DATETIME), Emergency_Contact_Number (VARCHAR(255)), Gender (VARCHAR(255)), Name (VARCHAR(255)), Patient_ID (INTEGER, PRIMARY KEY), and Phone (VARCHAR(255)).
The Doctor table contains information about doctors, including Age (INTEGER), Date_of_Birth (DATETIME), Department_Affiliation (VARCHAR(255)), Doctor_ID (INTEGER, PRIMARY KEY), Gender (VARCHAR(255)), Level (INTEGER), Name (VARCHAR(255)), and Phone_Number (VARCHAR(255)).
The Medicine table contains information about the medicines, including Medicine_Function (VARCHAR(255)), Medicine_ID (INTEGER, PRIMARY KEY), Medicine_Inventory (INTEGER), Medicine_Name (VARCHAR(255)), and Medicine_Unit_Price (FLOAT).
The Consultation_Record table records the consultation details, including Consultation_Time (DATETIME), Diagnosis_Results (VARCHAR(255)), Doctor_ID (INTEGER, NOT NULL, FOREIGN KEY referencing Doctor.Doctor_ID), Patient_ID (INTEGER, NOT NULL, FOREIGN KEY referencing Patient.Patient_ID), and Treatment_Recommendations (VARCHAR(255)).
Finally, the Patient_Medication_Record table keeps track of patient medication records, including Dosage (FLOAT), Frequency_of_Medication (VARCHAR(255)), Medicine_ID (INTEGER, NOT NULL, FOREIGN KEY referencing Medicine.Medicine_ID), Patient_ID (INTEGER, NOT NULL, FOREIGN KEY referencing Patient.Patient_ID), Precautions (VARCHAR(255)), and Prescription_Time (DATETIME).
