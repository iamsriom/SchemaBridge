The database schema named 'rschema_0306' contains 11 tables. The tables are designed to manage various tasks, triggers, schedulers, and locks.
The 'Task' table represents the main entity, with columns for Class Name, Concurrent Execution Flag, Persistence Flag, Task Description, Task ID (primary key), and Task Name.
The 'Trigger_Summary' table holds information about various triggers, including Trigger ID (primary key) and Trigger Name.
The 'Scheduler' table contains details about the schedulers, including Scheduler Configuration, Scheduler ID (primary key), Scheduler Log, Scheduler Name, and Scheduler Status.
The 'Simple_Trigger', 'Cron_Trigger', and 'Complex_Trigger' tables are derived from the 'Trigger_Summary' table, each with their own specific attributes.
The 'Blob_Trigger' table holds binary attributes, while the 'Lock' table contains information about the locks, including Lock Description, Lock ID (primary key), Lock Name, and Lock Status.
The 'Task_Uses_Trigger' table is a junction table that links the 'Task' and 'Trigger_Summary' tables, with columns for Calendar Name, End Time, Fault Instruction, Last Execution Time, Next Execution Time, Priority, Start Time, Task ID (foreign key), Trigger ID (foreign key), and Trigger Status.
The 'Scheduler_Schedules_Task' table is another junction table that links the 'Scheduler', 'Task', and 'Trigger_Summary' tables, with columns for Scheduler ID (foreign key), Task ID (foreign key), and Trigger ID (foreign key).
Finally, the 'Scheduler_Acquires_Lock' table links the 'Scheduler' and 'Lock' tables, with columns for Acquisition Time, Lock ID (foreign key), Release Time, and Scheduler ID (foreign key). This schema ensures referential integrity by maintaining relationships between the tables.
