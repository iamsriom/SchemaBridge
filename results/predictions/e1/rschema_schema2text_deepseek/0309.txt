The database schema named 'rschema_0309' comprises five tables. The primary function of this schema is to manage customer data, insurance purchases, and income group associations.
The 'customer' table holds information about each customer, including their name, email, phone number, gender, date of birth, marital status, region, and income group. The 'income_group' table contains information about income groups, including the income group name and range. The 'insurance' table contains information about different types of insurance, including the insurance name, type, premium, and vehicle segment. The 'customer_purchases_insurance' table tracks which customers have purchased which insurance, along with the purchase and expiration dates. Finally, the 'customer_associated_income_group' table links customers to their income groups.
All tables have primary keys that uniquely identify each record. Foreign keys are used to link these tables together, with cascading delete and update rules to ensure data integrity. This means that if a record in the 'customer' table is deleted or updated, corresponding records in the 'customer_purchases_insurance' and 'customer_associated_income_group' tables will also be affected.
