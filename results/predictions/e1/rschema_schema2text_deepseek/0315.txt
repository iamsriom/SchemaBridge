The database schema named "rschema_0315" consists of four tables: Borrower, Book, Book_Borrowing, and Book_Return.
The Borrower table represents the borrowers of the library. It has an integer primary key, Borrower_ID, and includes fields for the borrower's email, gender, name, and phone number.
The Book table contains information about the books in the library. It has an integer primary key, Book_ID, and includes fields for the book's author, category, price, publication year, publisher, and title.
The Book_Borrowing table records the borrowing activity of the library. It includes fields for the book's ID, borrow duration, borrow quantity, borrow time, borrower's ID, and expected return time. The primary key is a combination of Borrower_ID and Book_ID along with Borrow_Time. The Book_ID and Borrower_ID are foreign keys referencing the Book and Borrower tables respectively.
Finally, the Book_Return table records the return activity of the library. It includes fields for the book's ID, borrow duration, borrower's ID, whether the return is overdue, overdue penalty amount, return quantity, and return time. The primary key is a combination of Borrower_ID and Book_ID along with Return_Time. The Book_ID and Borrower_ID are foreign keys referencing the Book and Borrower tables respectively. This schema ensures data integrity by enforcing referential integrity constraints through foreign keys.
