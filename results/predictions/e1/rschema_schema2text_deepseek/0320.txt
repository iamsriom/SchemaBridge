The database schema named rschema_0320 is composed of five tables: Product, Style, Feature, SKU, and Photo.
The Product table represents the main product entity. It contains columns for Default_Price, Product_Category, Product_Description, Product_ID (which is the primary key), Product_Name, and Product_Slogan.
The Style table is associated with the Product table through the foreign key Associated_Product_ID. It contains columns for Associated_Product_ID (which cannot be null), Is_Default_Style, Original_Price, Sale_Price, Style_ID (which is the primary key), and Style_Name.
The Feature table is also associated with the Product table through the foreign key Associated_Product_ID. It contains columns for Associated_Product_ID (which cannot be null), Feature_ID (which is the primary key), Feature_Name, and Feature_Value.
The SKU table is associated with the Style table through the foreign key Associated_Style_ID. It contains columns for Associated_Style_ID (which cannot be null), SKU_ID (which is the primary key), Size, and Stock_Quantity.
Finally, the Photo table is associated with the Style table through the foreign key Associated_Style_ID. It contains columns for Associated_Style_ID (which cannot be null), Photo_ID (which is the primary key), Photo_URL, and Thumbnail_URL.
This schema ensures referential integrity by linking the tables together through the foreign keys. It also ensures entity integrity by having primary keys in each table and ensuring that foreign keys reference the primary keys of the associated tables.
