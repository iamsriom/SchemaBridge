The database schema named rschema_0321 consists of five tables. The General_User_Information table holds user information including their Account, Age, Email, Gender, Name, Password, Phone, and User_ID. The User_ID is the primary key for this table. The Member_Information table contains information about members including their Member_ID, Member_Level, Status, Validity_End, and Validity_Start. The Member_ID is the primary key for this table. The Team_Information table contains information about teams including the Team_Creation_Time, Team_ID, Team_Leader_ID, Team_Name, and Total_Team_Members. The Team_ID is the primary key and Team_Leader_ID is not null. The Football_Player_Information table contains information about football players including their Affiliated_Team_ID and Football_Player_ID. Both are the primary key and Affiliated_Team_ID is a foreign key referencing Team_Information(Team_ID), and Football_Player_ID is a foreign key referencing General_User_Information(User_ID). The Match_Information table contains information about matches including the Away_Team_ID, Home_Team_ID, Match_ID, Match_Location, Match_Result, and Match_Time. The Match_ID is the primary key and Away_Team_ID and Home_Team_ID are foreign keys referencing Team_Information(Team_ID).
This schema is designed to manage user information, membership information, team information, football player information, and match information. It ensures data integrity by enforcing primary and foreign key constraints, and it allows for referential integrity by setting up cascading deletion and updates.
