The database schema named 'rschema_0326' consists of three tables: 'User', 'Task', and 'Task_File'.
The 'User' table represents a user entity in the system. It has five columns: 'Avatar_File_ID' (an integer), 'Avatar_File_Name' (a string of up to 255 characters), 'Date_of_Birth' (a date and time), 'Full_Name' (a string of up to 255 characters), 'Password' (a string of up to 255 characters), and 'User_ID' (an integer, the primary key).
The 'Task' table represents a task entity in the system. It has nine columns: 'Assignee_User_ID' (an integer, not null), 'Completion_Date' (a date and time), 'Creation_Date' (a date and time), 'Creator_User_ID' (an integer, not null), 'Task_ID' (an integer, the primary key), 'Task_Name' (a string of up to 255 characters), 'Task_Priority' (an integer), 'Task_Remarks' (a string of up to 255 characters), and 'Task_Status' (a string of up to 255 characters). The 'Assignee_User_ID' and 'Creator_User_ID' columns are foreign keys referencing the 'User_ID' in the 'User' table.
The 'Task_File' table represents a file associated with a task. It has four columns: 'File_Name' (a string of up to 255 characters), 'Task_File_ID' (an integer, the primary key), 'Task_ID' (an integer, not null), and 'Task_ID' is a foreign key referencing the 'Task_ID' in the 'Task' table. This schema ensures data integrity by enforcing referential integrity constraints, primary key constraints, and foreign key constraints.
