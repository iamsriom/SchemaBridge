The database schema named 'rschema_0328' contains six tables: Administrator, Survey, Question, Option, Text_answer_record, and Choice_answer_record.
The Administrator table is used for storing information about the administrators of the survey system. It includes columns for Account, Administrator_ID, Name, Password, and Phone_number.
The Survey table is used for storing information about the surveys. It includes columns for Access_restriction, Access_rule, Anonymous, Background_image_URL, Description, End_time, Start_time, Survey_ID, Survey_logo_URL, Survey_status, and Survey_title.
The Question table is used for storing information about the questions in the surveys. It includes columns for Description, Display_order, Display_style, Evaluation_score, For_evaluation, Question_ID, Question_title, Question_type, Required, Survey_ID, and Validation_type. The Survey_ID column is a foreign key referencing the Survey table.
The Option table is used for storing information about the options for questions in the surveys. It includes columns for Display_order, Is_correct_answer, Option_ID, Option_content, Question_ID, and a foreign key referencing the Question table.
The Text_answer_record table is used for storing information about text answers to questions in the surveys. It includes columns for Answer_ID, Answer_content, Question_ID, Respondent_information, and Submission_time. The Question_ID column is a foreign key referencing the Question table.
The Choice_answer_record table is used for storing information about choice answers to questions in the surveys. It includes columns for Answer_ID, Answer_type, Option_ID, Respondent_information, and Submission_time. The Option_ID column is a foreign key referencing the Option table.
All tables allow null values except for the Survey_ID in the Question table, Question_ID in the Option table, and Question_ID in the Text_answer_record and Choice_answer_record tables. The primary keys are the unique identifiers for each record in their respective tables. The foreign keys enforce referential integrity by ensuring that the values in the foreign key columns match the values in the primary key columns of the referenced tables.
