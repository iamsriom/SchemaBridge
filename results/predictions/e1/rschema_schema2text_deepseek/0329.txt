The database schema named 'rschema_0329' contains four tables: User, Stock, Log, and User_Investment_Stock.
The User table represents a user of the system and contains columns for user_ID (integer, primary key), username (varchar with a maximum length of 255), and virtual_currency_balance (float).
The Stock table represents a stock in the system and contains columns for company_name (varchar with a maximum length of 255), issue_date (datetime), stock_code (varchar with a maximum length of 255, primary key), and stock_price (float).
The Log table represents a log of system activities and contains columns for date (datetime), log_ID (integer, primary key), record_value (float), and user_ID (integer, not null, foreign key referencing the User table).
The User_Investment_Stock table represents a user's investment in a stock and contains columns for earnings_value (float), quantity_held (integer), stock_code (varchar with a maximum length of 255, not null, foreign key referencing the Stock table), and user_ID (integer, not null, foreign key referencing the User table). It also has a composite primary key made up of user_ID and stock_code.
All columns allow null values except for the ones that are not null. The primary keys are user_ID in the User and Log tables, and a composite primary key consisting of user_ID and stock_code in the User_Investment_Stock table. The foreign keys enforce referential integrity by ensuring that the values in the foreign key columns match the values in the primary key columns of the related tables.
