The database schema named 'rschema_0331' consists of four tables: 'Player', 'Match_Information', 'Match_Result', and 'Battle'.
The 'Player' table holds information about the players, including their contact information, gender, nickname, unique player ID, and registration time. The player ID is the primary key of this table and is not allowed to be null.
The 'Match_Information' table contains information about the matches, including the end time, match ID, name, start time, total participants, and type of the match. The match ID is the primary key of this table and is not allowed to be null.
The 'Match_Result' table records the results of the matches, including the match ID, player ID, ranking, and total score. Both player ID and match ID are part of the primary key of this table.
The 'Battle' table contains information about the battles, including the battle duration, match end time, match ID, match start time, player 1 ID, player 2 ID, and the result of the battle. The combination of match ID, player 1 ID, player 2 ID, and match start time form the primary key of this table. The match ID, player 1 ID, and player 2 ID are foreign keys referencing the 'Match_Information' and 'Player' tables respectively. The result of the battle is a boolean value.
The 'Player' table has a foreign key constraint referencing the 'Player' table itself, ensuring referential integrity. The 'Match_Information' table has a foreign key constraint referencing the 'Match_Information' table, ensuring entity integrity. The 'Match_Result' and 'Battle' tables have foreign key constraints referencing the 'Player' table, ensuring referential integrity.
