The database schema named 'rschema_0345' consists of 8 tables. The tables are defined as follows:
1. **Subject**: This table represents the subjects offered in the university. It has three columns: Credits (FLOAT), Subject_Code (VARCHAR(255)), and Subject_Name (VARCHAR(255)). The Subject_Code is the primary key of this table.
2. **Professor**: This table represents the professors in the university. It has four columns: Email (VARCHAR(255)), Name (VARCHAR(255)), Professor_ID (INTEGER), and Credits (FLOAT). Professor_ID is the primary key of this table.
3. **Student**: This table represents the students enrolled in the university. It has five columns: Average_Grade (INTEGER), Credits_Completed (FLOAT), Date_of_Birth (DATETIME), Email (VARCHAR(255)), Name (VARCHAR(255)), and Student_ID (INTEGER). Student_ID is the primary key of this table.
4. **Subject_Equivalence**: This table represents the equivalences between subjects. It has two columns: Equivalent_Subject_Code (VARCHAR(255)) and Subject_Code (VARCHAR(255)). Both columns are primary keys and foreign keys referencing the Subject table.
5. **Subject_Prerequisites**: This table represents the prerequisites for subjects. It has two columns: Prerequisite_Subject (VARCHAR(255)) and Related_Subject (VARCHAR(255)). Both columns are primary keys and foreign keys referencing the Subject table.
6. **Course**: This table represents the courses offered in the university. It has four columns: Course_Code (VARCHAR(255)), Name (VARCHAR(255)), Responsible_Professor (INTEGER), and Total_Credits (FLOAT). Course_Code is the primary key and Responsible_Professor is a foreign key referencing the Professor table.
7. **Course_Assignment**: This table represents the assignments of subjects to courses. It has three columns: Course_Code (VARCHAR(255)), Semester (INTEGER), and Subject_Code (VARCHAR(255)). Both Course_Code and Subject_Code are foreign keys referencing the Course and Subject tables respectively.
8. **Student_Course_Enrollment**: This table represents the enrollment of students in courses. It has three columns: Course_Code (VARCHAR(255)), Course_Grade (INTEGER), and Student_ID (INTEGER). Both Course_Code and Student_ID are foreign keys referencing the Course and Student tables respectively.
This schema ensures referential integrity by enforcing foreign key constraints. It also ensures entity integrity by having primary keys for each table and composite or unique constraints for certain columns. The schema is designed to maintain the integrity of the data and to ensure that the relationships between the tables are maintained.
