The database schema for the database 'rschema_0347' consists of 12 tables. The database is designed to track and manage various aspects of machine learning model performance and usage.
The 'leaderboard_metadata' table holds metadata about the model runs, including the execution time, start and end times, run time, run path, maximum models, and model species. The primary key is 'run_id'.
The 'leaderboard' table represents the leaderboard, storing information about each model, including the model id, model name, and various metrics such as root mean squared error (RMSE), mean squared error (MSE), mean absolute error (MAE), root mean squared log error (RMSLE), and the presence of stacked ensemble best of family. The primary key is 'model_id'.
The 'model_map' table maps model types to their corresponding ids and names. The primary key is 'model_type_id'.
The 'dataset_variable_details' table holds information about the variables in the datasets, including the variable id, name of variables, data type of variable, unique values in each column, null values in each column, and the dataset id. The primary key is 'var_id' and a foreign key 'dataset_id' references 'dataset_metadata' table.
The 'tags' table stores tags and their corresponding ids. The primary key is 'tag_id'.
The 'hyperparameter_value' table holds the values of hyperparameters for each model, including the model id, hyperparameter id, and the value. The primary key is a combination of 'hyperparameter_id' and 'model_id', and foreign keys 'hyperparameter_id' and 'model_id' reference 'hyperparameter' and 'leaderboard' tables respectively.
The 'model_run' table maps model runs to their corresponding model ids and run ids. The primary key is a combination of 'model_id' and 'run_id', and foreign keys 'model_id' and 'run_id' reference 'leaderboard' and 'leaderboard_metadata' tables respectively.
The 'data_map' table maps datasets to their corresponding run ids. The primary key is a combination of 'dataset_id' and 'run_id', and foreign keys 'dataset_id' and 'run_id' reference 'dataset_metadata' and 'leaderboard_metadata' tables respectively.
The 'hyperparameter_def_values' table holds default values for hyperparameters for each model type. The primary key is a combination of 'model_type_id' and 'hyperparameter_id', and foreign keys 'hyperparameter_id' and 'model_type_id' reference 'hyperparameter' and 'model_map' tables respectively.
The 'id_map' table maps model ids to their corresponding model type ids. The primary key is 'model_id', and foreign key 'model_id' references 'leaderboard' table, while foreign key 'model_type_id' references 'model_map' table.
The 'hyperparameter' table holds information about hyperparameters and their corresponding ids. The primary key is 'hyperparameter_id'.
Finally, the 'dataset_metadata' table holds metadata about the datasets, including the dataset id, name, dataset owner, license, visibility, url, date created, last updated, data size, number of rows, and number of columns. The primary key is 'dataset_id'.
