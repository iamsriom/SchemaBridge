The database schema named "rschema_0355" consists of five tables: Race, Horse, Bettor, Horse_Participation, and Bettor_Betting_Race.
The Race table is used to store information about the races. It includes columns for End_Time (a datetime), Race_ID (an integer), Race_Name (a string), Race_Result (a string), and Start_Time (a datetime).
The Horse table stores information about the horses. It includes columns for Horse_ID (an integer) and Horse_Name (a string).
The Bettor table contains information about the bettors. It includes columns for Bettor_ID (an integer) and Identity_Information, Phone_Number (both strings).
The Horse_Participation table is used to track the participation of horses in races. It includes columns for Horse_ID (an integer), Horse_Ranking (an integer), Race_ID (an integer), and Race_Time (a datetime). Both Horse_ID and Race_ID are foreign keys referencing the Horse and Race tables respectively.
Lastly, the Bettor_Betting_Race table stores information about bettors' bets on races. It includes columns for Actual_Result (a string), Betting_Amount (a float), Betting_Time (a datetime), Bettor_ID (an integer), Expected_Ranking (an integer), Horse_ID (an integer), Race_ID (an integer), and Winning_Status (a string). Bettor_ID, Horse_ID, and Race_ID are all foreign keys referencing the Bettor, Horse, and Race tables respectively.
