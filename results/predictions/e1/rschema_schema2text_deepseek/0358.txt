The database named rschema_0358 is a task scheduling system. It contains two tables: scheduled_task and execution_instance.
The scheduled_task table represents tasks scheduled for execution. It has 17 columns: id, revision, type, lock_expiration_time, lock_owner, exclusive, execution_id, process_instance_id, process_definition_id, retries, exception_stack_id, exception_message, due_date, repeat, handler_type, handler_configuration, and tenant_id. All these columns allow null values and have a default value of null. The primary key of this table is the id column.
The execution_instance table represents instances of process executions. It has 3 columns: execution_id, process_instance_id, and process_definition_id. The primary key of this table is the execution_id column.
The scheduled_task table has two foreign keys: execution_id and process_instance_id. They reference the execution_id and process_instance_id columns of the execution_instance table respectively. The delete and update rules for these foreign keys are set to CASCADE, meaning that if a record in the execution_instance table is deleted or updated, the corresponding records in the scheduled_task table will also be deleted or updated.
This schema is used for managing tasks and their associated processes in a task scheduling system.
