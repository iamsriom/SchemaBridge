The database schema named 'rschema_0362' contains three tables: User, Post, and Comment.
The User table represents a user of the social media platform. It has the following columns: User_ID (integer, primary key), Name (varchar(255)), Email (varchar(255)), Phone_Number (integer), Personal_Bio (varchar(255)), Relationship_Status (varchar(255)), Creation_Time (datetime), and Last_Edit_Time (datetime).
The Post table is used to store the posts made by users. It has the following columns: Post_ID (integer, primary key), User_ID (integer, not null, foreign key referencing User.User_ID), Post_Title (varchar(255)), Post_Content (varchar(255)), Creation_Time (datetime), and Last_Edit_Time (datetime).
The Comment table is used to store comments made by users on posts. It has the following columns: User_ID (integer, not null, foreign key referencing User.User_ID), Post_ID (integer, not null, foreign key referencing Post.Post_ID), Comment_Content (varchar(255)), Creation_Time (datetime), and Last_Edit_Time (datetime). The primary key of this table is a composite key of User_ID, Post_ID, and Last_Edit_Time.
All columns allow null values, except for User_ID and Post_ID in the Comment table, which are not null and reference the User and Post tables respectively. This schema ensures data integrity by enforcing referential integrity constraints, ensuring that all foreign keys in the Comment table reference valid primary keys in the User and Post tables.
