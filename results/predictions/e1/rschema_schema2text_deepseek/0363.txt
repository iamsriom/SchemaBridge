The database schema named "rschema_0363" contains four tables: Book, Reader, Reader_book_borrowing, and Reader_book_reservation.
The Book table represents a collection of books, with each book having various attributes such as the author's name, the number of available copies, the number of circulating copies, the ISBN, the library location, the price, the publication date, the publisher, the shelf number, and the title. The Book table has the ISBN as the primary key.
The Reader table represents a collection of readers, with each reader having attributes such as the address, age, email, gender, library card number, loan period, maximum borrowing limit, name, phone number, reader ID, and reader type. The Reader table has the Reader_ID as the primary key.
The Reader_book_borrowing table represents the borrowing records of books by readers. It has attributes such as the actual return date, borrowing status, borrowing time, due date, ISBN, and Reader_ID. The combination of ISBN, Reader_ID, and borrowing time form the primary key. It has foreign keys referencing the Book and Reader tables respectively.
Finally, the Reader_book_reservation table represents the reservation records of books by readers. It has attributes such as the ISBN, Reader_ID, reservation expiration time, reservation status, and reservation time. The combination of ISBN, Reader_ID, and reservation time form the primary key. It has foreign keys referencing the Book and Reader tables respectively.
This schema ensures referential integrity by enforcing foreign key constraints, which ensure that the relationships between tables are maintained. It also ensures entity integrity by enforcing primary key constraints, and it allows for update and delete cascades, which means that when a record in the parent table is updated or deleted, the corresponding records in the child tables will be updated or deleted as well.
