The database schema named "rschema_0371" contains four tables: User, User_Account, User_Session, and User_Verification.
The User table represents a user in the system and contains information such as the user's email, username, avatar URL, creation and update times, and email verification time. The User_ID is the primary key for this table.
The User_Account table stores information related to user accounts, including access tokens, their expiration times, and account creation and update times. It also references the User table via the User_ID column.
The User_Session table contains information about user sessions, including access tokens, creation and expiration times, and session tokens. It also references the User table via the User_ID column.
Finally, the User_Verification table contains information about user verifications, including the verification request creation and expiration times, identifiers, and tokens. It also references the User table via the User_ID column. All columns in these tables allow null values, except for the User_ID in the User_Account, User_Session, and User_Verification tables, which are not nullable. The primary keys are highlighted in bold. Foreign keys are used to link these tables together. The database schema is designed to ensure referential integrity, with cascading deletions and updates to maintain data consistency.
