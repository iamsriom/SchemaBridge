The database schema for the database named 'rschema_0373' consists of seven tables. The schema is designed to manage various aspects of a project management system.
The 'project' table represents the main entity in the system, with columns for 'project_id', 'project_name', 'project_description', 'project_code', 'budget_level', 'creation_time', and 'project_leader'. The 'project_leader' column is a foreign key referencing the 'user_id' in the 'user_project_application' table, ensuring referential integrity.
The 'fund' table holds information about funds, with columns for 'fund_id', 'fund_name', 'fund_description', and 'total_fund'.
The 'department' table represents the departments within the organization, with columns for 'department_id', 'department_name', and 'department_leader'. The 'department_leader' column is a foreign key referencing the 'user_id' in the 'user_project_application' table.
The 'user_project_application' table represents the applications of users for projects, with columns for 'user_id', 'project_id', 'application_time', and 'application_status'. Both 'user_id' and 'project_id' are primary keys, and they are foreign keys referencing the 'user_id' and 'project_id' in the 'project' table respectively.
The 'user_fund_application_for_project' table represents the applications of users for funds for projects, with columns for 'user_id', 'project_id', 'application_amount', 'application_time', and 'application_status'. Both 'user_id' and 'project_id' are primary keys, and they are foreign keys referencing the 'user_id' and 'project_id' in the 'user_project_application' table respectively.
The 'user_held_activity' table represents the activities held by users in projects, with columns for 'activity_leader', 'project_id', 'activity_name', 'event_time', 'event_location', and 'budget_amount'. Both 'activity_leader' and 'project_id' are foreign keys referencing the 'user_id' and 'project_id' in the 'user_project_application' and 'project' tables respectively.
Finally, the 'user' table represents the users within the organization, with columns for 'user_id', 'username', 'password', 'email', 'phone', 'user_role', and 'department'. The 'department' column is a foreign key referencing the 'department_id' in the 'department' table, ensuring referential integrity.
All tables allow null values, and the default character set for the database is utf8mb3. The tables are engineered to maintain data integrity and consistency, with cascading deletions and updates ensuring that related data is also deleted or updated as expected.
