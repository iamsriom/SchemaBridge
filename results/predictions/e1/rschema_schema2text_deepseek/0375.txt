The database schema named rschema_0375 consists of seven tables.
The Device table is used to store information about the devices in the network. It includes columns for Device_Status, ID (which is the primary key), IP_Address, Installation_Location, Installation_Time, Name, and Type.
The User table stores user-related information. It includes columns for ID (the primary key), User_Account, and User_Password.
The Staff table contains information about the staff members. It includes columns for Contact_Information, ID (the primary key), and Name.
The Network_Traffic table records network traffic data. It includes columns for Device_ID (which is a foreign key referencing the ID in the Device table), Download_Traffic, Timestamp, Total_Traffic, Traffic_Status, and Upload_Traffic.
The Device_Failure_Record table records device failure data. It includes columns for Device_ID (a foreign key referencing the ID in the Device table), Failure_Description, Failure_Occurrence_Time, Failure_Type, Handling_Status, and Remarks.
The User_Connection_Device table records user-device connection data. It includes columns for Connection_Time, Device_ID (a foreign key referencing the ID in the Device table), Disconnection_Time, Used_Bandwidth, User_ID (a foreign key referencing the ID in the User table), and User_IP.
Finally, the Device_Maintenance_Record table records device maintenance data. It includes columns for Device_ID (a foreign key referencing the ID in the Device table), Maintenance_Content, Maintenance_Result, Maintenance_Time, Remarks, and Staff_ID (a foreign key referencing the ID in the Staff table).
