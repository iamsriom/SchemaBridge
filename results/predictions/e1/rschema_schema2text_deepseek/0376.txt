The database schema named 'rschema_0376' consists of 12 tables. The primary function of this database is to manage and track various aspects of a car repair service.
The 'customer' table represents the customers of the service. Each customer has a unique identifier, a name, and a phone number. The primary key is the 'customer_id'.
The 'technician' table holds information about the technicians involved in the service. Each technician has a unique identifier, a name, and an address. The primary key is the 'technician_id'.
The 'order_parts' table is a junction table that links the 'order' table and the 'part' table. It represents the parts ordered for a specific order. Each record in this table has an 'order_id' and a 'part_id', along with the quantity of parts ordered.
The 'task_parts' table is another junction table that links the 'repair_task' table and the 'part' table. It represents the parts used in a specific repair task. Each record in this table has a 'task_id' and a 'part_id', along with the quantity of parts used.
The 'car_model' table holds information about the car models that the service repairs. Each car model has a unique identifier and a name. The primary key is the 'car_model_id'.
The 'repair_task' table represents the repair tasks. Each task has a unique identifier, a status, a 'customer_id' (referring to the customer who the task is for), a task creation date, and a task completion date. The primary key is the 'task_id'.
The 'task_technician' table is a junction table that links the 'repair_task' table and the 'technician' table. It represents which technicians are assigned to which tasks. Each record in this table has a 'technician_id' and a 'task_id'.
The 'task_car_model' table is a junction table that links the 'repair_task' table and the 'car_model' table. It represents which car models are involved in which tasks. Each record in this table has a 'car_model_id' and a 'task_id'.
The 'order' table represents the orders placed by the customers. Each order has a unique identifier, an order creation date, and a flag indicating whether the order has been delivered. The primary key is the 'order_id'.
The 'order_task' table is a junction table that links the 'order' table and the 'repair_task' table. It represents which tasks are associated with which orders. Each record in this table has an 'order_id' and a 'task_id'.
The 'supplier' table represents the suppliers of the parts. Each supplier has a unique identifier and a name. The primary key is the 'supplier_id'.
The 'part' table represents the parts used in the service. Each part has a unique identifier, a serial number, a description, a price, a 'supplier_id' (referring to the supplier who supplied the part), and a stock quantity. The primary key is the 'part_id'.
All tables have foreign keys that reference other tables, ensuring referential integrity and maintaining the relationships between the tables. The DELETE and UPDATE rules are set to CASCADE, meaning that if a record in the referenced table is deleted or updated, the corresponding records in the referencing tables will also be deleted or updated.
