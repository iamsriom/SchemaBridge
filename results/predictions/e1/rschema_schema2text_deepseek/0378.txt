The Article table is used to store article information. The Author_ID column is a foreign key referencing the User_ID in the User table.
The Comment table is used to store comment information. The Article_ID and User_ID columns are foreign keys referencing the Article_ID and User_ID in the Article and User tables respectively.
The Operation_Record table is used to store operation record information. It has four columns: Article_ID, which is an INTEGER type and cannot be null, Operation_Type, which is a VARCHAR type and can store up to 255 characters, Timestamp, which is a DATETIME type, and (Article_ID, Timestamp) form the primary key. The Article_ID column is a foreign key referencing the Article_ID in the Article table.
Finally, the User_Manage_Article table is used to store information about which user manages which article. It has two columns: Article_ID, which is an INTEGER type and cannot be null, User_ID, which is an INTEGER type and cannot be null, and (User_ID, Article_ID) form the primary key. Both Article_ID and User_ID are foreign keys referencing the Article_ID and User_ID in the Article and User tables respectively.
