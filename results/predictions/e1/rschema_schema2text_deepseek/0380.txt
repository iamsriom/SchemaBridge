The database schema named 'rschema_0380' consists of four tables: 'Customer', 'Airline', 'Flight', and 'Flight_Reservation'.
The 'Customer' table represents customers of the airline service. It has an integer primary key 'Customer_ID', a 'Name' column of type VARCHAR(255), an 'Email' column of type VARCHAR(255), and a 'Phone' column of type VARCHAR(255).
The 'Airline' table holds information about the airlines. It has an integer primary key 'Airline_ID', a 'Name' column of type VARCHAR(255), an 'Address' column of type VARCHAR(255), and a 'Phone' column of type VARCHAR(255).
The 'Flight' table contains information about the flights. It has an integer primary key 'Flight_ID', a 'Departure_Time' column of type DATETIME, a 'Departure_Location' column of type VARCHAR(255), an 'Arrival_Time' column of type DATETIME, a 'Destination' column of type VARCHAR(255), and an 'Airline_ID' column of type INTEGER. The 'Airline_ID' column is a foreign key referencing the 'Airline_ID' in the 'Airline' table.
Finally, the 'Flight_Reservation' table holds reservations for flights. It has a 'Customer_ID' column of type INTEGER, a 'Flight_ID' column of type INTEGER, a 'Number_of_Tickets' column of type INTEGER, and a 'Reservation_Time' column of type DATETIME. Both the 'Customer_ID' and 'Flight_ID' columns are foreign keys referencing the 'Customer_ID' and 'Flight_ID' in the 'Customer' and 'Flight' tables respectively. The combination of 'Customer_ID', 'Flight_ID', and 'Reservation_Time' forms the primary key of this table.
