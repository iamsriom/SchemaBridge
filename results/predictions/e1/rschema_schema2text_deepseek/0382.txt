The Post table is another table in the schema. It has four columns: Description, Image_URL, Post_ID, Title, and User_ID. Post_ID is the primary key, and it is an integer. User_ID is a foreign key referencing the User table, indicating which user created the post. The Post table stores information about the post such as its description, image URL, title, and the user who created it.
The User_post_comment table is a junction table that connects the User and Post tables. It has four columns: Comment_content, Comment_time, Post_ID, and User_ID. Post_ID and User_ID are foreign keys referencing the Post and User tables respectively. The primary key of this table is a combination of User_ID, Post_ID, and Comment_time. The User_post_comment table stores information about the comments made by users on posts.

If a user or post is deleted, the corresponding entries in the User_post_comment table will be automatically deleted to maintain data consistency. The DELETE rule is set to CASCADE, meaning that if a user or post is deleted, all associated comments will also be deleted.
