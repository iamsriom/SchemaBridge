The database schema named 'rschema_0388' consists of seven tables.
The 'Supplier_Table' is used to store information about suppliers. It includes columns for 'Creation_Time', 'Supplier_ID', 'Supplier_Information', 'Supplier_Relationship_Management', and 'Update_Time'. 'Supplier_ID' is the primary key of this table.
The 'Project_Table' is used to store information about projects. It includes columns for 'Creation_Time', 'Project_ID', 'Project_Information', 'Project_Progress_Management', and 'Update_Time'. 'Project_ID' is the primary key of this table.
The 'Salary_Table' is used to store information about salary calculations and distributions. It includes columns for 'Creation_Time', 'Salary_Calculation', 'Salary_Distribution', 'Salary_ID', and 'Update_Time'. 'Salary_ID' is the primary key of this table.
The 'Supplier_Supply_Project' table is a linking table that links 'Supplier_Table' and 'Project_Table' via foreign keys. It includes columns for 'Project_ID' and 'Supplier_ID' and is the primary key of this table.
The 'Employee_Table' is used to store information about employees. It includes columns for 'Creation_Time', 'Employee_ID', 'Employee_Information', 'Performance_Evaluation', 'Position_Allocation', 'Salary_ID', and 'Update_Time'. 'Employee_ID' is the primary key of this table and 'Salary_ID' is a foreign key referencing 'Salary_Table'.
The 'Attendance_Record_Table' is used to store attendance records. It includes columns for 'Attendance_ID', 'Attendance_Record', 'Creation_Time', 'Employee_ID', 'Employee_Punch_In', 'Update_Time', and 'Employee_ID' is a foreign key referencing 'Employee_Table'.
The 'Employee_Project_Allocation' table is a linking table that links 'Employee_Table' and 'Project_Table' via foreign keys. It includes columns for 'Employee_ID' and 'Project_ID' and is the primary key of this table.
All columns allow null values except for 'Salary_Distribution' in the 'Salary_Table' and 'Employee_ID' in the 'Attendance_Record_Table'. The 'Update_Time' columns in all tables are used to track the last update time. The 'CASCADE' on delete and update rules are in place for foreign key references.
