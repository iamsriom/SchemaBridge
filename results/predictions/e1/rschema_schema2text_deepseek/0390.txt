The database schema named 'rschema_0390' consists of five tables: Consumer, Courier_Company, Courier_Tracking, Administrator, and Cooperation.
The Consumer table contains Address_Information and Consumer_ID as columns. The Consumer_ID is the primary key and is used to uniquely identify each consumer. The table also includes Phone_Number as a VARCHAR(255) column.
The Courier_Company table contains Arrival_Time as a DATETIME column, Charging_Price as a FLOAT column, and Company_Name as a VARCHAR(255) column. The Company_Name is the primary key and is used to uniquely identify each courier company.
The Courier_Tracking table contains Courier_Tracking_Number as a VARCHAR(255) column, Recipient_ID as an INTEGER column, Recipient_Name as a VARCHAR(255) column, and Recipient_Phone_Number as a VARCHAR(255) column. The Courier_Tracking_Number is the primary key and is used to uniquely identify each tracking record.
The Administrator table contains Administrator_ID as an INTEGER column, Courier_Username as a VARCHAR(255) column, Login_Password as a VARCHAR(255) column, and Name as a VARCHAR(255) column. The Administrator_ID is the primary key and is used to uniquely identify each administrator.
The Cooperation table is a junction table that links the Administrator and Courier_Company tables. It contains Administrator_ID and Company_Name as columns. Both columns are NOT NULL and are used to uniquely identify each record in the table. The Administrator_ID is a foreign key referencing the Administrator table and Company_Name is a foreign key referencing the Courier_Company table.
