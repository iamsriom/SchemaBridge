The database schema named 'rschema_0393' consists of five tables: 'patient', 'ward', 'registration_category', 'drug', and 'prescription'.
The 'patient' table represents a patient's information, including age, contact information, gender, name, patient ID, patient's treatment information, registration category ID, and ward ID. The age column is of type INTEGER, the contact information column is of type VARCHAR with a maximum length of 255 characters, the gender column is of type BOOL, the name column is of type VARCHAR with a maximum length of 255 characters, the patient ID column is of type INTEGER and is the primary key. The patient's treatment information and registration category ID columns are of type VARCHAR with a maximum length of 255 characters, and the ward ID column is of type INTEGER.
The 'ward' table represents ward information, including ward ID and ward information. The ward ID column is of type INTEGER and is the primary key. The ward information column is of type VARCHAR with a maximum length of 255 characters.
The 'registration_category' table represents registration category information, including registration category ID and registration information. The registration category ID column is of type INTEGER and is the primary key. The registration information column is of type VARCHAR with a maximum length of 255 characters.
The 'drug' table represents drug information, including drug ID and drug information. The drug ID column is of type INTEGER and is the primary key. The drug information column is of type VARCHAR with a maximum length of 255 characters.
The 'prescription' table represents a prescription, linking a drug to a patient. The drug ID and patient ID columns are of type INTEGER and are the primary key. The drug ID column is a foreign key referencing the drug table's drug ID column, and the patient ID column is a foreign key referencing the patient table's patient ID column.
