The database schema named 'rschema_0394' consists of four tables: User, Administrator, Menu, and Order.
The User table is used to store user information. It includes columns for Address, Last_Login_Time, Password, Phone_Number, Registration_Time, User_ID (primary key), and Username.
The Administrator table stores information about administrators. It includes columns for Administrator_ID (primary key), Administrator_Name, Last_Login_Time, Login_IP, and Password.
The Menu table is used to store information about the dishes served in the restaurant. It includes columns for Description, Dish_Name, Image (as a BLOB), Menu_ID (primary key), and Price.
The Order table is used to store information about orders placed by users. It includes columns for Creation_Time, Menu_ID (foreign key referencing Menu), Order_Amount, Order_Modification_Time, Order_Status, Remarks, and User_ID (foreign key referencing User). The primary key of this table is a composite key consisting of User_ID, Menu_ID, and Creation_Time.
