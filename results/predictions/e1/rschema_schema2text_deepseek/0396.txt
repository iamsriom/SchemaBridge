The database schema named 'rschema_0396' comprises seven tables. The primary function of this schema is to manage user profiles, travel guides, restaurant information, hotel details, scenic spots, routes, and user-written guides.
The User_Table represents user profiles. It contains columns for 'Nickname', 'Password', 'Profile_Picture', and 'Username', all of which are VARCHAR(255) data types. The 'Username' column is the primary key, ensuring entity integrity as it uniquely identifies each user.
The Guide_Table stores travel guides. It has columns for 'Category', 'Content', 'Guide_Title', and 'Tags', all of which are VARCHAR(255) data types. The 'Guide_Title' is the primary key, ensuring entity integrity.
The Restaurant_Table contains information about restaurants. It has columns for 'Image', 'Introduction', 'Location', and 'Restaurant_Name', all of which are VARCHAR(255) data types. The 'Restaurant_Name' is the primary key, ensuring entity integrity.
The Hotel_Table stores hotel details. It has columns for 'Hotel_Name', 'Image', 'Introduction', and 'Location', all of which are VARCHAR(255) data types. The 'Hotel_Name' is the primary key, ensuring entity integrity.
The Scenic_Spot_Table stores information about scenic spots. It has columns for 'Address', 'Days', 'Image', 'Introduction', 'Opening_Hours', 'Scenic_Spot_Name', and 'Tips', all of which are VARCHAR(255) data types. The 'Scenic_Spot_Name' is the primary key, ensuring entity integrity.
The Route table contains information about travel routes. It has columns for 'Content', 'Introduction', 'Route_Name', and 'Tags', all of which are VARCHAR(255) data types. The 'Route_Name' is the primary key, ensuring entity integrity.
The Write_Guide_Table is a junction table that links users to their written guides. It has columns for 'Guide_Title' and 'Username', both of which are VARCHAR(255) data types. Both columns are primary keys, ensuring entity integrity. The 'Guide_Title' and 'Username' columns are foreign keys referencing the 'Guide_Table' and 'User_Table', respectively, ensuring referential integrity.
