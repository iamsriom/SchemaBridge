The database schema named 'rschema_0400' consists of 6 tables. The tables are defined as follows:
1. **Role**: This table holds information about user roles. The columns include Permission_Description (a text field that describes the permissions associated with each role), Role_ID (a unique identifier for each role), and Role_Name (the name of the role).
2. **Book**: This table contains information about books. The columns include Author (the name of the author), Book_Category (the category of the book), Book_ID (a unique identifier for each book), Book_Name (the name of the book), Publication_Date (the date the book was published), and Publisher (the name of the publisher).
3. **User**: This table holds information about users. The columns include College (the name of the user's college), Email (the user's email address), Password (the user's password), Registration_Time (the time the user registered), Role_ID (the user's role, which is a foreign key referencing the Role table), User_ID (a unique identifier for each user), and Username (the user's username).
4. **Notification**: This table holds information about notifications. The columns include Notification_Content (the content of the notification), Notification_ID (a unique identifier for each notification), Notification_Title (the title of the notification), Publisher_ID (the user who published the notification, which is a foreign key referencing the User table), and Release_Date (the date the notification was released).
5. **User_Establishes_Friend_Relationship**: This table holds information about user-to-user friend relationships. The columns include Creation_Time (the time the relationship was created), Friend_ID (the ID of the user who is the friend, which is a foreign key referencing the User table), and User_ID (the ID of the user who is establishing the relationship, which is a foreign key referencing the User table).
6. **User_Borrows_Book**: This table holds information about user-to-book borrow relationships. The columns include Book_ID (the ID of the book being borrowed, which is a foreign key referencing the Book table), Borrow_Time (the time the book was borrowed), Return_Time (the time the book is expected to be returned), and User_ID (the ID of the user borrowing the book, which is a foreign key referencing the User table).
All columns allow null values except for the ones that are marked NOT NULL. Default values are not specified for any columns. Primary keys are marked in the respective tables and foreign keys are used to establish relationships between tables. Referential integrity is maintained through the use of foreign keys.
