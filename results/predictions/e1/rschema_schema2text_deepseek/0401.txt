The database schema named 'rschema_0401' comprises four tables: 'students', 'classes', 'departments', and 'teachers'.
The 'students' table holds information about the students, including their unique student ID, name, gender, grade, department, home address, date of birth, and enrollment time. The primary key for this table is the 'student_id' column. A foreign key constraint 'students_ibfk_department' exists to ensure the 'department' column references the 'department_id' in the 'departments' table.
The 'classes' table contains information about the classes, including the class ID, class name, grade, major, head teacher, department ID, and class monitor. The primary key for this table is 'class_id'. It also has foreign key constraints that ensure the 'head_teacher' and 'class_monitor' columns reference the 'teacher_id' and 'student_id' in their respective tables, respectively. The 'department_id' column also references the 'department_id' in the 'departments' table.
The 'departments' table holds information about the departments, including the department ID and department name, department size, and subordinate majors. The primary key for this table is 'department_id'.
Finally, the 'teachers' table contains information about the teachers, including their unique teacher ID, name, gender, grade, department, home address, date of birth, and entry time. The primary key for this table is 'teacher_id', and a foreign key constraint 'teachers_ibfk_department' ensures the 'department' column references the 'department_id' in the 'departments' table.
All tables are set up with InnoDB engine and default charset as utf8mb3. The schema is designed to maintain referential integrity, with cascading deletion and update operations on foreign keys.
