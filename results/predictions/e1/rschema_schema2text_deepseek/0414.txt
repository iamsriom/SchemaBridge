The database schema named 'rschema_0414' consists of 6 tables. The tables are City, Company, Venue, Sales_Point, Sales_Plan, and Device.
The City table represents the geographical locations. It has columns for City_ID (integer, primary key), City_Name (varchar(255)), and Province (varchar(255)).
The Company table is used to store information about the companies. It has columns for Company_Address (varchar(255)), Company_ID (integer, primary key), and Company_Name (varchar(255)).
The Venue table contains information about the venues. It has columns for Venue_Description (varchar(255)), Venue_ID (integer, primary key), and Venue_Name (varchar(255)).
The Sales_Point table is used to represent the sales points. It has columns for Address (varchar(255)), City_ID (integer, not null, foreign key referencing City(City_ID)), Company_ID (integer, not null, foreign key referencing Company(Company_ID)), Sales_Point_ID (integer, primary key), and Sales_Point_Name (varchar(255)).
The Sales_Plan table contains information about the sales plans. It has columns for Company_ID (integer, not null, foreign key referencing Company(Company_ID)), End_Date (datetime), Sales_Plan_Description (varchar(255)), Sales_Plan_ID (integer, primary key), Sales_Plan_Name (varchar(255)), Sales_Point_ID (integer, not null, foreign key referencing Sales_Point(Sales_Point_ID)), and Start_Date (datetime).
Finally, the Device table contains information about the devices. It has columns for Device_ID (integer, primary key), Device_Model (varchar(255)), Device_Name (varchar(255)), and Sales_Point_ID (integer, not null, foreign key referencing Sales_Point(Sales_Point_ID)). The database schema is designed with entity integrity in mind, ensuring that each table has a primary key and foreign keys are used to maintain referential integrity between the tables.
