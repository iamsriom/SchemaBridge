The database schema named 'rschema_0416' consists of 10 tables. The primary purpose of this schema is to manage user information, company details, job postings, and user interactions within a platform.
The 'User' table holds user information including avatar, email, nickname, password, registration time, role, user ID, and username. The 'Company' table contains details about the company including company address, company ID, company name, company profile, and contact information.
The 'Conversation' table is used to manage user conversations, with each conversation identified by a unique conversation ID. The 'Message_Board' table stores messages posted by users, with each message identified by a unique message ID.
The 'Job_Info' table contains job posting information, including company ID, content, education level, job category, job info ID, requirements, salary, title, and work location.
The 'User_and_Conversation' table is a junction table that links users to conversations, with each record representing a unique conversation between two users. The 'User_and_Message' table is another junction table that links users to messages, with each record representing a unique message sent by a user.
The 'Resume_Submission' and 'Resume_Save' tables are used to manage resume submissions and saves, with each record representing a unique submission or save by a user for a specific job posting.
Finally, the 'Company_and_Job_Info' table is a junction table that links companies to job postings, with each record representing a unique job posting by a company.
All tables in this schema allow null values except for the 'User_ID' in the 'User' and 'Company' tables, and the 'User_ID', 'Message_ID', and 'Job_Info_ID' in the 'Message_Board', 'User_and_Message', 'Resume_Submission', and 'Resume_Save' tables. The primary keys of these tables are unique and not null. The foreign keys in the schema enforce referential integrity, ensuring that the relationships between tables are maintained.
