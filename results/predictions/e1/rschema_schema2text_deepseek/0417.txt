The database schema for the database rschema_0417 consists of 8 tables. The primary tables are 'user', 'post', 'comment', 'category', 'notification_information', 'comment_reply', and 'comment_post'.
The 'user' table represents the users of the application. It has columns for user_id, user_name, email, password, avatar_link, and registration_date. The user_id is the primary key.
The 'post' table represents the posts made by users. It has columns for post_id, title, content, category_belonging, posting_user, posting_time, status, reply_count, like_count, and favorite_count. The post_id is the primary key and the posting_user and category_belonging are foreign keys referencing the user and category tables respectively.
The 'comment' table represents the comments made by users on posts. It has columns for comment_id, comment_content, posting_user, like_count, reply_count, and posting_time. The comment_id is the primary key and the posting_user is a foreign key referencing the user table.
The 'category' table represents the categories of posts. It has columns for category_id and category_name. The category_id is the primary key.
The 'notification_information' table represents the notifications. It has columns for message_number and notification_content. The message_number is the primary key.
The 'comment_reply' table represents the replies to comments. It has columns for comment_id and reply_comment_id. The comment_id and reply_comment_id are foreign keys referencing the comment table.
The 'comment_post' table represents the relationship between comments and posts. It has columns for comment_id and post_id. The comment_id and post_id are foreign keys referencing the comment and post tables respectively.
The 'notification_distribution' table represents the distribution of notifications to users. It has columns for notification_message_number, user_id, and read_status. The user_id and notification_message_number are foreign keys referencing the user and notification_information tables respectively. The read_status column indicates whether the notification has been read by the user.
All columns allow null values except for the ones that are marked NOT NULL. Default values are not specified for any columns. The database engine is InnoDB and the default character set is utf8mb3.
