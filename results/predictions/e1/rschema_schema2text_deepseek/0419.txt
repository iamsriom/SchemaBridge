The database schema named 'rschema_0419' consists of five tables: 'Dish', 'User', 'Order', 'Shopping_cart', and 'Order_detail'.
The 'Dish' table represents the dishes available for ordering. It has columns for 'Cuisine_type', 'Dish_ID', 'Dish_name', 'Ingredients', 'Price', 'Recommendation_index', 'Recommended', 'Special_features', and 'Taste'.
The 'User' table is used to store user information. It includes 'Account_status', 'Address', 'Name', 'Password', 'Phone', 'Registration_time', 'User_ID', and 'Username'.
The 'Order' table contains information about the orders made by the users. It includes 'Delivery_address', 'Delivery_person', 'Delivery_time', 'Order_ID', 'Order_status', and 'Order_time'.
The 'Shopping_cart' table is used to store the dishes added by the users in their shopping cart. It has columns for 'Add_time', 'Dish_ID', 'Quantity', 'Settlement_status', and 'User_ID'. The 'Dish_ID' and 'User_ID' columns are foreign keys referencing the 'Dish' and 'User' tables respectively.
Finally, the 'Order_detail' table stores the details of each order. It includes 'Dish_ID', 'Dish_quantity', 'Order_ID', 'Total_amount', and 'Unit_price'. The 'Dish_ID' and 'Order_ID' columns are foreign keys referencing the 'Dish' and 'Order' tables respectively.
