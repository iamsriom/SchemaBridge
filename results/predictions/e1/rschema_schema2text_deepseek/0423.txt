The database schema named 'rschema_0423' contains 7 tables. The tables are described as follows:
1. **Course**: This table holds information about the courses. The primary key is 'Course_ID', which is an integer. The columns include 'Course_category', 'Course_description', 'Course_name', 'Difficulty_level', 'Number_of_lessons', 'Recommended', 'Target_audience', and 'Total_duration'. All these columns allow null values.
2. **Chapter**: This table holds information about the chapters of the courses. The primary key is 'Chapter_ID', which is an integer. The columns include 'Chapter_description', 'Chapter_name', 'Duration', 'Next_chapter_ID', 'Parent_chapter_ID', 'Previous_chapter_ID', 'Video_URL'. The 'Next_chapter_ID', 'Parent_chapter_ID', and 'Previous_chapter_ID' columns all reference the 'Chapter_ID' in the 'Chapter' table.
3. **Instructor**: This table holds information about the instructors. The primary key is 'Instructor_ID', which is an integer. The columns include 'Avatar', 'Name', 'Personal_profile', 'Professional_field', and 'Teaching_experience'. All these columns allow null values.
4. **Student**: This table holds information about the students. The primary key is 'Student_ID', which is an integer. The columns include 'Account_status', 'Age', 'Avatar', 'Contact_information', 'Gender', 'Membership_level', 'Name', 'Points', 'Registration_time'. All these columns allow null values.
5. **Course_material**: This table holds information about the materials of the courses. The primary key is 'Material_ID', which is an integer. The columns include 'Course_ID', 'Material_URL', and 'Material_name'. The 'Course_ID' column references the 'Course_ID' in the 'Course' table.
6. **Instructor_teaching**: This table holds information about which instructor teaches which course. The primary key is a composite of 'Instructor_ID' and 'Course_ID'. The 'Course_ID' column references the 'Course_ID' in the 'Course' table, and the 'Instructor_ID' column references the 'Instructor_ID' in the 'Instructor' table.
7. **Viewing_record**: This table holds information about the viewing records of the chapters by the students. The primary key is a composite of 'Student_ID' and 'Chapter_ID'. The 'Chapter_ID' column references the 'Chapter_ID' in the 'Chapter' table, and the 'Student_ID' column references the 'Student_ID' in the 'Student' table.
The schema is designed to maintain the integrity of the data by enforcing primary key and foreign key constraints. It also includes indexes to optimize the performance of the queries.
