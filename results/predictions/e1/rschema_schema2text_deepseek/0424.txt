The database schema named "rschema_0424" contains four tables: User, System, Login_record, and System_authorization.
The User table represents a user of the system. It has columns for Account_status, Email, Last_login_time, Login_IP, Password, Phone_number, User_ID, and Username. These columns are all of type VARCHAR(255) and allow null values. The User_ID is the primary key of this table.
The System table represents a system that the users can access. It has columns for Access_time, Approval_required, Callback_URL, Enabled, Secret_key, System_ID, System_domain, System_name, and Token_validity_period. These columns are all of type VARCHAR(255) or BOOL and allow null values. The System_ID is the primary key of this table.
The Login_record table represents a login record of a user to a system. It has columns for Expiration_time, Login_IP, Login_time, Logout_time, System_ID, Token, User_ID, and Valid. The columns System_ID and User_ID are foreign keys referencing the System and User tables respectively. The combination of User_ID and System_ID is the primary key of this table.
The System_authorization table represents the authorization of a user to a system. It has columns for Authorization_time, Effective, Expiration_time, System_ID, and User_ID. The columns System_ID and User_ID are foreign keys referencing the System and User tables respectively. The combination of User_ID and System_ID is the primary key of this table.
This schema ensures referential integrity by enforcing foreign key constraints. When a record in the User or System table is deleted, the corresponding records in the Login_record and System_authorization tables will be automatically deleted to maintain the integrity of the data.
