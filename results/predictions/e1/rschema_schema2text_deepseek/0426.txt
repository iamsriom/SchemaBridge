The database schema we have here is named 'rschema_0426'. It consists of five tables: 'User', 'Attraction', 'User_Bookmark', 'Ticket_Reservation_Record', and 'User_Comment'.
The 'User' table represents the users of the application. It has five columns: 'Account', 'Bio', 'Nickname', 'Password'. The 'Account' column is the primary key of this table.
The 'Attraction' table represents the attractions that users can visit. It has five columns: 'Attraction_ID', 'Name', 'Picture_URL', 'Reference_Price', and 'Text_Description'. 'Attraction_ID' is the primary key of this table.
The 'User_Bookmark' table represents the bookmarks of users. It has two columns: 'Account' and 'Attraction_ID'. Both columns are not null and together form the primary key of this table. The 'Account' column references the 'Account' column in the 'User' table and the 'Attraction_ID' column references the 'Attraction_ID' column in the 'Attraction' table.
The 'Ticket_Reservation_Record' table represents the ticket reservations made by users. It has five columns: 'Attraction_ID', 'Number_of_Tickets_Purchased', 'Reservation_Time', 'Ticket_Purchase_Time', and 'User_Account'. 'User_Account' and 'Attraction_ID' together form the primary key of this table. The 'Attraction_ID' column references the 'Attraction_ID' column in the 'Attraction' table and the 'User_Account' column references the 'Account' column in the 'User' table.
Finally, the 'User_Comment' table represents the comments made by users. It has five columns: 'Attraction_ID', 'Comment_Content', 'Comment_Status', 'Comment_Time', and 'User_Account'. 'User_Account' and 'Attraction_ID' together form the primary key of this table. The 'Attraction_ID' column references the 'Attraction_ID' column in the 'Attraction' table and the 'User_Account' column references the 'Account' column in the 'User' table.
