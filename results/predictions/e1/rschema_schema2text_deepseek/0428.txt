The database schema for the database named rschema_0428 consists of five tables: student, super_user, course, dormitory, and student_course_selection.
The student table represents the students of a university. It has columns for student_id, name, class, gender, age, and belonging_dormitory. The student_id is the primary key and the belonging_dormitory is a foreign key referencing the dormitory table.
The super_user table represents the super users of the university system. It has columns for user_id, name, and user_role. The user_id is the primary key.
The course table represents the courses offered by the university. It has columns for course_id, course_leader, and class_time. The course_id is the primary key and the course_leader is a foreign key referencing the super_user table.
The dormitory table represents the dormitories of the university. It has columns for dormitory_id and dormitory_location. The dormitory_id is the primary key.
The student_course_selection table represents the selection of courses by students. It has columns for student_id, course_id, and grade. The combination of course_id and student_id is the primary key and both are foreign keys referencing the course and student tables respectively. The foreign key constraints are set to ON DELETE CASCADE and ON UPDATE CASCADE, which means that if a course or a student is deleted or updated, the corresponding records in the student_course_selection table will also be deleted or updated.
