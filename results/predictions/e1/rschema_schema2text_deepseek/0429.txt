The database schema named 'rschema_0429' contains four tables: 'user', 'dish', 'order', and 'order_detail'.
The 'user' table is used to store user information. It has three columns: 'username', 'password', and 'role'. The 'username' column is the primary key and cannot be null.
The 'dish' table is used to store information about the dishes. It has four columns: 'dish_name', 'price', 'category', and 'availability'. The 'dish_name' column is the primary key and cannot be null.
The 'order' table is used to store information about orders. It has five columns: 'order_id', 'ordering_user_id', 'order_time', 'total_order_amount', and 'order_status'. The 'order_id' column is the primary key and cannot be null. The 'ordering_user_id' column is a foreign key referencing the 'username' column in the 'user' table.
The 'order_detail' table is used to store details about the orders. It has four columns: 'order_detail_id', 'order_id', 'dish_id', and 'quantity'. The 'order_detail_id' column is the primary key and cannot be null. The 'order_id' and 'dish_id' columns are foreign keys referencing the 'order_id' and 'dish_name' columns in the 'order' and 'dish' tables respectively. The 'order_detail' table has cascade delete and update rules on both 'order_id' and 'dish_id' columns.
