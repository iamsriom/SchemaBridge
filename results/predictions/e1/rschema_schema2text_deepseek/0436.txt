The database schema for the database named rschema_0436 consists of 9 tables. The tables are described as follows:
1. The `administrator` table is used to store information about the administrators of the website. It includes fields such as `administrator_id`, `username`, `password`, `email`, `creation_time`, and `update_time`. The `administrator_id` is the primary key of this table.
2. The `news_article` table is used to store information about the news articles published on the website. It includes fields such as `article_id`, `article_title`, `article_content`, `article_author`, `publish_time`, `article_category`, `article_tags`, `creation_time`, and `update_time`. The `article_id` is the primary key of this table.
3. The `website_information` table is used to store information about the website itself. It includes fields such as `website_id`, `website_name`, `website_logo`, `copyright_information`, `creation_time`, and `update_time`. The `website_id` is the primary key of this table.
4. The `member` table is used to store information about the members of the website. It includes fields such as `member_id`, `username`, `password`, `email`, `registration_time`, and `update_time`. The `member_id` is the primary key of this table.
5. The `advertisement` table is used to store information about the advertisements posted on the website. It includes fields such as `advertisement_id`, `advertisement_title`, `advertisement_content`, `advertisement_publish_time`, `creation_time`, and `update_time`. The `advertisement_id` is the primary key of this table.
6. The `message` table is used to store information about the messages posted by members on news articles. It includes fields such as `message_id`, `user_id`, `article_id`, `message_content`, `message_time`, `reply_content`, and `reply_time`. The `message_id` is the primary key of this table and `user_id` and `article_id` are foreign keys referencing the `member` and `news_article` tables respectively.
7. The `administrator_publish_news` table is used to link the administrators and the news articles they publish. It includes fields such as `administrator_id` and `article_id`. Both are primary keys and foreign keys referencing the `administrator` and `news_article` tables respectively.
8. The `administrator_manage_advertisement` table is used to link the administrators and the advertisements they manage. It includes fields such as `administrator_id` and `advertisement_id`. Both are primary keys and foreign keys referencing the `administrator` and `advertisement` tables respectively.
9. The `user_message` table is used to link the members and the messages they post. It includes fields such as `member_id` and `message_id`. Both are primary keys and foreign keys referencing the `member` and `message` tables respectively.
All tables have been set up with the InnoDB engine and the default character set is utf8mb3. The tables are designed to maintain data integrity by enforcing primary key and foreign key constraints. The delete and update rules are set to CASCADE, meaning that if a record in the referenced table is deleted or updated, the corresponding records in the referencing table will also be deleted or updated.
