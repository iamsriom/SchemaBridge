The database schema named rschema_0438 consists of six tables.
The User table is used to store user information. It includes columns for Contact_Information, Password, Registration_Time, User_ID, and Username. The User_ID is the primary key, ensuring entity integrity as no two users can have the same ID.
The Product table stores product information. It includes columns for Price, Product_Description, Product_ID, Product_Name, and Stock_Quantity. The Product_ID is the primary key, ensuring entity integrity for each product.
The Add_to_Cart table is used to store information about which products a user has added to their cart. It includes columns for Is_Selected, Product_ID, Quantity, and User_ID. The combination of User_ID and Product_ID forms the primary key, ensuring entity integrity. The Product_ID and User_ID are foreign keys referencing the Product and User tables respectively.
The Order table stores information about user orders. It includes columns for Order_ID, Order_Status, Order_Time, Product_ID, Quantity, Total_Price, and User_ID. The Order_ID is the primary key, ensuring entity integrity for each order. The Product_ID and User_ID are foreign keys referencing the Product and User tables respectively.
The User_and_Order table is a junction table that links users and orders. It includes columns for Order_ID, Order_Status, Order_Time, Product_ID, Quantity, Total_Price, and User_ID. The combination of Order_ID and User_ID forms the primary key, ensuring entity integrity. The Order_ID and Product_ID, as well as User_ID, are foreign keys referencing the Order, Product, and User tables respectively.
Finally, the Order_and_Product table is another junction table that links orders and products. It includes columns for Order_ID, Order_Status, Order_Time, Product_ID, Quantity, Total_Price, and User_ID. The combination of Order_ID and Product_ID forms the primary key, ensuring entity integrity. The Order_ID and Product_ID, as well as User_ID, are foreign keys referencing the Order, Product, and User tables respectively. This schema provides a robust and normalized structure for managing user and product data, with constraints to ensure data integrity and consistency.
