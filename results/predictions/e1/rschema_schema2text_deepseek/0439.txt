The database schema named "rschema_0439" consists of five tables: User, Merchant, Recycling_Request, Transaction_Order, and Order_Review.
The User table is used to store user information. It includes columns for Password, Phone_Number, User_ID (which is the primary key), User_Name, and WeChat_ID.
The Merchant table is used to store merchant information. It includes columns for Address, Contact_Information, Merchant_Account (which is the primary key), and Password.
The Recycling_Request table is used to store recycling request information. It includes columns for Order_ID (which is the primary key), Recycling_Location, Recycling_Time, Request_Time, and Request_User (which is a foreign key referencing the User_ID in the User table).
The Transaction_Order table is used to store transaction order information. It includes columns for Accepting_Merchant (which is a foreign key referencing the Merchant_Account in the Merchant table), Order_ID (which is the primary key and also a foreign key referencing the Order_ID in the Recycling_Request table), Order_Status, Payment_Amount, and Payment_Method.
The Order_Review table is used to store order review information. It includes columns for Order_ID (which is the primary key and also a foreign key referencing the Order_ID in the Recycling_Request table), Rating, Review_Content.
All columns allow null values except for Request_User in the Recycling_Request table and Accepting_Merchant in the Transaction_Order table, which are not null. The database schema ensures referential integrity by maintaining foreign key relationships between the tables.
