The database schema for the database named rschema_0443 consists of seven tables. The first table, user_information, contains information about the users of the system. It includes fields for the user's ID, username, login password, registered phone number, and role permissions. The primary key for this table is the user_id.
The second table, asset_information, contains information about the assets in the system. It includes fields for the device's ID, device name, device number, device model, device status, calibration date, calibration validity, calibration result, device location, department, responsible person, and remarks. The primary key for this table is the device_id.
The third table, status_log_information, contains information about the status logs of the assets. It includes fields for the log ID, device number, borrow receiver, borrow time, borrow device photo, IOU photo, receiver, receiving area, receiving time, receiving device photo, return person, return time, return device photo, data monitoring, and remarks. The primary key for this table is the log_id. It also has a foreign key constraint referencing the asset_information table's device_number field.
The fourth table, account_dynamic_log_information, contains information about the dynamic logs of the accounts. It includes fields for the dynamic log ID, device number, borrow operation account, receive operation account, return operation account, and remarks. The primary key for this table is the dynamic_log_id. It also has a foreign key constraint referencing the asset_information table's device_number field.
The fifth table, user_asset_relationship, is a junction table that links the user_information and asset_information tables. It includes fields for the user ID and device number. The primary key for this table is a composite of user_id and device_number. It also has foreign key constraints referencing the user_information table's user_id field and the asset_information table's device_id field.
The sixth table, device_number,_log_id, is a junction table that links the asset_information and status_log_information tables. It includes fields for the device number and log ID. The primary key for this table is a composite of device_number and log_id. It also has foreign key constraints referencing the status_log_information table's log_id field and the asset_information table's device_id field.
The seventh table, asset_account_dynamic_log_relationship, is a junction table that links the asset_information and account_dynamic_log_information tables. It includes fields for the device number and dynamic log ID. The primary key for this table is a composite of device_number and dynamic_log_id. It also has foreign key constraints referencing the account_dynamic_log_information table's dynamic_log_id field and the asset_information table's device_id field. The foreign key constraints in this table are set to ON DELETE CASCADE and ON UPDATE CASCADE, which means that if a record in the asset_information table is deleted or updated, the corresponding records in this table will also be deleted or updated.
