The database schema named rschema_0447 consists of five tables: User, Financial_Document, Notification, System_Configuration, and Document_Management.
The User table is used to store user information, including Associated_Unit, Password, Phone_Number, Role, User_ID (as the primary key), and Username. Each field is a VARCHAR type and allows NULL values.
The Financial_Document table is used to store financial document information, including Attachment_Path, Document_Category, Document_Content, Document_ID (as the primary key), Document_Level, Document_Number, Document_Title, Issue_Date, Issuing_Unit, Remarks, and Validity_Status. All fields are VARCHAR type and allow NULL values.
The Notification table is used to store notification information, including Issue_Date, Notification_Content, Notification_ID (as the primary key), Notification_Status, Notification_Title, and User_ID. User_ID is a foreign key referencing the User table.
The System_Configuration table is used to store system configuration information, including Admin_ID, Configuration_ID (as the primary key), Data_Type, Database_Directory, File_Upload_Directory, and System_Name. Admin_ID is a foreign key referencing the User table.
The Document_Management table is used to manage document operations, including Admin_ID, Document_ID, Operation_Time, and Operation_Type. Both Admin_ID and Document_ID are foreign keys referencing the User and Financial_Document tables respectively. The combination of Admin_ID and Document_ID forms the primary key of this table.
This schema ensures data integrity by enforcing primary key and foreign key constraints. It also allows for referential integrity, as the foreign keys ensure that the referenced data exists in the referenced table.
