The database schema named "rschema_0448" consists of 9 tables. The main purpose of this schema is to manage various aspects of an experimental facility.
The "User" table represents the users of the system. It includes columns for the user's associated unit, password, phone number, role, user ID, and username. The User_ID is the primary key of this table.
The "Experimental_Equipment" table contains information about the experimental equipment. It includes columns for the acquisition time, device category, device ID, device model, device name, manufacturer, and status. The Device_ID is the primary key of this table.
The "Experimental_Consumables" table contains information about the consumables used in the experiments. It includes columns for the category, consumable ID, consumable name, inventory quantity, and status. The Consumable_ID is the primary key of this table.
The "Hazardous_Chemicals" table contains information about hazardous chemicals. It includes columns for the chemical ID, chemical name, inventory quantity, issuance time, and status. The Chemical_ID is the primary key of this table.
The "Experimental_Course" table contains information about the experimental courses. It includes columns for the class location, class time, course ID, course name, participants, and teacher ID. The Course_ID is the primary key of this table and the Teacher_ID is a foreign key referencing the User table.
The "User_Usage_of_Equipment" table contains information about the usage of equipment by users. It includes columns for the device ID, usage purpose, usage time, and user ID. The combination of Device_ID, User_ID, and Usage_Time forms the primary key of this table. The Device_ID and User_ID are foreign keys referencing the Experimental_Equipment and User tables respectively.
The "User_Purchase_Consumables" table contains information about the consumables purchased by users. It includes columns for the consumable ID, purchase time, and user ID. The combination of Consumable_ID, User_ID, and Purchase_Time forms the primary key of this table. The Consumable_ID and User_ID are foreign keys referencing the Experimental_Consumables and User tables respectively.
The "User_Purchase_Hazardous_Chemicals" table contains information about the hazardous chemicals purchased by users. It includes columns for the chemical ID, purchase time, and user ID. The combination of Chemical_ID, User_ID, and Purchase_Time forms the primary key of this table. The Chemical_ID and User_ID are foreign keys referencing the Hazardous_Chemicals and User tables respectively.
Finally, the "User_Participation_in_Course" table contains information about the participation of users in courses. It includes columns for the course ID, experimental course grade, participation status, and user ID. The combination of User_ID and Course_ID forms the primary key of this table. The Course_ID and User_ID are foreign keys referencing the Experimental_Course and User tables respectively.
This schema ensures referential integrity by enforcing foreign key constraints. It also ensures entity integrity by having primary keys for all tables and unique constraints for certain columns. It also allows for cascading updates and deletions when the referenced records are updated or deleted.
