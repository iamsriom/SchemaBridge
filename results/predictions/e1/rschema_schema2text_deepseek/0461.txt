The database schema named 'rschema_0461' contains 6 tables. The tables are described as follows:
1. **Product**: This table holds information about the products. The columns include Category (a string), Description (a string), Location (a string), Name (a string), Product_ID (an integer, primary key), Stock_Quantity (an integer), Unit_Price (a float), and Unit_of_Measurement (a string).
2. **Delivery_Personnel**: This table contains information about the delivery personnel. The columns include Delivery_Personnel_ID (an integer, primary key), Gender (a boolean), Name (a string), Phone (a string), and Position (a string).
3. **Customer**: This table contains information about the customers. The columns include Address (a string), Age (an integer), Customer_ID (an integer, primary key), Gender (a boolean), Name (a string), and Phone (a string).
4. **Order**: This table holds information about the orders. The columns include Customer_ID (an integer, foreign key referencing Customer), Delivery_Address (a string), Order_Creation_Time (a datetime), Order_Number (an integer, primary key), Order_Status (a string), and Total_Order_Price (a float).
5. **Order_Product**: This table maps the products in an order to the orders. The columns include Order_ID (an integer, foreign key referencing Order) and Product_ID (an integer, foreign key referencing Product), along with Product_Quantity (an integer). Both Order_ID and Product_ID form the primary key of this table.
6. **Order_Delivery**: This table maps the delivery personnel to the orders. The columns include Delivery_Personnel_ID (an integer, foreign key referencing Delivery_Personnel), Estimated_Delivery_Time (a datetime), and Order_ID (an integer, foreign key referencing Order). Both Order_ID and Delivery_Personnel_ID form the primary key of this table.
This schema is designed to maintain a detailed record of product orders, their quantities, delivery personnel, and associated information. It ensures referential integrity by linking all the tables together through foreign keys.
