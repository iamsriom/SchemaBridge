The database schema we have here is named 'rschema_0462' and it consists of four tables: 'Member', 'Book', 'Order', and 'Purchase'.
The 'Member' table represents a member of our bookstore. It contains columns for the member's address, consumption amount, member ID, name, password, phone number, points, postal code, and username. The member ID is the primary key of this table.
The 'Book' table contains information about the books available in our store. It includes columns for the author's name, book title, category name, ISBN, price, publication date, and publisher. The ISBN is the primary key of this table.
The 'Order' table records the orders made by the members. It includes columns for the member ID, order ID, order date, sales amount, and shipping date. The member ID is a foreign key referencing the Member table, and the order ID is the primary key of this table.
Finally, the 'Purchase' table records the purchases made by the members. It includes columns for the ISBN of the book, order ID, quantity, and primary key consisting of the order ID and ISBN. The ISBN is a foreign key referencing the Book table, and the order ID is a foreign key referencing the Order table.
