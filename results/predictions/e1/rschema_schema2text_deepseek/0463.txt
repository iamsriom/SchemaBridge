The database schema named 'rschema_0463' consists of three tables: 'Mall', 'Department', and 'Employee'.
The 'Mall' table represents a retail malls and contains columns for 'Address', 'Contact_Number', 'Mall_ID', and 'Mall_Name'. The 'Mall_ID' is the primary key for this table.
The 'Department' table represents a department within a mall and contains columns for 'Contact_Number', 'Department_ID', 'Department_Name', 'Location_Distribution', 'Mall_ID', 'Manager_Employee_ID', and 'Tenure'. The 'Department_ID' is the primary key for this table and 'Mall_ID' is a foreign key referencing the 'Mall' table. The 'Manager_Employee_ID' is a foreign key referencing the 'Employee' table.
The 'Employee' table represents employees within a department and contains columns for 'Department_ID', 'Emergency_Contact_Name', 'Emergency_Contact_Phone', 'Employee_ID', 'Name', 'Phone_Number', 'Position', and 'Salary'. The 'Employee_ID' is the primary key for this table and 'Department_ID' is a foreign key referencing the 'Department' table.
This schema ensures referential integrity by enforcing foreign key constraints. When a record in the 'Mall' table is deleted or updated, the corresponding records in the 'Department' and 'Employee' tables will be automatically updated or deleted due to the cascade delete or update rules.
