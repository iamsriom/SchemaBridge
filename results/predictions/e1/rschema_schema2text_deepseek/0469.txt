The database schema named 'rschema_0469' contains five tables: Property_owner, Housing, Department, Employee, and Fee_collection.
The Property_owner table represents the owners of the properties. It has columns for Contact_number (VARCHAR(255)), Name (VARCHAR(255)), Owner_ID (INTEGER, primary key), and Workplace (VARCHAR(255)).
The Housing table represents the housing units. It has columns for Floor_area (FLOAT), House_number (VARCHAR(255), primary key), and Owner_ID (INTEGER, not null, foreign key referencing Owner_ID in the Property_owner table).
The Department table represents the departments within the company. It has columns for Department_ID (INTEGER, primary key), Department_name (VARCHAR(255)), Department_phone (VARCHAR(255)), and Supervisor_employee_ID (INTEGER, not null, foreign key referencing Employee_ID in the Employee table).
The Employee table represents the employees within the company. It has columns for Address (VARCHAR(255)), Contact_number (VARCHAR(255)), Date_of_birth (DATETIME), Department_ID (INTEGER, not null, foreign key referencing Department_ID in the Department table), Employee_ID (INTEGER, primary key), Gender (BOOL), Name (VARCHAR(255)), Password (VARCHAR(255)), and Position (VARCHAR(255)).
The Fee_collection table represents the fee collections. It has columns for Collection_date (DATETIME, primary key), Collection_employee_ID (INTEGER, not null, foreign key referencing Employee_ID in the Employee table), Fee_amount (FLOAT), Fee_type (VARCHAR(255)), House_number (VARCHAR(255), not null, foreign key referencing House_number in the Housing table), and Quantity (INTEGER). The primary key of this table is a composite of House_number, Collection_employee_ID, and Collection_date.
This schema ensures data integrity by enforcing primary key and foreign key constraints. It also ensures entity integrity by ensuring that each row in a table has a unique primary key. The referential integrity is maintained by the foreign key constraints, ensuring that the foreign key values in a table correspond to the primary key values in another table.
