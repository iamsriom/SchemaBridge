The database schema named rschema_0470 consists of seven tables. The Enterprise_Employee table is used to store information about the employees of an enterprise. It includes columns for Employee_Address (a VARCHAR of up to 255 characters), Employee_ID (an INTEGER primary key), Employee_Name (a VARCHAR of up to 255 characters), and Employee_Phone (an INTEGER).
The Menu table stores information about the dishes served by the enterprise. It includes columns for Dish_ID (an INTEGER primary key), Dish_Name (a VARCHAR of up to 255 characters), Dish_Price (a FLOAT), and Dish_Special_Offer_Indicator (a BOOL).
The Delivery_Person table stores information about the delivery personnel. It includes columns for Delivery_Person_Address (a VARCHAR of up to 255 characters), Delivery_Person_ID (an INTEGER primary key), Delivery_Person_Name (a VARCHAR of up to 255 characters), and Delivery_Person_Phone (an INTEGER).
The Order table represents the orders placed by the enterprise employees. It includes columns for Delivery_Address (a VARCHAR of up to 255 characters), Delivery_Time (a DATETIME), Order_ID (an INTEGER primary key), Order_Payment_Method (a VARCHAR of up to 255 characters), Order_Total_Price (a FLOAT), and Ordering_Employee (an INTEGER not null, referencing Employee_ID in the Enterprise_Employee table).
The Order_Dish table represents the dishes ordered by the enterprise employees. It includes columns for Dish_ID (an INTEGER not null, referencing Dish_ID in the Menu table), Dish_Quantity (an INTEGER), Order_ID (an INTEGER not null, referencing Order_ID in the Order table), and is the primary key for (Order_ID, Dish_ID).
The Delivery_Record table records the delivery orders. It includes columns for Delivery_Order_ID (an INTEGER not null, referencing Order_ID in the Order table), Delivery_Record_ID (an INTEGER primary key), Delivery_Time (a DATETIME), and Responsible_Delivery_Person_ID (an INTEGER not null, referencing Delivery_Person_ID in the Delivery_Person table).
Finally, the Payment_Request table records payment requests. It includes columns for Paying_Employee_ID (an INTEGER not null, referencing Employee_ID in the Enterprise_Employee table), Paying_Order_ID (an INTEGER not null, referencing Order_ID in the Order table), Payment_Request_ID (an INTEGER primary key), Request_Payment_Amount (a FLOAT), and Request_Payment_Status (a VARCHAR of up to 255 characters).
