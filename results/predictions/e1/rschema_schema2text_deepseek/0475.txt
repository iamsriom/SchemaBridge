The database schema for the database named 'rschema_0475' consists of five tables: 'supermarket', 'department', 'employee', 'product', and 'salesperson_product_distribution'.
The 'supermarket' table represents the supermarket information, including the supermarket ID, name, address, manager, and phone number. The supermarket name is the primary key.
The 'department' table contains information about the departments within the supermarket. It includes the department name, department manager, contact number, and supermarket ID. The department name is the primary key and the supermarket ID is a foreign key referencing the supermarket table.
The 'employee' table holds data about the employees, including the employee ID, name, contact information, position, salary, and department ID. The employee ID is the primary key and the department ID is a foreign key referencing the department table.
The 'product' table contains information about the products, including the product ID, product name, model, unit price, and quantity. The product ID is the primary key.
Finally, the 'salesperson_product_distribution' table holds data about the distribution of products among employees. It includes the product ID and employee ID, along with the sales volume and stock. Both the product ID and employee ID are primary keys and the product ID and employee ID are foreign keys respectively referencing the product and employee tables. The foreign key constraints are set to CASCADE on delete and update operations. This means that if a product or an employee record is deleted or updated, the corresponding records in the 'salesperson_product_distribution' table will also be deleted or updated.
