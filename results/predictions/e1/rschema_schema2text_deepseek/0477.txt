The database schema named 'rschema_0477' consists of two tables, 'billing_method' and 'transaction_record'.
The 'billing_method' table represents the methods of billing used in the system. It has three columns: 'billing_method_id' which is a unique identifier for each billing method, 'name' which represents the name of the billing method, and 'calculation_function' which represents the function used to calculate the billing amount. The 'billing_method_id' column is the primary key of this table.
The 'transaction_record' table represents the records of transactions made in the system. It has five columns: 'transaction_id' which is a unique identifier for each transaction, 'input_amount' which represents the input amount for the transaction, 'billing_method_id' which is a foreign key referencing the 'billing_method_id' in the 'billing_method' table, 'actual_payment_amount' which represents the actual payment amount, and 'transaction_time' which represents the time of the transaction. The 'transaction_id' column is the primary key of this table. The 'billing_method_id' column is a foreign key referencing the 'billing_method_id' in the 'billing_method' table. The 'transaction_record' table has ON DELETE CASCADE and ON UPDATE CASCADE rules to ensure referential integrity.
This schema allows for a clear and efficient tracking of transactions and billing methods in the system.
