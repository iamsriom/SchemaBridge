The database schema named 'rschema_0495' contains seven tables. The tables are:
1. **Ward**: This table represents the wards in the hospital. It has columns for Location (a string of up to 255 characters), Number_of_Beds (an integer), Ward_ID (an integer), and Ward_Level (an integer). The primary key for this table is Ward_ID.
2. **Medicine**: This table represents the medicines in the hospital's inventory. It has columns for Inventory_Quantity (an integer), Medicine_ID (an integer), Medicine_Name (a string of up to 255 characters), Remarks (a string of up to 255 characters), and Sales_Price (a float). The primary key for this table is Medicine_ID.
3. **Patient**: This table represents the patients in the hospital. It has columns for Age (an integer), Contact_Information (a string of up to 255 characters), Gender (a string of up to 255 characters), Name (a string of up to 255 characters), Patient_ID (an integer), and Ward_ID (an integer). The primary key for this table is Patient_ID and Ward_ID is a foreign key referencing the Ward table.
4. **Medication_Dispensing**: This table represents the dispensing of medicines to patients. It has columns for Medication_Retrieval_Time (a datetime), Medicine_ID (an integer), Patient_ID (an integer), and Quantity_Retrieved (an integer). The primary key for this table is a composite of Patient_ID, Medicine_ID, and Medication_Retrieval_Time. Medicine_ID and Patient_ID are foreign keys referencing the Medicine and Patient tables respectively.
5. **Doctor**: This table represents the doctors in the hospital. It has columns for Department_ID (an integer), Gender (a string of up to 255 characters), ID (an integer), Name (a string of up to 255 characters), Phone_Number (a string of up to 255 characters), Title (a string of up to 255 characters), and Years_of_Service (an integer). The primary key for this table is ID and Department_ID is a foreign key referencing the Department table.
6. **Department**: This table represents the departments in the hospital. It has columns for Department_ID (an integer), Department_Name (a string of up to 255 characters), Department_Phone_Number (a string of up to 255 characters), Location (a string of up to 255 characters), Person_in_Charge_ID (an integer), and Total_Number_of_Personnel (an integer). The primary key for this table is Department_ID and Person_in_Charge_ID is a foreign key referencing the Doctor table.
7. **Consultation_Record**: This table represents the consultation records in the hospital. It has columns for Consultation_Time (a datetime), Diagnosis_Description (a string of up to 255 characters), Doctor_ID (an integer), Patient_ID (an integer), Remarks (a string of up to 255 characters), and Treatment_Results (a string of up to 255 characters). The primary key for this table is a composite of Patient_ID and Doctor_ID along with Consultation_Time. Doctor_ID and Patient_ID are foreign keys referencing the Doctor and Patient tables respectively.
All columns allow null values except for the ones that are not nullable in the table definition. The database schema ensures referential integrity by enforcing foreign key constraints.
