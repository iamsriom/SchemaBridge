The database schema for the database named rschema_0498 consists of five tables: student_table, class_table, sports_team_table, school_table, and dormitory_table.
The student_table represents a collection of students, with each student having an id, name, gender, age, dormitory_id, and class_id. The student_id is the primary key of this table, and it is used to uniquely identify each student. The foreign keys dormitory_id and class_id reference the dormitory_table and class_table respectively, with cascade delete and update rules.
The class_table holds information about classes, with each class having a class_id, class_teacher, number_of_students, and location. The class_id is the primary key of this table.
The sports_team_table contains information about sports teams, with each team having a team_name, activity_time, coach, activity_venue, team_id, and affiliated_school. The team_id is the primary key of this table, and the foreign key affiliated_school references the school_table.
The school_table contains information about schools, with each school having a school_id and school_name. The school_id is the primary key of this table.
Finally, the dormitory_table holds information about dormitories, with each dormitory having a dormitory_id, building_number, administrator, and dormitory_capacity. The dormitory_id is the primary key of this table.
All columns in these tables allow null values, and they use the InnoDB engine with a default character set of utf8mb3.
