The database schema named 'rschema_0500' contains six tables. The tables are described as follows:
1. **Role_Table**: This table represents the roles that users can have in the system. It has three columns: Role_Description (a text field for a description of the role), Role_ID (an integer field serving as the primary key), and Role_Name (a text field for the name of the role).
2. **Task_Type**: This table represents the types of tasks that can be created in the system. It has three columns: Task_Type_Description (a text field for a description of the task type), Task_Type_ID (an integer field serving as the primary key), and Task_Type_Name (a text field for the name of the task type).
3. **Task_Status**: This table represents the statuses of tasks in the system. It has three columns: Task_Status_Description (a text field for a description of the task status), Task_Status_ID (an integer field serving as the primary key), and Task_Status_Name (a text field for the name of the task status).
4. **Task_Priority**: This table represents the priorities of tasks in the system. It has three columns: Task_Priority_Description (a text field for a description of the task priority), Task_Priority_ID (an integer field serving as the primary key), and Task_Priority_Name (a text field for the name of the task priority).
5. **User**: This table represents the users of the system. It has five columns: Email (a text field for the user's email), Password (a text field for the user's password), Role_ID (an integer field serving as the foreign key referencing Role_Table), User_ID (an integer field serving as the primary key), and Username (a text field for the user's username).
6. **Task_Table**: This table represents the tasks in the system. It has nine columns: Assigned_User_ID (an integer field serving as the foreign key referencing User), Task_Deadline (a date and time field for the task's deadline), Task_Description (a text field for the task's description), Task_ID (an integer field serving as the primary key), Task_Name (a text field for the task's name), Task_Priority_ID (an integer field serving as the foreign key referencing Task_Priority), Task_Progress (a text field for the task's progress), Task_Status_ID (an integer field serving as the foreign key referencing Task_Status), and Task_Type_ID (an integer field serving as the foreign key referencing Task_Type).
All columns allow null values except for Role_ID, User_ID, Task_Priority_ID, Task_Status_ID, and Task_Type_ID which are not allowed to have null values. There are also foreign key constraints to ensure referential integrity between the tables.
