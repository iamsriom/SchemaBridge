The database schema named 'rschema_0501' contains six tables.
The 'Aircraft' table represents the fleet of aircrafts managed by an airline. It includes attributes such as the affiliated airline, aircraft ID, model, status, manufacture date, and maximum passenger capacity.
The 'Crew_Member' table holds information about the crew members. It includes attributes like crew member ID, gender, name, phone number, and position.
The 'Passenger' table contains details about the passengers. It includes attributes like gender, identification number, name, passenger ID, and phone number.
The 'Flight' table records information about the flights. It includes attributes like aircraft ID, departure airport, departure time, flight ID, landing airport, landing time, and the ID of the responsible captain. The aircraft ID and the captain ID are foreign keys referencing the Aircraft and Crew_Member tables respectively.
The 'Maintenance_Record' table keeps track of the maintenance records. It includes attributes like aircraft ID, maintenance date, description, personnel ID, and type. The aircraft ID and personnel ID are foreign keys referencing the Aircraft and Crew_Member tables respectively.
Finally, the 'Ticket_Order' table records ticket orders. It includes attributes like booking time, flight ID, passenger ID, seat number, and ticket price. The flight ID and passenger ID are foreign keys referencing the Flight and Passenger tables respectively. This schema ensures referential integrity by linking these tables together through foreign keys.
