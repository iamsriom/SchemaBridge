The database schema named "rschema_0502" contains five tables: Venue, User, Equipment, Venue_Reservation, and Venue_Evaluation.
The Venue table represents a venue in the database, with columns for Address, Area_Size, Creation_Time, Last_Maintenance_Time, Maximum_Capacity, Name, Status, Type, and Venue_ID. Venue_ID is the primary key.
The User table represents a user in the database, with columns for Creation_Time, Email, Name, Phone_Number, and User_ID. User_ID is the primary key.
The Equipment table represents the equipment available at the venues, with columns for Equipment_ID, Equipment_Name, Last_Maintenance_Time, Start_Usage_Time, and Venue_ID. Venue_ID is a foreign key referencing the Venue table.
The Venue_Reservation table represents reservations made by users for venues, with columns for End_Time, Reservation_Cancellation_Time, Reservation_Status, Reservation_Success_Time, Start_Time, User_ID, and Venue_ID. User_ID and Venue_ID are foreign keys referencing the User and Venue tables respectively. The combination of User_ID, Venue_ID, and Reservation_Success_Time forms the primary key.
Finally, the Venue_Evaluation table represents evaluations made by users for venues, with columns for Evaluation_Content, Evaluation_Time, Rating, User_ID, and Venue_ID. User_ID and Venue_ID are foreign keys referencing the User and Venue tables respectively. The combination of User_ID, Venue_ID, and Evaluation_Time forms the primary key. This schema ensures data integrity by enforcing primary and foreign key constraints, and referential integrity by maintaining relationships between tables.
