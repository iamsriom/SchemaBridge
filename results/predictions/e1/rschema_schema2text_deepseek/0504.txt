The database schema named 'rschema_0504' contains five tables. The main table is 'Cultural_Relic', which represents cultural relics and contains columns for Category, Cultural_Relic_ID, Excavation_Site, Last_Repair_Time, Name, and Year. The 'Staff' table represents the staff members and contains columns for Gender, Name, Phone_Number, and Staff_ID. The 'Cultural_Relic_Exhibition' table represents the exhibitions of cultural relics and contains columns for Cultural_Relic_ID, Exhibition_End_Time, Exhibition_Location, and Exhibition_Start_Time. The 'Cultural_Relic_Repair_Record' table represents the repair records of cultural relics and contains columns for Cultural_Relic_ID, Notes, Repair_End_Time, Repair_Method, Repair_Start_Time, and Staff_ID. The 'Cultural_Relic_Monitoring_Record' table represents the monitoring records of cultural relics and contains columns for Air_Quality, Cultural_Relic_ID, Humidity, Light, Monitoring_Time, Notes, Person_In_Charge_ID, Temperature. All tables have primary keys and foreign keys to ensure entity integrity and referential integrity.
The 'Cultural_Relic' table has a primary key on Cultural_Relic_ID and a foreign key on Staff_ID in the 'Cultural_Relic_Repair_Record' table. The 'Staff' table has a primary key on Staff_ID and foreign keys in the 'Cultural_Relic_Repair_Record' and 'Cultural_Relic_Monitoring_Record' tables. The 'Cultural_Relic_Exhibition' table has a composite primary key on Cultural_Relic_ID and Exhibition_Start_Time. The 'Cultural_Relic_Repair_Record' table has a composite primary key on Staff_ID and Cultural_Relic_ID and Repair_Start_Time. The 'Cultural_Relic_Monitoring_Record' table has a composite primary key on Cultural_Relic_ID, Monitoring_Time, and Person_In_Charge_ID.
The 'Cultural_Relic' table allows null values in the Category, Excavation_Site, Name, and Year columns. The 'Staff' table allows null values in the Gender, Name, and Phone_Number columns. The 'Cultural_Relic_Exhibition' table allows null values in the Exhibition_End_Time, Exhibition_Location, and Exhibition_Start_Time columns. The 'Cultural_Relic_Repair_Record' table allows null values in the Notes, Repair_End_Time, Repair_Method, and Repair_Start_Time columns. The 'Cultural_Relic_Monitoring_Record' table allows null values in the Air_Quality, Humidity, Light, Notes, Temperature columns.
The 'Cultural_Relic' table has a default value of the current date and time in the Last_Repair_Time column. The 'Cultural_Relic_Repair_Record' table has a default value of the current date and time in the Repair_Start_Time column. The 'Cultural_Relic_Monitoring_Record' table has a default value of the current date and time in the Monitoring_Time column.
