The database schema named rschema_0505 consists of six tables: User, Student, Teacher, Log_Information, Research_Project, and Teacher_Responsible_for_Research_Project.
The User table represents the users of the system, with columns for Account (a unique identifier), Password, and Role. The User table has a primary key on the Account column.
The Student table contains information about students, including their Average_Grade, Major, Name, and Student_ID. The Student_ID is the primary key for this table.
The Teacher table contains information about teachers, including Age, Contact_Information, Gender, Job_Title, Name, Teacher_ID, and Work_History. The Teacher_ID is the primary key for this table.
The Log_Information table logs information about operations performed by users. It includes Detailed_Description, Operation_Time, Operation_Type, and User_Account. The User_Account column is a foreign key referencing the Account column in the User table.
The Research_Project table contains information about research projects, including Funding, Outcome, Project_ID, Project_Name, and Responsible_Teacher. The Project_ID is the primary key and Responsible_Teacher is a foreign key referencing Teacher_ID in the Teacher table.
Finally, the Teacher_Responsible_for_Research_Project table links teachers and research projects. It includes Project_ID and Teacher_ID, both of which are foreign keys referencing the respective tables. This schema ensures entity integrity by having primary and foreign keys, and it also maintains referential integrity by ensuring that the foreign keys reference valid primary keys.
