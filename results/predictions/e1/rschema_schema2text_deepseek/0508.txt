The Book table contains details about books, including the author's name, book ID, book title, category name, ISBN, price, publication date, and publisher.
The Order table represents orders made by members. It contains information about the member ID, order ID, order date, sales amount, and shipping date. The Order_book table is a junction table that links the Order and Book tables, indicating the quantity of each book in an order. The Place_order table is another junction table that links the Member and Order tables, indicating which member placed which order.
The Member table's Member_ID column is the primary key and the Order table's Order_ID column is the primary key. The Order_book table's (Order_ID, Book_ID) combination is the primary key. The Place_order table's (Member_ID, Order_ID) combination is the primary key.
Foreign keys are used to establish relationships between the tables. The Place_order table's Member_ID column references the Member table's Member_ID column, and the Place_order table's Order_ID column references the Order table's Order_ID column.
The schema ensures referential integrity by enforcing foreign key constraints. When a record in the Member table is deleted, any associated records in the Order table (via the Member_ID foreign key) will also be deleted.
