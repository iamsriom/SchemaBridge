The database schema named 'rschema_0511' contains four tables: Owner_Table, Department_Table, Employee_Table, and Charge_Table.
The Owner_Table represents the owners of the property. It includes columns for Contact_Number (VARCHAR), Employer (VARCHAR), House_Area (FLOAT), Name (VARCHAR), Owner_ID (INTEGER, primary key), and Room_Number (VARCHAR).
The Department_Table holds information about the departments. It includes columns for Department_Head (VARCHAR), Department_ID (INTEGER, primary key), Department_Name (VARCHAR), and Department_Phone (VARCHAR).
The Employee_Table contains information about the employees. It includes columns for Address (VARCHAR), Contact_Number (VARCHAR), Date_of_Birth (DATETIME), Department_ID (INTEGER, not null, foreign key referencing Department_Table), Employee_ID (INTEGER, primary key), Gender (VARCHAR), Name (VARCHAR), Password (VARCHAR), and Position (VARCHAR).
The Charge_Table keeps track of charges. It includes columns for Charge_Amount (INTEGER), Charge_Date (DATETIME), Charge_Type (VARCHAR), Employee_ID (INTEGER, not null, foreign key referencing Employee_Table), Owner_ID (INTEGER, not null, foreign key referencing Owner_Table), Quantity (INTEGER), and Room_Number (VARCHAR, primary key, composite key with Owner_ID and Charge_Date).
