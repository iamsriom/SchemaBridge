The database schema named 'rschema_0516' consists of six tables: Customer, Pizza, Sales_Order, Income/Expenditure, Production_Plan, and Delivery_Content.
The Customer table is used to store customer information. It includes columns for Address, Customer_ID (which is the primary key), Name, and Phone.
The Pizza table is used to store pizza information. It includes columns for Flavor, Ingredients, Pizza_ID (which is the primary key), and Stock.
The Sales_Order table is used to store sales order information. It includes columns for Customer_ID (which is not null and references the Customer table), Expected_Delivery_Date, Order_ID (which is the primary key), and Status.
The Income/Expenditure table is used to store income and expenditure records. It includes columns for Amount, Description, Pizza_ID (which is not null and references the Pizza table), Record_ID (which is the primary key), Time, and Type.
The Production_Plan table is used to store production plan information. It includes columns for Order_ID (which is not null and references the Sales_Order table) and Pizza_ID (which is not null and references the Pizza table), Production_Quantity, and Production_Sequence. The primary key of this table is a combination of Order_ID and Pizza_ID.
Finally, the Delivery_Content table is used to store delivery content information. It includes columns for Delivery_Time, Order_ID (which is not null and references the Sales_Order table), Record_ID (which is the primary key), and Status.
