The database schema named 'rschema_0518' consists of seven tables.
The 'Maze' table holds information about the maze files and their associated IDs. It includes columns for the Maze_File_Path, Maze_ID, and Maze_Name.
The 'User' table stores user-related information. It includes columns for Contact_Information, Name, and User_ID.
The 'Robot' table contains information about the robots. It includes columns for Current_Position, Maze_ID, Robot_ID, Robot_Type, and Timer_Status. The Maze_ID column is a foreign key referencing the Maze table.
The 'Forward_Sensor' table holds information about the forward sensors. It includes columns for Front_Status, Left_Status, Right_Status, Robot_ID, and Sensor_ID. The Robot_ID column is a foreign key referencing the Robot table.
The 'Proximity_Sensor' table contains information about the proximity sensors. It includes columns for Coin_Status, Ghost_Status, Robot_ID, and Sensor_ID. The Robot_ID column is a foreign key referencing the Robot table.
The 'Timer' table stores information about the timers. It includes columns for Robot_ID, Timer_Event_Description, Timer_Event_Time, and Timer_ID. The Robot_ID column is a foreign key referencing the Robot table.
Finally, the 'User_Robot_Operation' table logs operations performed by users on the robots. It includes columns for Operation_Time, Operation_Type, Robot_ID, and User_ID. Both Robot_ID and User_ID are foreign keys referencing the Robot and User tables respectively. The combination of Robot_ID and User_ID forms the primary key of this table, ensuring entity integrity.
