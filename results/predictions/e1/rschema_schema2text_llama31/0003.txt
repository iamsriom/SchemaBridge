The rschema_0003 database is designed to manage the inventory and transactions of goods in a warehouse. The warehouse table stores information about each warehouse, including its unique identifier, address, and capacity. The goods table contains details about the goods stored in the warehouse, identified by a unique goods ID and a name. The loader table keeps track of the individuals responsible for loading and unloading goods, with each loader having a unique ID and a phone number. The transaction record table logs all transactions, including the transaction ID, time, warehouse number, and type of transaction, with each transaction linked to a specific warehouse. The good transaction record details table provides a detailed breakdown of each transaction, including the goods ID, transaction ID, and quantity of goods involved, with each transaction linked to a specific good and transaction record. The stevedore-transaction record table tracks the loaders involved in each transaction, linking each loader ID to a transaction ID, with each transaction linked to a specific loader and transaction record. The warehouse number in the transaction record table is a foreign key referencing the warehouse table, and the goods ID and transaction ID in the good transaction record details table are foreign keys referencing the goods and transaction record tables, respectively, with all these relationships enforcing cascading deletes and updates.
