The rschema_0007 database is designed to manage advertising clients and their associated advertisements, as well as records of when and where these advertisements are broadcast. The database contains three tables: advertising_client, advertisement, and client_broadcast_record. The advertising_client table stores information about the clients, including their unique client ID, name, phone number, and email address, with all of these fields being required. The advertisement table holds details about each advertisement, including its unique advertisement ID, name, broadcast time, duration, price, and the client ID it belongs to, with all fields being mandatory. The client ID in the advertisement table references the client ID in the advertising_client table, meaning that an advertisement must be associated with a valid client, and if the client is deleted, all associated advertisements will also be deleted. The client_broadcast_record table stores records of when and where each advertisement is broadcast, including the advertisement ID, client ID, broadcast time, broadcast channel, and the operating personnel involved, with all fields being required. The primary key for this table is a composite key consisting of the advertisement ID and client ID, ensuring that each broadcast record is unique to a specific advertisement and client. The client ID in the client_broadcast_record table also references the client ID in the advertising_client table, with the same deletion rule as the advertisement table, and the advertisement ID references the advertisement ID in the advertisement table, meaning that a broadcast record must be associated with a valid advertisement, and if the advertisement is deleted, all associated broadcast records will also be deleted.
