The rschema_0009 database is designed to manage information about candidates and voters in an election. The candidate table stores details about each candidate, including their unique candidate ID, name, gender, date of birth, and position. Each candidate ID is a primary key, meaning it uniquely identifies each candidate in the database. The voter table contains information about each voter, including their unique voter ID, name, gender, date of birth, and contact information. A foreign key in the voter table references the candidate ID in the candidate table, indicating that a voter can only be associated with one candidate, and if that candidate is deleted, all related voter information will also be deleted. The voting record table stores the voting history, including the voter ID, candidate ID, voting time, and voting location. The primary key in this table is a composite key consisting of the voting time, candidate ID, and voter ID, ensuring that each voting record is unique. Foreign keys in the voting record table reference both the candidate ID in the candidate table and the voter ID in the voter table, indicating that each voting record is associated with one candidate and one voter, and if either the candidate or voter is deleted, all related voting records will also be deleted.
