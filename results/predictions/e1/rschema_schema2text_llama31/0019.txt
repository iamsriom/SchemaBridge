The rschema_0019 database is designed to manage customer orders for a restaurant. The database contains four main tables: Customer, Dish, Order, and Order_Details. The Customer table stores information about each customer, including their unique identifier, name, and phone number. The Dish table holds details about each dish on the menu, with a unique identifier, name, and price. The Order table represents each customer's order, containing the customer's ID, a unique order ID, the status of the order, the time it was placed, and the total amount due. The Order table is linked to the Customer table through the Customer_ID field, which ensures that each order is associated with a valid customer. The Order_Details table stores the specifics of each dish ordered, including the dish ID, order ID, and quantity, with a composite primary key combining the order and dish IDs to uniquely identify each order detail. This table also references the Dish and Order tables through foreign keys, which enforce the relationships between orders and the dishes they contain, and between orders and the customers who placed them.
