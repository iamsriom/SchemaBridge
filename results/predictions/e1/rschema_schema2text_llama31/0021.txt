The rschema_0021 database is designed to manage employee information and their work schedules. The Employee table stores details about each employee, including their date of birth, a unique employee ID, name, gender, phone number, and position. The Date of Birth is stored as a date and time, and the Employee ID is the primary key, meaning it uniquely identifies each employee and cannot be null. The Employee Name, Gender, Phone Number, and Position are all character fields that can hold up to 255 characters, but can be null. The Shift table contains information about each shift, including its end time, a unique shift ID, and start time, with the Shift ID serving as the primary key. The Schedule table links employees to specific shifts they are scheduled to work, with the Employee ID and Shift ID forming a composite primary key, meaning each employee can only be scheduled for one shift at a time. The Employee ID and Shift ID in the Schedule table are also foreign keys that reference the Employee and Shift tables, respectively, ensuring that only valid employee and shift IDs are used. The Scheduled Time is a date and time field that cannot be null. Additionally, the Employee ID in the Schedule table has an ON DELETE RESTRICT rule, meaning that if an employee is deleted from the Employee table, they cannot be scheduled for any shifts, and the Schedule table will not be updated.
