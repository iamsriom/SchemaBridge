The rschema_0036 database is designed to store information about projects and their associated contracts. The Project table contains details about each project, including its name, number, location, budget, start and expected completion dates, and actual completion date. Each project is uniquely identified by its Project_Number, which is a primary key. The Contract table stores information about the contracts related to each project, including the contract name, number, amount, status, and signing date. A contract is also uniquely identified by its Contract_Number, which is the primary key. The Contract table is linked to the Project table through a foreign key, Project_Number, which references the Project_Number in the Project table. The Project_Includes_Contract table serves as a bridge between projects and contracts, allowing for many-to-many relationships between them. It contains the Contract_Number and Project_Number of each contract-project pair, with both columns being not null and forming a composite primary key. The Contract_Change_Record table tracks changes made to contracts, including the change amount, content, date, and a unique change number. Each change is linked to a contract through the Contract_Number foreign key, which references the Contract_Number in the Contract table.
