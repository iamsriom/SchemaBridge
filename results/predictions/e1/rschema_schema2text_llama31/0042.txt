The rschema_0042 database is designed to manage information about residential communities, property managers, residents, maintenance records, and maintenance personnel. The database contains seven tables: community, property_manager, resident, maintenance_record, maintenance_personnel, building, and worker_handles_maintenance_records. The community table stores information about each community, including its number, name, location, and the property manager's number, which is a foreign key referencing the property_manager table. The property_manager table contains details about each property manager, including their number, name, phone, and email. The resident table stores information about each resident, including their number, community number, name, phone, email, and building number, which is a foreign key referencing the building table. The building table contains information about each building, including its name and location. The maintenance_record table stores maintenance records, including the order number, community number, resident number, and maintenance content, with foreign keys referencing the community and resident tables. The maintenance_personnel table stores information about each maintenance personnel, including their number, name, phone, and email. The worker_handles_maintenance_records table stores information about which maintenance personnel handled each maintenance record, including the order number, date, cost, and personnel number, which is a foreign key referencing the maintenance_personnel table.
