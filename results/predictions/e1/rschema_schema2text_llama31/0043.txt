The rschema_0043 database is designed to manage loan applications and their associated approvals. The loan_application table stores information about each loan application, including a unique application number, property number, loan amount, loan term, approval status, the applicant's name, phone number, and ID number, as well as the time the application was submitted. The loan_approval table tracks the approval process for each loan application, linking each application to the approval officer who processed it, the time of approval, and the result of the approval. This table also includes a composite primary key consisting of the approval officer's number, the approval time, and the loan application number, ensuring that each approval is uniquely tied to a specific officer and application. The loan_approval table references the approval_officer table, which stores information about each approval officer, including their unique number, name, and phone number. The approval_officer table has a primary key of the officer's number, ensuring each officer is uniquely identified. The loan_approval table has foreign keys referencing the loan_application table, which means that when a loan application is deleted, all associated approvals will also be deleted, and when an approval officer is deleted, all associated approvals will also be deleted.
