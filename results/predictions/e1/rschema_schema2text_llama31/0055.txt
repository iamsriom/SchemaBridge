The rschema_0055 database is used to store information about operators, users, and their electricity usage records. The Operator table contains details about each operator, including their contact information, department, a unique identifier, and name. The Department column is an integer that represents the operator's department, and the ID column is a unique identifier for each operator, which is the primary key of the table. The Name column stores the operator's name, and the Contact_Information column stores their contact details. The User table stores information about each user, including their address, contact information, a unique identifier, and name, with the ID column serving as the primary key. The Electricity_Usage_Record table stores records of electricity usage, including the consumption amount, the time of the record, and the IDs of the operator and user involved. The Operator_ID and User_ID columns in this table are foreign keys that reference the ID columns in the Operator and User tables, respectively, and are not nullable, indicating that each record must be associated with a valid operator and user. The primary key of the Electricity_Usage_Record table is a composite key consisting of the Operator_ID, User_ID, and Record_Time columns, ensuring that each record is unique and cannot be duplicated.
