The rschema_0064 database is designed to manage information about projects and their reviews. The project table stores details about each project, including a unique project number, project name, application date, and the unit that applied for the project. The expert table contains information about the experts who review these projects, with a unique expert number, name, unit, and title. The project_review_record table links projects with the experts who reviewed them, storing the project number, expert number, review date, and the expert's opinion. The project table has a primary key of project number, ensuring each project is uniquely identified. The expert table also has a primary key of expert number, guaranteeing each expert is uniquely identified. The project_review_record table has a composite primary key of project number and expert number, meaning each review is uniquely tied to a project and an expert. The project_review_record table also references the project and expert tables through foreign keys, which link each review to its corresponding project and expert. These foreign keys are set to cascade, meaning if a project or expert is deleted, all associated reviews will also be deleted.
