The rschema_0077 database is designed to manage user information, products, and orders for an e-commerce platform. The User table stores details about each registered user, including their name, email, phone number, membership number, and password, with a unique identifier (ID) serving as the primary key. The Product table contains information about the items available for purchase, such as their name, category, manufacturer, price, and product image URL, with a unique product ID as the primary key. The Order table tracks each purchase made by a user, including the order ID, purchase date, and user ID, with a foreign key referencing the User table to establish the relationship between orders and users. The Announcement table allows users to post announcements, with a unique announcement number as the primary key, a title, content, and a publisher ID referencing the User table to identify the author. The Order_Detail table links orders to the products purchased, with a composite primary key consisting of the order ID and product ID, and foreign keys referencing both the Order and Product tables to ensure data consistency.
