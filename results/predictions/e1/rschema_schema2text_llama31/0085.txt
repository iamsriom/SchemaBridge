The rschema_0085 database is designed to manage a collection of recipes and their associated metadata, as well as the users who create and collect them. The User table stores information about each user, including their username, email, password, and profile, with a unique User_ID serving as the primary key. The Recipe table contains details about each recipe, such as its bitter, meaty, salty, sour, and spicy levels, as well as its ingredients, images, and steps, with a Creator_ID referencing the User who created it. The Blog table stores blog posts written by users, including the author's User_ID, the blog's title and summary, and the publication time. The Collected_Recipe table tracks which recipes have been collected by each user, with a composite primary key of User_ID and Recipe_ID referencing both the User and Recipe tables, ensuring that a user can only collect a recipe once. The Creator_ID in the Recipe table and the Author_User_ID in the Blog table both reference the User_ID in the User table, establishing a relationship between the creators of recipes and blog posts and the users who create them.
