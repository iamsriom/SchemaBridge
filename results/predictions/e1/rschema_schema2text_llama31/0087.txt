The rschema_0087 database is designed to manage user information, podcasts, and playlists. The User table stores details about each user, including their areas of interest, date of birth, email, gender, number of followers, password, user account, user creation time, user description, and a unique user ID. The Podcast table contains information about each podcast, such as its cover image path, creation time, last update time, number of favorites, likes, and visits, as well as its file path and a unique podcast ID. The Publisher ID in the Podcast table references the User ID in the User table, establishing a relationship between podcast publishers and their respective users. The Playlist table stores details about each playlist, including its creation time, last update time, number of favorites, likes, and visits, as well as a unique playlist ID and the path to its location. The User ID who created the playlist in the Playlist table references the User ID in the User table, linking each playlist to its creator. The User_Publishes_Podcast table tracks which users publish podcasts, with a composite primary key of User ID and Podcast ID, referencing both the User and Podcast tables. Similarly, the User_Creates_Playlist table records which users create playlists, with a composite primary key of User ID and Playlist ID, referencing both the User and Playlist tables. The Playlist_Contains_Podcasts table stores the podcasts included in each playlist, with a composite primary key of Podcast ID and Playlist ID, referencing both the Podcast and Playlist tables.
