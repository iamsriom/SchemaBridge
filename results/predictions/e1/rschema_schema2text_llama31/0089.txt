The rschema_0089 database is designed to track the history of a blockchain, a digital ledger that records transactions between accounts. At the core of this database is the Block table, which stores information about each block in the blockchain, including its unique hash, height, Merkle root, the hash of the previous block, a timestamp, and a reference to the previous block's hash, ensuring that each block is linked to the one before it. The Account table contains information about each account, with a unique address and a balance. The Transaction table represents the transactions that occur between accounts, including the block in which they were recorded, the fee paid, the input and output addresses, a timestamp, and a unique transaction hash. The Block table references itself through the Previous_Block_Hash field, establishing the chain of blocks, while the Transaction table references both the Block table through the Block_Hash field and the Account table through both the Input_Address and Output_Address fields, ensuring that transactions are linked to the blocks in which they occur and the accounts involved. The Address field in the Account table serves as its primary key, uniquely identifying each account, and the Transaction_Hash field in the Transaction table serves as its primary key, uniquely identifying each transaction.
