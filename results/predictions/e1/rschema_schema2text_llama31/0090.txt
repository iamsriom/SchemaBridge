The rschema_0090 database is designed to manage information about users, conferences, and sessions. The User table stores details about each user, including their authentication method, email, name, a unique user ID, and permission level. The Venue table contains information about various venues, such as their geographic location, address, and a unique venue ID. The Conference table holds data about conferences, including the administrator and creator of the conference, the conference ID, time, and title, with the administrator and creator being linked to the User table through foreign keys. The Session table stores details about each session, including its abstract, belonging conference, duration, speaker, start time, and title, with the belonging conference linked to the Conference table through a foreign key. The Conference_Venue_Selection table maintains a record of which conferences are held at which venues, linking the Conference and Venue tables through foreign keys. The User_Create_Conference and User_Manage_Conference tables track which users are involved in creating and managing conferences, respectively, linking the User and Conference tables through foreign keys. Finally, the User_Presentation table records which users are presenting at which sessions, linking the User and Session tables through foreign keys.
