The rschema_0100 database is designed to manage customer orders and quotations, and it consists of five main tables: Customer, User, Order, Quotation, and Order_Item. The Customer table stores information about each customer, including their creation and deletion times, email address, name, and a unique identifier. The User table holds details about each user, such as their creation and deletion times, email address, password, username, and a unique identifier. The Order table represents each order made by a customer, containing information like the creation and deletion times, the user who created the order, the customer who made the purchase, the order description, delivery date, and a unique identifier. The Quotation table is similar to the Order table but is used for quotations, which are essentially proposals for orders. The Order_Item table stores details about each item in an order, including its creation and deletion times, description, the order it belongs to, quantity, unit, unit price, and a unique identifier. The relationships between these tables are established through foreign keys: the Order and Quotation tables reference the Customer and User tables, and the Order_Item table references the Order table. The database also enforces data integrity through primary keys, which uniquely identify each record in each table, and unique constraints, which prevent duplicate values in certain columns. Additionally, the database uses composite and unique constraints to ensure that certain combinations of values are unique.
