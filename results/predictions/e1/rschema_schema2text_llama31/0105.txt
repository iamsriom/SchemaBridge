The rschema_0105 database is designed to store information about users and their interactions. The User table holds details about each user, including their account name, birthday, email, gender, nickname, password, phone number, and registration time, with a unique identifier for each user. The User_dynamic_information table stores dynamic content published by users, such as the content itself, the number of comments, favorites, and likes it has received, the time it was published, and the user who published it, referencing the User table for the publisher's ID. The Add_Contact table tracks relationships between users, including the time the relationship was added, the type of relationship, any remarks, and the IDs of the users involved, with a composite primary key that includes the user ID, the ID of the user being added, and the time of addition, referencing the User table for both user IDs. The Social_Activity table records user interactions with dynamic content, including whether the content was collected, any comments made, the time of creation, whether the user liked the content, and the IDs of the user and the dynamic content involved, with a composite primary key that includes the user ID, the dynamic content ID, and the creation time, referencing the User_dynamic_information table for the dynamic content ID and the User table for the user ID.
