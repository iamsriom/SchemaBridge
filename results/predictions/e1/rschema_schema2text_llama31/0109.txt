The rschema_0109 database is designed to store information about countries, members, their addresses, and the management of these addresses. The Country table contains a list of countries, with each country identified by a unique code and a corresponding name. The Member table stores details about individual members, including their company name, country of origin, a unique member ID, name, name pronunciation, and public status, with the country of origin being a foreign key referencing the Country table to ensure data consistency. The Address table holds information about the physical addresses of members, with each address having a unique ID, a contact number, a country code that references the Country table, a postal code, and a specific address. The Member_Address_Management table is used to manage the relationships between members and their addresses, with each entry consisting of an address ID and a member ID, both of which are foreign keys referencing the Address and Member tables respectively, and together forming a composite primary key to uniquely identify each address-member pair.
