The rschema_0114 database is designed to manage user interactions with articles and comments. It consists of five tables: user, article, comment, comment_like, and log. The user table stores information about each user, including their unique user ID, username, password, email, creation time, and whether their email address is publicly visible. The article table stores details about each article, such as its unique article ID, title, body, type, timestamp, publisher ID (which references the user who published the article), and whether the article is publicly accessible. The comment table contains comments made by users on articles, with each comment having a unique comment ID, article ID, user ID, comment content, and timestamp. The comment_like table tracks likes on comments, with each entry consisting of a user ID, comment ID, and like time. The log table stores a record of all operations performed within the database, including the operation type, time, user ID, operation object ID, and a description of the operation. The primary keys of each table uniquely identify each record, while foreign keys establish relationships between tables, such as the publisher ID in the article table referencing the user ID in the user table, and the user ID and comment ID in the comment table referencing the user ID and comment ID in the comment table, respectively. Additionally, the comment table has a composite primary key consisting of the article ID and user ID, and the comment_like table has a composite primary key consisting of the comment ID, like time, and user ID.
