The rschema_0119 database is designed to store information about users and their assigned indicators, along with data records for these indicators. The User table contains details about each user, including their age, email, gender, name, phone number, and a unique User_ID. The Indicator table stores information about the indicators themselves, such as their calculation method, description, name, target, and unit of measurement, with a unique Indicator_ID. The User_assigned_indicator table links users to the indicators they are assigned to, with a composite primary key of User_ID, Indicator_ID, and Allocation_time, and foreign keys referencing the User and Indicator tables. The Indicator_data_record table stores data records for each indicator, including the improvement relative to the last record, the record's value, any remarks, the submission time, and a composite primary key of User_ID, Indicator_ID, and Submission_record_time, with foreign keys referencing the User and Indicator tables.
