The rschema_0120 database is designed to store information about users, corporations, and various applications and their associated data. At its core, the database contains a table for users, which stores unique identifiers, usernames, passwords, email addresses, and active status for each user. The game_character table stores information about characters within a game, including their names, corporations, active status, and whether they are the default character for a user. The corporation table holds details about companies, including their IDs, tickers, names, and CEOs, with the CEO's user ID referencing the user table. The user_login_record table tracks login attempts, including the user ID, source address, browser agent, login result, and timestamp, with a composite primary key to ensure uniqueness. The application table stores information about various applications, including their IDs, names, maintainers, keys, callback URLs, and active status, with foreign keys referencing the user and api_key tables. The api_key table stores unique keys for corporations, with a foreign key referencing the corporation table. This schema is designed to maintain referential integrity through cascading deletes and updates, ensuring that when a user or corporation is deleted, their associated data is also removed, and when a user or corporation is updated, their associated data is updated accordingly.
