The rschema_0124 database is designed to manage user information and their interactions on a social media platform. The User table stores details about each user, including their email, password, phone number, registration time, unique user ID, and username. The User_ID is the primary key, ensuring each user has a unique identifier. The User_Follow table represents the relationships between users, where each entry indicates that one user is following another. The table contains the time the follow was established, the ID of the user being followed, and the ID of the user doing the following, with both the Follower_ID and Followed_ID being non-null foreign keys referencing the User_ID in the User table, and the primary key being a composite of both IDs. The User_Post table stores the content of posts made by users, including the post content, a unique post ID, the time the post was made, and the ID of the user who made the post, with the User_ID being a non-null foreign key referencing the User_ID in the User table.
