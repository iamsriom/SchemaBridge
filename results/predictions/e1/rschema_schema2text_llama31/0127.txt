The rschema_0127 database is designed to manage user information and their participation in matches. The User table stores details about each registered user, including their Avatar, Balance, Gender, Password, Registration Time, a unique User ID, and User Name. The Match table contains information about each match, with a unique Match ID and Match Name, along with the Match Time. The User_Match_Record table tracks the results of each match for each user, with a composite primary key consisting of the User ID and Match ID, ensuring that each user can only participate in a match once. The Match ID in User_Match_Record references the Match ID in the Match table, establishing a relationship between the match results and the match itself, and the User ID references the User ID in the User table, linking the match results to the user who participated. The Match ID in User_Match_Record is not nullable, and the User ID is also not nullable, indicating that a match result must be associated with a valid match and a valid user.
