The rschema_0128 database is used to track and record information about tasks and their executions. The task_execution_record table stores details about each task execution, including the unique execution ID, task name, start and end times, exit code and message, error message, and last update time. It also includes the external execution ID, parent task execution ID, and batch ID, which references the task_batch table. The batch ID is a foreign key that references the batch_id in task_batch, and when a batch is deleted, all associated task execution records are also deleted. The task_execution_record table also references itself through the external execution ID and parent task execution ID foreign keys, which means that if a task execution record is deleted, all its associated records will also be deleted. The task_parameter table stores parameters for each task execution, with the execution ID and parameter name serving as a composite primary key, and the parameter value being the actual value of the parameter. The execution ID in task_parameter references the execution ID in task_execution_record, and when a task execution record is deleted, all its associated parameters will also be deleted. The task_batch table stores information about each batch, including the unique batch ID, batch name, start and end times. The batch ID in task_batch serves as the primary key, uniquely identifying each batch.
