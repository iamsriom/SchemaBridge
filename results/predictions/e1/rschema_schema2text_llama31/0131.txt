The rschema_0131 database is designed to manage information about employees, suppliers, and projects. The employee table contains details about each employee, including their unique employee ID, position, performance, name, and age. Each employee is identified by a unique employee ID, which is the primary key of the table. The supplier table stores information about the suppliers, with each supplier having a unique supplier ID and a supplier name. The project table represents the various projects being undertaken, with each project having a unique project ID, a responsible person (who is an employee), a supplier, and a project progress. The project table has foreign keys referencing the employee and supplier tables, which means that when an employee or supplier is deleted, all projects assigned to them will also be deleted. The attendance record table keeps track of each employee's attendance, with each record containing the employee's ID, the date of attendance, and the attendance time. The attendance record table has a composite primary key consisting of the employee ID and attendance date, and it also has a foreign key referencing the employee table, which means that when an employee is deleted, all their attendance records will also be deleted. The salary payment record table stores information about each employee's salary payments, with each record containing the employee's ID, the payment date, and the payment amount. This table also has a composite primary key consisting of the payment date and employee ID, and a foreign key referencing the employee table, which means that when an employee is deleted, all their salary payment records will also be deleted.
