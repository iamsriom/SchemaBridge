The rschema_0134 database is designed to manage user interactions with properties for rent. The Users table stores information about each registered user, including their email, password, phone number, unique user ID, role, and username. The Houses table contains details about available properties, such as the property's description, facilities, location, price, title, type, and publisher, linked to the user ID of the landlord who published it. The Demands table represents requests from users for specific properties, including the budget, description, location, title, type, and the user ID of the requesting party. The Orders table tracks rental agreements between users and landlords, including the lease start and end dates, order price, status, payment status, and property ID, as well as the user ID of the renter. The relationships between these tables are established through foreign keys: the Landlord_ID in the Houses table references the User_ID in the Users table, the User_ID in the Demands table references the User_ID in the Users table, and the Property_ID in the Orders table references the Property_ID in the Houses table, while the User_ID in the Orders table references the User_ID in the Users table.
