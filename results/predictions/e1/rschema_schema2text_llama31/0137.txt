The rschema_0137 database is designed to manage user information and transactions for an e-commerce platform. The User table stores details about each registered user, including their email address, password, username, and a unique user ID, which serves as the primary key to uniquely identify each user. The Product table contains information about the products being sold, such as their discounted and original prices, and a unique product ID that serves as the primary key. The Order table represents transactions made by users, including the amount paid, order number, status, time of order and payment, and shipping address, with a foreign key referencing the User table to link each order to its corresponding user. The Shopping Cart table stores the items a user has added to their cart, including the discounted amount, product ID, quantity, and total amount, with foreign keys referencing both the Product and User tables to establish relationships between cart items and their corresponding products and users, and a composite primary key combining the user ID and product ID to ensure each user can have multiple items in their cart, but each item can only be in one cart.
