The rschema_0143 database is designed to manage user information, products, orders, and shipping addresses for an e-commerce system. The database contains six tables: user, product, order, role, role_shipping_address, and order_details. The user table stores information about each registered user, including a unique user ID, username, password, contact information, and role. The role table defines different roles within the system, with each role having a unique role ID and a corresponding role name and permission. The user table is linked to the role table through a foreign key constraint, which means that each user is assigned a specific role. The product table stores information about each product, including a unique product ID, product name, description, price, inventory quantity, and image. The order table stores information about each order, including a unique order ID, user ID, total price, order status, and shipping address ID. The order table is linked to the user table and role_shipping_address table through foreign key constraints, which means that each order is associated with a specific user and shipping address. The role_shipping_address table stores the shipping addresses associated with each user, with each address having a unique address ID, user ID, and default status. The order_details table stores information about the products included in each order, including the order ID, product ID, and quantity. This table is linked to both the order table and product table through foreign key constraints, which means that each order can have multiple products and each product can be included in multiple orders.
