The rschema_0146 database is designed to store information about dormitories, their occupants, and additional user details. The Dormitory table contains information about each dormitory, including its affiliated college, a unique identifier, the dormitory number, the type of dormitory, and the number of members it can accommodate. The Information_Summary table stores a summary of information for each user, linked to the user's ID and the dormitory ID they belong to, with the user ID serving as the primary key. The User table holds personal details about each user, including their age, contact information, gender, personal profile, and a unique user ID, which is the primary key. The User table also includes a foreign key referencing the Dormitory table, indicating the dormitory each user is affiliated with, and this relationship is enforced with a not null constraint to ensure that every user is assigned to a dormitory.
