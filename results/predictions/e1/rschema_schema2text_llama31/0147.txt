The rschema_0147 database is designed to manage information about classes, members, announcements, messages, logs, and applications. The Class table stores details about each class, including its unique identifier, name, department name, and grade level. The Member table contains information about each member, such as their age, class affiliation, contact number, email, name, password, and workplace, with the Class_ID referencing the Class table to establish the relationship between a member and their class. The Announcement table stores announcements made to classes, including the announcement content, time, and the class it belongs to, with the Class_ID referencing the Class table to link the announcement to its class. The Message table stores messages sent between members, including the message content, read flag, send time, and the sender and receiver IDs, with the Receiver_ID and Sender_ID referencing the Member table to establish the sender and receiver relationships. The Log table stores logs of member activities, including the log content, member ID, mood, and time, with the Member_ID referencing the Member table to link the log to its member. The Application table stores applications submitted by members, including the application content, time, and approval flag, with the Member_ID referencing the Member table to establish the relationship between the application and its submitter.
