The rschema_0149 database is designed to manage user information, roles, permissions, notifications, requests, categories, and to-do items. The user table stores information about each user, including their unique identifier, username, password, email, avatar, nickname, registration time, role, and category. The role table contains details about each role, including its unique identifier, name, description, and associated permissions. Permissions are stored in the permission table, which links to the role table through a foreign key. The notification table stores notifications sent to users, including the title, content, sending time, and the user who received the notification. The request table stores information about user requests, including the request content, time, status, and the user who made the request. The category table stores information about categories, including the unique identifier and description. The to-do item table stores information about each to-do item, including its unique identifier, content, status, creation time, deadline, and the user who created it. The relationships between these tables are established through foreign keys, with some tables having cascade delete and update rules, meaning that when a related record is deleted or updated, the corresponding records in other tables will be automatically updated or deleted accordingly.
