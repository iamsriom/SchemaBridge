The rschema_0150 database is designed to manage information about suppliers, projects, parts, and warehouses, as well as the relationships between these entities. The Supplier table stores details about each supplier, including their address and phone number, with a unique identifier for each supplier. The Project table contains information about each project, such as its budget and start date, with a unique identifier for each project. The Part table holds details about each part, including its description, name, specification, and unit price, with a unique identifier for each part. The Supplier_Supply_Project table tracks the projects that each supplier is involved in, with the start and end times of their involvement, and the Supplier_Supply_Part table tracks the parts that each supplier supplies, along with the quantity supplied. The Project_Requires_Parts table shows which parts are required for each project, along with the quantity needed. The Warehouse table stores information about each warehouse, including its area and the employee in charge, with a unique identifier for each warehouse, and a foreign key referencing the Employee table to link the warehouse manager to their employee ID. The Employee table contains details about each employee, including their age, job title, name, and work location, with a unique identifier for each employee and a foreign key referencing the Warehouse table to link each employee to their workplace. The Warehouse_Inventory_Parts table tracks the quantity of each part stored in each warehouse, with foreign keys referencing both the Part and Warehouse tables to link the inventory to the parts and warehouses involved.
