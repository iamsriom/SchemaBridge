The rschema_0155 database is designed to manage user accounts, store product information, and track orders. It contains six tables: user, admin, product, order, shipping_address_record, and order_detail. The user table stores information about each registered user, including their unique user ID, username, password, email, and phone number. The admin table holds details about administrative accounts, such as the admin ID, admin account name, password, and creation time. The product table stores product information, including the product ID, category, name, description, price, and inventory level. The order table tracks each order made by a user, with fields for the order ID, the user who made the order, order time, and order status. The shipping_address_record table stores shipping addresses for each user, with fields for the user ID, creation time, and shipping address. The order_detail table links orders to the products they contain, with fields for the order ID, product ID, and quantity. The user table serves as the primary key for the order and shipping_address_record tables, indicating that a user can have multiple orders and shipping addresses, but an order and shipping address can only be associated with one user. The order table is linked to the user table through the ordering_user field, which means that if a user is deleted, all their associated orders will also be deleted. Similarly, the order_detail table is linked to both the order and product tables, meaning that if an order or product is deleted, all associated order details will also be deleted.
