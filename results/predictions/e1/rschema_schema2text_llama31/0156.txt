The rschema_0156 database is designed to manage user information and their interactions with products. The User table stores details about each registered user, including their delivery address, email, last login time, password, phone number, registration time, and a unique user ID. The Product table contains information about the products available for sale, including the product name, description, sales price, and inventory quantity. The Product_added_to_cart table tracks when a user adds a product to their cart, recording the product ID, quantity, and user ID, with a composite primary key that ensures each user can only add a product to their cart once at a given time. The Purchase_product table records the products a user has purchased, including the product ID, purchase quantity, purchase time, payment method, and total order price, with a composite primary key that prevents a user from making multiple purchases of the same product at the same time. The relationships between these tables are established through foreign keys: the Product_added_to_cart table references both the User and Product tables by their respective IDs, and the Purchase_product table references both the User and Product tables in the same way.
