The rschema_0158 database is designed to manage a system for creating and administering exams. The database contains seven tables, each representing a distinct entity within the system. The Role table stores information about different roles within the system, with a unique Role ID and a corresponding role name. The Category table holds details about different categories of questions, identified by a unique category ID and category name. The User table stores information about individual users, including their contact information, name, and role ID, which links them to a specific role in the system. The Question table contains details about individual questions, such as their category ID, content, correct answer, difficulty level, explanation, and options, with a unique question ID. The Exam table stores information about exams, including their creator ID, description, exam name, status, time range, and a unique exam ID. The Exam_Question table links exams to specific questions, with a unique combination of exam and question IDs, and a sequence number for the question within the exam. The User_Answer_Sheet table tracks user answers to exams, including the exam ID, score, student ID, and submission time, with a unique combination of student and exam IDs. Each table has constraints to ensure data integrity, such as primary keys to uniquely identify each record, foreign keys to link related records, and not null constraints to prevent missing values in required fields. For example, a user must be assigned a role, and an exam must have a creator. Additionally, the database includes indexes and constraints to optimize data retrieval and prevent data inconsistencies, such as the composite primary key in the Exam_Question table and the unique constraints on the primary keys of each table.
