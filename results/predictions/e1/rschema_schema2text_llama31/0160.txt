The rschema_0160 database is designed to manage information about users, countryside scenic spots, agricultural products, and orders. The database contains seven tables: 'user', 'countryside_scenic_spot', 'agricultural_product', 'scenic_spot_comment', 'product_comment', 'order', and 'order_detail'. The 'user' table stores information about registered users, with each user having a unique 'user_id', a 'username', and a 'password'. The 'countryside_scenic_spot' table holds details about scenic spots, including their 'name', 'location', 'image_url', and a brief 'main_scenic_spot_introduction'. The 'agricultural_product' table lists available products, with each product having a unique 'product_id', a 'product_name', and a 'product_price'. The 'scenic_spot_comment' table stores comments left by users on scenic spots, linking each comment to the user who posted it and the scenic spot it refers to. The 'product_comment' table does the same for comments on products, linking each comment to the user who posted it and the product it refers to. The 'order' table tracks orders made by users, with each order having a unique 'order_id', the 'ordering_user', the 'order_time', the 'order_amount', and the 'order_status'. The 'order_detail' table links orders to the products they contain, specifying the quantity of each product ordered. The database enforces referential integrity by ensuring that comments are linked to valid users and scenic spots or products, and that orders are linked to valid users and products.
