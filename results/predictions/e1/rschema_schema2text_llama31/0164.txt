The rschema_0164 database is designed to manage information about warehouses, users, and their interactions with warehouse stack positions. The Warehouse table stores details about each warehouse, including its creation and update dates, description, location, name, type, and image path. Each warehouse is uniquely identified by its Warehouse_ID. The User table contains user information, such as email, password, phone number, role, and username, with each user having a unique User_ID. The Stack_Position table represents stack positions within warehouses, including their description, image path, name, type, and the warehouse they belong to, identified by the Belonging_Warehouse_ID foreign key referencing the Warehouse table. Sensors are associated with stack positions in the Sensor table, which stores data such as the sensor's collected data value, collection time, description, status, type, and the stack position it belongs to, identified by the Stack_Position_ID foreign key referencing the Stack_Position table. The User_Operation_Stack_Position table tracks user interactions with stack positions, including the operation description, time, type, and the user and stack position involved, with a composite primary key combining the Operation_User_ID and Stack_Position_ID foreign keys referencing the User and Stack_Position tables, respectively. The Stack_Position_Alert table stores alerts related to stack positions, including the alert description, level, status, time, and type, with a composite primary key combining the Stack_Position_ID and Alert_Time foreign keys referencing the Stack_Position table.
