The rschema_0173 database is designed to manage the borrowing and fine tracking system of a library. The Borrower table stores information about each individual who borrows books, including their ID, name, any accumulated fines, and the number of overdue books they have. The Book table contains details about each book, such as its title, author, publication date, publisher, and stock level, along with its ID and fine amount. The Borrower_Loaned_Books table keeps track of which books are currently borrowed by whom, including the expected return date and loan date, and it uniquely identifies each loan by combining the borrower's ID and the book's ID. The Fines table records any fines incurred by borrowers for overdue books, with each entry referencing the book's ID and the borrower's ID, as well as the fine amount and the number of overdue days. The Borrower table's ID serves as its primary key, while the Borrower_Loaned_Books and Fines tables use composite primary keys combining the borrower and book IDs, and the Book table uses its ID as its primary key. The Borrower_Loaned_Books and Fines tables also reference the Book and Borrower tables through foreign keys, which ensure that a book can only be borrowed by one borrower at a time and that a borrower can only incur one fine per book.
