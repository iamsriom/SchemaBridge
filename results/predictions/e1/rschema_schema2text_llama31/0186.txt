The rschema_0186 database is designed to store information about insured individuals and their associated payments and receipts. The Insured_Person table contains details about each individual, including their contact information, date of birth, gender, identity card number, name, and a unique social security ID, which serves as the primary key. The Social_Security_Type table lists different types of social security, with each type having a unique ID. The Insured_Person_Payment table stores information about payments made by each insured individual, including the payer, payment amount, payment time, and the type of social security involved, which is linked to the Insured_Person and Social_Security_Type tables through foreign keys. The primary key in this table is a composite of the payment ID, social security ID, and type ID, ensuring that each payment is uniquely identified. The Insured_Person_Receipt table is similar, storing information about receipts received by each insured individual, including the receipt amount, receipt time, recipient, and the type of social security involved, also linked to the Insured_Person and Social_Security_Type tables through foreign keys. The primary key in this table is also a composite of the receipt ID, social security ID, and type ID. In both tables, the social security ID and type ID are not nullable, indicating that each payment and receipt must be associated with a specific insured individual and type of social security.
