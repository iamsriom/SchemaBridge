The rschema_0192 database is designed to manage information about employees, departments, and projects within an organization. The database contains four main tables: department, employee, project, and project_participation_record. The department table stores information about each department, including its head's employee number, a unique department ID, and the department's name. The employee table holds details about each employee, such as their date of birth, department ID, gender, name, phone number, and position, with the employee number serving as the primary key. The project table contains data about each project, including its actual and estimated completion dates, budget, location, manager's employee number, name, number, progress, and start date, with the project number being the primary key. The project_participation_record table tracks the participation of employees in projects, including the employee's number, participation time, project number, role, and work hours, with a composite primary key consisting of the employee number, project number, and participation time. The department table references the employee table through the Department_Head column, which links each department to its head, while the employee table references the department table through the Department_ID column, linking each employee to their department. Similarly, the project table references the employee table through the Project_Manager_ID column, which links each project to its manager, and the project_participation_record table references both the employee and project tables through their respective columns, ensuring that each participation record is linked to a valid employee and project.
