The rschema_0197 database is designed to manage information about personnel, projects, and construction cost records. The Personnel table stores details about each individual, including their email, name, personnel ID, phone number, and role. The primary key, Personnel_ID, uniquely identifies each person. The Project table contains information about each project, such as its location, project manager's ID, name, and a foreign key referencing the Personnel table to link the project manager to their personnel record. The Project_ID serves as the primary key for this table. The Construction_Cost_Record table tracks expenses for each project, including the cost amount, expense type, project ID, record date, and a unique record ID. The primary key, Record_ID, uniquely identifies each record. This table also includes foreign keys referencing the Project and Personnel tables to link each record to its corresponding project and the staff member who recorded it. The Project_ID and Recording_Staff_ID columns are not nullable, ensuring that each record is associated with a project and a staff member.
