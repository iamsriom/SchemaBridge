The rschema_0217 database is designed to manage various aspects of a school or educational institution, including courses, students, users, tools, and system settings. The course table stores information about each course, including its unique identifier, teacher, class hours, description, and schedule. The student table contains details about each student, such as their unique identifier, name, grade, class, and a reference to their user account. The user table holds information about each user, including their unique identifier, email, password, username, and role. The tool table tracks the tools available, including their name, asset number, and the user who is responsible for holding them. The tool_loan_record table keeps a record of when tools are borrowed, including the borrower's user ID, the tool's asset number, and the time of borrowing. The system_settings table stores information about the system itself, including its name, theme, page configuration, and version information. The course_enrollment table links students to the courses they are enrolled in, with each unique combination of student and course ID serving as a primary key. The relationships between these tables are enforced through foreign keys, such as the user ID in the student table referencing the user table, and the asset number in the tool_loan_record table referencing the tool table, ensuring that data remains consistent and accurate.
