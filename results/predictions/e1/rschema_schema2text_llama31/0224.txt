The rschema_0224 database is designed to manage user information and task-related data. The database contains five tables: user, task, task_execution_status, user_quote, and user_evaluation. The user table stores information about each user, including their unique identifier, name, avatar URL, contact information, the number of failed tasks, and the number of completed tasks. The task table holds details about each task, such as its unique identifier, title, description, budget, deadline, category, and address. The task_execution_status table tracks the progress of each task, linking it to the user who is executing the task and the task itself, with the relationship between the task executor and the task being a many-to-one relationship. The user_quote table stores quotes from users for specific tasks, linking the user who made the quote, the task, the quote itself, and any additional comments. The user_evaluation table contains records of user evaluations, including the unique identifier for the evaluation, the evaluator and executor of the task, and the rating given, with both the evaluator and executor being linked to the user table.
