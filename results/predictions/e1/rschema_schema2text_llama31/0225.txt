The rschema_0225 database is designed to manage user interactions and company information. At its core, the Company table stores details about each company, including a unique identifier, name, creation and modification timestamps, an authorization token, and a token hash value. Each company is associated with a User table, which contains information about the users within that company, such as their user ID, name, creation and modification timestamps, password hash and salt values, and permission level. The User table is linked to the Company table through a foreign key, ensuring that each user is tied to a specific company. The Request_Log table tracks user interactions, storing the request data, status, timestamp, and user ID, with the user ID referencing the User table to establish the relationship. The User_Feedback table captures user feedback, including a comment, creation timestamp, rating, and user ID, which references the User table to identify the user who provided the feedback.
