The rschema_0232 database is designed to manage information about users, scholarships, and their relationships. The User table stores details about each registered user, including their unique User ID, email address, password hash, username, and activation token. The Scholarship table contains information about available scholarships, such as the application requirements, deadline, description, link, amount, and name. The Category table lists different categories that scholarships can be associated with, identified by a unique Category ID and name. The User_Likes_Scholarship table tracks which users have liked which scholarships, with each like recorded by a timestamp and referencing the User and Scholarship tables through foreign keys. The Scholarship_Category table establishes the many-to-many relationship between scholarships and categories, allowing a scholarship to be associated with multiple categories and a category to be associated with multiple scholarships, with both tables referencing each other through foreign keys.
