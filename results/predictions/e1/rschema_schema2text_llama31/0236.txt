The rschema_0236 database is designed to store information about security cameras and their associated video recordings and alarms. At the heart of this database is the Camera table, which contains details about each camera, including its unique identifier, location, RTSP stream address, title, and video stream path. Each camera is assigned a unique Camera_ID, which serves as the primary key and ensures that each camera can be uniquely identified. The Video_Recording table stores information about the video recordings captured by each camera, including the camera's ID, cover path, duration, start time, and video file path. The Video_ID in this table serves as the primary key, and it is also referenced in the Alarm table to link an alarm to the specific video recording it is associated with. The Alarm table stores details about each alarm, including its unique identifier, alarm level, type, start and end times, and the Video_ID it is linked to. The Camera_ID in the Video_Recording table is a foreign key that references the Camera_ID in the Camera table, establishing a relationship between the camera and the video recordings it captures, while the Video_ID in the Alarm table is a foreign key that references the Video_ID in the Video_Recording table, linking each alarm to the specific video recording it is associated with.
