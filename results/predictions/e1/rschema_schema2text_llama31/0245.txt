The rschema_0245 database is designed to manage user information, novels, bookshelves, and book reviews. The User table stores user data, including their creation and update times, email, password, username, and a unique identifier (User_ID) that serves as the primary key. The Novel table contains information about each novel, such as its title, description, author, ISBN, publication date, and creation and update times, with a unique identifier (Novel_ID) as its primary key. The Bookshelf table represents a collection of novels owned by a user, with each entry including the bookshelf's creation time, a unique identifier (Bookshelf_ID), the user's ID, and the novel's ID, referencing the User and Novel tables respectively. The Book_review table stores user reviews of novels, including the review's creation time, the novel's ID, a rating, the review content, and the user's ID, referencing the Novel and User tables. The Novel_added_to_Bookshelf table tracks when a novel is added to a bookshelf, with each entry including the addition time, the bookshelf's ID, and the novel's ID, referencing the Bookshelf and Novel tables, and forming a composite primary key with the addition time.
