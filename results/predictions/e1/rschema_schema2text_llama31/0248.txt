The rschema_0248 database is designed to manage user interactions and activities within a platform. It contains nine tables: User, Article, Book, Activity, Video_Interview, User_Comments, Book_Recommendation, Activity_Lottery, and User_Activity_Participation. The User table stores information about each registered user, including their username, password, role, and registration and last login times, with a unique identifier for each user. The Article table holds details about published articles, such as the title, author, content, and publication time. The Book table contains information about books, including the title, author, and description. The Activity table stores details about various activities, including their names, descriptions, and times. The Video_Interview table stores information about video interviews, including the title, publication time, and link. The User_Comments table links users to articles they have commented on, with a composite primary key of user and article IDs, referencing the User and Article tables respectively. The Book_Recommendation table stores recommendations made by users for books, with a composite primary key of book and recommender IDs, referencing the Book and User tables. The Activity_Lottery table stores information about winners of activities, with a composite primary key of activity and winner IDs, referencing the Activity and User tables. The User_Activity_Participation table tracks user participation in activities, with a composite primary key of user and activity IDs, referencing the User and Activity tables. Each of these tables is designed to maintain data integrity through primary keys, composite keys, and foreign keys that enforce relationships between tables, ensuring that data remains consistent and accurate.
