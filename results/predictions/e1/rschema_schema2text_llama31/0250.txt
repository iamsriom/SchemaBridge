The rschema_0250 database is designed to manage user accounts, products, orders, and administrative activities within an e-commerce system. The User table stores information about registered users, including their login history, contact details, and roles, with each user uniquely identified by a User_ID. The Product table contains details about available products, such as their category, description, price, and stock quantity, with each product assigned a unique Product_ID. The Order table captures information about completed orders, including the order status, total amount, and the user who placed the order, with each order linked to the corresponding user through the User_ID foreign key. The User_Shopping_Cart table represents the items in a user's shopping cart, with each entry consisting of a product, quantity, and the user who added it, while the Admin_Product_Management table tracks administrative actions on products, such as updates and deletions, performed by specific administrators. The Order_Product table stores the items included in each order, along with their quantities and prices, and the User_Order table provides an alternative view of orders, linking each order to the user who placed it. The Admin_Order_Management table records administrative actions on orders, such as updates and cancellations, performed by specific administrators. Each of these tables is linked to others through foreign keys, ensuring data consistency and integrity, with primary keys and unique constraints ensuring that each record is uniquely identifiable and that relationships between tables are maintained.
