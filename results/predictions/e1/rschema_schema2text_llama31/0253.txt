The rschema_0253 database is designed to manage user interactions and group chats within a social platform. The User table stores information about each registered user, including their username, password, phone number, and registration time, with a unique User_ID serving as the primary key. The Group_Chat table represents a group chat, containing details such as the creation time, creator's ID, group chat name, and total members, with the creator's ID referencing the User table for ownership. The Chat_Record table tracks individual messages sent between users, including the message content, type, send and read times, and the IDs of the two users involved, with both user IDs referencing the User table for authenticity. The User_Joining_Group_Chat table records when a user joins a group chat, including the application information, group chat ID, and join time, with both the group chat ID and user ID referencing the Group_Chat and User tables, respectively. Similarly, the User_Leaving_Group_Chat table tracks when a user leaves a group chat, including the group chat ID, leaving time, and user ID, with both the group chat ID and user ID referencing the Group_Chat and User tables.
