The rschema_0254 database is designed to manage information related to earthquake monitoring and seismometer calibration. At its core, it stores user information in the User table, which contains details such as the affiliated earthquake monitoring center station, name, password, and a unique user name that serves as the primary key. The Seismometer_Calibration_Information table holds data about the calibration of seismometers, including amplitude, coil sensitivity, calibration time, equivalent pendulum length, mechanical cycle, moment of inertia, ratio test result, vibration table test result, and width. The System_Management_Information table stores information about system management, specifically equivalent pendulum length, moment of inertia, personnel information that serves as the primary key, seismometer calibration coil sensitivity, and seismometer voltage sensitivity. The User_Role_Access_Control table tracks user roles and access control, linking users to specific calibration times and roles, with the combination of user name and calibration time serving as the primary key, referencing the Calibration_Time in Seismometer_Calibration_Information and the User_Name in User. The Calibration_Time in User_Role_Access_Control is a foreign key referencing Calibration_Time in Seismometer_Calibration_Information, and the User_Name is a foreign key referencing User_Name in User, ensuring referential integrity.
