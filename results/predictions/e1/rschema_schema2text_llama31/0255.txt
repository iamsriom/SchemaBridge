The rschema_0255 database is designed to manage and track various aspects of a production process, including equipment maintenance, quality control, and employee management. The database consists of 11 tables that work together to provide a comprehensive view of the production process. The production_report table stores information about production reports, including the report ID, type, date, production data, indicators, completion status, metal recovery rate, and grade. The equipment table contains details about the equipment used in the production process, such as the equipment ID, name, model, category, subcategory, location, and operation status. The equipment_inspection table tracks equipment inspections, including the equipment ID, inspector ID, inspection plan, and execution progress, with the inspector ID referencing the user table, which stores information about the users involved in the production process, including their ID, username, role, permissions, status, and operation history. The equipment_failure_reporting table records equipment failures, including the equipment ID, failure reporter ID, failure type, failure time, and processing status, with the failure reporter ID also referencing the user table. The equipment_repair table tracks equipment repairs, including the equipment ID, repair person ID, repair progress, and repair time, with the repair person ID referencing the user table. The quality_report table stores quality reports, including the report ID, metal recovery rate, warehouse sample, metal grade, recovery rate daily report, and grade daily report. The equipment_monitoring table tracks equipment monitoring data, including the equipment ID, equipment type, collected data, status, monitoring data, fault alarm, data visualization, and administrator ID, with the administrator ID referencing the user table. The announcement table stores announcements, including the announcement ID, content, release time, publisher ID, and announcement status, with the publisher ID referencing the user table. The job_position table contains job information, including the job ID, name, description, responsibilities, and requirements. Finally, the user_job_application table tracks job applications, including the user ID, job ID, and job match rate, with both the user ID and job ID referencing the user and job_position tables, respectively.
