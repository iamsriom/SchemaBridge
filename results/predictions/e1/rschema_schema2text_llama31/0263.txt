The rschema_0263 database is designed to manage student assignments and their associated corrections and sampling records. The database contains five tables: student, lecturer, assignment, correction_record, and sampling_record. The student table stores information about each student, including their unique student ID, name, telephone number, and email address. The lecturer table stores information about each lecturer, including their unique lecturer ID, name, telephone number, and email address. The assignment table stores information about each assignment submitted by students, including the assignment ID, the student who submitted it, the submission time, the content of the assignment, and its status. The correction_record table stores information about the corrections made to each assignment, including the correction ID, the assignment ID it corresponds to, the lecturer who made the correction, the correction time, the score given, and the evaluation. The sampling_record table stores information about the sampling records of each correction, including the sampling ID, the correction ID it corresponds to, the teaching staff ID, the sampling time, and the sampling opinion. The student ID in the assignment table is a foreign key referencing the student table, meaning that each assignment is associated with a specific student, and if the student record is deleted, all their assignments will also be deleted. Similarly, the assignment ID in the correction_record table is a foreign key referencing the assignment table, and the lecturer ID is a foreign key referencing the lecturer table, meaning that each correction is associated with a specific assignment and lecturer, and if the assignment or lecturer record is deleted, all their corrections will also be deleted. The correction ID in the sampling_record table is a foreign key referencing the correction_record table, meaning that each sampling record is associated with a specific correction, and if the correction record is deleted, all its sampling records will also be deleted.
