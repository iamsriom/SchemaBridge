The rschema_0270 database is designed to manage information about television programs and the staff involved in their production and review. At the heart of the database is the Program table, which stores details about each program, including its broadcast start and end times, duration, name, and type. Each program is uniquely identified by a Program ID, which serves as the primary key. The Staff table contains information about the individuals involved in the production process, including their contact number, gender, name, and position, with each staff member assigned a unique Staff ID. The Program_Production table links staff members to the programs they work on, with each entry representing a specific staff member's working duration on a particular program. The primary key for this table is a composite of the Program ID and Production Staff ID, ensuring that each staff member can only be associated with a program once. The Program_Review table tracks the review process for each program, with each entry representing a review result and the reviewer's ID, along with the working duration. The primary key for this table is also a composite of the Program ID and Reviewer ID, ensuring that each program can only be reviewed once by a staff member. The database enforces referential integrity through foreign key constraints, which dictate that a staff member can only be associated with a program they exist in the Staff table, and a program can only be reviewed or produced by a staff member who exists in the Staff table.
