The rschema_0275 database is designed to manage information about ecosystems, operators, and monitoring records. The Ecosystem table stores details about different ecosystems, including their current status, location, name, a unique system ID, and type. The Operator table contains information about the individuals responsible for monitoring these ecosystems, such as their contact information, employee ID, gender, name, and position. The Monitoring_Record table captures data collected during monitoring activities, including the employee ID of the person conducting the monitoring, humidity and temperature readings, plant growth observations, soil moisture levels, and the date of the monitoring activity. Each monitoring record is linked to a specific ecosystem through the System_ID, which is a foreign key referencing the Ecosystem table, and to the operator who conducted the monitoring through the Employee_ID, which is a foreign key referencing the Operator table. The primary key for the Monitoring_Record table is a composite key consisting of the System_ID and Monitoring_Date, ensuring that each ecosystem can only have one monitoring record per date.
