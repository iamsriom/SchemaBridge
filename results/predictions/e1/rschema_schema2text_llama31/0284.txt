The rschema_0284 database is designed to manage advertisements and their interactions with users. The Advertisement table stores information about individual advertisements, with each advertisement having a unique identifier, a name, and a description of its content. The User table holds details about the individuals who interact with these advertisements, including their name and contact information, with each user uniquely identified by their User_ID. The Broadcast_Record table tracks the timing of when advertisements are broadcast, linking each broadcast to a specific advertisement through its Advertisement_ID, and the time slot in which it was shown. The Advertisement_Push table records when a user has been shown an advertisement, linking each push to both the advertisement it came from and the user it was shown to, ensuring that each advertisement and user is uniquely identified by their respective IDs.
