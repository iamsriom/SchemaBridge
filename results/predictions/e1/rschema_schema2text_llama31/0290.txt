The rschema_0290 database is designed to track financial information related to various projects. It consists of two main tables: Project and Fund_Flow_Record. The Project table stores details about each project, including its budget, name, and a unique identifier, Project_ID, which serves as the primary key to uniquely identify each project. The Fund_Flow_Record table, on the other hand, records the flow of funds associated with each project, including the amount, date, type of fund, and any remarks. Each fund flow record is linked to a specific project through the Project_ID column, which is a foreign key referencing the Project_ID in the Project table, ensuring that every fund flow record is tied to an existing project. The Project_ID column in Fund_Flow_Record is not nullable, indicating that every fund flow record must be associated with a project.
