The rschema_0305 database is designed to manage user interactions and content sharing within a social media platform. The database consists of four main tables: user, post, notification, and follow. The user table stores information about each registered user, including their account ID, name, email, password, verification status, and account status. The post table contains details about each published post, such as the post ID, the user who published it, the content of the post, the time it was published, and a link to any attached files. The post table has a foreign key referencing the user table, indicating that each post is associated with a specific user, and this relationship is set up to cascade in both directions, meaning that if a user is deleted, all their posts will also be deleted, and if a post is deleted, the user who published it will still be intact. The notification table stores information about notifications sent to users, including the notification ID, the recipient's account ID, the type of notification, and the time it was sent. Like the post table, the notification table also has a foreign key referencing the user table, set up to cascade in both directions. The follow table represents the relationships between users, where each entry represents a user who is following another user, with the primary key being a composite of both users involved in the relationship. This table also has foreign keys referencing the user table, set up to cascade in both directions, meaning that if a user is deleted, all their followers will also be deleted, and if a user is deleted, all users who follow them will still be intact.
