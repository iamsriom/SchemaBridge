The rschema_0308 database is designed to manage information about customers, projects, and user accounts. The customer table stores details about each customer, including their unique customer ID, name, address, contact information, and any additional remarks. The project table contains information about each project, such as its unique project ID, name, start date, status, scale, remarks, and the project manager's user ID, which references the user table. The project_report table stores reports related to each project, including the report date, time, description, creator's user ID, and the associated project ID, which references the project table. The user table stores information about each user, including their unique user ID, name, abbreviation, password, active status, and status information. The project_customer_record table serves as a bridge between the customer and project tables, linking each customer to the projects they are associated with, and vice versa, with each record uniquely identified by a combination of the customer ID and project ID. The database enforces referential integrity through various constraints, such as the ON DELETE CASCADE rule, which automatically deletes related records in other tables when a record is deleted, ensuring data consistency across the database.
