The rschema_0313 database is designed to manage the creation, ordering, and permissions of Mexican tortillas. It contains seven tables: Ingredient, Mexican_Tortilla_Design, User, Permission, Mexican_Tortilla_Ingredient, Order, and User_Permission. The Ingredient table stores information about the various ingredients used in making tortillas, with each ingredient having a unique ID, name, and type. The Mexican_Tortilla_Design table holds details about the different tortilla designs, including their creation time, ID, and name. The User table stores user information, with each user having a unique username and password, as well as an activation status. The Permission table lists the different permissions available, with each permission having a unique name and description. The Mexican_Tortilla_Ingredient table links ingredients to specific tortilla designs, with each entry referencing the ingredient ID and tortilla design ID. The Order table manages orders for tortillas, including the credit card details, recipient information, and the tortilla design ID, with each order having a unique combination of tortilla design ID, creation time, and recipient. The User_Permission table grants permissions to users, with each entry referencing the user's username, permission name, and validity period. The database enforces data integrity through primary keys, which uniquely identify each ingredient, tortilla design, user, permission, and order, as well as composite keys in the Mexican_Tortilla_Ingredient and Order tables. Foreign keys, such as the ones referencing the Ingredient, Mexican_Tortilla_Design, and User tables, ensure that related data is consistent and accurate, with update and delete rules like CASCADE and RESTRICT applied to maintain data consistency. Additionally, indexes and constraints are used to optimize data retrieval and enforce data integrity, ensuring that the database remains organized and reliable.
