The rschema_0315 database is designed to manage a library's borrowing system, allowing users to track books and their borrowers. The Borrower table stores information about each individual who borrows books, including their unique Borrower ID, email address, gender, name, and phone number. The Book table contains details about each book, such as its author, title, category, price, publication year, and publisher. The Book Borrowing table tracks the borrowing history of each book, including the borrower's ID, the quantity borrowed, the borrowing and expected return times, and the duration of the loan. This table has a composite primary key consisting of the borrower's ID, book ID, and borrowing time, ensuring that each borrowing instance is unique. The Book Borrowing table also references the Book and Borrower tables through foreign keys, which enforce referential integrity by linking each borrowing instance to the corresponding book and borrower. The Book Return table is similar to Book Borrowing, but it stores information about when a book is returned, including the return time, whether the return was overdue, and any associated penalty amount. This table also has a composite primary key and references the Book and Borrower tables through foreign keys, ensuring that each return instance is linked to the corresponding book and borrower.
