The rschema_0316 database is designed to manage a collection of e-books and their associated metadata, user information, and statistics. The Category table represents a hierarchical categorization system, where each category has a unique ID, a name, a display order, and a parent category ID, which references the ID of its parent category, establishing a self-referential relationship that allows for nested categories. The User table stores information about registered users, with a unique ID, a password, and a username. The E-book table contains details about each e-book, including its title, category ID, cover URL, and detailed description, with a unique ID and a foreign key referencing the Category table to establish the relationship between e-books and their categories. The Document table stores the content of each e-book, with a unique ID and a foreign key referencing the E-book table to link documents to their respective e-books. The Statistics table tracks various metrics for each e-book, including the date of each update, the e-book ID, like count, and read count, with a unique ID and a foreign key referencing the E-book table to establish the relationship between statistics and their corresponding e-books.
