The rschema_0318 database is designed to manage user roles and menu navigation within a system. The Role table stores information about different roles, with each role having a unique Role_ID and a descriptive Role_name. The Menu table organizes the system's menu structure, where each menu item has a Label, a unique Menu_ID, a Parent_menu_ID that references its parent menu, and a Relative_URL that links to the actual page. The Parent_menu_ID is not allowed to be null, indicating that every menu item must have a parent. The User table stores details about individual users, including their First_name, Last_name, Password, and Username, with each user having a unique User_ID. The Role_ID for each user is not allowed to be null, indicating that every user must be assigned a role. The Role_ID in the User table references the Role_ID in the Role table, establishing the relationship between users and their respective roles.
