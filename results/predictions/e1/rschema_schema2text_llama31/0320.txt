The rschema_0320 database is designed to manage information about products, their styles, features, stock, and images. At the core of the database is the Product table, which stores details about each product, including its ID, name, description, slogan, and default price. Each product can have multiple styles, which are stored in the Style table, along with their associated product ID, name, original and sale prices, and a flag indicating whether they are the default style. The Style table is linked to the Product table through a foreign key, which ensures that a style is always associated with a valid product. The Style table also references the SKU table, which stores stock information for each style, including the stock quantity and size. The SKU table is linked to the Style table through a foreign key, ensuring that stock information is always associated with a valid style. The Style table is also linked to the Photo table, which stores image URLs for each style, including the main photo and thumbnail. The Photo table references the Style table through a foreign key, ensuring that images are always associated with a valid style. The Feature table stores additional information about each product, including its ID, name, and value, and is linked to the Product table through a foreign key, ensuring that features are always associated with a valid product.
