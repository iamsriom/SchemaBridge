The rschema_0322 database is designed to manage information about companies, employees, devices, users, and their interactions. The database contains seven tables: company, employee, device, user, site, employee_uses_device, and user_creates_site. The company table stores details about each company, including its unique identifier, name, website, and creation date. The employee table contains information about each employee, such as their unique identifier, name, position, salary, and the company they belong to, with the company ID referencing the company table and enforcing a cascade delete and update rule. The device table stores details about each device, including its unique identifier, name, and the employee it belongs to, with the employee ID referencing the employee table and enforcing a cascade delete and update rule. The user table stores user credentials, including their unique identifier, username, password, email, and last login time. The site table contains information about each site, including its name, hostname, status, and the user who created it, with the user ID referencing the user table and enforcing a cascade delete and update rule. The employee_uses_device table tracks the usage of devices by employees, including the employee ID, device ID, start and end usage times, and forms a composite primary key with these three columns. This table also references the employee and device tables, enforcing a cascade delete and update rule. Finally, the user_creates_site table stores information about which user created each site, including the username, site name, and creation time, with a composite primary key and referencing the user and site tables, enforcing a cascade delete and update rule.
