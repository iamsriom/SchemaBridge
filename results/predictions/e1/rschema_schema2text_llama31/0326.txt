The rschema_0326 database is designed to manage user information and task assignments. The User table stores details about each registered user, including their avatar file information, date of birth, full name, password, and unique user ID. The User_ID field serves as the primary key, ensuring each user is uniquely identified. The Task table represents tasks assigned to users, with fields for the assignee and creator of the task, creation and completion dates, task name, priority, remarks, and status. The Task_ID field is the primary key, linking tasks to their respective users through the Assignee_User_ID and Creator_User_ID foreign keys, which reference the User_ID field in the User table. The Task_File table stores files associated with tasks, with a unique Task_File_ID and a foreign key referencing the Task_ID in the Task table, ensuring that each file is linked to a specific task.
