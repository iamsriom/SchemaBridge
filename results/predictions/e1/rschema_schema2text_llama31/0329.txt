The rschema_0329 database is designed to track user information and their investments in the stock market. The User table stores details about each user, including a unique identifier (user_ID), a username, and their virtual currency balance. The Stock table contains information about publicly traded companies, with columns for the company name, the date the stock was issued, a unique stock code, and the current stock price. The Log table is used to record transactions or events, with a timestamp, a unique log ID, the value of the transaction, and a reference to the user who made the transaction, which is linked to the User table through a foreign key. The User_Investment_Stock table tracks the investments made by each user in the stock market, with columns for the earnings value of the investment, the quantity of stock held, the stock code, and the user ID, with the latter two columns forming a composite primary key that uniquely identifies each investment. The stock code is also linked to the Stock table through a foreign key, and the user ID is linked to the User table, ensuring that each investment is associated with a valid user and stock.
