The rschema_0331 database is designed to store information about players, matches, and match results in a competitive environment. The Player table contains details about each player, including their contact information, gender, nickname, and a unique player ID, which serves as the primary key and cannot be null. The Registration_Time field records when each player registered. The Match_Information table stores details about each match, such as its end and start times, name, total participants, and type, with the Match_ID serving as the primary key and not allowing null values. The Match_Result table tracks the ranking and total score of each player in a match, with a composite primary key consisting of the Player_ID and Match_ID, and no null values allowed. The Battle table represents a match between two players, with fields for the match's duration, end and start times, and the result, as well as foreign keys referencing the Player table for the two players involved and the Match_Information table for the match itself, with the primary key being a composite of the Match_ID, Player_1_ID, Player_2_ID, and Match_Start_Time, and the Match_ID, Player_1_ID, and Player_2_ID fields are not nullable.
