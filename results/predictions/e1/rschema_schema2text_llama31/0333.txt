The rschema_0333 database is designed to manage user information and their interactions on a social networking platform. The User table stores information about each user, including their address, birthday, current location, email, gender, hometown, interests, motto, name, password, personal profile, phone number, relationship status, user type, and username. The User_ID is the primary key, uniquely identifying each user, and is a required field. The User_homepage table represents a user's homepage, containing details such as creation time, title, and introduction, with a foreign key referencing the User table to link the homepage to its owner. The User_connection_request_record table tracks user connection requests, including the sender and receiver's user IDs, the send time, and a unique record ID. The User_connection_establishment_record table records established connections between users, with foreign keys referencing the User table to identify the sender and receiver. The Feed table stores user posts, including the feed content, post time, and a foreign key referencing the User table to identify the poster and the User_homepage table to identify the homepage where the post was made. The User_homepage_join table tracks when a user joins a homepage, with a composite primary key of join time, homepage ID, and user ID, and foreign keys referencing the User_homepage and User tables to link the join to the homepage and user.
