The rschema_0345 database is designed to manage information about courses, professors, students, and their interactions. The Subject table stores details about each course, including its code, name, and credits, with the subject code serving as the primary key. The Professor table contains information about each instructor, with their email, name, and a unique professor ID, which is the primary key. The Student table holds details about each student, including their average grade, credits completed, date of birth, email, and a unique student ID, which is the primary key. The Subject_Equivalence table maintains a list of equivalent subjects, linking two subject codes together in a unique combination, with each subject code serving as a foreign key referencing the Subject table. The Subject_Prerequisites table lists the prerequisites for each subject, linking the prerequisite subject and the related subject in a unique combination, with both subject codes serving as foreign keys referencing the Subject table. The Course table stores information about each course, including its code, name, responsible professor, and total credits, with the course code serving as the primary key and the professor ID referencing the Professor table. The Course_Assignment table links each course to its corresponding subject and semester, with the course code, subject code, and semester forming a composite primary key, and both course code and subject code serving as foreign keys referencing the Course and Subject tables, respectively. The Student_Course_Enrollment table tracks each student's enrollment in courses, with the student ID and course code forming a composite primary key, and both student ID and course code serving as foreign keys referencing the Student and Course tables, respectively.
