The rschema_0347 database is designed to store and manage metadata related to machine learning models and their associated datasets. The database consists of 12 tables that work together to provide a comprehensive view of the models, their performance, and the datasets they are trained on. The leaderboard_metadata table stores information about each model run, including the run ID, model execution time, start and end times, run time, run path, maximum models, and model species. The leaderboard table contains details about each model, such as its ID, name, root mean squared error (RMSE), mean squared error (MSE), mean absolute error (MAE), root mean squared log error (RMSLE), and presence stacked ensemble best of family. The model_map table maps model types to their corresponding names, while the dataset_variable_details table stores information about the variables in each dataset, including their names, data types, unique and null values, and the dataset ID they belong to. The tags table stores unique tags, and the hyperparameter_value table links models to their hyperparameters and their corresponding values. The model_run table associates model runs with their corresponding models, and the data_map table links datasets to their associated model runs. The hyperparameter_def_values table stores default values for hyperparameters based on model types, and the id_map table maps model IDs to their corresponding model types. The hyperparameter table stores unique hyperparameters, and the dataset_metadata table contains metadata about each dataset, including its ID, name, owner, license, visibility, URL, creation and last update dates, data size, number of rows, and number of columns. The relationships between these tables are established through foreign keys, which ensure data consistency and integrity, such as the cascade delete and update rules that ensure that related data is deleted or updated when a parent record is modified or deleted.
