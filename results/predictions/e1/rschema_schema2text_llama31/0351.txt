The rschema_0351 database is designed to manage objects, users, and permissions within a system. The database consists of six tables: object, user, permission_entry, permission_inheritance, authorization, and object_assignment. The object table stores information about individual objects, with each object having a unique identifier (object_id), a category, and no null values allowed for these fields. The user table holds details about system users, including a unique identifier (user_id), a name, and contact information, all of which cannot be left blank. The permission_entry table tracks permission entries, with each entry having a unique number, a log recording status, and a log path, all of which are non-null. The permission_inheritance table establishes relationships between objects, where a parent object can have multiple child objects, and both the parent and child objects are referenced back to the object table, with the relationship being deleted or updated in tandem. The authorization table grants permissions to objects, linking permission entries to specific objects, and both the permission entry and authorized object are referenced back to their respective tables, with the relationship being deleted or updated in tandem. The object_assignment table assigns objects to users, linking objects to their respective users, with both the object and user being referenced back to their respective tables, with the relationship being deleted or updated in tandem.
