The rschema_0363 database is designed to manage a library's catalog and borrowing system. The Book table stores information about each book, including its title, author, publication date, price, publisher, and location within the library. Each book is uniquely identified by its ISBN, which is also the primary key of this table. The Reader table holds details about each library patron, such as their name, address, phone number, email, age, and reader type. The Reader_ID, a unique identifier for each patron, serves as the primary key. The Reader_book_borrowing table tracks the borrowing history of each book, including the borrowing time, due date, and actual return date, with the ISBN and Reader_ID referencing the Book and Reader tables, respectively. The primary key of this table is a composite of the Reader_ID, ISBN, and borrowing time. The Reader_book_reservation table is similar, but it records the reservation status and expiration time of each book, also referencing the Book and Reader tables. The primary key of this table is also a composite of the Reader_ID, ISBN, and reservation time.
