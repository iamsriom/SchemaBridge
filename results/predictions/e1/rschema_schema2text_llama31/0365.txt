The rschema_0365 database is designed to manage customer orders and products. It consists of four tables: Customer, Product, Order, and Order_Item. The Customer table stores information about each customer, including their ID, detailed address, email, name, and password. The Product table holds details about each product, such as its description, image path, name, price, and stock quantity, with each product uniquely identified by its ID. The Order table represents each transaction, containing the customer's ID, a unique order ID, the order time, and its status. The Order table is linked to the Customer table through a foreign key, indicating that each order is associated with a specific customer. The Order_Item table is used to store the items included in each order, consisting of the order ID, product ID, and quantity, with a composite primary key combining the order and product IDs to ensure each item is unique to a specific order. Additionally, the Order_Item table has foreign keys referencing both the Order and Product tables, enforcing that each item is part of a valid order and product.
