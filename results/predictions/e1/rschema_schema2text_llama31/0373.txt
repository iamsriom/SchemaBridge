The rschema_0373 database is a comprehensive system for managing projects, users, and their interactions. At its core is the project table, which stores information about each project, including its unique identifier, name, description, code, budget level, creation time, and leader, who is linked to a specific user through the user_project_application table. The user_project_application table itself contains details about a user's application to join a project, including the application time and status. Users can also apply for funds for a project through the user_fund_application_for_project table, which links the user to the project and the amount of funds they've applied for. The user_held_activity table tracks activities held by users for a project, including the activity name, event time, location, and budget amount. The user table stores information about each user, including their unique identifier, username, password, email, phone number, role, and department, which is linked to the department table that contains information about each department, including its unique identifier, name, and leader. The department leader is also linked to a specific user through the user_project_application table, allowing for a hierarchical structure.
