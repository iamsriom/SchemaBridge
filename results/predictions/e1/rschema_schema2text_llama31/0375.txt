The rschema_0375 database is designed to manage and track various aspects of devices and their interactions with users. The Device table stores information about each device, including its status, name, type, IP address, installation location, installation time, and ID, which serves as the primary key. The User table contains details about users, such as their ID and password, while the Staff table holds information about staff members, including their ID and name. The Network_Traffic table tracks network traffic data for each device, including download and upload traffic, timestamp, and status, with a composite primary key consisting of the device ID and timestamp, and a foreign key referencing the Device table to establish the relationship between network traffic and the device it belongs to. The Device_Failure_Record table stores records of device failures, including the device ID, failure description, occurrence time, type, handling status, and remarks, with a composite primary key of device ID and failure occurrence time, and a foreign key referencing the Device table to link the failure record to the device it pertains to. The User_Connection_Device table tracks user connections to devices, including connection and disconnection times, used bandwidth, user ID, and user IP, with a composite primary key of user ID, device ID, and connection time, and foreign keys referencing the User and Device tables to establish relationships between users, devices, and their connections. The Device_Maintenance_Record table stores maintenance records for devices, including device ID, maintenance content, result, time, and remarks, with a composite primary key of device ID, staff ID, and maintenance time, and foreign keys referencing the Device and Staff tables to link the maintenance record to the device and staff member involved.
