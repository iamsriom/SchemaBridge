The rschema_0384 database is designed to manage tasks and their associated parameters, organisms, and execution details. The Task table stores information about each task, including its title, status, owner, creation and end dates, and the executable file used to run it. Each task has a unique ID and can be in one of several statuses, with a reason for its current status also recorded. The Parameter table contains a list of parameter names, each with a unique ID. The Task_Parameter table links tasks to their associated parameters, with each parameter having a value and a task ID, and the combination of task ID, parameter ID, and parameter value uniquely identifying each record. The Organism table stores information about different organisms, with each organism having a unique ID and a name. The Task_Related_Organism and Task_Excluded_Organism tables record the relationships between tasks and organisms, with each table storing the creation time, task ID, and organism ID for each relationship, and the combination of task ID, organism ID, and creation time uniquely identifying each record. The relationships in these tables are established through foreign keys referencing the Task and Organism tables, ensuring that only valid task and organism IDs are used.
