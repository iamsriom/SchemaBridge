The rschema_0386 database is designed to manage user accounts and transactions within a blockchain system. At its core, the User table stores information about each registered user, including their public key, username, and creation time, with a unique identifier for each user. The Block table tracks the blocks that make up the blockchain, containing details such as the block's hash, size, creation time, and the ID of the previous block in the chain. The Transaction_Record table records each transaction made between users, including the block it belongs to, the type and content of the operation, the sender and receiver IDs, the transaction amount, and the time of the transaction. The Transaction_Record table has a composite primary key that ensures each transaction is uniquely identified by the sender and receiver IDs, the transaction time, and the block ID. The Block table is referenced by the Transaction_Record table through a foreign key, which links each transaction to its corresponding block. Similarly, the User table is referenced by the Transaction_Record table through two foreign keys, one for the sender ID and one for the receiver ID, which establish the relationships between users and the transactions they make.
