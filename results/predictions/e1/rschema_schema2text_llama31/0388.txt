The rschema_0388 database is designed to manage information about suppliers, projects, salaries, employees, and their attendance records. The database contains seven tables: Supplier_Table, Project_Table, Salary_Table, Supplier_Supply_Project, Employee_Table, Attendance_Record_Table, and Employee_Project_Allocation. The Supplier_Table stores information about each supplier, including their creation and update times, supplier ID, supplier information, and supplier relationship management. The Project_Table holds details about each project, such as creation and update times, project ID, project information, and project progress management. The Salary_Table contains information about salary calculations, distribution, and ID. The Supplier_Supply_Project table links suppliers to projects, with each supplier ID and project ID forming a composite primary key, and both referencing the Supplier_Table and Project_Table respectively. The Employee_Table stores employee details, including creation and update times, employee ID, employee information, performance evaluation, position allocation, and a foreign key referencing the Salary_Table for each employee's salary. The Attendance_Record_Table tracks attendance records for each employee, with a unique attendance ID, attendance record, creation time, employee ID, and employee punch-in time, referencing the Employee_Table for each employee. The Employee_Project_Allocation table assigns employees to projects, with a composite primary key of employee ID and project ID, referencing the Employee_Table and Project_Table respectively.
