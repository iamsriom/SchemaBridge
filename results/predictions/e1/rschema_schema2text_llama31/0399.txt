The rschema_0399 database is designed to manage user accounts, code submissions, problems, and projects. At its core, the database contains a table called "user" which stores information about each registered user, including their unique identifier, username, password, email, registration time, and personal details. The "code" table is used to store code submissions, each identified by a unique code ID, and linked to the user who submitted it, the problem it was submitted for, and the time of submission. The "problem" table contains details about each problem, including its unique identifier, name, description, difficulty level, and creation time. The "project" table stores information about each project, including its unique identifier, name, description, creation time, and the user who created it. The "sign-in" table tracks each time a user signs in, recording their unique identifier, sign-in time, and date. The "user_participation_in_project" table links users to the projects they participate in, including the project's difficulty level. Each of these tables is linked together through foreign keys, ensuring that a user can only submit code for a problem they exist, a user can only create a project if they have an account, and a user can only participate in a project if they exist and the project exists.
