The rschema_0400 database is designed to manage user interactions and book borrowing within a community. The database consists of six tables: Role, Book, User, Notification, User_Establishes_Friend_Relationship, and User_Borrows_Book. The Role table stores information about different roles, including a unique role ID, a descriptive name, and a brief description. The Book table contains details about each book, such as its title, author, category, publication date, and publisher. The User table represents individual users, with attributes like their college affiliation, email, password, registration time, and a unique user ID, which is linked to a specific role through the Role_ID foreign key. The Notification table stores notifications sent by users, including the content, title, release date, and the user ID of the publisher. The User_Establishes_Friend_Relationship table tracks friendships between users, with each relationship having a creation time and referencing the IDs of both users involved. The User_Borrows_Book table records when a user borrows a book, including the book ID, borrow and return times, and the user ID, with both the book and user IDs serving as composite primary keys to ensure uniqueness.
