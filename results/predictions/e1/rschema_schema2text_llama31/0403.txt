The rschema_0403 database is designed to manage the borrowing and auditing of books by students and administrators. The Student table stores information about each student, including their contact number, email, grade, major, name, student ID, and student number, with the student ID serving as the primary key. The Administrator table contains details about each administrator, such as their contact number, email, job number, name, and position, with the administrator ID as the primary key. The Book table holds information about each book, including its author, title, publication date, publisher, category, stock quantity, and borrowed quantity, with the book ID as the primary key. The Student_Borrow_Book table tracks the borrowing history of each student, including the borrowed book ID, borrow date, return date, and review status, with a composite primary key of student ID and borrowed book ID, referencing the Student and Book tables, and enforcing that a student cannot borrow a book without a valid student ID and that a book cannot be borrowed without a valid book ID. The Student_Return_Book table is similar to the Student_Borrow_Book table but for returned books, with a composite primary key of student ID and returned book ID, referencing the Student and Book tables, and enforcing the same constraints as the Student_Borrow_Book table. The Administrator_Audit table records the auditing history of administrators, including the administrator ID, audit date, audit result, book ID, and borrowing status, with a composite primary key of administrator ID and book ID, referencing the Administrator and Book tables, and ensuring that an administrator can only audit a book with a valid administrator ID and book ID.
