The rschema_0409 database is designed to manage user interactions with products and orders. At its core, the User table stores information about each registered user, including their email address, password, unique user ID, and username. The Product table contains details about the products available for purchase, such as their name, price, product ID, a brief description, and current stock level. The Cart table represents a user's shopping cart, with each cart having a unique ID, creation time, and a foreign key referencing the user who owns the cart, ensuring that a cart can only be owned by a registered user. The Order table tracks completed orders, with each order having a unique order number, status, order time, and a foreign key referencing the user who placed the order. The Cart_Details table stores the products added to each cart, with each entry consisting of the cart ID, product ID, and quantity, and is linked to both the Cart and Product tables through foreign keys. Similarly, the Order_Details table stores the products included in each order, with each entry consisting of the order number, product ID, and quantity, and is linked to both the Order and Product tables through foreign keys.
