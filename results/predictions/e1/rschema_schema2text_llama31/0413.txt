The rschema_0413 database is designed to manage employee information and training data for a company. It consists of four tables: employee, department, training_course, and course_participation. The employee table stores details about each employee, including their unique employee ID, name, gender, position, department, contact number, and hire date. The department table contains information about each department, such as its unique department ID, name, manager's employee ID, and phone number. The training_course table lists available training courses, including their unique course ID, name, duration, instructor, and description. The course_participation table tracks which employees have participated in which courses, with details about the training date, score, and pass status. The employee table is linked to the department table through a foreign key, meaning that each employee is assigned to a specific department, and the department table is also linked back to the employee table through a foreign key, indicating the manager of each department. The course_participation table has composite primary keys consisting of the employee ID, course ID, and training date, ensuring that each employee can participate in a course only once per date. Additionally, the course_participation table has foreign keys referencing both the employee and training_course tables, meaning that an employee can only participate in a course if it exists in the training_course table, and a course can only have employees participating in it if it exists in the training_course table.
