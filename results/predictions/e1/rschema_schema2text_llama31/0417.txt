The rschema_0417 database is designed to manage a social media platform where users can create and share posts, comments, and replies. The database consists of eight tables: user, post, comment, category, notification_information, comment_reply, comment_post, and notification_distribution. The user table stores information about each user, including their unique user ID, name, email, password, avatar link, and registration date. The post table stores details about each post, such as its ID, title, content, category, posting user, posting time, status, reply count, and like and favorite counts. The category table contains a list of available categories, identified by their unique category ID and name. The notification_information table stores notification messages, identified by a unique message number. The comment table stores comments made by users, including their content, posting user, like count, reply count, and posting time. The comment_reply table links comments to their replies, while the comment_post table links comments to the posts they belong to. The notification_distribution table tracks the distribution of notifications to users, including the notification message number, user ID, and read status. The relationships between these tables are established through foreign keys, which ensure that when a user is deleted, all their posts, comments, and notifications are also deleted, and when a post or comment is deleted, all related comments and replies are also deleted.
