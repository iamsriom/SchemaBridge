The rschema_0418 database is designed to manage user information and financial records. It contains four tables: User, Announcement, Type, and Income_Expense_Record. The User table stores details about each user, including their address, age, contact information, email, gender, login name, password, security question, status, and user type, with a unique user ID serving as the primary key. The Announcement table holds information about announcements, such as their content, publication time, status, and title, with a unique announcement ID as the primary key. The Type table categorizes different types, featuring a status and a type name, with a unique type ID as the primary key. The Income_Expense_Record table tracks financial transactions, including the amount, record name, remark, status, and time, with a unique record ID as the primary key, and it references the Type and User tables through foreign keys, meaning that each record must be associated with a valid type and user, and when a type or user is deleted, all related records in the Income_Expense_Record table will also be deleted.
