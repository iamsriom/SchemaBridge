The rschema_0420 database is designed to manage user interactions with educational videos and news articles. It consists of 12 tables that work together to store user information, video and news content, and their relationships. The user table stores information about each user, including their ID, username, password, phone number, WeChat OpenID, name, QQ number, email, and registration time. The news table stores news articles with their ID, title, content, publication time, read count, and status, as well as a foreign key referencing the news category table. The news category table stores categories with their ID, name, and sort order. The video table stores video information, including their ID, title, description, cover image URL, market, directory structure, course count, total duration, price, and status, with a foreign key referencing the video category table. The video category table stores categories with their ID, name, and parent category ID, allowing for hierarchical categorization. The instructor table stores instructor information, including their ID, name, avatar, title, introduction, teaching experience, professional field, and teaching achievements. The instructor course table links instructors to the videos they teach, with foreign keys referencing both the instructor and video tables. The video category assignment table links videos to categories, and the news category assignment table links news articles to categories. The user collection table stores which videos a user has collected, with foreign keys referencing both the user and video tables. The user video order table stores user purchases of videos, including the order time, payment amount, payment method, payment status, payment time, and order status, with foreign keys referencing both the user and video tables. Finally, the user learning record table stores user learning records, including the user ID, video ID, purchase time, expiration time, viewing duration, last viewing time, and completion status, with foreign keys referencing both the user and video tables.
