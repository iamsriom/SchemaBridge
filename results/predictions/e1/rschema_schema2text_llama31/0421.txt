The rschema_0421 database is designed to manage user accounts and property rentals. The User table stores information about each registered user, including their account creation and update times, email, password, phone number, and role, with a unique User ID serving as the primary key. The Property table contains details about each property, such as images, owner ID referencing the User table, property area, creation and update times, description, location, title, and status, with a primary key of Property ID. The Rental Transaction Record table tracks rental transactions, including lease start and end dates, total rent, creation and update times, and status, with a composite primary key consisting of User ID, Property ID, and Lease Start Date. This table also references the User and Property tables through foreign keys, with the User ID referencing the User table and Property ID referencing the Property table, enforcing referential integrity by requiring a matching User ID and Property ID for each rental transaction.
