The rschema_0422 database is designed to manage user information, projects, and their associated tasks and code submissions. The User table stores details about each registered user, including their email, phone number, and login information, with a unique User_ID serving as the primary key. The Project table contains information about each project, such as its creation time, introduction, and status, with a Project_ID serving as the primary key. The Project_Version table tracks different versions of a project, with each version having a unique Version_ID and being associated with a specific Project_ID, forming a composite primary key. The Code_Submission table stores details about code submissions made by users for specific projects, with a unique combination of User_ID, Project_ID, and Submission_Time serving as the primary key, and referencing the User and Project tables for foreign key integrity. The Task table manages tasks assigned to users for specific projects, with a unique combination of Project_ID, Assigned_To_User_ID, and Start_Time serving as the primary key, and referencing the User and Project tables for foreign key integrity.
