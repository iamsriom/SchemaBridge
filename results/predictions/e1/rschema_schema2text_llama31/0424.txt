The rschema_0424 database is designed to manage user accounts and system access. The User table stores information about each registered user, including their account status, email address, last login time, login IP address, password, phone number, and unique user ID, which serves as the primary key. The System table contains details about each system, such as its access time, approval requirements, callback URL, enabled status, secret key, domain, name, and token validity period, with the system ID being its primary key. The Login_record table tracks login activities, including the expiration time, login IP address, login and logout times, system ID, token, user ID, and a validity flag, with both user ID and system ID being non-nullable foreign keys referencing the User and System tables, respectively, and forming a composite primary key. The System_authorization table stores information about user authorizations for each system, including the authorization time, effectiveness, expiration time, system ID, and user ID, with both user ID and system ID being non-nullable foreign keys referencing the User and System tables, respectively, and forming a composite primary key.
