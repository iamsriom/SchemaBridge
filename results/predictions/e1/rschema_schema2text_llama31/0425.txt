The rschema_0425 database is designed to manage various aspects of a residential facility, including user information, building details, announcements, dormitory management, student records, maintenance records, and applications. At the core of the database is the User table, which stores information about individuals with unique User IDs, usernames, and passwords, as well as their roles within the facility. Each user can be assigned to a role, and users with the role of dormitory supervisor are linked to specific buildings through the Building table, which contains details such as the building's name, location, and type. The Building table also references the User table to establish the relationship between the dormitory supervisor and the building they oversee. The Announcement table stores announcements made by users, including the announcement's title, content, and release time, and is linked to the User table to identify the administrator who made the announcement. The Dormitory table contains information about each dormitory, including its name, facilities, number of beds, and type, and is linked to the Building table to establish the relationship between the dormitory and the building it is located in. The Student table stores information about students, including their name, class, gender, and dormitory ID, and is linked to the Dormitory table to establish the relationship between the student and their assigned dormitory. The Maintenance_Record table stores maintenance records, including the completion time, fault description, maintenance status, and report time, and is linked to the Dormitory table to identify the dormitory where the maintenance was performed and the User table to identify the maintenance staff member. Finally, the Application table stores applications made by students, including the application content, application time, application type, processing opinion, and processing status, and is linked to the Student table to establish the relationship between the student and their application.
