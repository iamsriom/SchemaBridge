The rschema_0426 database is designed to manage user interactions with attractions, including ticket reservations and comments. The User table stores information about each user, with a unique Account identifier, a Bio, a Nickname, and a Password. The Attraction table contains details about each attraction, including its Name, a Picture URL, a Reference Price, and a Text Description. The User Bookmark table links users to attractions they have bookmarked, with a composite primary key of Account and Attraction ID, referencing the User and Attraction tables respectively. The Ticket Reservation Record table stores records of ticket purchases, including the Attraction ID, the number of tickets purchased, the reservation and ticket purchase times, and the user's Account, with a composite primary key of User Account and Attraction ID, referencing the User and Attraction tables. The User Comment table stores user comments about attractions, including the Attraction ID, comment content, status, and time, as well as the user's Account, with a composite primary key of User Account and Attraction ID, referencing the User and Attraction tables. The database enforces referential integrity by ensuring that a user can only bookmark or comment on an attraction that exists, and that a ticket purchase or comment is associated with a valid user and attraction.
