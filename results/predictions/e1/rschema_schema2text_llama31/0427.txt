The rschema_0427 database is designed to manage student and teacher information, as well as their interactions within a university setting. The Student table stores details about each student, including their age, department, enrollment date, gender, major, name, password, and a unique student ID, which serves as the primary key. The Teacher table contains information about each teacher, such as their department, employee ID, gender, name, password, and title, with the employee ID being the primary key. The Course table holds details about each course, including its name, credits, and prerequisite course ID. The Student_Course_Selection table tracks the courses each student is enrolled in, with a composite primary key of student ID and course ID, and foreign keys referencing the Course and Student tables to ensure data consistency. The Teacher_Teaching table lists the courses each teacher is assigned to, with a composite primary key of employee ID and course ID, and foreign keys referencing the Course and Teacher tables. The Timetable table keeps track of the classes students are attending, with a composite primary key of student ID and course ID, and foreign keys referencing the Course and Student tables. Each of these tables is indexed to ensure efficient data retrieval, with the Student and Teacher tables having no additional constraints, the Course table having a unique index on the Course_ID column, and the Student_Course_Selection, Teacher_Teaching, and Timetable tables having unique indexes on their composite primary keys.
