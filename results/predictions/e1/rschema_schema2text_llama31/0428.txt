The rschema_0428 database is designed to manage information about students, courses, and dormitories within an educational institution. The student table stores details about each student, including their unique student ID, name, class, gender, age, and the dormitory they belong to. The student ID is the primary key, and it references the dormitory ID in the dormitory table, meaning that a student can only be associated with one dormitory, and if a dormitory is deleted, all students belonging to it will also be deleted. The super_user table contains information about administrators, with each user having a unique user ID, name, and role. The course table stores details about each course, including its unique course ID, leader, and class time, with the course leader referencing the user ID in the super_user table, meaning that if a user is deleted, all courses they lead will also be deleted. The dormitory table stores information about each dormitory, including its unique dormitory ID and location. The student_course_selection table tracks which students are enrolled in which courses, with each student and course combination having a unique grade. This table has a composite primary key consisting of the student ID and course ID, and both the student ID and course ID reference their respective tables, meaning that if a student or course is deleted, all their enrollments will also be deleted.
