The rschema_0430 database is designed to manage user interactions with attractions, such as booking tickets and leaving comments. The database contains six tables: user, attraction, message, ticket_booking, attraction_comment, and attraction_favorite. The user table stores information about each registered user, including their account creation and update times, email, full name, password, QQ number, remarks, user ID, and WeChat open ID. The attraction table holds details about each attraction, including its creation and update times, name, description, era, images, reference price, region, type, and ID. The message table stores messages sent by users, with each message containing its content, creation time, and update time, as well as a reference to the user who sent it. The ticket_booking table tracks ticket bookings, including the attraction ID, booking date, order creation and update times, order status, remarks, ticket quantity, and user ID, with a composite primary key combining the user ID, attraction ID, and order update time. The attraction_comment table stores comments left by users on attractions, including the attraction ID, comment content, creation and update times, review status, and user ID, with a composite primary key combining the user ID, attraction ID, and comment creation time. The attraction_favorite table tracks user favorites, with each entry containing the attraction ID, creation and update times, and user ID, with a composite primary key combining the user ID, attraction ID, and favorite creation time. Foreign keys are used to establish relationships between these tables, such as linking a message to its sender, a ticket booking to its user and attraction, a comment to its attraction and user, and a favorite to its attraction and user, with update and delete rules set to restrict or cascade changes to related records.
