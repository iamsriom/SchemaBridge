The rschema_0439 database is designed to manage user interactions with a recycling service. The User table stores information about individuals who can make recycling requests, including their user ID, name, phone number, WeChat ID, and password. The Merchant table holds details about businesses that accept recycling requests, with each merchant having a unique account ID and password. The Recycling_Request table represents the recycling requests made by users, containing the order ID, location, time of recycling, and the user who made the request. Each request is linked to the corresponding user through a foreign key referencing the User table. The Transaction_Order table tracks the transactions associated with each recycling request, including the accepting merchant, order status, payment amount, and payment method, with foreign keys referencing both the Merchant and Recycling_Request tables. The Order_Review table stores reviews of the recycling requests, linked to the corresponding request through a foreign key referencing the Recycling_Request table.
