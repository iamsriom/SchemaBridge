The rschema_0444 database is designed to manage student information and their interactions with courses and instructors. The Student table stores details about each student, including their age, game preference, gender, name, phone number, and a unique student ID, which serves as the primary key. The Instructor table contains information about each instructor, such as their gender, name, title, and work duration, with the instructor ID being the primary key. The Course table holds details about each course, including its name, credits, location, and the instructor ID, which references the Instructor table and is not nullable. The Attendance_Record table tracks student attendance, with columns for attendance status, check-in and class times, remarks, and foreign keys referencing the Course and Student tables, with a composite primary key consisting of student ID, course ID, and check-in time. The Leave_Record table similarly tracks student leaves, with columns for class time, leave reason, status, leave time, and foreign keys referencing the Course and Student tables, with a composite primary key consisting of student ID, course ID, and leave time.
