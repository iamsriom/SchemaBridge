The rschema_0447 database is designed to manage user information, financial documents, and system configuration, as well as track notifications and document management activities. The User table stores details about each user, including their associated unit, password, phone number, role, unique user ID, and username. The Financial_Document table contains information about financial documents, such as the attachment path, category, content, ID, level, number, title, issue date, issuing unit, remarks, and validity status. The Notification table keeps track of notifications sent to users, including the issue date, content, ID, status, title, and the user who received the notification, with a foreign key referencing the User table to establish the relationship between notifications and users. The System_Configuration table stores system-wide settings, including the admin ID, configuration ID, data type, database directory, file upload directory, and system name, with a foreign key referencing the User table to link the admin to their user account. The Document_Management table tracks document management activities, including the admin ID, document ID, operation time, and operation type, with composite primary key constraints on both admin ID and document ID to uniquely identify each activity, and foreign keys referencing the User and Financial_Document tables to link the activity to the user and document involved.
