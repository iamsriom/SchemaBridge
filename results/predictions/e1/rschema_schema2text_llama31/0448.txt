The rschema_0448 database is designed to manage various aspects of a laboratory setting, including user information, equipment, consumables, hazardous chemicals, and course participation. The User table stores information about each user, including their associated unit, password, phone number, role, username, and a unique identifier. The Experimental_Equipment table contains details about the laboratory equipment, such as its acquisition time, category, device ID, model, name, manufacturer, and status. The Experimental_Consumables table tracks consumables, including their category, ID, name, inventory quantity, and status. Hazardous_Chemicals stores information about hazardous chemicals, including their ID, name, inventory quantity, issuance time, and status. The Experimental_Course table manages course information, including the class location, time, ID, name, participants, and the ID of the teacher who teaches the course. The User_Usage_of_Equipment table records when a user uses a piece of equipment, including the device ID, usage purpose, usage time, and the user's ID. The User_Purchase_Consumables table tracks when a user purchases consumables, including the consumable ID, purchase time, and the user's ID. Similarly, the User_Purchase_Hazardous_Chemicals table records when a user purchases hazardous chemicals, including the chemical ID, purchase time, and the user's ID. The User_Participation_in_Course table tracks a user's participation in a course, including the course ID, grade, participation status, and the user's ID. Each of these tables is linked to the User table through foreign keys, which establish relationships between users and the various laboratory resources they interact with.
