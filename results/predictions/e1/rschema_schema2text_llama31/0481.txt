The rschema_0481 database is designed to store information about crops and their monitoring through sensors. The Crop table contains details about each crop, including a unique Crop ID, the crop's name, and its type. The Sensor table holds data about the sensors used for monitoring, with a unique Sensor ID, the sensor's location, its light intensity, rainfall, and temperature readings. The Sensor_Monitoring_Crop table links the crop and sensor data together, recording the time of each collection, the type of data collected, its value, and the crop and sensor IDs involved. The Crop table's Crop ID serves as the primary key, uniquely identifying each crop. The Sensor table's Sensor ID is also a primary key, ensuring each sensor is distinct. The Sensor_Monitoring_Crop table has a composite primary key consisting of the Crop ID and Sensor ID, ensuring each crop-sensor combination is unique. The Crop ID in Sensor_Monitoring_Crop references the Crop table's Crop ID, and the Sensor ID references the Sensor table's Sensor ID, establishing relationships between the tables. The Crop ID and Sensor ID in Sensor_Monitoring_Crop are not nullable, indicating that every data collection is associated with a specific crop and sensor.
