The rschema_0505 database is designed to manage user information, academic data, and research projects within an educational institution. The User table stores information about the accounts of individuals, including their account names, passwords, and roles. The Student table contains details about students, such as their average grade, major, name, and unique student ID, which serves as the primary key. The Teacher table holds information about instructors, including their age, contact details, gender, job title, name, and work history, with the Teacher ID being the primary key. The Log_Information table tracks various operations performed within the system, including the user account responsible, the type of operation, and the time it occurred, with a composite primary key consisting of the user account and operation time, and a foreign key referencing the User table to ensure data consistency. The Research_Project table stores details about research projects, such as funding, outcome, project name, and the responsible teacher, with the project ID as the primary key and a foreign key referencing the Teacher table to link the project to its responsible teacher. The Teacher_Responsible_for_Research_Project table maintains a many-to-many relationship between teachers and research projects, with a composite primary key consisting of the project ID and teacher ID, and foreign keys referencing both the Research_Project and Teacher tables to ensure data integrity.
