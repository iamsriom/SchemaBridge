The rschema_0518 database is designed to manage information about mazes, users, robots, and their interactions. The Maze table stores details about individual mazes, including their file paths and names, with each maze uniquely identified by a Maze ID. The User table holds information about the individuals who interact with the mazes, such as their contact information and names, with each user assigned a unique User ID. The Robot table contains details about the robots that navigate the mazes, including their current positions, types, and timer statuses, with each robot linked to a specific maze through its Maze ID. The Forward Sensor and Proximity Sensor tables track the status of the sensors on each robot, with the Robot ID referencing the robot they are attached to. The Timer table logs events related to the robots, such as timer events and their corresponding times, also referencing the Robot ID. The User_Robot_Operation table records the interactions between users and robots, including the type of operation and the time it occurred, with both the Robot ID and User ID serving as primary keys to establish a unique combination of user and robot.
