The schemabench_0002 database is used to store information about users, data types, menus, menu items, roles, settings, permissions, permission roles, translations, data rows, and user roles. The users table contains information about each user, including their ID, avatar, role ID, and settings. The data types table contains information about each data type, including its ID, name, slug, display name singular and plural, icon, model name, policy name, controller, description, generate permissions, server side, details, created at, and updated at. The menus table contains information about each menu, including its ID, name, created at, and updated at. The menu items table contains information about each menu item, including its ID, menu ID, title, URL, target, icon class, color, parent ID, order, created at, updated at, route, parameters, and foreign keys to the menu items and menus tables. The roles table contains information about each role, including its ID, name, display name, created at, and updated at. The settings table contains information about each setting, including its ID, key, display name, value, details, type, order, and group. The permissions table contains information about each permission, including its ID, key, table name, created at, and updated at. The permission roles table contains information about each permission role, including its permission ID and role ID, and foreign keys to the permissions and roles tables. The translations table contains information about each translation, including its ID, table name, column name, foreign key, locale, value, created at, and updated at. The data rows table contains information about each data row, including its ID, data type ID, field, type, display name, required, browse, read, edit, add, delete, details, and order, and foreign keys to the data types table. The user roles table contains information about each user role, including its user ID and role ID, and foreign keys to the roles and users tables.
