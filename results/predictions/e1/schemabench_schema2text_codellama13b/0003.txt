The schemabench_0003 database is used to store information about users, teams, and their relationships. The database contains 12 tables, each with its own set of columns and constraints.
The users table contains information about individual users, including their name, email, password, and other personal details. The table also includes columns for tracking whether the user has verified their email address and whether they use two-factor authentication.
The teams table contains information about teams, including the team owner's ID, team name, and other details. The table also includes columns for tracking the team's billing information and any subscriptions the team has.
The announcements table contains information about announcements made by users or teams. The table includes columns for the announcement's ID, user ID, body, and other details.
The api_tokens table contains information about API tokens used by users to access the system. The table includes columns for the token's ID, user ID, name, and other details.
The invitations table contains information about invitations sent to users to join teams. The table includes columns for the invitation's ID, team ID, user ID, role, and other details.
The invoices table contains information about invoices generated by the system. The table includes columns for the invoice's ID, user ID, team ID, provider ID, total, tax, and other details.
The notifications table contains information about notifications sent to users. The table includes columns for the notification's ID, user ID, icon, body, action text, action URL, and other details.
The password_resets table contains information about password reset requests made by users. The table includes columns for the email address, token, and creation date.
The performance_indicators table contains information about the system's performance, including monthly recurring revenue, yearly recurring revenue, daily volume, and new users.
The subscriptions table contains information about subscriptions made by users. The table includes columns for the subscription's ID, user ID, name, Stripe ID, Stripe plan, Stripe status, quantity, trial ends at, and other details.
The team_subscriptions table contains information about subscriptions made by teams. The table includes columns for the subscription's ID, team ID, name, Stripe ID, Stripe plan, Stripe status, quantity, trial ends at, and other details.
The team_users table contains information about the relationships between teams and users. The table includes columns for the team ID, user ID, and role.
In summary, the schemabench_0003 database is used to store information about users, teams, and their relationships, as well as other system-related information such as announcements, API tokens, invitations, invoices, notifications, password resets, performance indicators, subscriptions, and team subscriptions. The database is designed to be flexible and scalable, with a clear and consistent structure that allows for easy data retrieval and manipulation.
