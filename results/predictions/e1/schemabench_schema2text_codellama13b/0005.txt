The schemabench_0005 database is used to store information about users, subscriptions, subscription items, receipts, and tax rates. The users table contains information about each user, including their ID, Stripe ID, payment method type, payment method last four digits, payment method expiration, extra billing information, trial end date, billing address, billing address line 2, billing city, billing state, billing postal code, billing country, VAT ID, and receipt emails. The subscriptions table contains information about each subscription, including their ID, user ID, name, Stripe ID, Stripe status, Stripe price, quantity, trial end date, end date, updated at, and created at. The subscription items table contains information about each subscription item, including their ID, subscription ID, Stripe ID, Stripe product, Stripe price, quantity, updated at, and created at. The receipts table contains information about each receipt, including their ID, user ID, provider ID, amount, tax, paid at, updated at, and created at. The tax rates table contains information about each tax rate, including their ID, Stripe ID, percentage, updated at, and created at. The foreign keys in the tables reference the primary keys in the users, subscriptions, and tax rates tables, and the update and delete rules are set to CASCADE and RESTRICT, respectively.
