The schemabench_0010 database is used for a monitoring and incident management system. It contains 24 tables, each representing a different entity or relationship in the system.
The actions table stores information about user actions, including the class name, user ID, username, information, description, created at, and updated at timestamps. The cache table stores key-value pairs with an expiration timestamp. The component_groups table stores information about component groups, including the group ID, name, order, visible, collapsed, created at, and updated at timestamps. The components table stores information about components, including the component ID, name, description, link, status, order, group ID, user ID, enabled, meta, created at, updated at, and deleted at timestamps.
The failed_jobs table stores information about failed jobs, including the job ID, connection, queue, payload, and failed at timestamp. The incident_components table stores information about incident components, including the incident ID, component ID, status ID, created at, and updated at timestamps. The incident_templates table stores information about incident templates, including the template ID, name, slug, template, created at, updated at, and deleted at timestamps. The incident_updates table stores information about incident updates, including the incident ID, status, message, user ID, created at, and updated at timestamps. The incidents table stores information about incidents, including the incident ID, user ID, component ID, name, status, visible, stickied, notifications, message, occurred at, created at, updated at, and deleted at timestamps.
The invites table stores information about invites, including the invite ID, code, email, claimed at, created at, and updated at timestamps. The jobs table stores information about jobs, including the job ID, queue, payload, attempts, reserved, reserved at, available at, and created at timestamps. The meta table stores information about meta data, including the meta ID, key, value, meta ID, meta type, created at, and updated at timestamps. The metric_points table stores information about metric points, including the metric ID, value, counter, created at, and updated at timestamps. The metrics table stores information about metrics, including the metric ID, name, suffix, description, default value, calc type, display chart, places, default view, threshold, order, and visible timestamps.
The notifications table stores information about notifications, including the notification ID, type, notifiable type, notifiable ID, data, read at, created at, and updated at timestamps. The schedule_components table stores information about schedule components, including the schedule ID, component ID, component status, created at, and updated at timestamps. The schedules table stores information about schedules, including the schedule ID, name, message, status, scheduled at, completed at, created at, updated at, and deleted at timestamps. The sessions table stores information about sessions, including the session ID, user ID, IP address, user agent, payload, last activity, and created at timestamps.
The settings table stores information about settings, including the setting ID, name, value, created at, and updated at timestamps. The subscribers table stores information about subscribers, including the subscriber ID, email, verify code, phone number, slack webhook URL, verified at, global, created at, and updated at timestamps.
