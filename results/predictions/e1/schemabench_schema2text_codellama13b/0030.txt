The schemabench_0030 database is a schema used for storing information related to push notifications. It contains five tables: auth_user, push_notifications_apnsdevice, push_notifications_gcmdevice, push_notifications_webpushdevice, and push_notifications_wnsdevice.
The auth_user table contains information about users who have registered for push notifications. Each row represents a single user, and the columns include an ID, password, last login, is superuser, username, first name, last name, email, is staff, is active, and date joined. The ID column is the primary key, and the other columns are not nullable.
The push_notifications_apnsdevice, push_notifications_gcmdevice, push_notifications_webpushdevice, and push_notifications_wnsdevice tables contain information about the devices that have registered for push notifications. Each row represents a single device, and the columns include an ID, name, active, date created, device ID, registration ID, user ID, application ID, and p256dh, auth, and browser columns. The ID column is the primary key, and the other columns are not nullable. The user ID column is a foreign key that references the ID column in the auth_user table.
The push_notifications_apnsdevice table contains information about Apple Push Notification Service (APNS) devices. The push_notifications_gcmdevice table contains information about Google Cloud Messaging (GCM) devices. The push_notifications_webpushdevice table contains information about web push devices. The push_notifications_wnsdevice table contains information about Windows Notification Service (WNS) devices.
The foreign key constraints ensure that the user ID column in the push_notifications_apnsdevice, push_notifications_gcmdevice, push_notifications_webpushdevice, and push_notifications_wnsdevice tables references the ID column in the auth_user table. This ensures that each device is associated with a specific user. The update and delete rules for the foreign key constraints are set to CASCADE, which means that if a user is deleted, all of their devices will also be deleted.
In summary, the schemabench_0030 database schema is used to store information about users and their devices for push notifications. It contains five tables, each with its own set of columns, and foreign key constraints ensure that the data is consistent and accurate.
