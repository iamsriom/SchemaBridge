The schemabench_0031 database is a schema used for storing information related to an OAuth2 authorization server. It contains five tables: auth_user, oauth2_provider_accesstoken, oauth2_provider_application, oauth2_provider_grant, and oauth2_provider_refreshtoken.
The auth_user table contains information about the users of the authorization server, including their ID, password, last login, and other personal information. The table has a primary key on the ID column and allows null values for the last login column.
The oauth2_provider_accesstoken table contains information about the access tokens issued by the authorization server, including the token itself, the expiration date, the scope of the token, the application ID, the user ID, and the creation and update dates. The table has a primary key on the ID column and allows null values for the application ID and user ID columns.
The oauth2_provider_application table contains information about the applications registered with the authorization server, including their ID, client ID, redirect URIs, client type, authorization grant type, client secret, name, user ID, skip authorization, creation, and update dates. The table has a primary key on the ID column and allows null values for the user ID column.
The oauth2_provider_grant table contains information about the grants issued by the authorization server, including the code, expiration date, redirect URI, scope, application ID, user ID, creation, update, code challenge, and code challenge method. The table has a primary key on the ID column and allows null values for the application ID and user ID columns.
The oauth2_provider_refreshtoken table contains information about the refresh tokens issued by the authorization server, including the token, access token ID, application ID, user ID, creation, update, and revocation dates. The table has a primary key on the ID column and allows null values for the access token ID, application ID, and user ID columns.
The foreign keys in the schema ensure referential integrity, with the oauth2_provider_accesstoken table referencing the oauth2_provider_application table, the oauth2_provider_grant table referencing the oauth2_provider_application table, and the oauth2_provider_refreshtoken table referencing the oauth2_provider_application and oauth2_provider_accesstoken tables. The update and delete rules for the foreign keys are set to CASCADE, which means that if a referenced row is deleted or updated, the referencing row will also be deleted or updated.
