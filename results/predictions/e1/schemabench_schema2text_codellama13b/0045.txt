The schemabench_0045 database is a collection of tables that store information related to GitHub. The database contains 11 tables, each with its own unique purpose.
The app_installation_permissions table stores information about the permissions granted to users for specific GitHub apps. The table has six columns: id, app_installation_id, user_id, created_at, updated_at, and permission_statuses. The id column is the primary key, and the app_installation_id and user_id columns are foreign keys that reference the app_installations and users tables, respectively.
The app_installations table contains information about GitHub apps that have been installed on a user's account. The table has 13 columns: id, github_id, app_id, account_login, account_id, account_type, target_type, target_id, permission_pull_requests, permission_issues, created_at, updated_at, and permission_statuses. The id column is the primary key, and the github_id column is a foreign key that references the users table.
The comments table stores information about comments made on GitHub. The table has 11 columns: id, subject_id, github_id, author, author_association, body, created_at, updated_at, review_state, url, and starred. The id column is the primary key, and the subject_id column is a foreign key that references the subjects table.
The labels table contains information about labels assigned to GitHub issues. The table has 9 columns: id, name, color, subject_id, created_at, updated_at, github_id, and archived. The id column is the primary key, and the subject_id column is a foreign key that references the subjects table.
The notifications table stores information about notifications received by users on GitHub. The table has 22 columns: id, user_id, github_id, repository_id, repository_full_name, subject_title, subject_url, subject_type, reason, unread, last_read_at, url, archived, created_at, updated_at, starred, repository_owner_name, latest_comment_url, and muted_at. The id column is the primary key, and the user_id, repository_id, and repository_full_name columns are foreign keys that reference the users, repositories, and subjects tables, respectively.
The pinned_searches table stores information about searches that have been pinned by users on GitHub. The table has 6 columns: id, user_id, query, name, created_at, and updated_at. The id column is the primary key, and the user_id column is a foreign key that references the users table.
The repositories table contains information about GitHub repositories. The table has 10 columns: id, full_name, github_id, private, owner, last_synced_at, created_at, updated_at, app_installation_id, and archived. The id column is the primary key, and the app_installation_id column is a foreign key that references the app_installations table.
The subjects table stores information about GitHub issues, pull requests, and comments. The table has 16 columns: id, url, state, author, created_at, updated_at, html_url, assignees, github_id, repository_full_name, locked, sha, status, body, comment_count, and draft. The id column is the primary key.
The subscription_plans table contains information about the different subscription plans offered by GitHub. The table has 11 columns: id, github_id, name, description, monthly_price_in_cents, yearly_price_in_cents, price_model, has_free_trial, unit_name, created_at, and updated_at. The id column is the primary key.
The subscription_purchases table stores information about the purchases made by users on GitHub. The table has 12 columns: id, subscription_plan_id, account_id, billing_cycle, unit_count, on_free_trial, free_trial_ends_on, next_billing_date, created_at, updated_at, oc_transactionid, and archived. The id column is the primary key, and the subscription_plan_id column is a foreign key that references the subscription_plans table.
The users table contains information about GitHub users. The table has 17 columns: id, github_id, github_login, created_at, updated_at, last_synced_at, refresh_interval, api_token, sync_job_id, encrypted_access_token, encrypted_access_token_iv, encrypted_personal_access_token, encrypted_personal_access_token_iv, encrypted_app_token, encrypted_app_token_iv, theme, and display_comments. The id column is the primary key.
In summary, the schemabench_0045 database is a comprehensive collection of tables that store information related to GitHub, including user accounts, repositories, issues, pull requests, comments, labels, notifications, pinned searches, subscription plans, and subscription purchases. Each table has its own unique purpose and is connected to other tables through foreign keys, ensuring data integrity and consistency.
