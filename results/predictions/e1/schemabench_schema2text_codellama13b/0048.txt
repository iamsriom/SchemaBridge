The schemabench_0048 database is used to store information about accounts, invites, and users. The account table contains information about each account, including its ID, email, date created, Stripe customer ID, subscription ID, plan, referrer, and whether it is active. The invite table contains information about each invite, including its ID, invite ID, email, account ID, date sent, and whether it has been used. The user table contains information about each user, including their ID, name, email, password, date created, last login, permission, push token, and account ID. The account ID in the user table is a foreign key that references the ID in the account table. The account ID in the invite table is also a foreign key that references the ID in the account table. The foreign key relationships are set to cascade on update and restrict on delete. Additionally, there are no indexes or constraints defined in the schema.
