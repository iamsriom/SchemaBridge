The api_log table stores information about API requests, including the user ID, API key ID, images, creation date, and update date. The user ID and API key ID are foreign keys that reference the ID columns in the users and api_keys tables, respectively.
The migrations table stores information about database migrations, including the migration name and batch number.
The password_resets table stores information about password reset requests, including the email address, token, and creation date.
The users table stores information about users, including their ID, email address, token, provider, provider ID, creation date, update date, name, password, and remember token. The provider ID is a foreign key that references the ID column in the users table.
