This schema is for a web analytics database that tracks user interactions with a website. It contains 25 tables, each with a specific purpose.
The `tracker_agents` table stores information about the web browsers used by users, including the browser name, version, and creation and update timestamps.
The `tracker_connections` table tracks the connections made to the website, including the connection name and creation and update timestamps.
The `tracker_cookies` table stores information about the cookies set by the website, including the cookie UUID, creation and update timestamps.
The `tracker_devices` table tracks the devices used by users to access the website, including the device kind, model, platform, platform version, and whether the device is mobile or not.
The `tracker_domains` table stores information about the domains visited by users, including the domain name and creation and update timestamps.
The `tracker_errors` table tracks any errors that occur on the website, including the error code, message, and creation and update timestamps.
The `tracker_events` table stores information about the events that occur on the website, including the event name and creation and update timestamps.
The `tracker_events_log` table tracks the events that occur on the website, including the event ID, class ID, log ID, creation and update timestamps, and foreign keys to the `tracker_log`, `tracker_system_classes`, and `tracker_events` tables.
The `tracker_geoip` table stores information about the geolocation of users, including the latitude, longitude, country code, country code3, country name, region, city, postal code, area code, DMA code, metro code, and continent code.
The `tracker_languages` table stores information about the languages used by users, including the language preference, language range, and creation and update timestamps.
The `tracker_log` table tracks the user interactions with the website, including the log ID, session ID, path ID, query ID, method, route path ID, is AJAX, is secure, is JSON, wants JSON, error ID, creation and update timestamps, and foreign keys to the `tracker_sessions`, `tracker_errors`, `tracker_paths`, `tracker_route_paths`, and `tracker_queries` tables.
The `tracker_paths` table stores information about the paths visited by users, including the path and creation and update timestamps.
The `tracker_queries` table stores information about the queries made by users, including the query and creation and update timestamps.
The `tracker_query_arguments` table stores information about the arguments passed in queries, including the query ID, argument, value, and creation and update timestamps.
The `tracker_referers` table stores information about the websites that referred users to the website, including the domain ID, URL, host, creation and update timestamps, medium, source, search terms hash, and foreign key to the `tracker_domains` table.
The `tracker_referers_search_terms` table stores information about the search terms used by users when they visited the website, including the referer ID, search term, and creation and update timestamps.
The `tracker_route_path_parameters` table stores information about the parameters passed in routes, including the route path ID, parameter, value, and creation and update timestamps.
The `tracker_route_paths` table stores information about the routes visited by users, including the route ID, path, and creation and update timestamps.
The `tracker_routes` table stores information about the routes on the website, including the route name, action, and creation and update timestamps.
The `tracker_sessions` table tracks the user sessions on the website, including the session ID, UUID, user ID, device ID, agent ID, client IP, referer ID, cookie ID, geoip ID, is robot, creation and update timestamps, and foreign keys to the `tracker_geoip`, `tracker_devices`, `tracker_referers`, `tracker_languages`, `tracker_cookies`, and `tracker_agents` tables.
The `tracker_sql_queries` table stores information about the SQL queries made by the website, including the query ID, SHA1 hash, statement, time, connection ID, and creation and update timestamps.
The `tracker_sql_queries_log` table tracks the SQL queries made by the website, including the log ID, SQL query ID, and creation and update timestamps.
The `tracker_sql_query_bindings` table stores information about the bindings used in SQL queries, including the binding ID, SHA1 hash, serialized data, and creation and update timestamps.
The `tracker_sql_query_bindings_parameters` table stores information about the parameters used in SQL queries, including the binding ID, name, value, and creation and update timestamps.
The `tracker_system_classes` table stores information about the system classes used by the website, including the class ID, name, and creation and update timestamps.
Overall, this schema provides a comprehensive view of user interactions with a website, including information about the devices, browsers, and languages used, as well as the events and errors that occur on the website.
