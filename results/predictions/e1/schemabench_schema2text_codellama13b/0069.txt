The schemabench_0069 database is used for storing information related to OAuth 2.0 authorization and authentication. It contains four tables: oauth_access_grants, oauth_access_tokens, oauth_applications, and users.
The oauth_access_grants table stores information about OAuth 2.0 access grants, including the grant ID, resource owner ID, application ID, token, expiration date, redirect URI, creation date, revocation date, scopes, and foreign keys to the users and oauth_applications tables. The resource owner ID and application ID columns are not nullable, and the token and expiration date columns are not nullable. The scopes column is a string of space-separated values. The foreign keys to the users and oauth_applications tables are used to enforce referential integrity.
The oauth_access_tokens table stores information about OAuth 2.0 access tokens, including the token ID, resource owner ID, application ID, token, refresh token, expiration date, revocation date, creation date, scopes, previous refresh token, and foreign keys to the users and oauth_applications tables. The resource owner ID and application ID columns are nullable, and the token and expiration date columns are nullable. The scopes column is a string of space-separated values. The foreign keys to the users and oauth_applications tables are used to enforce referential integrity.
The oauth_applications table stores information about OAuth 2.0 applications, including the application ID, name, UID, secret, redirect URI, scopes, confidentiality, creation date, and update date. The UID and secret columns are not nullable, and the redirect URI and scopes columns are not nullable. The confidentiality column is a boolean value indicating whether the application is confidential or not.
The users table stores information about users, including the user ID. The user ID column is the primary key and is not nullable.
