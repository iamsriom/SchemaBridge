The schemabench_0070 database contains 22 tables, each with its own unique purpose. The users table stores information about the users of the system, including their login credentials, personal information, and location. The user_ssos table contains information about the social media accounts linked to each user. The topics table stores information about the topics created by users, including the user who created it, the node it belongs to, and the last reply made to it. The team_users table stores information about the teams that users are a part of, including their role and status. The settings table stores information about the system's settings, including the variables and their values. The sections table stores information about the sections of the system, including their name and sort order. The replies table stores information about the replies made to topics, including the user who made it and the topic it belongs to. The photos table stores information about the photos uploaded by users. The pages table stores information about the pages created by users, including their title, body, and locked status. The page_versions table stores information about the versions of the pages, including the user who made the change and the version number. The oauth_applications table stores information about the OAuth applications registered with the system, including their name, uid, and scopes. The oauth_access_tokens table stores information about the OAuth access tokens issued to users, including the resource owner, application, and token. The oauth_access_grants table stores information about the OAuth access grants issued to users, including the resource owner, application, and token. The notifications table stores information about the notifications sent to users, including the type of notification and the target. The notes table stores information about the notes created by users, including the title, body, and publish status. The nodes table stores information about the nodes in the system, including their name, summary, and section. The locations table stores information about the locations in the system, including their name and number of users. The exception_tracks table stores information about the exception tracks in the system, including the title and body. The devices table stores information about the devices used by users, including the platform and token. The comments table stores information about the comments made on the system, including the body and user who made it. The authorizations table stores information about the authorizations made by users, including the provider and uid. The actions table stores information about the actions made by users, including the type of action and the target.
