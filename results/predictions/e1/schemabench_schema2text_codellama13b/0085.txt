The schemabench_0085 database is used to store information about subscriptions, users, subscription items, receipts, and tax rates. The subscriptions table contains information about each subscription, including the user who owns the subscription, the name of the subscription, the Stripe ID, the Stripe status, the Stripe price, the quantity, the trial end date, the end date, the updated date, and the created date. The subscriptions table also has a foreign key referencing the users table, which contains information about the user who owns the subscription.
The users table contains information about each user, including the Stripe ID, the payment method type, the last four digits of the payment method, the payment method expiration, extra billing information, the trial end date, the billing address, the billing address line 2, the billing city, the billing state, the billing postal code, the billing country, the VAT ID, and the receipt emails.
The subscription_items table contains information about each subscription item, including the subscription ID, the Stripe ID, the Stripe product, the Stripe price, the quantity, the updated date, and the created date. The subscription_items table also has a foreign key referencing the subscriptions table, which contains information about the subscription that the item belongs to.
The receipts table contains information about each receipt, including the user ID, the provider ID, the amount, the tax, the paid date, the updated date, and the created date. The receipts table also has a foreign key referencing the users table, which contains information about the user who owns the receipt.
The tax_rates table contains information about each tax rate, including the Stripe ID, the percentage, the updated date, and the created date.
In summary, the schemabench_0085 database is used to store information about subscriptions, users, subscription items, receipts, and tax rates. The database is designed to ensure that the data is consistent and accurate, with foreign keys and constraints in place to enforce referential integrity and entity integrity.
