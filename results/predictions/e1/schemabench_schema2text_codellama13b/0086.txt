The schemabench_0086 database contains five tables: subscriptions, users, subscription_items, receipts, and tax_rates. The subscriptions table stores information about user subscriptions, including the user's ID, subscription name, Stripe ID, status, price, quantity, trial end date, end date, and update and creation timestamps. The users table contains information about the users, including their Stripe ID, payment method type, last four digits of their payment method, expiration date, extra billing information, trial end date, billing address, billing address line 2, billing city, billing state, billing postal code, billing country, VAT ID, and receipt emails. The subscription_items table contains information about the items in a subscription, including the subscription ID, Stripe ID, product, price, quantity, and update and creation timestamps. The receipts table contains information about the receipts, including the user ID, provider ID, amount, tax, paid date, update and creation timestamps. The tax_rates table contains information about the tax rates, including the Stripe ID, percentage, and update and creation timestamps. The subscriptions table has a foreign key relationship with the users table, and the subscription_items table has a foreign key relationship with the subscriptions table. The receipts table has a foreign key relationship with the users table. The tax_rates table has no foreign key relationships.
