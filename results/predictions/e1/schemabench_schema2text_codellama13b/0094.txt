The schemabench_0094 database is used to store information about molecules and their properties. It contains five tables: atom, bond, gmember, group, and molecule.
The atom table contains information about individual atoms, including their ID, molecule ID, type, and foreign key references to the molecule and bond tables. The bond table contains information about the bonds between atoms, including the IDs of the atoms involved, the type of bond, and foreign key references to the atom table.
The gmember table contains information about the groups that atoms belong to, including the ID of the atom and the group, and foreign key references to the atom and group tables. The group table contains information about the groups themselves, including their ID and type.
The molecule table contains information about the molecules, including their ID, activity, logP, and molecular weight.
