The schemabench_0101 database contains four tables: Data, Metadata - Countries, Metadata - Indicators, and target. The Data table contains information on the values of various indicators for different countries over the years 1960 to 2012. Each row in the table represents a specific country and indicator combination, with columns for the country name, country code, indicator name, indicator code, and the values for each year. The table has a primary key composed of the country code and indicator code, and foreign keys to the Metadata - Countries and Metadata - Indicators tables. The Metadata - Countries table contains information on the countries, including their names, codes, regions, income groups, and special notes. The Metadata - Indicators table contains information on the indicators, including their names, codes, source notes, and source organizations. The target table contains the values of the indicators for the year 2012, with a foreign key to the Metadata - Countries table.
