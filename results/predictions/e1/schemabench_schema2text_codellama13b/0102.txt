The schemabench_0102 database contains two tables: beers and breweries. The beers table has the following columns: id (primary key, integer), brewery_id (integer), abv (float), ibu (decimal), name (string), style (string), ounces (decimal). The breweries table has the following columns: id (primary key, integer), name (string), city (string), state (string). The beers table has a foreign key constraint on the brewery_id column, which references the id column in the breweries table. The breweries table has no foreign keys. The beers table has no unique or composite constraints, but the breweries table has a unique constraint on the id column. The beers table has no indexes, but the breweries table has a unique index on the id column.
