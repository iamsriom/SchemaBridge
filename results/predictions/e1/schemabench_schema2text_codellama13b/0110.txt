The schemabench_0110 database contains 12 tables, each with its own unique purpose. The first table, "awards," stores information about individual awards, including the title, effective and expiration dates, amount, instrument, organization code, program officer, abstract narration, minimum and maximum AMD letter dates, ARRA amount, and award ID. The award ID is the primary key, and the organization code is a foreign key that references the organization table. The foa_info table contains information about the funding agency, including the code and name. The foa_info_awards table links the award ID and the funding agency code, allowing for the assignment of multiple funding agencies to a single award. The institution table contains information about the institution that received the award, including the name, city, zip code, contact, address, country, state, and state code. The institution_awards table links the award ID and the institution name and zip code, allowing for the assignment of multiple institutions to a single award. The investigator table contains information about the investigator, including the email ID, first name, and last name. The investigator_awards table links the award ID and the investigator email ID, allowing for the assignment of multiple investigators to a single award. The organization table contains information about the organization, including the code and division. The program_element table contains information about the program element, including the code and text. The program_element_awards table links the award ID and the program element code, allowing for the assignment of multiple program elements to a single award. The program_reference table contains information about the program reference, including the code and text. The program_reference_awards table links the award ID and the program reference code, allowing for the assignment of multiple program references to a single award.
