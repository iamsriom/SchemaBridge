The schemabench_0123 database contains two tables: molecule and position. The molecule table has two columns: molecule_id, which is an integer and not null, and activity, which is a float and can be null. The primary key of the molecule table is molecule_id. The position table has ten columns: molecule_id, which is an integer and not null, position, which is an integer and not null, flex, h_acceptor, h_doner, pi_acceptor, pi_doner, polar, polarisable, and sigma, which are all floats and can be null. The primary key of the position table is a composite key of molecule_id and position. The position table also has a foreign key constraint on molecule_id, which references the molecule table and has an ON DELETE CASCADE ON UPDATE CASCADE rule.
