The schemabench_0125 database contains 16 tables that represent various entities and relationships in a video rental store. The tables are:
1. actor: This table contains information about the actors in the video rental store, including their first and last names, and a unique identifier for each actor.
2. address: This table contains information about the addresses of the video rental store, including the address, address2, district, city, postal code, and phone number.
3. category: This table contains information about the categories of films available in the video rental store, including the name of each category.
4. city: This table contains information about the cities in which the video rental store is located, including the city name and country.
5. country: This table contains information about the countries in which the video rental store is located, including the country name.
6. customer: This table contains information about the customers of the video rental store, including their first and last names, email address, address, and active status.
7. film: This table contains information about the films available in the video rental store, including the title, description, release year, language, original language, rental duration, rental rate, length, replacement cost, and rating.
8. film_actor: This table contains information about the actors in each film, including the film ID and actor ID.
9. film_category: This table contains information about the categories of each film, including the film ID and category ID.
10. film_text: This table contains information about the text of each film, including the title and description.
11. inventory: This table contains information about the inventory of films available in the video rental store, including the film ID, store ID, and last update date.
12. language: This table contains information about the languages in which films are available in the video rental store, including the language name.
13. payment: This table contains information about the payments made by customers, including the payment ID, customer ID, staff ID, rental ID, amount, payment date, and last update date.
14. rental: This table contains information about the rentals made by customers, including the rental ID, rental date, inventory ID, customer ID, return date, staff ID, and last update date.
15. staff: This table contains information about the staff members of the video rental store, including their first and last names, address ID, email, store ID, active status, username, and password.
16. store: This table contains information about the video rental store, including the store ID, manager staff ID, address ID, and last update date.
Each table has its own set of columns, with some tables having foreign key relationships with other tables. For example, the film_actor table has a foreign key relationship with the actor and film tables, and the rental table has a foreign key relationship with the customer, inventory, and staff tables. The database also has various constraints, such as primary keys, foreign keys, and unique constraints, to ensure data integrity and consistency.
