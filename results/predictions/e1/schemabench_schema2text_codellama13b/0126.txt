This database schema, named schemabench_0126, consists of four tables: Customers, Employees, Products, and Sales. The Customers table contains information about customers, including their first and last names, as well as a unique customer ID. The Employees table contains information about employees, including their first and last names, as well as a unique employee ID. The Products table contains information about products, including their names and prices. The Sales table contains information about sales, including the salesperson ID, customer ID, product ID, and quantity sold. Each table has a primary key, which is a unique identifier for each row in the table. The Sales table also has foreign keys that reference the Employees and Customers tables, which ensures that the salesperson and customer IDs are valid. The Sales table also has foreign keys that reference the Products table, which ensures that the product IDs are valid. The foreign keys have update and delete rules that cascade, which means that if a row in the referenced table is updated or deleted, the corresponding rows in the Sales table will be updated or deleted as well.
