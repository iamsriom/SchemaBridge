The schemabench_0129 database is used to store information about a collection of works, including their titles, descriptions, and genres. It contains four tables: works, chapters, characters, and paragraphs.
The works table contains information about each work, including its title, long title, date, and genre type. Each work has a unique ID, which is used as a primary key.
The chapters table contains information about each chapter in a work, including its act, scene, description, and work ID. Each chapter has a unique ID, which is used as a primary key. The work ID is a foreign key that references the works table.
The characters table contains information about each character in a work, including their name, abbreviation, and description. Each character has a unique ID, which is used as a primary key.
The paragraphs table contains information about each paragraph in a chapter, including its number, plain text, character ID, and chapter ID. Each paragraph has a unique ID, which is used as a primary key. The character ID and chapter ID are foreign keys that reference the characters and chapters tables, respectively.
The database enforces referential integrity by using foreign keys to ensure that the character and chapter IDs in the paragraphs table reference existing rows in the characters and chapters tables, respectively. It also enforces entity integrity by using primary keys to ensure that each row in each table has a unique ID.
