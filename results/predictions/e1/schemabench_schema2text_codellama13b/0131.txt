The schemabench_0131 database is a benchmark for a fictional retail company that sells goods to customers through a network of warehouses and distribution centers. The database contains nine tables, each representing a different entity or relationship in the system.
The C_Customer table stores information about customers, including their personal details, payment history, and order history. The table has 21 columns, including the customer ID, district ID, and warehouse ID, which together form the primary key. The table also has foreign keys to the C_District and C_Warehouse tables, which reference the district and warehouse where the customer is located.
The C_District table stores information about distribution centers, including their location, tax rate, and year-to-date sales. The table has 10 columns, including the district ID, warehouse ID, and district name, which together form the primary key. The table also has foreign keys to the C_Warehouse table, which references the warehouse where the district is located.
The C_History table stores information about customer payments and orders, including the customer ID, district ID, and warehouse ID, which together form the primary key. The table also has foreign keys to the C_Customer and C_District tables, which reference the customer and district where the payment or order was made.
The C_Item table stores information about the items sold by the retail company, including the item ID, name, price, and description. The table has 5 columns, including the item ID, which is the primary key.
The C_New_Order table stores information about new orders, including the order ID, district ID, and warehouse ID, which together form the primary key. The table also has foreign keys to the C_Order table, which references the order.
The C_Order table stores information about orders, including the order ID, district ID, warehouse ID, customer ID, entry date, carrier ID, and order line count. The table has 9 columns, including the order ID, which is the primary key. The table also has foreign keys to the C_Customer, C_District, and C_Warehouse tables, which reference the customer, district, and warehouse where the order was placed.
The C_Order_Line table stores information about order lines, including the order ID, district ID, warehouse ID, order line number, item ID, and quantity. The table has 11 columns, including the order ID, which is the primary key. The table also has foreign keys to the C_Order, C_Item, and C_Stock tables, which reference the order, item, and stock where the order line was placed.
The C_Stock table stores information about inventory, including the item ID, warehouse ID, quantity, and distribution information. The table has 14 columns, including the item ID and warehouse ID, which together form the primary key. The table also has foreign keys to the C_Item and C_Warehouse tables, which reference the item and warehouse where the stock is located.
The C_Warehouse table stores information about warehouses, including their location, name, and tax rate. The table has 8 columns, including the warehouse ID, which is the primary key.
In summary, the schemabench_0131 database is a benchmark for a retail company that stores information about customers, distribution centers, items, orders, and inventory. The database contains nine tables, each representing a different entity or relationship in the system, and has foreign key relationships between the tables to ensure data consistency and integrity.
