The schemabench_0138 database is used to store information about a university's courses, professors, and students. It contains four tables: advisedBy, course, person, and taughtBy.
The advisedBy table contains information about which professors are advising which students. It has two columns: p_id and p_id_dummy. The p_id column references the person table, and the p_id_dummy column references the person table as well. The primary key is a composite key made up of both columns. The foreign key constraints ensure that the values in these columns reference existing rows in the person table.
The course table contains information about the university's courses. It has two columns: course_id and courseLevel. The course_id column is the primary key, and the courseLevel column is a string that represents the level of the course.
The person table contains information about the university's professors and students. It has six columns: p_id, professor, student, hasPosition, inPhase, and yearsInProgram. The p_id column is the primary key, and the other columns represent various attributes of the person. The foreign key constraints ensure that the values in the professor, student, and hasPosition columns reference existing rows in the person table.
The taughtBy table contains information about which professors are teaching which courses. It has two columns: course_id and p_id. The course_id column references the course table, and the p_id column references the person table. The primary key is a composite key made up of both columns. The foreign key constraints ensure that the values in these columns reference existing rows in the course and person tables.
In summary, the schemabench_0138 database is a relational database that stores information about a university's courses, professors, and students. It has four tables that are interconnected through foreign key constraints, ensuring data consistency and integrity.
