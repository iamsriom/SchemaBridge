The schemabench_0143 database contains three tables: City, Country, and CountryLanguage. The City table has the following columns: ID (primary key, auto-incrementing integer), Name (string), CountryCode (string), District (string), Population (integer), and a foreign key referencing the Country table. The Country table has the following columns: Code (primary key, string), Name (string), Continent (string), Region (string), SurfaceArea (float), IndepYear (integer), Population (integer), LifeExpectancy (float), GNP (float), GNPOld (float), LocalName (string), GovernmentForm (string), HeadOfState (string), Capital (integer), Code2 (string), and a foreign key referencing the CountryLanguage table. The CountryLanguage table has the following columns: CountryCode (string), Language (string), IsOfficial (string), Percentage (float), and a composite primary key consisting of CountryCode and Language.
