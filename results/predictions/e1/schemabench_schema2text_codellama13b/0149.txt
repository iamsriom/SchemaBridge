The schemabench_0149 database is used for a subscription-based service that allows users to access features and services based on their subscription plan. The database contains nine tables, each representing a different entity or relationship in the system.
The subscription table contains information about each subscription, including the account ID, plan, status, start and end dates, and Stripe subscription ID. The table also has foreign keys to the account and user tables, which are used to link the subscription to the user and account that it belongs to.
The audit_log table contains information about any changes made to the system, including the user who made the change, the account affected, and the action taken. The table also has foreign keys to the account and user tables, which are used to link the audit log entry to the user and account that it affects.
The account table contains information about each account, including the email address, date created, Stripe customer ID, Stripe subscription ID, plan, referrer, and whether the account is active. The table also has foreign keys to the user and invite tables, which are used to link the account to the user who created it and any invites that have been sent to the account.
The user table contains information about each user, including the name, email address, password, date created, last login, permission, push token, and account ID. The table also has foreign keys to the account and session tables, which are used to link the user to the account they belong to and any sessions they have started.
The feature table contains information about each feature, including the name, description, and date created. The table also has a unique constraint on the name column to ensure that each feature has a unique name.
The invite table contains information about each invite, including the invite ID, email address, account ID, date sent, and whether the invite has been used. The table also has a foreign key to the account table, which is used to link the invite to the account it belongs to.
The session table contains information about each session, including the user ID, session token, date created, expiration date, and whether the session is still active. The table also has a foreign key to the user table, which is used to link the session to the user who started it.
The plan_feature table contains information about the features that are included in each plan, including the plan name and feature ID. The table also has a foreign key to the feature table, which is used to link the plan to the features it includes.
The payment table contains information about each payment, including the account ID, amount, currency, payment date, status, and Stripe payment ID. The table also has a foreign key to the account table, which is used to link the payment to the account it belongs to.
Overall, the schemabench_0149 database is designed to support the subscription-based service by storing information about subscriptions, accounts, users, features, invites, sessions, and payments. The database uses foreign keys and constraints to ensure data integrity and consistency, and it is designed to be easily scalable and flexible to support future changes and updates.
