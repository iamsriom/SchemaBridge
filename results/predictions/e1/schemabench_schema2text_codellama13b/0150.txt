This database schema, named schemabench_0150, is used to store information for a social news aggregation website. It contains 15 tables, each representing a different entity or relationship in the system.
The moderations table stores information about moderation actions taken on stories, such as banning or deleting comments. It has columns for the moderator's user ID, the story ID, the comment ID, the reason for the moderation action, the suggested action, and the date and time of the moderation.
The tags table stores information about tags that can be applied to stories. It has columns for the tag ID, the tag name, the description, and the date and time the tag was created.
The story_tags table stores information about which tags have been applied to which stories. It has columns for the story ID, the tag ID, and the date and time the tag was applied.
The saved_stories table stores information about which stories have been saved by which users. It has columns for the user ID, the story ID, and the date and time the story was saved.
The domains table stores information about the domains that are allowed to post stories. It has columns for the domain ID, the domain name, the date and time the domain was created, and a flag indicating whether the domain is banned.
The votes table stores information about which users have voted on which stories and comments. It has columns for the user ID, the story ID, the comment ID, the vote (1 for upvote, -1 for downvote), and the date and time the vote was cast.
The invitations table stores information about invitations that have been sent to users to join the website. It has columns for the invitation ID, the user ID, the email address, the date and time the invitation was sent, and the date and time the invitation was used.
The messages table stores information about messages that have been sent between users. It has columns for the message ID, the sender ID, the recipient ID, the subject, the body, the date and time the message was sent, a flag indicating whether the message has been read, and a flag indicating whether the message has been deleted by either the sender or the recipient.
The moderation_logs table stores information about moderation actions taken on stories, such as banning or deleting comments. It has columns for the moderation ID, the story ID, the user ID, the action taken, and the date and time the action was taken.
The ar_internal_metadata table stores information about the internal metadata of the database. It has columns for the key, the value, the date and time the key was created, and the date and time the key was updated.
The schema_migrations table stores information about the schema migrations that have been applied to the database. It has columns for the version.
The stories table stores information about the stories that have been posted to the website. It has columns for the story ID, the user ID, the title, the description, the URL, the date and time the story was created, the date and time the story was updated, a flag indicating whether the story has been moderated, and the score.
The hidden_stories table stores information about which stories have been hidden by which users. It has columns for the user ID, the story ID, and the date and time the story was hidden.
The users table stores information about the users who have registered on the website. It has columns for the user ID, the username, the email address, the encrypted password, the password digest, the date and time the user was created, the date and time the user was updated, the settings, a flag indicating whether the user is banned, and a flag indicating whether the user is an admin.
The comments table stores information about the comments that have been posted on stories. It has columns for the comment ID, the story ID, the user ID, the body, the date and time the comment was created, the date and time the comment was updated, and a flag indicating whether the comment has been deleted.
