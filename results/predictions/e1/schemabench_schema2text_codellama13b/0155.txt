The schemabench_0155 database is a comprehensive schema that stores information about a fictional crime scene investigation. It includes 19 tables, each representing a different entity or aspect of the investigation.
The Residents table contains information about the people who live in the house where the crime occurred. Each resident has a unique ID, first name, last name, gender, birth date, role, and bracelet ID. The bracelet ID is a unique identifier for each resident's bracelet, which is used to track their movements and activities.
The Employee table contains information about the employees who work at the house where the crime occurred. Each employee has a unique ID, first name, last name, gender, birth date, hire date, function, and bracelet ID.
The Robots table contains information about the robots that are used in the house. Each robot has a unique ID, name, company, function, hire date, price, and bracelet ID.
The House table contains information about the house where the crime occurred. Each house has a unique ID, room name, CCTV ID, crime scene, and bracelet ID. The CCTV ID is a unique identifier for each CCTV camera in the house.
The Location table contains information about the location of each resident, employee, and robot at a specific time. Each location has a unique ID, house ID, time, and bracelet ID.
The Bracelet table contains information about each bracelet used in the investigation. Each bracelet has a unique ID and bracelet name.
The Cctv table contains information about each CCTV camera in the house. Each CCTV camera has a unique ID, CCTV room, date, switch on, switch off, breakdown, and modification.
The Modification_type table contains information about the type of modification made to each CCTV camera. Each modification type has a unique ID, CCTV ID, and description.
The Evidence_One, Evidence_Two, and Evidence_Three tables contain information about the evidence found at the crime scene. Each evidence has a unique ID and description.
The Ransack_One, Ransack_Two, and Ransack_Three tables contain information about the ransacking of the house. Each ransack has a unique ID and description.
The Crime_scene table contains information about the crime scene. Each crime scene has a unique ID, victim, date, house ID, evidence one ID, evidence two ID, evidence three ID, ransack one ID, ransack two ID, and ransack three ID.
The Suspect_Analyse_Post_Crime table contains information about the analysis of each suspect after the crime. Each analysis has a unique ID, bracelet ID, and analyse.
The Innocent table contains information about the innocent people who were present at the crime scene. Each innocent person has a unique ID, bracelet ID, and statut.
The Real_Suspect table contains information about the real suspect who committed the crime. Each real suspect has a unique ID and bracelet ID.
The Culprit table contains information about the culprit who was caught and arrested. Each culprit has a unique ID, bracelet ID, and statut.
In summary, the schemabench_0155 database is a comprehensive schema that stores information about a fictional crime scene investigation. It includes 19 tables, each representing a different entity or aspect of the investigation, and is designed to support the analysis and investigation of the crime.
