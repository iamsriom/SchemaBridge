The schemabench_0158 database is used to store information about installations, labor codes, billing codes, tickets, reports, and shell components. The installations table contains information about the different installations, including their names. The labor codes table contains information about the different labor codes, including their names. The billing codes table contains information about the different billing codes, including their names. The tickets table contains information about the different tickets, including their numbers, descriptions, labor codes, creation dates, installations, and whether they are closed. The reports table contains information about the different reports, including their dates, billing codes, ticket IDs, arrival times, exit times, activities, and shell components. The shell table contains information about the different shell components, including their titles, icons, menu items, and themes. The installations, labor codes, billing codes, tickets, and reports tables have primary keys, while the shell table does not. The installations, labor codes, and billing codes tables have foreign keys that reference the installations, labor codes, and billing codes tables, respectively. The tickets and reports tables have foreign keys that reference the installations and tickets tables, respectively. The tickets table has a composite primary key consisting of the ticket ID and the installation ID. The reports table has a composite primary key consisting of the report ID and the ticket ID. The tickets and reports tables have unique constraints on the ticket number and the report ID, respectively. The tickets table has a default value of FALSE for the isclosed column. The reports table has a default value of 'B05' for the billing code column. The tickets and reports tables have foreign key constraints that cascade on update and restrict on delete.
