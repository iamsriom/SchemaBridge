The schemabench_0159 database contains nine tables that represent various entities and relationships in a film rental store. The tables are:
1. actor: This table contains information about the actors who have appeared in films. Each actor has an actor ID, first name, last name, address ID, and a timestamp for the last update.
2. address: This table contains information about the addresses of the actors and the rental store. Each address has an address ID, address, address2, district, city ID, postal code, phone number, and a timestamp for the last update.
3. category: This table contains information about the categories of films. Each category has a category ID, name, and a timestamp for the last update.
4. city: This table contains information about the cities where the rental store is located. Each city has a city ID, city name, country ID, and a timestamp for the last update.
5. country: This table contains information about the countries where the rental store is located. Each country has a country ID, country name, and a timestamp for the last update.
6. film: This table contains information about the films that are available for rent. Each film has a film ID, title, description, release year, language ID, original language ID, rental duration, rental rate, length, replacement cost, rating, special features, and a timestamp for the last update.
7. film_actor: This table contains information about the actors who have appeared in each film. Each film-actor combination has an actor ID, film ID, and a timestamp for the last update.
8. film_category: This table contains information about the categories of films. Each film-category combination has a film ID, category ID, and a timestamp for the last update.
9. language: This table contains information about the languages in which films are available. Each language has a language ID, name, and a timestamp for the last update.
The tables are related to each other through foreign keys, which ensure that the data is consistent and accurate. For example, the film table has a foreign key to the language table, which ensures that the language of the film is valid. The film_actor table has foreign keys to the actor and film tables, which ensures that the actors who have appeared in each film are valid. The film_category table has foreign keys to the film and category tables, which ensures that the categories of each film are valid.
Overall, the schemabench_0159 database provides a comprehensive and accurate representation of the data in a film rental store, with clear relationships between the different tables and a consistent structure.
