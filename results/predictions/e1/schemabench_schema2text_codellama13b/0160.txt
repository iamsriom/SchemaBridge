This schema is for a database that stores information about a stock exchange, including companies, brokers, traders, and transactions. The database is called schemabench_0160 and it has eight tables.
The first table, company_info, stores information about the companies that are traded on the exchange. It has the following columns: company_id (primary key), company_name, streetNo, city, c_state, zipcode, and established_date.
The second table, exchange, stores information about the exchange itself. It has the following columns: exchange_id (primary key), exchange_name.
The third table, broker_info, stores information about the brokers who work on the exchange. It has the following columns: broker_id (primary key), broker_fname, broker_lname, broker_contact, broker_streetno, broker_streetname, broker_city, broker_state, and broker_zip.
The fourth table, trader_info, stores information about the traders who participate in the exchange. It has the following columns: trader_id (primary key), trader_fname, trader_lname, account_no, trader_contact, trader_streetno, trader_streetname, trader_city, trader_state, and trader_zip.
The fifth table, Account_info, stores information about the accounts that traders use to buy and sell stocks. It has the following columns: account_id (primary key), cash, security, trader_id (foreign key), broker_id (foreign key).
The sixth table, broker_exchange_deals, stores information about the deals that brokers make on behalf of traders. It has the following columns: id (primary key), fees_given, broker_id (foreign key), exchange_id (foreign key).
The seventh table, stock_info, stores information about the stocks that are traded on the exchange. It has the following columns: stock_id (primary key), stock_name, shares_no, stock_symbol, stock_launchDate, s_price, company_id (foreign key), trade_exchange_id (foreign key).
The eighth and final table, transaction_info, stores information about the transactions that take place on the exchange. It has the following columns: order_id (primary key), T_Price, No_Of_Shares, brokeragepaidby_seller, brokeragepaidby_buyer, id (foreign key), stock_id (foreign key), broker_id (foreign key), exchange_id (foreign key), trader_id (foreign key), account_id (foreign key).
In summary, this schema is a comprehensive database that stores information about a stock exchange, including companies, brokers, traders, and transactions. It has eight tables, each with its own set of columns, and each table has its own unique purpose in storing and organizing the data.
