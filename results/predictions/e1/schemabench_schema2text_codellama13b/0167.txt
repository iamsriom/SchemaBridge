The schemabench_0167 database is a simple hotel reservation system that contains three tables: reservations, customers, and room. The reservations table stores information about individual reservations, including the customer who made the reservation, the dates of their stay, and the room number they reserved. The customer table contains information about each customer, including their name, email, and phone number. The room table contains information about each room in the hotel, including the number of beds, maximum occupants, whether it is a smoking or pet-friendly room, and the nightly cost.
The reservations table has a primary key on the reservation_id column, which is an auto-incrementing integer. The customer_id column references the customer table, and the room_number column references the room table. The reservation_date column is a datetime column that cannot be null, and the check_in_date and check_out_date columns are also datetime columns that can be null.
The customers table has a primary key on the customer_id column, which is an auto-incrementing integer. The first_name, last_name, email, and phone columns are all varchar columns that cannot be null.
The room table has a primary key on the room_number column, which is an auto-incrementing integer. The beds, max_occupants, smoking_room, and pet_room columns are all integer columns that cannot be null. The nightly_cost column is a float column that cannot be null.
In summary, the schemabench_0167 database is a simple hotel reservation system that stores information about reservations, customers, and rooms. The reservations table has a primary key on the reservation_id column, and foreign keys to the customer and room tables. The customers table has a primary key on the customer_id column, and the room table has a primary key on the room_number column.
