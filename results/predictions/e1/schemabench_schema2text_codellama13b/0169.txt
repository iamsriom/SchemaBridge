The schemabench_0169 database is a comprehensive schema for a bookstore management system. It consists of 18 tables, each representing a different entity or relationship in the system.
The Region table contains postal codes and their corresponding states and countries, which are used to identify the location of a particular address.
The Address table contains information about the physical address of a publisher, warehouse, or client. It includes the address ID, building number, street, city, postal code, and foreign key references to the Region table.
The Publisher table contains information about the publishers of books in the system. It includes the publisher ID, name, email, phone number, and address ID, as well as foreign key references to the Address table.
The Book table contains information about the books in the system. It includes the ISBN, title, author name, genre, publisher ID, number of pages, cost, price, publisher percentage, stock, and threshold. It also includes foreign key references to the Publisher table.
The Staff table contains information about the staff members in the system. It includes the staff ID and email.
The Warehouse table contains information about the warehouses in the system. It includes the warehouse ID and address ID, as well as foreign key references to the Address table.
The Client table contains information about the clients in the system. It includes the client ID, name, email, phone number, and address ID, as well as foreign key references to the Address table.
The BankAccount table contains information about the bank accounts in the system. It includes the account number and amount.
The Sales table contains information about the sales of books in the system. It includes the ISBN, month, year, quantity, and foreign key references to the Book table.
The Orders table contains information about the orders placed by clients in the system. It includes the order number, order placement date, status, final total, address ID, and warehouse ID, as well as foreign key references to the Address and Warehouse tables.
The manage table contains information about the books managed by staff members in the system. It includes the ISBN, staff ID, and foreign key references to the Book and Staff tables.
The update_sales table contains information about the sales of books in the system, including the order number, ISBN, month, year, and quantity, as well as foreign key references to the Orders and Sales tables.
The handle_account table contains information about the bank accounts associated with orders in the system. It includes the order number and account number, as well as foreign key references to the Orders and BankAccount tables.
The client_account table contains information about the bank accounts associated with clients in the system. It includes the client ID and account number, as well as foreign key references to the Client and BankAccount tables.
The publisher_account table contains information about the bank accounts associated with publishers in the system. It includes the publisher ID and account number, as well as foreign key references to the Publisher and BankAccount tables.
The tracks table contains information about the tracking of orders in the system. It includes the order number and client ID, as well as foreign key references to the Orders and Client tables.
The emails table contains information about the emails sent to staff members and publishers in the system. It includes the staff ID and publisher ID, as well as foreign key references to the Staff and Publisher tables.
The checkout table contains information about the books checked out by clients in the system. It includes the ISBN, order number, and quantity, as well as foreign key references to the Book and Orders tables.
Overall, the schemabench_0169 database schema provides a comprehensive framework for managing a bookstore management system, including information about publishers, books, clients, orders, and sales. It also includes information about the physical locations of publishers, warehouses, and clients, as well as the bank accounts associated with these entities.
