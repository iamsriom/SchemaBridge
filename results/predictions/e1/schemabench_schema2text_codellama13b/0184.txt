The schemabench_0184 database is a comprehensive schema that contains nine tables, each representing a distinct entity or relationship in the system. The User table contains information about the users of the system, including their phone number, password, email, first name, middle name, last name, date of birth, and address. The Food table contains information about the food items available for purchase, including their name, price, availability, rating, quantity, and description. The Restaurant table contains information about the restaurants that sell the food items, including their name, founding date, address, rating, and description. The CustomerService table contains information about the customer service inquiries, including the email address of the customer, the name of the customer, the inquiry, the status, and the submission date. The OrderHistory table contains information about the orders placed by the users, including the order ID, the user ID, the total price, the order date, and the foreign key referencing the User table. The Products table contains information about the products purchased by the users, including the product ID, the user ID, the order ID, the product, and the foreign keys referencing the User and OrderHistory tables. The Interacts table contains information about the interactions between the users and the customer service, including the interaction ID, the customer service ID, the user ID, and the foreign keys referencing the CustomerService and User tables. The Buys table contains information about the food items purchased by the users, including the buy ID, the user ID, the food ID, and the foreign keys referencing the User and Food tables. The Sells table contains information about the food items sold by the restaurants, including the sell ID, the restaurant ID, the food ID, and the foreign keys referencing the Restaurant and Food tables.
