This schema is for a retail store that sells books, and it includes the following tables:
* Author: This table contains information about the authors of the books sold in the store. Each author has a unique name, a picture, and a summary of their work.
* Book: This table contains information about the books sold in the store. Each book has a unique product ID, a name, a description, a price, a publisher price, a sold count, an ISBN, a series, a format, and a page count.
* Coupon: This table contains information about coupons that can be used to discount the price of books. Each coupon has a unique code, a boolean indicating whether it is a percentage or a fixed amount, a savings, a valid from date, and a valid to date.
* Storeuser: This table contains information about the users of the store. Each user has a unique username, a first name, a last name, an email, an address, a picture, a time created, and a time last login.
* Product: This table contains information about the products sold in the store, including books and other items. Each product has a unique product ID, a name, a description, a price, a publisher price, and a sold count.
* Publisher: This table contains information about the publishers of the books sold in the store. Each publisher has a unique name, an address, an email, a phone number, an institution number, a branch number, and an account number.
* Role: This table contains information about the roles that users can have in the store. Each role has a unique ID, a name, and a description.
* Warehouse: This table contains information about the warehouses where the products are stored. Each warehouse has a unique name, an address, a phone number, and an area in square feet.
* Storeorder: This table contains information about the orders placed by customers in the store. Each order has a unique order number, a username, a status, a billed to address, a shipped to address, a time placed, a delivery fee, and a primary key consisting of the order number and the username.
* Cart: This table contains information about the items in a customer's shopping cart. Each cart has a unique username, a last edited timestamp, and a primary key consisting of the username.
* Book_genre: This table contains information about the genres of the books sold in the store. Each book genre has a unique product ID and a genre.
* Product_image: This table contains information about the images associated with the products sold in the store. Each product image has a unique product ID and an image.
* Product_tag: This table contains information about the tags associated with the products sold in the store. Each product tag has a unique product ID and a tag.
* Cart_coupon: This table contains information about the coupons associated with a customer's shopping cart. Each cart coupon has a unique username and a coupon code.
* Cart_product: This table contains information about the products in a customer's shopping cart. Each cart product has a unique username, a product ID, and a quantity.
* Order_coupon: This table contains information about the coupons associated with an order. Each order coupon has a unique order number and a coupon code.
* Order_product: This table contains information about the products in an order. Each order product has a unique order number, a product ID, a quantity, and a price.
* Publishes: This table contains information about the books published by the publishers in the store. Each publishes has a unique product ID, a publisher name, a year published, a reorder threshold, and a commission percent.
* Stored_in: This table contains information about the warehouses where the products are stored. Each stored in has a unique product ID, a warehouse name, a stock, an aisle, and a primary key consisting of the product ID and the warehouse name.
* User_role: This table contains information about the roles that users have in the store. Each user role has a unique username, a role ID, and a primary key consisting of the username and the role ID.
* Writes: This table contains information about the authors of the books sold in the store. Each write has a unique product ID and an author name.
The schema also includes foreign keys to enforce referential integrity, such as the foreign key from the cart table to the storeuser table, which ensures that the cart belongs to a specific user. The schema also includes primary keys and unique constraints to ensure that each table has a unique identifier, and to enforce entity integrity.
