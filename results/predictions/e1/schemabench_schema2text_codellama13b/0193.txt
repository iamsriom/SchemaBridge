The schemabench_0193 database is a collection of tables that store information about books, authors, themes, qualities, cities, customers, prices, orders, ratings, and viewings. The tables are interconnected through foreign keys, which ensure that the data is consistent and accurate.
The titles table contains information about each book, including its ISBN number and title. The authors table lists the authors of each book, along with their rank and the ISBN number of the book they wrote. The themes table lists the themes associated with each book, along with their rank and the ISBN number of the book they are associated with. The qualities table lists the qualities of each book, along with their rank and the ISBN number of the book they are associated with.
The cities table contains information about cities, including their ID, name, and country. The customers table contains information about customers, including their ID, first name, surname, date of birth, sex, date joined, email, password, and city ID. The prices table contains information about the prices of each book, along with its ISBN number and price. The orders table contains information about orders, including the order ID, ISBN number, customer ID, quantity, purchase date, cost, and primary key. The ratings table contains information about customer ratings for each book, along with the ISBN number, customer ID, rating date, and rating. The viewings table contains information about customer viewings of each book, along with the ISBN number, customer ID, viewing date, and view time.

Similarly, the foreign key in the themes table references the titles table, ensuring that the ISBN number in the themes table is a valid ISBN number. The foreign key in the orders table references the titles table and the customers table, ensuring that the ISBN number and customer ID in the orders table are valid.
