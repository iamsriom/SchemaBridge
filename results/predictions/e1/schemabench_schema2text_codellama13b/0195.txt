The schemabench_0195 database is a collection of six tables that store information about pizza delivery orders, customers, runners, and pizza recipes. The tables are designed to ensure data integrity and consistency across the schema.

The customer_orders table stores information about the orders placed by customers, including the order ID, customer ID, pizza ID, exclusions, extras, and order time. The runner_orders table contains information about the orders assigned to runners, including the order ID, runner ID, pickup time, distance, duration, and cancellation status.
The pizza_recipes table stores information about the different pizza recipes available, including the pizza ID and toppings. The pizza_names table contains information about the names of the pizzas, including the pizza ID and pizza name. The pizza_toppings table stores information about the different toppings available, including the topping ID and topping name.
To ensure data integrity, the schema includes primary keys and foreign keys to enforce entity and referential integrity. The primary keys are used to uniquely identify each record in a table, while the foreign keys are used to establish relationships between tables. For example, the customer_orders table has a foreign key that references the runners table, ensuring that the runner ID in the customer_orders table is valid.
In addition to primary and foreign keys, the schema includes composite and unique constraints to enforce data consistency. For example, the customer_orders table has a composite key that combines the order ID and customer ID to ensure that each order is unique. The pizza_recipes table has a unique constraint on the pizza ID to ensure that each pizza recipe is unique.
Overall, the schemabench_0195 database schema is designed to provide a comprehensive and consistent way to store and manage information about pizza delivery orders, customers, runners, and pizza recipes.
