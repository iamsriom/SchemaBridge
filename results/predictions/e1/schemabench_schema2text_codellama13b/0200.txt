The schemabench_0200 database is used to store information about interests and their metrics. It contains two tables: interest_map and interest_metrics.
The interest_map table has five columns: id, interest_name, interest_summary, created_at, and last_modified. The id column is the primary key and is an integer that uniquely identifies each interest. The interest_name and interest_summary columns are both strings that contain the name and summary of the interest, respectively. The created_at and last_modified columns are timestamps that record when the interest was created and last modified.
The interest_metrics table has nine columns: _month, _year, month_year, interest_id, composition, index_value, ranking, percentile_ranking. The _month and _year columns are strings that represent the month and year of the metric, respectively. The month_year column is a string that combines the _month and _year columns. The interest_id column is a string that references the id column in the interest_map table. The composition, index_value, ranking, and percentile_ranking columns are all floats that contain the metric values.
The interest_metrics table has a composite primary key consisting of the _month, _year, and interest_id columns. The interest_id column is a foreign key that references the id column in the interest_map table. The update and delete rules for the interest_metrics table are set to CASCADE, which means that if an interest is deleted, all of its metrics will also be deleted.

The interest_map table has five columns that store information about interests, while the interest_metrics table has nine columns that store information about metrics. The interest_metrics table has a composite primary key and a foreign key that references the interest_map table.
