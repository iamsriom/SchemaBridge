This schema is for a restaurant management system. It consists of seven tables: Customers, Staff, Bookings, Orders, Orders_Delivery_Status, Menu, and Orders_Details.
The Customers table stores information about the customers who make bookings at the restaurant. It has three columns: Customer_ID (primary key), Full_Name, and Phone_Number.
The Staff table stores information about the staff members who work at the restaurant. It has seven columns: Staff_ID (primary key), Name, Role, Salary, Address, Contact_Number, and Email.
The Bookings table stores information about the bookings made by customers at the restaurant. It has six columns: Booking_ID (primary key), Booking_Date, Customer_ID (foreign key referencing Customers), Table_number, Number_of_Persons, and Staff_ID (foreign key referencing Staff).
The Orders table stores information about the orders placed by customers at the restaurant. It has five columns: Order_ID (primary key), Table_number, Order_Date, Total_Cost, and Booking_ID (foreign key referencing Bookings).
The Orders_Delivery_Status table stores information about the delivery status of orders. It has three columns: Order_ID (primary key), Delivery_Date, and Delivery_Status.
The Menu table stores information about the menu items available at the restaurant. It has five columns: Item_ID (primary key), Name, Category, Cuisine, and Price.
The Orders_Details table stores information about the items ordered by customers. It has three columns: OrderID (foreign key referencing Orders), Item_ID (foreign key referencing Menu), and Quantity.
The schema enforces entity integrity by using primary keys and foreign keys to ensure that each table has a unique identifier and that the relationships between tables are consistent. It also enforces domain integrity by specifying the data types of each column and whether they allow null values. Finally, it enforces referential integrity by using foreign keys to ensure that the relationships between tables are consistent and that the data in each table is valid.
