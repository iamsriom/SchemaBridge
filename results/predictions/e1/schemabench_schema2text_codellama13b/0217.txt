The schemabench_0217 database is a comprehensive library management system that includes various tables to manage books, authors, categories, and stores. The database is designed to store information about books, authors, categories, and stores, as well as user information, applications, and reviews.
The admin table contains information about the database administrator, including their username and password.
The school table contains information about the schools that are associated with the library, including their name, email, principal's first and last name, city, address, and phone number.
The user table contains information about the users of the library, including their username, password, first and last name, birth date, status, active borrowings, role, school name, and active reservations.
The book table contains information about the books in the library, including their ISBN, title, summary, publisher, page number, language, and image.
The category table contains information about the categories of books in the library, including their category name.
The book_category table contains information about the relationship between books and categories, including the category ID and the ISBN of the book.
The author table contains information about the authors of the books in the library, including their author name.
The book_author table contains information about the relationship between books and authors, including the author ID and the ISBN of the book.
The key_words table contains information about the keywords associated with the books in the library, including the word and the ISBN of the book.
The stores table contains information about the stores in the library, including the school ID, ISBN, available copies, and the relationship between the school and the book.
The applications table contains information about the applications made by users to borrow books, including the application ID, user ID, ISBN, start date, expiration date, status, and the relationship between the user and the book.
The review table contains information about the reviews left by users about the books in the library, including the ISBN, user ID, evaluation, like scale, approval status, review date, and the relationship between the user and the book.
The database is designed to ensure data integrity through the use of primary keys, foreign keys, and unique constraints. The primary keys ensure that each table has a unique identifier, while the foreign keys establish relationships between tables. The unique constraints ensure that each book, author, and category has a unique name. The data types of the columns are also carefully chosen to ensure that the data is accurate and consistent.
