This database schema, named schemabench_0222, is used to store information about an art gallery. It contains 17 tables, each representing a different entity or relationship in the system.
The first table, ArtistInfoT, stores information about the artists who create the artwork on display at the gallery. It has columns for the artist's ID, name, date of birth, address, email, and phone number. The artist ID is the primary key and is set to auto-increment.
The second table, EventT, stores information about the events that take place at the gallery. It has columns for the event's ID, name, description, start and end dates, and start and end times. The event ID is the primary key and is set to auto-increment.
The third table, EmployeeInfoT, stores information about the employees who work at the gallery. It has columns for the employee's ID, name, date of birth, address, email, phone number, start date, end date, salary, and title. The employee ID is the primary key and is set to auto-increment.
The fourth table, CustomerInfoT, stores information about the customers who purchase artwork from the gallery. It has columns for the customer's ID, name, date of birth, phone number, email, address, and zip code. The customer ID is the primary key and is set to auto-increment.
The fifth table, ProductInfoT, stores information about the artwork that is on display at the gallery. It has columns for the product's ID and name. The product ID is the primary key and is set to auto-increment.
The sixth table, CustomerInterestT, stores information about the artwork that each customer is interested in. It has columns for the customer's ID and the product's ID. The customer ID and product ID are both foreign keys that reference the corresponding tables.
The seventh table, InventoryArtT, stores information about the artwork that is currently on display at the gallery. It has columns for the item's ID, name, artist ID, creation date, move-in date, move-out date, and display location. The item ID is the primary key and is set to auto-increment.
The eighth table, PartnerOrgT, stores information about the partner organizations that the gallery works with. It has columns for the partner organization's ID, name, address, email, phone number, start date, end date, and type. The partner organization ID is the primary key and is set to auto-increment.
The ninth table, DisplayArtT, stores information about the artwork that is currently on display at the gallery. It has columns for the item's ID and display location. The item ID is a foreign key that references the InventoryArtT table.
The tenth table, LedgerT, stores information about the transactions that take place at the gallery. It has columns for the transaction's ID, amount, and timestamp. The transaction ID is the primary key and is set to auto-increment.
The eleventh table, CreditT, stores information about the credits that are given to customers at the gallery. It has columns for the transaction's ID, credit amount, and timestamp. The transaction ID is a foreign key that references the LedgerT table.
The twelfth table, DebitT, stores information about the debits that are taken from customers at the gallery. It has columns for the transaction's ID, debit amount, and timestamp. The transaction ID is a foreign key that references the LedgerT table.
The thirteenth table, CollabT, stores information about the collaborations that take place between the gallery and other organizations. It has columns for the collaboration's ID, name, description, start date, and end date. The collaboration ID is the primary key and is set to auto-increment.
The fourteenth table, ArtistContractT, stores information about the contracts that are signed between the gallery and the artists. It has columns for the contract's ID, artist ID, sign date, start date, end date, and commission percentage. The contract ID is the primary key and is set to auto-increment.
The fifteenth table, SalesT, stores information about the sales that take place at the gallery. It has columns for the sale's ID, transaction ID, item ID, customer ID, salesman ID, sales amount, artist ID, and sale date. The sale ID is the primary key and is set to auto-increment.
The sixteenth table, artistcontract_auditT, stores information about the changes made to the artist contracts. It has columns for the ID, action, change timestamp, contract ID, artist ID, sign date, start date, end date, commission percentage, and current commission.
The seventeenth table, partnerOrg_auditT, stores information about the changes made to the partner organizations. It has columns for the ID, action, partner organization ID, name, address, email, phone number, start date, end date, and type.
Overall, this schema is designed to store and manage information about an art gallery, including the artists, events, employees, customers, artwork, transactions, and collaborations. It is well-structured and organized, with clear relationships between the tables and consistent naming conventions.
