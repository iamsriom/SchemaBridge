The schemabench_0225 database is a comprehensive system for managing a training center. It includes tables for employees, clients, courses, and course materials. The trainer table contains information about the trainers, including their contact information, employment history, and qualifications. The client table contains information about the clients, including their contact information and initial enrollment date. The course table contains information about the courses, including the course length, fee, level, and course materials. The course_book table contains information about the course materials, including the book title, publisher, and list price. The author table contains information about the authors of the course materials. The course_prerequisites table contains information about the prerequisites for each course. The course_software table contains information about the software required for each course. The class table contains information about the classes, including the start and end dates, trainer, classroom, and course. The enrollment_request table contains information about the enrollment requests, including the request date, status, payment, and client. The vendor table contains information about the vendors, including their contact information. The order table contains information about the orders, including the order date, order status, and vendor. The shipment table contains information about the shipments, including the shipment date, vendor, and course materials. The order_line table contains information about the order line items, including the course book ISBN, quantity ordered, and price charged. The shipment_line table contains information about the shipment line items, including the course book ISBN and quantity received. The course_book_vendor table contains information about the course materials and their vendors.
