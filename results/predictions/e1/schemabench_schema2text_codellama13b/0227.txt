The schemabench_0227 database is a comprehensive schema for a flight reservation system. It contains 21 tables that represent various aspects of the system, including airlines, airports, flights, crew members, and passengers.
The Airline table contains information about each airline, including its name, headquarters location, and logo. The AirportAbbreviation table contains a list of airport abbreviations used throughout the system. The Airport table contains information about each airport, including its abbreviation, name, location, radio operator, and any airlines that operate out of the airport.
The AirportAirline table contains information about the airlines that operate at each airport, including the airport's abbreviation, the airline's name, and the location of the airport. The Amenity table contains information about the amenities offered on flights, including the amenity code and name. The FlightCrew table contains information about the crew members on each flight, including their ID and size.
The FlightSchedule table contains information about each flight, including the flight number, airline, departure and arrival times, crew ID, origin and destination airports, and any amenities offered on the flight. The Model table contains information about the aircraft models used by the airline, including the model name, manufacturer, and number of passengers.
The Airplane table contains information about each aircraft, including its tail number, airline, model, manufacturer, nickname, and any amenities offered on the flight. The Role table contains information about the roles of the crew members, including the name of the role. The CrewMember table contains information about each crew member, including their FAA number, name, last name, sex, and role.
The FlightCrew_CrewMember table contains information about the crew members on each flight, including their crew ID, FAA number, and present role. The Status table contains information about the status of each flight, including the name of the status. The FlightInstance table contains information about each flight instance, including the flight instance ID, flight number, tail number, status, departure date, departure time, arrival time, number of registered passengers, and any amenities offered on the flight.
The ChargableInstance table contains information about the charges associated with each flight instance, including the flight instance ID. The AmenityChargableInstance table contains information about the amenities offered on each flight instance, including the amenity code and flight instance ID. The DomesticInstance table contains information about domestic flights, including the flight instance ID.
The InternationalInstance table contains information about international flights, including the flight instance ID. The LocalInstance table contains information about local flights, including the flight instance ID. The IncidentReport table contains information about incidents that occurred during flights, including the incident ID, flight instance ID, reporter FAA number, reported FAA number, incident type, report time, and description.
The PersonnelReport table contains information about the sentiments of crew members about incidents that occurred during flights, including the incident ID, sentiment, and reported FAA number.
Overall, the schemabench_0227 database provides a comprehensive schema for a flight reservation system, allowing for the management of airlines, airports, flights, crew members, and passengers.
