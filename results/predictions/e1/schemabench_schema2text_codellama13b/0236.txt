The schemabench_0236 database is a schema used for a retail store, with five tables: categories, products, customers, orders, and reviews. The categories table contains a list of product categories, with each row representing a single category and containing two columns: an ID column and a name column. The products table contains a list of products, with each row representing a single product and containing six columns: an ID column, a name column, a description column, a price column, a category ID column, and a foreign key referencing the categories table. The customers table contains a list of customers, with each row representing a single customer and containing five columns: an ID column, a name column, an address column, an email column, and a phone column. The orders table contains a list of orders, with each row representing a single order and containing six columns: an ID column, a date column, a customer ID column, an amount column, a status column, a product ID column, and two foreign keys referencing the customers and products tables. The reviews table contains a list of reviews, with each row representing a single review and containing six columns: an ID column, a customer ID column, a product ID column, a rating column, a content column, and a date column, and two foreign keys referencing the customers and products tables.
