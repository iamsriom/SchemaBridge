The database schema named 'schemabench_0034' consists of 10 tables. The primary key is used as the unique identifier for each record in the database.
The 'auth_group' table represents a set of permissions, with each permission represented by a unique name. It has an 'id' and 'name' column.
The 'auth_user' table represents a user in the system, with columns for 'password', 'last_login', 'is_superuser', 'username', 'first_name', 'last_name', 'email', 'is_staff', 'is_active', and 'date_joined'.
The 'django_content_type' table is used to store the type of content that each table in the database represents. It has 'id', 'app_label', and 'model' columns.
The 'filer_clipboard' and 'filer_clipboarditem' tables represent clipboards and items in clipboards respectively. The 'filer_clipboard' table has a 'user_id' foreign key referencing the 'auth_user' table, while the 'filer_clipboarditem' table has 'clipboard_id' and 'file_id' foreign keys referencing the 'filer_clipboard' and 'filer_file' tables respectively.
The 'filer_file' table represents files in the system. It has columns for 'file', '_file_size', 'sha1', 'has_all_mandatory_data', 'original_filename', 'name', 'description', 'uploaded_at', 'modified_at', 'is_public', 'folder_id', 'owner_id', and 'polymorphic_ctype_id'. The 'id' is a foreign key referencing the 'filer_image' table, 'owner_id' references 'auth_user', and 'polymorphic_ctype_id' references 'django_content_type'.
The 'filer_folder' table represents folders in the system. It has columns for 'name', 'uploaded_at', 'created_at', 'modified_at', 'lft', 'rght', 'tree_id', 'level', 'owner_id', and 'parent_id'. The 'owner_id' references 'auth_user', and 'parent_id' references itself.
The 'filer_folderpermission' table represents permissions for folders. It has columns for 'type', 'everybody', 'can_edit', 'can_read', 'can_add_children', 'folder_id', 'user_id', and 'group_id'. The 'user_id' references 'auth_user', 'group_id' references 'auth_group', and 'folder_id' references 'filer_folder'.
The 'filer_image' table represents images in the system. It has columns for 'file_ptr_id', '_height', '_width', 'date_taken', 'default_alt_text', 'default_caption', 'author', 'must_always_publish_author_credit', 'must_always_publish_copyright', and 'subject_location'. The 'file_ptr_id' is a foreign key referencing the 'filer_file' table.
The 'filer_thumbnailoption' table represents thumbnail options in the system. It has columns for 'name', 'width', 'height', 'crop', and 'upscale'.
