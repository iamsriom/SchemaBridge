The database schema named "schemabench_0045" contains 11 tables. The main purpose of this schema is to manage various aspects of GitHub applications and their users.
A primary key is used for identification and relationships among tables. The 'app_installation_permissions' table, for instance, references 'users' and 'app_installations' tables through foreign keys. This schema is used to store information about the permissions of users on different app installations.
The 'app_installations' table holds information about different app installations, including the GitHub ID, app ID, account login, account ID, account type, target type, target ID, permission statuses, and timestamps for creation and update.
The 'comments' table contains information about comments made on various subjects, including the subject ID, GitHub ID, author, author association, body, creation and update timestamps, review state, and URL.
The 'labels' table stores information about labels, including the name, color, subject ID, creation and update timestamps, and GitHub ID.
The 'notifications' table contains information about notifications, including the user ID, GitHub ID, repository ID, repository full name, subject title, subject URL, subject type, reason, unread status, last read timestamp, URL, archived status, creation and update timestamps, starred status, repository owner name, latest comment URL, and mute timestamp.
The 'pinned_searches' table stores information about pinned searches, including the user ID, query, name, and creation and update timestamps.
The 'repositories' table contains information about repositories, including the full name, GitHub ID, privacy status, owner, last synced timestamp, creation and update timestamps, and app installation ID.
The 'subjects' table holds information about various subjects, including the URL, state, author, creation and update timestamps, HTML URL, assignees, GitHub ID, repository full name, locked status, SHA, status, body, comment count, and draft status.
The 'subscription_plans' table contains information about subscription plans, including the GitHub ID, name, description, monthly and yearly prices in cents, price model, free trial status, unit name, and creation and update timestamps.
The 'subscription_purchases' table contains information about subscription purchases, including the subscription plan ID, account ID, billing cycle, unit count, free trial status, free trial end date, next billing date, and creation and update timestamps.
Finally, the 'users' table contains information about users, including the GitHub ID, GitHub login, creation and update timestamps, last synced timestamp, refresh interval, API token, sync job ID, encrypted access token, encrypted access token initialization vector, encrypted personal access token, encrypted personal access token initialization vector, encrypted app token, encrypted app token initialization vector, theme, and display comments status.
This schema is designed to ensure referential integrity, with foreign keys ensuring that the relationships between tables are maintained. It also covers data integrity, with primary keys ensuring unique identification of records and constraints ensuring data validity.
