The database schema named "schemabench_0062" contains six tables.
The "love_reactant_reaction_counters" table is used to store reaction counters for each reactant. It has seven columns: 'id', 'reactant_id', 'reaction_type_id', 'count', 'weight', 'created_at', and 'updated_at'. The 'id' column is a primary key and 'reactant_id' and 'reaction_type_id' are foreign keys referencing the 'id' in the 'love_reactants' and 'love_reaction_types' tables respectively.
The "love_reactant_reaction_totals" table is also used to store reaction totals for each reactant. It has six columns: 'id', 'reactant_id', 'count', 'weight', 'created_at', and 'updated_at'. The 'id' column is a primary key and 'reactant_id' is a foreign key referencing the 'id' in the 'love_reactants' table.
The "love_reactants" table is used to store information about the reactants. It has four columns: 'id', 'type', 'created_at', and 'updated_at'. The 'id' column is a primary key.
The "love_reacters" table is used to store information about the reacters. It has four columns: 'id', 'type', 'created_at', and 'updated_at'. The 'id' column is a primary key.
The "love_reaction_types" table is used to store information about the reaction types. It has five columns: 'id', 'name', 'mass', 'created_at', and 'updated_at'. The 'id' column is a primary key.
The "love_reactions" table is used to store information about the reactions. It has eight columns: 'id', 'reactant_id', 'reacter_id', 'reaction_type_id', 'rate', 'created_at', 'updated_at'. The 'id' column is a primary key and 'reactant_id', 'reacter_id', and 'reaction_type_id' are foreign keys referencing the 'id' in the 'love_reactants', 'love_reacters', and 'love_reaction_types' tables respectively.
All columns allow null values except for the 'created_at' and 'updated_at' columns in all tables. The 'created_at' and 'updated_at' columns default to the current timestamp when a new row is inserted.
