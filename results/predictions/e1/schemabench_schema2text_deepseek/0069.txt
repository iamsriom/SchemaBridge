The database schema named "schemabench_0069" contains four tables: `oauth_access_grants`, `oauth_access_tokens`, `oauth_applications`, and `users`.
The `oauth_access_grants` table represents the grant of access to resources. It contains columns for the grant's id, the id of the resource owner, the id of the application, the token, the expiration time, the redirect URI, creation time, revocation time, and scopes. The table has foreign keys referencing the `users` and `oauth_applications` tables.
The `oauth_access_tokens` table represents the access tokens. It contains columns for the token's id, the id of the resource owner, the id of the application, the token, the refresh token, expiration time, revocation time, creation time, scopes, and the previous refresh token. The table has foreign keys referencing the `users` and `oauth_applications` tables.
The `oauth_applications` table represents the OAuth applications. It contains columns for the application's id, name, UID, secret, redirect URI, scopes, confidentiality status, creation time, and update time.
The `users` table represents the users. It contains a single column for the user's id. This table does not contain any foreign keys.
All columns in these tables allow null values except for the `token`, `redirect_uri`, `scopes`, `secret`, and `previous_refresh_token` columns in the `oauth_access_grants` and `oauth_access_tokens` tables. The `created_at`, `updated_at`, and `revoked_at` columns in the `oauth_access_grants` and `oauth_access_tokens` tables, and the `created_at` and `updated_at` columns in the `oauth_applications` table have default values. The `id` columns in all tables are primary keys and do not allow null values. The `id` columns in the `users` table are also primary keys and do not allow null values.
The `id` columns in the `oauth_access_grants` and `oauth_access_tokens` tables are foreign keys referencing the `id` column in the `users` table and the `id` column in the `oauth_applications` table. The `application_id` column in both tables is also a foreign key referencing the `id` column in the `oauth_applications` table. The `resource_owner_id` column in the `oauth_access_grants` table is also a foreign key referencing the `id` column in the `users` table.
There are no other indexes or constraints in this schema.
