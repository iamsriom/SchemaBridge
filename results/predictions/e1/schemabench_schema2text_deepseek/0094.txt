The database schema named "schemabench_0094" consists of five tables: "atom", "bond", "gmember", "group", and "molecule".
The "atom" table represents the atomic elements in a molecule. It has three columns: "atom_id" which is a unique identifier for each atom, "molecule_id" which represents the molecule the atom belongs to, and "type" which specifies the type of the atom. The "atom_id" column allows null values and is the primary key. The "molecule_id" column also allows null values and is a foreign key referencing the "molecule" table.
The "bond" table represents the bonds between atoms. It has three columns: "atom_id" and "atom_id2" which represent the two atoms involved in the bond, and "type" which specifies the type of the bond. The combination of "atom_id" and "atom_id2" forms the primary key. Both "atom_id" and "atom_id2" are foreign keys referencing the "atom" table.
The "gmember" table represents the group memberships of atoms. It has two columns: "atom_id" which represents the atom and "group_id" which represents the group. The combination of "atom_id" and "group_id" forms the primary key. Both "atom_id" and "group_id" are foreign keys referencing the "atom" and "group" tables respectively.
The "group" table represents the groups of atoms. It has two columns: "group_id" which is a unique identifier for each group, and "type" which specifies the type of the group. The "group_id" column allows null values and is the primary key.
The "molecule" table represents the molecules. It has four columns: "molecule_id" which is a unique identifier for each molecule, "activity" which represents the activity of the molecule, "logp" which represents the log partition coefficient, and "mweight" which represents the molecular weight. The "molecule_id" column allows null values and is the primary key.
All foreign key references are set to CASCADE on delete and update, meaning that when a referenced record in the parent table is deleted or updated, the corresponding records in the child table will automatically be deleted or updated.
