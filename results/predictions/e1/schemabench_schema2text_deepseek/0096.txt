The database schema named "schemabench_0096" consists of 6 tables: 'customers', 'gasstations', 'products', 'transactions', 'transactions_1k', and 'yearmonth'.
The 'customers' table represents a list of customers with columns for 'CustomerID' (an integer), 'Segment' (a string), and 'Currency' (a string). The primary key for this table is 'CustomerID'.
The 'gasstations' table contains information about gas stations, including 'GasStationID' (an integer), 'ChainID' (an integer), 'Country' (a string), and 'Segment' (a string). The primary key for this table is 'GasStationID'.
The 'products' table contains product details with 'ProductID' (an integer) and 'Description' (a string). The primary key for this table is 'ProductID'.
The 'transactions' table records transactions with columns for 'Date', 'Time', 'CustomerID', 'CardID', 'GasStationID', 'ProductID', 'Amount', and 'Price'. It has foreign keys linking to 'CustomerID' in the 'customers' table, 'GasStationID' in the 'gasstations' table, and 'ProductID' in the 'products' table. If a record in these tables is deleted, the corresponding records in the 'transactions' table will be deleted due to the ON DELETE CASCADE ON UPDATE CASCADE constraints.
The 'transactions_1k' table is a copy of the 'transactions' table but with an additional 'TransactionID' column. This table also has foreign keys linking to 'CustomerID', 'GasStationID', and 'ProductID' in the 'customers', 'gasstations', and 'products' tables respectively.
Finally, the 'yearmonth' table records consumption data for each customer for each month. It has 'CustomerID' (an integer), 'Date' (an integer), and 'Consumption' (a decimal). The primary key for this table is a composite key consisting of 'CustomerID' and 'Date', and it has a foreign key linking to 'CustomerID' in the 'customers' table. If a record in the 'customers' table is deleted, the corresponding records in the 'yearmonth' table will be deleted due to the ON DELETE CASCADE ON UPDATE CASCADE constraints.
This schema is designed to efficiently manage and analyze data related to gas station transactions and consumption.
