The database schema named "schemabench_0100" consists of three tables: "EXPENDITURES", "HOUSEHOLDS", and "HOUSEHOLD_MEMBERS".
The "EXPENDITURES" table is used to track expenditures made by households. It contains seven columns: "EXPENDITURE_ID", "HOUSEHOLD_ID", "YEAR", "MONTH", "PRODUCT_CODE", "COST", "GIFT", and "IS_TRAINING". The "HOUSEHOLD_ID" column is the primary key and is used to reference the "HOUSEHOLDS" table.
The "HOUSEHOLDS" table holds information about households. It includes columns for "HOUSEHOLD_ID", "YEAR", and "INCOME_RANK" to "INCOME_RANK_5" and "INCOME_RANK_MEAN". The "HOUSEHOLD_ID" is the primary key of this table.
The "HOUSEHOLD_MEMBERS" table contains information about the members of the households. It includes columns for "HOUSEHOLD_ID", "YEAR", "MARITAL", "SEX", "AGE", and "WORK_STATUS". The "HOUSEHOLD_ID" column is a foreign key referencing the "HOUSEHOLDS" table.
All columns allow null values except for the "IS_TRAINING" column, which has a default value of 1. This schema ensures referential integrity by enforcing foreign key constraints and maintaining the integrity of the data by ensuring that the "HOUSEHOLD_ID" in the "EXPENDITURES" table matches the "HOUSEHOLD_ID" in the "HOUSEHOLDS" table.
