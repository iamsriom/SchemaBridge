The database schema named "schemabench_0105" consists of two tables: "sentences" and "terms".
The "sentences" table is used to store sentence-related information. It has a single column, "id", which is an integer and serves as the primary key. This column does not allow null values.
The "terms" table is used to store term-related information. It has three columns: "id_sentence", "id_term", and "term". "id_sentence" and "id_term" are both integers and serve as the primary key of this table. The "term" column is a variable character field with a maximum length of 7 characters and allows null values by default.
The "terms" table has a foreign key relationship with the "sentences" table. The "id" column in the "sentences" table is referenced by the "id_sentence" column in the "terms" table. This relationship is set up to automatically delete all associated terms in the "terms" table when a sentence is deleted in the "sentences" table, and to update the corresponding terms when a sentence is updated in the "sentences" table.
