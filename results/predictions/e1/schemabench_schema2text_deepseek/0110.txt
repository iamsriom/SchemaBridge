The database schema named 'schemabench_0110' consists of 12 tables.
The 'awards' table is used to store information about various awards. It includes columns for the award title, effective and expiration dates, the award amount, the award instrument, the organisation code, the program officer, the abstract narration, the minimum and maximum AMD letter dates, the ARRA amount, and the award ID. The award ID is the primary key and is used as a foreign key in the 'foa_info_awards', 'institution_awards', and 'investigator_awards' tables.
The 'foa_info' table stores information about various FOA (Funding Opportunity Announcement) codes. Each code is a primary key and is used as a foreign key in the 'foa_info_awards' table.
The 'foa_info_awards' table is a junction table that links the 'awards' and 'foa_info' tables. It includes columns for the award ID and the FOA code. Both are primary keys and are used as foreign keys in the 'awards' and 'foa_info' tables respectively.
The 'institution' table stores information about various institutions. It includes columns for the institution name, city name, zipcode, contact number, address, country name, state name, and state code. The combination of institution name and zipcode is the primary key. It is used as a foreign key in the 'institution_awards' table.
The 'institution_awards' table is a junction table that links the 'awards' and 'institution' tables. It includes columns for the award ID and the institution name and zipcode. Both are primary keys and are used as foreign keys in the 'awards' and 'institution' tables respectively.
The 'investigator' table stores information about various investigators. It includes columns for the investigator's email ID, first name, and last name. The email ID is the primary key. It is used as a foreign key in the 'investigator_awards' table.
The 'investigator_awards' table is a junction table that links the 'awards' and 'investigator' tables. It includes columns for the award ID, investigator's email ID, start and end dates, and role code. Both are primary keys and are used as foreign keys in the 'awards' and 'investigator' tables respectively.
The 'organization' table stores information about various organizations. It includes columns for the organization code and the division and directorate. The organization code is the primary key.
The 'program_element' table stores information about various program elements. It includes columns for the program element code and text. The program element code is the primary key. It is used as a foreign key in the 'program_element_awards' table.
The 'program_element_awards' table is a junction table that links the 'awards' and 'program_element' tables. It includes columns for the award ID and the program element code. Both are primary keys and are used as foreign keys in the 'awards' and 'program_element' tables respectively.
The 'program_reference' table stores information about various program references. It includes columns for the program reference code and text. The program reference code is the primary key. It is used as a foreign key in the 'program_reference_awards' table.
The 'program_reference_awards' table is a junction table that links the 'awards' and 'program_reference' tables. It includes columns for the award ID and the program reference code. Both are primary keys and are used as foreign keys in the 'awards' and 'program_reference' tables respectively.
This schema ensures referential integrity by linking the tables together through the primary and foreign keys. It also ensures data integrity by ensuring that the data types match between the columns in the tables and that null values are allowed or not based on the default values.
