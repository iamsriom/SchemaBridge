The database schema named "schemabench_0122" contains 11 tables.
The "authors" table is used to store information about authors. It has columns for author ID (au_id), last name (au_lname), first name (au_fname), phone number (phone), address (address), city (city), state (state), zip code (zip), and a contract flag (contract).
The "discounts" table is used to store information about discounts. It has columns for discount type (discounttype), store ID (stor_id), low quantity (lowqty), high quantity (highqty), and discount (discount). The store ID is a foreign key referencing the "stores" table.
The "employee" table is used to store information about employees. It has columns for employee ID (emp_id), first name (fname), middle initial (minit), last name (lname), job ID (job_id), job level (job_lvl), publisher ID (pub_id), and hire date (hire_date). The job ID and publisher ID are foreign keys referencing the "jobs" and "publishers" tables respectively.
The "jobs" table is used to store information about jobs. It has columns for job ID (job_id), job description (job_desc), minimum level (min_lvl), and maximum level (max_lvl).
The "pub_info" table is used to store information about publishers. It has columns for publisher ID (pub_id), logo (logo), and publisher information (pr_info). The publisher ID is a foreign key referencing the "publishers" table.
The "publishers" table is used to store information about publishers. It has columns for publisher ID (pub_id), publisher name (pub_name), city (city), state (state), and country (country).
The "roysched" table is used to store information about royalties. It has columns for title ID (title_id), low range (lorange), high range (hirange), and royalty (royalty). The title ID is a foreign key referencing the "titles" table.
The "sales" table is used to store information about sales. It has columns for store ID (stor_id), order number (ord_num), order date (ord_date), quantity (qty), payment terms (payterms), and title ID (title_id). The store ID and title ID are foreign keys referencing the "stores" and "titles" tables respectively.
The "stores" table is used to store information about stores. It has columns for store ID (stor_id), store name (stor_name), store address (stor_address), city (city), state (state), and zip code (zip).
The "titleauthor" table is used to store information about authors and their contributions to titles. It has columns for author ID (au_id), title ID (title_id), author order (au_ord), and royalty percentage (royaltyper). The title ID and author ID are foreign keys referencing the "titles" and "authors" tables respectively.
The "titles" table is used to store information about titles. It has columns for title ID (title_id), title (title), type (type), publisher ID (pub_id), price (price), advance (advance), royalty (royalty), year-to-date sales (ytd_sales), notes (notes), and publication date (pubdate). The publisher ID is a foreign key referencing the "publishers" table.
