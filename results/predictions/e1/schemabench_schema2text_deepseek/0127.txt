The database schema named 'schemabench_0127' consists of five tables: 'Customers', 'Demog', 'Mailings1_2', 'Sales', and 'mailings3'.
The 'Customers' table contains information about customers, including their ID, sex, marital status, geographical ID, education number, occupation, and various data points. The 'Demog' table provides demographic information related to the geographical ID, including the number of inhabitants, income, and various variables. The 'Mailings1_2' table contains information about mailings, including a reference ID, index, date, and response. The 'Sales' table contains information about sales events, including an event ID, reference ID, date, and amount. The 'mailings3' table contains information about mailings, including a reference ID, date, and response.
All tables have primary keys that uniquely identify each record. The 'Customers' table has a foreign key 'GEOID' that references the 'Demog' table's 'GEOID'. The 'Mailings1_2' and 'Sales' tables have a foreign key 'REFID' that references the 'Customers' table's 'ID'. The 'Mailings1_2' and 'Sales' tables also have on delete cascade and on update cascade rules, meaning that if a record in the 'Customers' table is deleted or updated, the corresponding records in these tables will also be deleted or updated.
