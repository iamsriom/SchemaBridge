The database schema named 'schemabench_0128' consists of three tables: 'businesses', 'inspections', and 'violations'.
The 'businesses' table is used to store information about various businesses. It includes columns for 'business_id', 'name', 'address', 'city', 'postal_code', 'latitude', 'longitude', 'phone_number', 'tax_code', 'business_certificate', 'application_date', 'owner_name', 'owner_address', 'owner_city', 'owner_state', and 'owner_zip'. These columns all allow null values except for 'name' and 'business_certificate' which are not null. The 'business_id' is the primary key for this table.
The 'inspections' table is used to store information about business inspections. It includes columns for 'business_id', 'score', 'date', and 'type'. The 'business_id' column is a foreign key referencing the 'businesses' table.
The 'violations' table is used to store information about business violations. It includes columns for 'business_id', 'date', 'violation_type_id', 'risk_category', and 'description'. The 'business_id' column is a foreign key referencing the 'businesses' table.
This schema ensures referential integrity by enforcing the constraints of foreign keys. When a record in the 'businesses' table is deleted, any corresponding records in the 'inspections' and 'violations' tables will also be deleted to maintain data integrity.
