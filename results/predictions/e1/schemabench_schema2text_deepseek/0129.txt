The database schema named 'schemabench_0129' contains four tables: 'chapters', 'characters', 'paragraphs', and 'works'.
The 'chapters' table represents a collection of literary chapters. It has five columns: 'id', 'Act', 'Scene', 'Description', and 'work_id'. The 'id' column is the primary key and auto-increments. The 'work_id' column is a foreign key referencing the 'id' column in the 'works' table, indicating the work to which each chapter belongs.
The 'characters' table represents a collection of literary characters. It has three columns: 'id', 'CharName', 'Abbrev', and 'Description'. The 'id' column is the primary key and auto-increments.
The 'paragraphs' table represents a collection of paragraphs written by characters in chapters. It has four columns: 'id', 'ParagraphNum', 'PlainText', 'character_id', and 'chapter_id'. The 'id' column is the primary key and auto-increments. The 'character_id' and 'chapter_id' columns are foreign keys referencing the 'id' columns in the 'characters' and 'chapters' tables, respectively, indicating the character and chapter to which each paragraph belongs.
The 'works' table represents a collection of literary works. It has four columns: 'id', 'Title', 'LongTitle', 'Date', and 'GenreType'. The 'id' column is the primary key and auto-increments.
All columns allow null values except for the 'work_id' column in the 'chapters' table, the 'id' columns in the 'characters', 'paragraphs', and 'works' tables, and the 'character_id' and 'chapter_id' columns in the 'paragraphs' table. There are no default values for any columns. The primary keys are 'id' in the 'chapters', 'characters', 'paragraphs', and 'works' tables. The foreign keys enforce referential integrity by preventing deletion of records in the 'chapters' and 'paragraphs' tables that are referenced by records in the 'characters' and 'works' tables.
