The database schema named "schemabench_0130" consists of 8 tables.
The "badges" table is used to store information about user badges. It includes columns for Id (an integer, primary key), UserId (an integer, foreign key referencing the users table), Name (a string), and Date (a datetime).
The "comments" table is used to store information about user comments. It includes columns for Id (an integer, primary key), PostId (an integer, foreign key referencing the posts table), Score (an integer), Text (a long text), CreationDate (a datetime), UserId (an integer, foreign key referencing the users table), and UserDisplayName (a string).
The "postHistory" table is used to store information about post history. It includes columns for Id (an integer, primary key), PostHistoryTypeId (an integer), PostId (an integer, foreign key referencing the posts table), RevisionGUID (a string), CreationDate (a datetime), UserId (an integer, foreign key referencing the users table), Text (a long text), Comment (a text), and UserDisplayName (a string).
The "postLinks" table is used to store information about post links. It includes columns for Id (an integer, primary key), CreationDate (a datetime), PostId (an integer, foreign key referencing the posts table), RelatedPostId (an integer, foreign key referencing the posts table), and LinkTypeId (an integer).
The "posts" table is used to store information about posts. It includes columns for Id (an integer, primary key), PostTypeId (an integer), AcceptedAnswerId (an integer), CreationDate (a datetime), Score (an integer), ViewCount (an integer), Body (a long text), OwnerUserId (an integer, foreign key referencing the users table), LastActivityDate (a datetime), Title (a string), Tags (a string), AnswerCount (an integer), CommentCount (an integer), FavoriteCount (an integer), LastEditorUserId (an integer, foreign key referencing the users table), LastEditDate (a datetime), CommunityOwnedDate (a datetime), ParentId (an integer, foreign key referencing the posts table), ClosedDate (a datetime), OwnerDisplayName (a string), and LastEditorDisplayName (a string).
The "tags" table is used to store information about tags. It includes columns for Id (an integer, primary key), TagName (a string), Count (an integer), ExcerptPostId (an integer, foreign key referencing the posts table), and WikiPostId (an integer, foreign key referencing the posts table).
The "users" table is used to store information about users. It includes columns for Id (an integer, primary key), Reputation (an integer), CreationDate (a datetime), DisplayName (a string), LastAccessDate (a datetime), WebsiteUrl (a string), Location (a string), AboutMe (a long text), Views (an integer), UpVotes (an integer), DownVotes (an integer), AccountId (an integer), Age (an integer), and ProfileImageUrl (a string).
Finally, the "votes" table is used to store information about votes. It includes columns for Id (an integer, primary key), PostId (an integer, foreign key referencing the posts table), VoteTypeId (an integer), CreationDate (a date), UserId (an integer, foreign key referencing the users table), and BountyAmount (an integer). All foreign keys have on delete cascade on update cascade rules, meaning that if a record in the parent table is deleted or updated, the corresponding records in the child table will automatically be deleted or updated.
