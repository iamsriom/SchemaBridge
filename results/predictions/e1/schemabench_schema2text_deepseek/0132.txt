The database schema named schemabench_0132 consists of 8 tables. The primary function of this schema is to manage and store data related to customers, orders, line items, parts, suppliers, regions, and nation.
The `dss_customer` table contains information about customers including their key, name, address, nation key, phone number, account balance, market segment, and a comment. The `c_nationkey` is a foreign key referencing the `dss_nation` table.
The `dss_lineitem` table contains line item information including the order key, part key, supplier key, line number, quantity, extended price, discount, tax, return flag, line status, ship date, commit date, receipt date, ship instruction, ship mode, and a comment. The `l_orderkey` and `l_partkey`, `l_suppkey` are primary keys. The `l_orderkey` is a foreign key referencing the `dss_order` table, and `l_partkey` and `l_suppkey` are foreign keys referencing the `dss_partsupp` table.
The `dss_nation` table contains information about nations including their key, name, region key, and a comment. The `n_regionkey` is a foreign key referencing the `dss_region` table.
The `dss_order` table contains information about orders including the order key, customer key, order status, total price, order date, order priority, clerk, ship priority, and a comment. The `o_custkey` is a foreign key referencing the `dss_customer` table.
The `dss_part` table contains information about parts including the part key, name, manufacturer, brand, type, size, container, retail price, and a comment.
The `dss_partsupp` table contains part supplier information including the part key, supplier key, available quantity, supply cost, and a comment. The `ps_partkey` and `ps_suppkey` are primary keys. The `ps_suppkey` is a foreign key referencing the `dss_supplier` table, and `ps_partkey` is a foreign key referencing the `dss_part` table. The combination of `ps_partkey` and `ps_suppkey` is also a foreign key referencing the `dss_lineitem` table.
The `dss_region` table contains information about regions including the region key, name, and a comment.
The `dss_supplier` table contains information about suppliers including the supplier key, name, address, nation key, phone number, account balance, and a comment. The `s_nationkey` is a foreign key referencing the `dss_nation` table.
All tables allow null values except for the NOT NULL constraints. The database schema is designed to maintain referential integrity by cascading deletions and updates.
