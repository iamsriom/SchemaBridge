The database schema named "schemabench_0136" consists of five tables: 'RA', 'course', 'prof', 'registration', and 'student'.
The 'RA' table represents the relationship between professors and students. It has three columns: 'capability', 'prof_id', and 'student_id', which are foreign keys referencing the 'prof' and 'student' tables respectively. The 'salary' column stores the salary information of the professors. The primary key of this table is a composite key consisting of 'prof_id' and 'student_id'.
The 'course' table represents the courses. It has two columns: 'course_id' and 'rating', which are the primary key and the rating of the course respectively. The 'diff' column stores the difficulty level of the course.
The 'prof' table represents the professors. It has two columns: 'prof_id' and 'popularity', which are the primary key and the popularity of the professor respectively. The 'teachingability' column stores the teaching ability of the professor.
The 'registration' table represents the registration of students for courses. It has four columns: 'course_id', 'student_id', 'grade', and 'sat', which are foreign keys referencing the 'course' and 'student' tables respectively. The primary key of this table is a composite key consisting of 'course_id' and 'student_id'.
The 'student' table represents the students. It has two columns: 'student_id' and 'intelligence', which are the primary key and the intelligence level of the student respectively. The 'ranking' column stores the ranking of the student.
All columns allow null values except for the 'prof_id', 'student_id', 'course_id', 'grade', 'sat' in the 'RA', 'registration' tables. The default value for 'prof_id' and 'student_id' in the 'RA' and 'registration' tables is 0.
The foreign key constraints in the 'RA', 'registration' tables are set to CASCADE on delete and update operations, meaning that if a record in the 'student' or 'course' table is deleted or updated, the corresponding records in the 'RA' and 'registration' tables will also be deleted or updated.
