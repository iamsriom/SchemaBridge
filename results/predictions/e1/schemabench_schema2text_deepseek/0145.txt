The database schema named "schemabench_0145" contains 14 tables. The main purpose of this schema is to manage and organize data related to different aspects of the Pokemon game.
The "type_efficacy" table represents the effectiveness of different damage types against different target types, with columns for damage_type_id, target_type_id, and damage_factor. This table has a primary key composed of damage_type_id and target_type_id.
The "moves" table contains information about different moves in the game, including move_id, move_name, type_id, move_power, move_pp, and move_accuracy. The type_id column is a foreign key referencing the types table.
The "pokemon" table contains information about the Pokemon, including pok_id, pok_name, pok_height, pok_weight, and pok_base_experience.
The "pokemon_moves" table represents the moves that Pokemon can learn, with columns for pok_id, version_group_id, move_id, method_id, and level. It has foreign keys referencing the pokemon, version_groups, moves, and pokemon_move_methods tables.
The "pokemon_evolution" table contains information about Pokemon evolutions, with evol_id, evolved_species_id, and evol_minimum_level. The evolved_species_id is a foreign key referencing the pokemon table.
The "pokemon_abilities" table represents the abilities that Pokemon can have, with columns for pok_id, abil_id, is_hidden, slot, and foreign keys referencing the pokemon and abilities tables.
The "abilities" table contains information about the abilities, including abil_id and abil_name.
The "pokemon_types" table represents the types that Pokemon can have, with columns for pok_id, type_id, slot, and foreign keys referencing the pokemon and types tables.
The "base_stats" table contains the base stats of the Pokemon, including pok_id, b_hp, b_atk, b_def, b_sp_atk, b_sp_def, and b_speed. It has a foreign key referencing the pokemon table.
The "version_groups" table contains information about the different version groups, including version_id, version_name, and `order`.
The "pokemon_habitats" table contains information about the habitats where Pokemon can be found, including hab_id, hab_name, and hab_description.
The "pokemon_evolution_matchup" table contains information about the matchups between different Pokemon species, including pok_id, evolves_from_species_id, hab_id, gender_rate, capture_rate, and base_happiness. It has foreign keys referencing the pokemon and pokemon_habitats tables.
The "types" table contains information about the different types, including type_id and type_name, and a foreign key referencing the type_efficacy table.
The "pokemon_move_methods" table contains information about the different methods a Pokemon can learn moves, including method_id and method_name.
All tables in this schema allow null values except for the ones that have NOT NULL constraints, and they have appropriate defaults where applicable. Primary keys are unique and not null, and foreign keys ensure referential integrity by referencing the primary keys of other tables. There are no other indexes or constraints in this schema.
