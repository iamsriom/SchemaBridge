The database schema named "schemabench_0146" consists of 15 tables. The primary purpose of this schema is to manage various aspects of a hotel reservation system.
The "payments" table holds information about payments made by users. It contains columns for the payment id, the id of the reservation, the id of the user, the amount of the payment, the date and time of the payment, and the status of the payment. The table has foreign key relationships with the "reservations" and "users" tables, respectively.
The "amenities" table represents the various amenities offered by the hotel. It contains columns for the amenity id and the name of the amenity, with the name being unique.
The "users" table stores information about the users of the system. It includes columns for the user id, name, email, email verification timestamp, password, remember token, creation and update timestamps, phone number, description, and profile image. The email is unique to prevent duplicate entries.
The "promotions" table contains information about the promotions offered by the hotel. It includes columns for the promotion id, code, discount percentage, start and end dates.
The "user_notifications" table keeps track of notifications sent to users. It includes columns for the notification id, the id of the user, the text of the notification, and the creation and read timestamps.
The "reviews_media" table stores information about media associated with reviews. It includes columns for the media id, the id of the review, file name, mime type, and the upload timestamp.
The "reservations" table contains information about reservations made by users. It includes columns for the reservation id, the ids of the user and room, start and end dates, price, total, and creation and update timestamps. It also has foreign key relationships with the "rooms" and "users" tables.
The "wishlists" table contains information about user wishlists. It includes columns for the wishlist id, the id of the user, name, and creation timestamp.
The "room_amenities" table represents the many-to-many relationship between rooms and amenities. It includes columns for the room id and amenity id, and has foreign key relationships with both the "amenities" and "rooms" tables.
The "messages" table contains information about messages exchanged between users. It includes columns for the message id, the ids of the sender, receiver, and reservation, the text of the message, and the sent and read timestamps. It also has foreign key relationships with the "users" and "reservations" tables.
The "media" table stores information about media associated with various models. It includes columns for the media id, model id, model type, file name, and mime type.
The "reviews" table contains information about reviews made by users. It includes columns for the review id, the id of the reservation, rating, and comment. It also has a foreign key relationship with the "reservations" table.
The "reservation_promotions" table represents the many-to-many relationship between reservations and promotions. It includes columns for the reservation id and promotion id, as well as the discount amount. It also has foreign key relationships with both the "reservations" and "promotions" tables.
Finally, the "wishlist_rooms" table represents the many-to-many relationship between wishlists and rooms. It includes columns for the wishlist id and room id, and has foreign key relationships with both the "rooms" and "wishlists" tables.
The "rooms" table contains information about the rooms offered by the hotel. It includes columns for the room id, home type, room type, total occupancy, total bedrooms, total bathrooms, summary, address, amenities (like TV, kitchen, air conditioning, heating, internet), price, published timestamp, and the id of the owner. It also has a foreign key relationship with the "users" table.
