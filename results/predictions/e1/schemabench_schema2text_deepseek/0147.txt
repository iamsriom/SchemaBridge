The database schema named "schemabench_0147" contains 10 tables. The tables are described as follows:
1. **Chat**: This table represents the chat messages exchanged between users. It has three columns: 'id', 'userid', and 'participantid'. The 'id' column is the primary key and 'userid' and 'participantid' are foreign keys referencing the 'id' of the User table.
2. **Like**: This table represents the likes given by users to posts. It has four columns: 'id', 'postid', 'userid', and 'createdat'. The 'id' column is the primary key and 'postid' and 'userid' are foreign keys referencing the 'id' of the Post and User tables respectively.
3. **Session**: This table represents user sessions. It has four columns: 'id', 'refreshtoken', 'expirationtime', 'userid', and 'createdat'. The 'id' column is the primary key and 'userid' is a foreign key referencing the 'id' of the User table.
4. **UserFollows**: This table represents the relationship between users. It has two columns: 'userid' and 'followerid'. Both 'userid' and 'followerid' are foreign keys referencing the 'id' of the User table.
5. **Notification**: This table represents notifications sent to users. It has eight columns: 'id', 'senderid', 'recipientid', 'type', 'objecttype', 'objecturi', 'read', and 'createdat'. The 'id' column is the primary key and 'recipientid' and 'senderid' are foreign keys referencing the 'id' of the User table.
6. **Message**: This table represents private messages sent by users. It has five columns: 'id', 'userid', 'content', 'read', and 'createdat'. The 'id' column is the primary key and 'userid' is a foreign key referencing the 'id' of the User table.
7. **Repost**: This table represents the reposts made by users. It has four columns: 'id', 'postid', 'userid', and 'createdat'. The 'id' column is the primary key and 'postid' and 'userid' are foreign keys referencing the 'id' of the Post and User tables respectively.
8. **User**: This table represents users. It has eight columns: 'id', 'email', 'username', 'newuser', 'hashedpassword', 'googleid', 'provider', and 'createdat'. The 'id' column is the primary key and 'email', 'username', 'googleid', and 'provider' are unique constraints.
9. **Profile**: This table represents user profiles. It has six columns: 'id', 'name', 'bio', 'img', 'website', 'dob', and 'userid'. The 'id' column is the primary key and 'userid' is a foreign key referencing the 'id' of the User table.
10. **Post**: This table represents posts made by users. It has five columns: 'id', 'content', 'userid', 'parentpostid', and 'createdat'. The 'id' column is the primary key and 'parentpostid' and 'userid' are foreign keys referencing the 'id' of the Post and User tables respectively.
This schema is designed to maintain a social media platform's data integrity by ensuring referential integrity between tables. It also ensures domain integrity by enforcing constraints on the data types and whether null values are allowed or not. The schema also includes indexes or constraints as per the requirements of the application.
