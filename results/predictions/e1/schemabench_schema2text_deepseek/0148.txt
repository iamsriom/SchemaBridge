The database schema "schemabench_0148" consists of 8 tables. The main entities in this schema are Orders, Payments, Refunds, Order Items, Products, Categories, Users, and Invoices.
The Orders table represents a collection of orders made by users. It has an id as the primary key, user_id as a foreign key referencing the Users table, total_amount as a numeric value representing the total amount of the order, status as a string representing the status of the order, and timestamps for created_at and updated_at.
The Payments table represents the payments made for the orders. It has an id as the primary key, invoice_id as a foreign key referencing the Invoices table, amount as a numeric value representing the payment amount, payment_date as a timestamp representing the date of payment, method as a string representing the payment method, and timestamps for created_at and updated_at.
The Refunds table represents the refunds made for the orders. It has an id as the primary key, order_id as a foreign key referencing the Orders table, amount as a numeric value representing the refund amount, reason as a text field representing the reason for the refund, refunded_at as a timestamp representing the date of refund, and timestamps for created_at and updated_at.
The Order Items table represents the items in the orders. It has an id as the primary key, order_id and product_id as foreign keys referencing the Orders and Products tables respectively, quantity as an integer representing the quantity of the product in the order, price as a numeric value representing the price of the product, and timestamps for created_at and updated_at.
The Products table represents the products available for purchase. It has an id as the primary key, name as a string representing the name of the product, category_id as a foreign key referencing the Categories table, price as a numeric value representing the price of the product, stock as an integer representing the stock of the product, description as a text field representing the description of the product, and timestamps for created_at and updated_at.
The Categories table represents the categories of the products. It has an id as the primary key, name as a string representing the name of the category, description as a text field representing the description of the category, and timestamps for created_at and updated_at.
The Users table represents the users of the system. It has an id as the primary key, name as a string representing the name of the user, email as a string representing the email of the user, email_verified_at as a timestamp representing the date of email verification, password as a string representing the password of the user, remember_token as a string representing the remember token of the user, and timestamps for created_at and updated_at.
The Invoices table represents the invoices for the orders. It has an id as the primary key, order_id as a foreign key referencing the Orders table, amount as a numeric value representing the invoice amount, issued_date as a timestamp representing the date of invoice issuance, due_date as a timestamp representing the due date of the invoice, status as a string representing the status of the invoice, and timestamps for created_at and updated_at.
All tables allow null values except for the NOT NULL constraints. Default values are set for created_at and updated_at timestamps. The primary keys are id for all tables and foreign keys are used to maintain referential integrity between tables.
