The database schema named "schemabench_0149" consists of 9 tables. The main purpose of this schema is to manage various aspects of a subscription-based service. Here are the details of each table:
1. The "subscription" table: This table holds information about the subscriptions of users. It has columns for the subscription id, account id, plan, status, start and end dates, stripe subscription id, and timestamps for creation and update. The account id is a foreign key referencing the "account" table.
2. The "audit_log" table: This table logs all the actions performed by users on the system. It has columns for the user id, account id, action, details, and a timestamp for creation. The account id and user id are foreign keys referencing the "account" and "user" tables respectively.
3. The "account" table: This table holds information about the accounts of users. It has columns for the account id, email, date created, stripe customer id, stripe subscription id, plan, referrer, and an active status.
4. The "user" table: This table holds information about the users. It has columns for the user id, name, email, password, date created, last login, permission, push token, and account id. The account id is a foreign key referencing the "account" table.
5. The "feature" table: This table holds information about the features of the service. It has columns for the feature id, name, description, and a timestamp for creation.
6. The "invite" table: This table holds information about invites sent by users. It has columns for the invite id, email, account id, date sent, and a boolean indicating whether the invite has been used. The account id is a foreign key referencing the "account" table.
7. The "session" table: This table holds information about user sessions. It has columns for the session id, user id, session token, creation and expiry dates. The user id is a foreign key referencing the "user" table.
8. The "plan_feature" table: This table maps the plans to the features. It has columns for the plan and feature id. The feature id is a foreign key referencing the "feature" table.
9. The "payment" table: This table holds information about payments made by users. It has columns for the payment id, account id, amount, currency, payment date, status, and stripe payment id. The account id is a foreign key referencing the "account" table.
All tables have primary keys that uniquely identify each record. Foreign keys are used to maintain referential integrity, ensuring that the data in the tables is consistent and accurate. The schema also includes indexes on some columns for performance optimization.
