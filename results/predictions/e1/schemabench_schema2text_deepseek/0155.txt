The database schema named "schemabench_0155" consists of 19 tables. The primary key is used to uniquely identify each record in the table. The schema is designed to manage various aspects of a crime scene investigation.
The "Residents" table represents the residents of a house. Each resident has a unique bracelet id that references the "Bracelet" table. The gender, birth date, and role of the resident are also stored.
The "Employee" table contains information about the employees of the investigation team. Each employee has a unique bracelet id that references the "Bracelet" table. The gender, birth date, hire date, and function of the employee are stored.
The "Robots" table contains information about the robots used in the investigation. Each robot has a unique bracelet id that references the "Bracelet" table. The function of the robot, hire date, and price are stored.
The "House" table contains information about the houses in the investigation. Each house has a unique id and a unique cctv id that references the "Cctv" table. The crime scene of the house is also stored.
The "Location" table contains information about the locations of the houses. Each location has a house id that references the "House" table and a bracelet id that references the "Bracelet" table.
The "Bracelet" table contains information about the bracelets used in the investigation. Each bracelet has a unique id.
The "Cctv" table contains information about the cctv cameras used in the investigation. Each cctv has a unique id. The switch on, switch off, breakdown, and modification status of the cctv are stored.
The "Modification_type" table contains information about the types of modifications made to the cctv cameras. Each modification has a cctv id that references the "Cctv" table.
The "Evidence_One", "Evidence_Two", "Evidence_Three", "Ransack_One", "Ransack_Two", and "Ransack_Three" tables contain information about the different types of evidence and ransacks used in the investigation.
The "Crime_scene" table contains information about the crime scene. Each crime scene has a unique id and a house id that references the "House" table. It also has references to the evidence and ransacks used in the investigation.
The "Suspect_Analyse_Post_Crime", "Innocent", "Real_Suspect", and "Culprit" tables contain information about the suspects and their status after the crime. Each suspect has a bracelet id that references the "Bracelet" table.
This schema is designed to ensure referential integrity by using foreign keys to link the tables together. It also ensures entity integrity by having primary keys that uniquely identify each record in the table. The schema is exhaustive and covers all aspects of the crime scene investigation.
