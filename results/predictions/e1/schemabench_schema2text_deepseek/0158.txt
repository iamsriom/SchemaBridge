The database schema named "schemabench_0158" consists of 6 tables. The tables are:
1. **INSTALLATIONS**: This table holds information about different installations. The primary key is `INSTALLATIONID` which is an integer. The `INSTALLATIONNAME` column is a varchar of maximum length 255 and cannot be null.
2. **LABORCODES**: This table represents labor codes. The primary key is `LABORCODEID` which is an integer. The `LABORCODENAME` column is a varchar of maximum length 255 and cannot be null.
3. **BILLINGCODES**: This table holds billing codes. The primary key is `BILLINGCODEID` which is a varchar. The `BILLINGCODE` column is a varchar of maximum length 255 and cannot be null.
4. **TICKETS**: This table represents support tickets. The primary key is `TICKETID` which is an integer and auto-increments. The `TICKETNUMBER`, `TICKETDESC`, `LABORCODE`, `DATEOFCREATION`, `INSTALLATION`, and `ISCLOSED` columns are all integers and cannot be null. The `ISCLOSED` column has a default value of false. The `INSTALLATION` and `LABORCODE` columns are foreign keys referencing the `INSTALLATIONS` and `LABORCODES` tables respectively.
5. **REPORTS**: This table holds reports. The primary key is `REPORTID` which is an integer and auto-increments. The `DATEOFREPORT`, `BILLINGCODE`, `TICKETID`, `ARRIVALTIME`, `EXITTIME`, and `ACTIVITY` columns are all not null. The `DATEOFREPORT` column has a default value of the current date. The `BILLINGCODE` column has a default value of 'B05'. The `TICKETID` column is a foreign key referencing the `TICKETS` table.
6. **shell**: This table is used for shell component configuration. The `component`, `title`, `icon`, `menu_item`, and `theme` columns are all text.
All tables have been created using the CREATE TABLE IF NOT EXISTS statement to ensure they are only created if they do not already exist. The schema is designed to maintain referential integrity by using foreign keys to link related data across tables.
