The database schema named "schemabench_0163" consists of 8 tables. The primary purpose of this schema is to manage various aspects of event planning and administration.
The CUSTOMER table represents customers who are interested in hosting events. It contains columns for customer number, name, address, internal status, contact information, phone number, city, state, and zip code. The CUSTNO column is the primary key.
The FACILITY table represents facilities that can host events. It contains columns for facility number and name. The FACNO column is the primary key and the FACNAME column is unique.
The LOCATION table represents locations within these facilities. It contains columns for location number, facility number, and location name. The LOCNO column is the primary key and the FACNO column is a foreign key referencing the FACILITY table.
The EVENTREQUEST table represents requests for events. It contains columns for event number, date held, date required, facility number, customer number, date authorized, status, estimated cost, estimated audience, and budget number. The EVENTNO column is the primary key, and the CUSTNO and FACNO columns are foreign keys referencing the CUSTOMER and FACILITY tables respectively. The STATUS column has a check constraint to ensure its value is either 'Pending', 'Denied', or 'Approved'. The ESTAUDIENCE column has a check constraint to ensure its value is greater than 0.
The EMPLOYEE table represents employees who work at the facility. It contains columns for employee number, name, department, email, and phone number. The EMPNO column is the primary key.
The EVENTPLAN table represents plans for events. It contains columns for plan number, event number, work date, notes, activity, and employee number. The PLANNO column is the primary key and the EVENTNO and EMPNO columns are foreign keys referencing the EVENTREQUEST and EMPLOYEE tables respectively.
The RESOURCETBL table represents resources used in event planning. It contains columns for resource number, name, and rate. The RESNO column is the primary key. The RATE column has a check constraint to ensure its value is greater than 0.
The EVENTPLANLINE table represents lines in event plans. It contains columns for plan number, line number, time start, time end, number of people, location number, and resource number. The LINENO and PLANNO columns form a composite primary key. The PLANNO column is a foreign key referencing the EVENTPLAN table, and the LOCNO and RESNO columns are foreign keys referencing the LOCATION and RESOURCETBL tables respectively. The TIMESTART and TIMEEND columns have a check constraint to ensure the start time is before the end time.
