The database schema named "schemabench_0184" consists of 9 tables. The main tables are User, Food, Restaurant, CustomerService, OrderHistory, Products, Interacts, Buys, and Sells.
The User table is used to store user information including user ID, phone number, password, email, first name, middle name, last name, date of birth, and address. It allows null values for phone number, password, and email. The user ID is the primary key.
The Food table is used to store food items information including item ID, name, price, availability, rating, quantity, and description. It allows null values for availability. The item ID is the primary key.
The Restaurant table is used to store restaurant information including restaurant ID, name, founding date, address, rating, and description. It allows null values for name, address, and description. The restaurant ID is the primary key.
The CustomerService table is used to store customer service information including cs ID, email, name, inquiry, status, and submission date. It allows null values for email, name, and status. The cs ID is the primary key.
The OrderHistory table is used to store order history information including order ID, user ID, total price, and order date. The user ID is a foreign key referencing the User table. The order ID is the primary key.
The Products table is used to store product information including product ID, user ID, order ID, and product. The user ID and order ID are foreign keys referencing the User and OrderHistory tables respectively. The product ID is the primary key.
The Interacts table is used to store interaction information including Interact ID, cs ID, and user ID. The cs ID and user ID are foreign keys referencing the CustomerService and User tables respectively. The Interact ID is the primary key.
The Buys table is used to store buy information including Buys ID, user ID, and food ID. The user ID and food ID are foreign keys referencing the User and Food tables respectively. The Buys ID is the primary key.
The Sells table is used to store sell information including Sells ID, restaurant ID, and food ID. The restaurant ID and food ID are foreign keys referencing the Restaurant and Food tables respectively. The Sells ID is the primary key.
This schema ensures referential integrity by enforcing foreign key constraints. It also ensures entity integrity by having primary keys for all tables. It also ensures domain integrity by defining data types and constraints for each column.
