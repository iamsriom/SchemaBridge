The database schema named schemabench_0188 consists of 8 tables. The tables are described as follows:
1. **DEPARTMENTS**: This table represents the departments in the hospital. The table has four columns: Dept_ID, which is the primary key and used as a foreign key in other tables, Available_Rooms, which has a default value of 0, Location, which is a required field, and Num_Employees.
2. **EMPLOYEES**: This table represents the employees in the hospital. It has seven columns: Fname, Minit, LName, Position, Address, Salary, EMP_ID, and Dept_ID. The primary key is a combination of EMP_ID and Dept_ID. The Dept_ID is a foreign key referencing the DEPARTMENTS table.
3. **SCHEDULES**: This table represents the schedules of the employees. It has six columns: Shift_ID, Start_Time, End_Time, EMP_ID, Date, and the primary key is a combination of EMP_ID and Shift_ID. The EMP_ID is a foreign key referencing the EMPLOYEES table.
4. **HOSPITAL_RESOURCES**: This table represents the resources in the hospital. It has four columns: Supply_Name, Supply_Type, Supply_Count, and Dept_ID. The primary key is a combination of Supply_Name and Dept_ID. The Dept_ID is a foreign key referencing the DEPARTMENTS table.
5. **PATIENTS**: This table represents the patients in the hospital. It has nine columns: FName, MInit, LName, SSN, Patient_ID, DOB, Address, Insurance, and Policy_ID. The primary key is a combination of SSN and Patient_ID. The Patient_ID is unique.
6. **CASES**: This table represents the cases in the hospital. It has eight columns: Case_ID, Room_Num, Admitted_By, Prescriptions, Patient_ID, Admit_Date, Discharge_Date, and the primary key is a combination of Case_ID and Patient_ID. The Patient_ID is a foreign key referencing the PATIENTS table.
7. **HANDLES**: This table represents the relationship between employees and cases. It has two columns: Emp_ID and Case_ID. The primary key is a combination of Emp_ID and Case_ID. Both Emp_ID and Case_ID are foreign keys referencing the EMPLOYEES and CASES tables respectively.
8. **HOUSED_UNDER**: This table represents the relationship between patients, departments, and cases. It has three columns: Patient_ID, Dept_ID, and Case_ID. The primary key is a combination of Patient_ID, Dept_ID, and Case_ID. All three are foreign keys referencing the PATIENTS, DEPARTMENTS, and CASES tables respectively.
All columns allow null values except for those that are marked as NOT NULL. Default values are set for Available_Rooms in the DEPARTMENTS table and Salary in the EMPLOYEES table. Referential integrity is maintained through foreign key constraints.
