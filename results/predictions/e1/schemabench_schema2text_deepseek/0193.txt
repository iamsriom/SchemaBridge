The database schema named "schemabench_0193" consists of 10 tables. The main purpose of this schema is to manage various aspects of a bookstore.
The "titles" table contains information about the books, including their ISBNs and titles. The primary key is the ISBN, which is a big integer of 13 digits.
The "authors" table stores information about the authors of the books. It includes the author's name, author_rank, and the ISBN of the book they wrote. The primary key is a composite of the author's name and the ISBN. The foreign key is the ISBN, which references the "titles" table.
The "themes" table holds information about the themes of the books. It includes the theme name, theme_rank, and the ISBN of the book. The primary key is a composite of the theme name and the ISBN. The foreign key is the ISBN, which references the "titles" table.
The "qualities" table contains information about the qualities of the books. It includes the quality name, quality_rank, and the ISBN of the book. The primary key is a composite of the quality name and the ISBN. The foreign key is the ISBN, which references the "titles" table.
The "cities" table stores information about the cities where customers live. It includes the city_id, city_name, and country. The primary key is the city_id, which is an auto-incrementing integer.
The "customers" table contains information about the customers. It includes the customer_id, first_name, surname, date of birth (dob), sex, date_joined, email, password, and city_id. The primary key is the customer_id, which is an auto-incrementing integer. The foreign key is the city_id, which references the "cities" table.
The "prices" table contains information about the prices of the books. It includes the ISBN and price. The primary key is the ISBN, which references the "titles" table.
The "orders" table contains information about the orders made by the customers. It includes the order_id, isbn, customer_id, quantity, purchase_date, and cost. The primary key is a composite of the order_id and the isbn. The foreign keys are the isbn and customer_id, which reference the "titles" and "customers" tables respectively.
The "ratings" table contains information about the ratings given by the customers. It includes the isbn, customer_id, rating_date, and rating. The primary key is a composite of the isbn and customer_id. The foreign keys are the isbn and customer_id, which reference the "titles" and "customers" tables respectively.
The "viewings" table contains information about the viewings of the books by the customers. It includes the isbn, customer_id, viewing_date, and view_time. The primary key is a composite of the isbn and customer_id. The foreign keys are the isbn and customer_id, which reference the "titles" and "customers" tables respectively.
All tables allow null values except for the ones that have notnull constraint. The default values are 'USA' for country in the "cities" table and 1 for author_rank, theme_rank, quality_rank in the "authors", "themes", and "qualities" tables respectively. The foreign keys have on update cascade and on delete cascade options.
