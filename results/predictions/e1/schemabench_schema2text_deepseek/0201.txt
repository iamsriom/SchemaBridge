The database schema named "schemabench_0201" contains five tables: authors, books, customers, orders, and reviews.
The authors table contains information about authors, including their ID, first name, last name, biography, birth date, nationality, and website. The primary key for this table is AUTHOR_ID, which is an integer and auto-increments.
The books table represents books in the database. It contains columns for BOOK_ID (a varchar), TITLE (a varchar), ISBN (a varchar), GENRE (a varchar), PRICE_IN_DOLLAR (a decimal), PUBLISHED_DATE (a date), and AUTHOR_ID (an integer). The BOOK_ID is the primary key, and the AUTHOR_ID is a foreign key referencing the AUTHOR_ID in the authors table.
The customers table contains information about customers, including their ID, first name, last name, email, passcode, address, and phone number. The primary key for this table is CUSTOMER_ID, which is a varchar.
The orders table records orders made by customers. It includes columns for ORDER_ID (an integer, auto-incrementing), CUSTOMER_ID (a varchar), ORDER_DATE (a datetime), TOTAL_AMOUNT (a decimal), and STATUS (a varchar). The ORDER_ID is the primary key, and the CUSTOMER_ID is a foreign key referencing the CUSTOMER_ID in the customers table.
The review table records reviews made by customers for books. It includes columns for REVIEW_ID (an integer, auto-incrementing), BOOK_ID (a varchar), CUSTOMER_ID (a varchar), RATING (a tinyint), COMMENT (a varchar), and REVIEW_DATE (a datetime). The REVIEW_ID is the primary key, and the BOOK_ID and CUSTOMER_ID are foreign keys, respectively, referencing the BOOK_ID and CUSTOMER_ID in the books and customers tables.
All tables allow null values except for NOT NULL constraints, and default values are used where appropriate. The database schema is designed to enforce referential integrity, with foreign keys ensuring that all references to valid primary keys exist in the referenced tables.
