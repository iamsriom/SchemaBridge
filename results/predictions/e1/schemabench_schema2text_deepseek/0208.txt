The database schema named "schemabench_0208" consists of 10 tables. The main purpose of this schema is to manage various aspects of events, including the organizing, hosting, participation, and feedback.
The "venues" table represents the locations where events are held. It includes columns for the venue's ID, name, address, capacity, and a description. The primary key is VENUE_ID, which is an auto-incrementing integer.
The "organizers" table contains information about the event organizers. It includes columns for the organizer's ID, name, email, phone number, address, and a description. The primary key is ORGANIZER_ID, which is an auto-incrementing integer.
The "events" table represents the events themselves. It includes columns for the event's ID, name, start and end date/time, venue ID, organizer ID, and a description. The primary key is EVENT_ID, which is an auto-incrementing integer. The foreign keys VENUE_ID and ORGANIZER_ID reference the venues and organizers tables respectively.
The "participants" table contains information about the event participants. It includes columns for the participant's ID, first, middle, last name, event ID, email, phone number, and a description. The primary key is PARTICIPANT_ID, which is an auto-incrementing integer. The foreign key EVENT_ID references the events table.
The "event_categories" table represents the categories of events. It includes columns for the category's ID and name, and a description. The primary key is CATEGORY_ID, which is an auto-incrementing integer.
The "event_category_mapping" table maps events to categories. It includes columns for the event ID, category ID, and a description. The foreign keys EVENT_ID and CATEGORY_ID reference the events and event_categories tables respectively.
The "event_speakers" table contains information about the speakers. It includes columns for the speaker's ID, name, email, phone number, participant ID, and a description. The primary key is SPEAKER_ID, which is an auto-incrementing integer. The foreign key PARTICIPANT_ID references the participants table.
The "event_speaker_mapping" table maps events to speakers. It includes columns for the event ID, speaker ID, and a description. The foreign keys EVENT_ID and SPEAKER_ID reference the events and event_speakers tables respectively.
The "event_participants_mapping" table maps events to participants. It includes columns for the event ID and participant ID. The foreign keys EVENT_ID and PARTICIPANT_ID reference the events and participants tables respectively.
Finally, the "event_feedback" table contains feedback from participants about events. It includes columns for the feedback ID, event ID, participant ID, rating, comment, feedback date, and a description. The primary key is FEEDBACK_ID, which is an auto-incrementing integer. The foreign keys EVENT_ID and PARTICIPANT_ID reference the events and participants tables respectively. The feedback date is set to the current date by default.
