The database schema named "schemabench_0212" contains 6 tables.
The 'movie' table represents a collection of movies, with each movie having a unique identifier (id), a title, the year it was released, the date it was published, duration, country of origin, worldwide gross income, languages spoken, and the production company. The id column is the primary key and allows null values. The title column has a default value of null. The year, date_published, duration, and country columns also have default values of null.
The 'genre' table lists the genres of movies, with each genre linked to a movie via a foreign key (movie_id). The movie_id column is the primary key.
The 'director_mapping' table maps directors to movies, with each director linked to a movie via a foreign key (movie_id). The movie_id column is the primary key.
The 'role_mapping' table maps roles to movies and names, with each role linked to both a movie and a name via foreign keys (movie_id and name_id). The movie_id and name_id columns are the primary keys, and the category column indicates the role of the name in the movie.
The 'names' table represents a collection of names, with each name having a unique identifier (id), a name, height, date of birth, and a list of movies they are known for. The id column is the primary key and allows null values. The name column has a default value of null. The height and date_of_birth columns also have default values of null.
The 'ratings' table provides ratings for movies, with each movie linked to a rating via a foreign key (movie_id). The movie_id column is the primary key. The ratings include the average rating, total votes, and median rating.
All tables have been designed with entity integrity in mind, with primary keys ensuring unique identification of records. Referential integrity has been maintained through foreign keys, ensuring that data in one table can be linked to data in another table.
