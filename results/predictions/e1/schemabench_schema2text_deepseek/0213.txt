The database schema named "schemabench_0213" consists of six tables: `Products`, `Orders`, `Sales`, `Address`, `Shipping`, and `Sales_`.
The `Products` table contains information about different products, including the product ID, product name, category, and sub-category. The product ID is the primary key and cannot be null.
The `Orders` table holds information about orders made by customers. It includes columns for the order ID, product ID, customer ID, order date, market, order priority, and quantity. The order ID and product ID are foreign keys referencing the `Products` and `Customers` tables respectively.
The `Sales` table contains sales data, including sales amount, discount, profit, and shipping cost. The order ID is a foreign key referencing the `Orders` table.
The `Address` table contains information about different addresses, including address ID, city, state, country, postal code, and region. The address ID is the primary key and cannot be null.
The `Shipping` table holds information about shipping details, including order ID, address ID, shipping date, shipping mode, and shipping cost. The order ID and address ID are foreign keys referencing the `Orders` and `Address` tables respectively.
Finally, the `Sales_` table contains detailed sales data, including price, cost, discount, shipping cost, quantity, location ID, time ID, and product ID. The location ID, time ID, and product ID are foreign keys referencing the `Location`, `Time`, and `Products_` tables respectively.
This schema ensures the integrity of data by enforcing primary and foreign key constraints, and by maintaining referential integrity through the use of foreign key references.
