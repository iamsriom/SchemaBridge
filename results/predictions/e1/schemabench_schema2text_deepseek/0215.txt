The database schema named "schemabench_0215" contains 7 tables. The main purpose of this schema is to manage the information about passengers, airports, aircrafts, flight crews, flights, tickets, and luggage.
The "PASSENGER" table represents the passengers who use the service. It has an AccountID as the primary key, which is an integer and cannot be null. It also includes columns for the PassengerName, PassengerAge, and FrequentflyerID, all of which are of varying length.
The "AIRPORT" table holds information about airports. The AirportCode is the primary key, which is a varchar of length 8. It also includes columns for AirportName, AirportCity, AirportState, AirportAddress, Classification, and TimeZone.
The "AIRCRAFT" table contains information about aircrafts. The AirplaneNumber is the primary key, which is a varchar of length 30. It also includes columns for AirplaneMake, WeightLimit, FlightNumber, and AirportCode. The AirportCode is a foreign key referencing the AIRPORT table.
The "FLIGHTCREW" table contains information about flight crew members. The EmployeeID is the primary key, which is an integer and cannot be null. It also includes columns for EmployeeName, EmployeeTitle, EmployeeAge, EmployeeStreetAddress, EmployeeZipCode, EmployeeCity, EmployeeState, and AirportCode. The AirportCode is a foreign key referencing the AIRPORT table.
The "FLIGHT" table contains information about flights. The FlightNumber is the primary key, which is a varchar of length 30. It also includes columns for DepartureTime, ArrivalTime, FlightPrice, AirportCode, GateNumber, AirplaneNumber, and EmployeeID. The AirplaneNumber is a foreign key referencing the AIRCRAFT table and EmployeeID is a foreign key referencing the FLIGHTCREW table.
The "TICKET" table contains information about tickets. The TicketID is the primary key, which is a varchar of length 20. It also includes columns for FromLocation, ToLocation, Seat, Price, FlightStatus, Class, AccountID, and FlightNumber. The AccountID is a foreign key referencing the PASSENGER table and FlightNumber is a foreign key referencing the FLIGHT table.
The "LUGGAGE" table contains information about luggage. The LuggageID is the primary key, which is a varchar of length 20. It also includes columns for CarouselNumber, Weight, AccountID, and AirplaneNumber. The AccountID is a foreign key referencing the PASSENGER table and AirplaneNumber is a foreign key referencing the AIRCRAFT table.
This schema ensures referential integrity by having foreign keys that reference the primary keys of other tables. It also ensures entity integrity by having primary keys that uniquely identify each record in the table. The schema is designed to ensure data integrity by enforcing constraints on the data types and lengths of the columns.
