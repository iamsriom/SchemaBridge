The database schema named "schemabench_0216" contains five tables: game_sales, reviews, top_critic_years, top_critic_years_more_than_four_games, and top_user_years_more_than_four_games.
The game_sales table represents the sales data of video games. It has five columns: game (a string of up to 100 characters), platform (a string of up to 64 characters), publisher (a string of up to 64 characters), developer (a string of up to 64 characters), games_sold (a numeric value with 5 decimal places), and year (an integer). The game column is the primary key of this table.
The reviews table contains data about the reviews of video games. It has three columns: game (a string of up to 100 characters), critic_score (a floating-point number), and user_score (a floating-point number). The game column is the primary key of this table.
The top_critic_years table represents the average critic scores for each year. It has two columns: year (an integer) and avg_critic_score (a numeric value with 4 decimal places). The year column is the primary key of this table.
The top_critic_years_more_than_four_games and top_user_years_more_than_four_games tables represent the average critic and user scores for each year, respectively, when there were more than four games sold in that year. They have three columns: year (an integer), num_games (an integer), and avg_critic_score and avg_user_score (numeric values with 4 decimal places). The year column is the primary key of these tables.
The foreign keys in the reviews table reference the game_sales table through the game column. The foreign keys in the top_critic_years_more_than_four_games and top_user_years_more_than_four_games tables reference the top_critic_years table through the year column. The referential integrity rules are set to CASCADE on delete and update.
This schema is designed to track and analyze video game sales, reviews, and critic and user scores over time.
