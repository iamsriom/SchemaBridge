The database schema named "schemabench_0218" consists of 8 tables. The main purpose of this schema is to manage the details of various entities involved in a farming community.
The "GRAM_PANCHAYAT" table represents the gram panchayat, which is a village or a block in rural areas. It has columns for total wards, taluka name, and panchayat id. The panchayat id is the primary key of this table.
The "VILLAGES" table represents the villages within the panchayat. It has columns for panchayat id, total wards, village name, ward number, and aadhar number. The primary key of this table is a composite of panchayat id, village name, ward number, and aadhar number. The panchayat id, ward number, and aadhar number are foreign keys referencing the "GRAM_PANCHAYAT", "WARD", and "FARMER" tables respectively.
The "WARD" table represents the wards within the villages. It has columns for ward number, village name, and ward name. The ward number is the primary key and the village name and ward name are unique.
The "FARMER" table represents the farmers. It has columns for aadhar number, gender, and name. The aadhar number is the primary key and the name is unique.
The "MEMBERS" table represents the members of the farming community. It has columns for member id, ward number, and member name. The member id is the primary key and the ward number and member name are unique. The ward number is a foreign key referencing the "WARD" table.
The "MACHINES" table represents the farming machines. It has columns for supplier name, ward number, price, machine id, member id, and machine name. The machine id is the primary key and the member id is a foreign key referencing the "MEMBERS" table. The ward number is a foreign key referencing the "WARD" table.
The "RENT" table represents the rent details. It has columns for machine id, aadhar number, and time. The primary key of this table is a composite of machine id and aadhar number. The machine id is a foreign key referencing the "MACHINES" table and the aadhar number is a foreign key referencing the "FARMER" table.
Finally, the "BILL" table represents the bills. It has columns for aadhar number, payment method, date, bill id, and amount. The aadhar number is the primary key and the bill id is the primary key. The aadhar number is a foreign key referencing the "FARMER" table.
