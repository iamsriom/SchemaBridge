The database schema named "schemabench_0220" consists of 14 tables. The primary purpose of this database is to manage and organize information related to hotel reservations, activities, guest information, and other related aspects.
The "Hotel" table represents the main entity in the schema. It contains information about the hotel's location, name, and rating. The "Room" table represents the rooms in the hotels. It contains information about the room number, price, hotel ID, view, availability, and room type.
The "Reservation" table represents the reservations made by the customers. It contains information about the board type, start date, duration, paid amount, number of children, reservee ID, and room ID. The "Reservee" table represents the customers who make the reservations.
The "Booking_Agency" table represents the booking agencies. It contains information about the agency's name, location, discount rate, and the reservee ID. The "Activities" table represents the activities offered in the hotels. It contains information about the activity's name and price.
The "Offers" table represents the offers made by the hotels. It contains information about the hotel ID and activity ID. The "Guest" table represents the guests staying in the hotels. It contains information about the guest's SSN, name, reservee ID, gender, date of birth, and reservation ID.
The "Participates_in" table represents the activities participated by the guests. It contains information about the guest's SSN and activity ID. The "Department" table represents the departments in the hotels. It contains information about the department's name and hotel ID.
The "Employee" table represents the employees working in the hotels. It contains information about the employee's SSN, name, management SSN, department ID and hotel ID, and salary. The "Gym" and "Equipment" tables represent the gyms and the equipment provided in the gyms. They contain information about the facility ID, hotel ID, name, and working hours.
The "Restaurant" table represents the restaurants in the hotels. It contains information about the facility ID, hotel ID, name, rating, price range, and food type. The foreign keys are used to establish relationships between these tables.
This schema ensures data integrity by enforcing primary and foreign key constraints, and referential integrity by maintaining the relationships between the tables.
