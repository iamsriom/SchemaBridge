The database schema named "schemabench_0221" consists of five tables: Customer_Ratings, Customer_Details, Customer_Preference, Restaurants, and restaurant_cuisines.
The Customer_Ratings table holds information about customer ratings for various restaurants. It includes columns for Consumer_ID, Restaurant_ID, Overall_Rating, Food_Rating, and Service_Rating.
The Customer_Details table contains detailed information about the customers. It includes columns for Consumer_ID, City, State, Country, Latitude, Longitude, Smoker, Drink_Level, Transportation_Method, Marital_Status, Children, Age, Occupation, Budget.
The Customer_Preference table contains preferences of the customers. It includes columns for Consumer_ID and Preferred_Cuisine.
The Restaurants table holds information about various restaurants. It includes columns for Restaurant_ID, Name, City, State, Country, Zip_Code, Latitude, Longitude, Alcohol_Service, Smoking_Allowed, Price, Franchise, Area, and Parking.
Finally, the restaurant_cuisines table contains information about the cuisines offered by the restaurants. It includes columns for Restaurant_ID and Cuisine.
All tables allow null values except for the Consumer_ID, Restaurant_ID, and Name columns in the Restaurants table. The default value for Smoker, Drink_Level, Transportation_Method, Marital_Status, Children, Occupation, Budget, Alcohol_Service, Smoking_Allowed, Price, Franchise, Area, and Parking is NULL. The primary keys are Consumer_ID and Restaurant_ID, respectively, in the Customer_Ratings and Restaurants tables. The unique constraints are on the Consumer_ID and Restaurant_ID columns in the Customer_Ratings and Restaurants tables. The foreign keys are Consumer_ID in the Customer_Details, Customer_Preference, and Customer_Ratings tables referencing Consumer_ID in the Customer_Details table. The foreign keys are Restaurant_ID in the Customer_Ratings, restaurant_cuisines, and Restaurants tables referencing Restaurant_ID in the Restaurants table. The update and delete rules are set to CASCADE for the foreign keys.
