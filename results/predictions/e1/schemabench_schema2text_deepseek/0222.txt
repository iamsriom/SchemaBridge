The database schema named "schemabench_0222" consists of 17 tables.
The ArtistInfoT table represents the artist's information. It has an artistID as the primary key, which is an auto-incrementing integer. The other columns include artistName, artistDOB, artistApt, artistStreet, artistCountry, artistState, artistZip, artistEmail, and artistPhone, all of which are not null.
The EventT table is used to store event details. It has an eventID as the primary key, which is an auto-incrementing integer. The other columns include eventName, eventDesc, eventStartDate, eventEndDate, eventStartTime, and eventEndTime, all of which are not null.
The EmployeeInfoT table stores employee information. It has an empID as the primary key, which is an auto-incrementing integer. The other columns include empName, empDOB, empApt, empStreet, empCountry, empState, empZip, empEmail, empPhone, empStartDate, empEndDate, empSalary, and empTitle, all of which are not null.
The CustomerInfoT table stores customer information. It has a custID as the primary key, which is an auto-incrementing integer. The other columns include custName, custDOB, custPhone, custEmail, custStreet, custApt, custCountry, custState, and custZip.
The ProductInfoT table stores product information. It has a prodID as the primary key, which is an auto-incrementing integer. The other column is prodName, which is not null.
The CustomerInterestT table is used to store customer interests in different products. It has custID and prodID as foreign keys referencing the CustomerInfoT and ProductInfoT tables respectively.
The InventoryArtT table stores information about the art items in the inventory. It has an itemID as the primary key, which is an auto-incrementing integer. The other columns include itemName, artistID, itemCreateDate, itemMoveInDate, and itemMoveoutDate. The artistID is a foreign key referencing the ArtistInfoT table.
The PartnerOrgT table stores information about partner organizations. It has partorgID as the primary key, which is an auto-incrementing integer. The other columns include partorgName, partorgApt, partorgStreet, partorgCountry, partorgState, partorgZip, partorgEmail, partorgPhone, partorgStartDate, and partorgType. The partorgType is a check constraint that ensures the value is either 'janitorial', 'catering', or 'wastedisposal'.
The DisplayArtT table stores information about the display of art items. It has itemID as a foreign key referencing the InventoryArtT table and a check constraint ensuring the displayLocation is either 'H1', 'H2', or 'H3'.
The LedgerT table stores transaction information. It has a transactionID as the primary key, which is an auto-incrementing integer. The other columns include transactionAmt and transactionTS.
The CreditT and DebitT tables store credit and debit transaction information, respectively. They have transaction_ID as a foreign key referencing the LedgerT table.
The CollabT table stores collaboration information. It has a collabID as the primary key, which is an auto-incrementing integer. The other columns include collabName, collabDesc, collabStartDate, and collabEndDate.
The ArtistContractT table stores artist contract information. It has a contractID as the primary key, which is an auto-incrementing integer. The other columns include artistID, contractSignDate, contractStartDate, contractEndDate, and contractComPer, all of which are not null. The artistID is a foreign key referencing the ArtistInfoT table.
The SalesT table stores sales information. It has a salesID as the primary key, which is an auto-incrementing integer. The other columns include transactionID, itemID, custID, salesmanID, salesAmount, and artistID, all of which are not null. The transactionID, itemID, custID, and salesmanID are foreign keys referencing the LedgerT, InventoryArtT, CustomerInfoT, and EmployeeInfoT tables respectively. The artistID is also a foreign key referencing the ArtistInfoT table.
The artistcontract_auditT and partnerOrg_auditT tables are audit tables that store information about changes made to the ArtistContractT and PartnerOrgT tables respectively. They have an id as the primary key, which is an auto-incrementing integer. The other columns include action, changeTimestamp, and the columns from the corresponding tables.
This schema is designed to maintain a comprehensive record of all the information related to artists, events, employees, customers, products, and inventory. It also includes tables for collaboration, sales, and audit trails.
