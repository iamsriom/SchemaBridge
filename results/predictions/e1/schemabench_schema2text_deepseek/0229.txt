The database schema named 'schemabench_0229' consists of seven tables.
The 'artifact_tags' table represents a many-to-many relationship between artifacts and tags. It has five columns: 'id', 'artifact_id', 'tag_id', 'created_at', and 'updated_at'.
The 'artifacts' table is used to store information about the artifacts. It has seven columns: 'id', 'latitude', 'longitude', 'created_at', 'updated_at', 'votes', 'is_reported', and 'open311_token'.
The 'neighborhoods' table stores information about neighborhoods. It has nine columns: 'gid', 'object_id', 'pri_neigh', 'pri_neigh_name', 'sec_neigh', 'sec_neigh_name', 'shape_area', 'shape_len', and 'geom'.
The 'pictures' table stores information about pictures associated with artifacts. It has four columns: 'id', 'artifact_id', 'image', 'created_at', and 'updated_at'.
The 'reflections' table stores information about reflections on artifacts. It has six columns: 'id', 'artifact_id', 'name', 'text', 'created_at', and 'updated_at'.
The 'schema_migrations' table is used to track the version of the database schema. It has one column: 'version'.
Finally, the 'tags' table is used to store information about tags. It has four columns: 'id', 'name', 'created_at', and 'updated_at'.
