The schemabench_0003 database is a comprehensive system for managing user accounts, teams, and billing information. At its core, it contains a users table, which stores information about each registered user, including their name, email address, password, and two-factor authentication details. Each user can be associated with a team, which is stored in the teams table, and teams are owned by a single user, as indicated by the owner_id foreign key in the teams table. The announcements table tracks important messages sent to users, while the api_tokens table stores authentication tokens for users. The invitations table manages invitations sent to users to join teams, and the invoices table keeps track of billing information for both users and teams. The notifications table stores notifications sent to users, and the password_resets table stores tokens for password reset requests. The performance_indicators table contains metrics about the system's performance, including recurring revenue and new user growth. Subscriptions for both users and teams are stored in the subscriptions and team_subscriptions tables, respectively, and the team_users table links users to the teams they belong to.
