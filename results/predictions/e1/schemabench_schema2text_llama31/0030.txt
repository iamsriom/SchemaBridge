The schemabench_0030 database is designed to manage user authentication and push notification devices. At its core, the database contains a table called auth_user, which stores information about each user, including their unique identifier, password, last login date, and various status flags such as whether they are a superuser, staff member, or active. The auth_user table has a primary key on the id column, ensuring that each user is uniquely identified. The push_notifications_apnsdevice, push_notifications_gcmdevice, push_notifications_webpushdevice, and push_notifications_wnsdevice tables store information about different types of push notification devices, including their names, active status, creation dates, and registration IDs. Each of these tables has a foreign key referencing the id column in the auth_user table, establishing a relationship between a user and their associated devices. The push_notifications_apnsdevice table also has a device_id column, which is a character string, and a registration_id column, which is a string of up to 255 characters, while the push_notifications_gcmdevice table has a device_id column with a larger capacity and a registration_id column that can store much longer strings. The push_notifications_webpushdevice table includes additional columns for p256dh, auth, browser, and registration_id, which are all strings, while the push_notifications_wnsdevice table has a device_id column and a registration_id column with a large capacity. All of these tables have a primary key on the id column, ensuring that each device is uniquely identified.
