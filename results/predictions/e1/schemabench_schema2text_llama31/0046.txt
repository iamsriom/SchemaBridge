The schemabench_0046 database is designed to manage various aspects of a customer support platform, including user accounts, conversations, messages, and integrations with different channels such as email, Facebook, Twitter, and Telegram. The database consists of 27 tables, each representing a specific entity or relationship within the platform. The access_tokens table stores information about access tokens, including the owner type, owner ID, token, creation and update timestamps, and is the primary key. The account_users table links users to their respective accounts, with foreign keys referencing the users and accounts tables. The accounts table stores information about each account, including the account ID, name, creation and update timestamps, and locale. The active_storage_attachments table stores information about uploaded files, including the attachment ID, name, record type, record ID, blob ID, and creation timestamp, with a foreign key referencing the active_storage_blobs table. The active_storage_blobs table stores information about the actual files, including the blob ID, key, filename, content type, metadata, byte size, checksum, and creation timestamp. The agent_bot_inboxes table links agent bots to their respective inboxes, with foreign keys referencing the agent_bots and inboxes tables. The agent_bots table stores information about each agent bot, including the bot ID, name, description, outgoing URL, creation and update timestamps. The attachments table stores information about attachments, including the attachment ID, file type, external URL, coordinates, message ID, account ID, creation and update timestamps, fallback title, and extension, with foreign keys referencing the messages and accounts tables. The canned_responses table stores pre-defined responses, including the response ID, account ID, short code, content, creation and update timestamps, with a foreign key referencing the accounts table. The channel_facebook_pages table stores information about Facebook pages, including the page ID, user access token, page access token, account ID, creation and update timestamps, with a foreign key referencing the accounts table. The channel_twilio_sms table stores information about Twilio SMS channels, including the phone number, auth token, account SID, account ID, creation and update timestamps, with a foreign key referencing the accounts table. The channel_twitter_profiles table stores information about Twitter profiles, including the profile ID, Twitter access token, Twitter access token secret, account ID, creation and update timestamps, with a foreign key referencing the accounts table. The channel_web_widgets table stores information about web widgets, including the website name, website URL, account ID, creation and update timestamps, website token, and widget color, with a foreign key referencing the accounts table. The contact_inboxes table links contacts to their respective inboxes, with foreign keys referencing the contacts and inboxes tables. The contacts table stores information about each contact, including the contact ID, name, email, phone number, account ID, creation and update timestamps, pubsub token, source ID, identifier, and additional attributes, with a foreign key referencing the accounts table. The conversations table stores information about conversations, including the conversation ID, account ID, inbox ID, status, assignee ID, creation and update timestamps, contact ID, display ID, user last seen at, agent last seen at, locked, and additional attributes, with foreign keys referencing the inboxes, contacts, and accounts tables. The events table stores information about events, including the event ID, name, value, account ID, inbox ID, user ID, conversation ID, creation and update timestamps, with foreign keys referencing the inboxes, users, accounts, and conversations tables. The inbox_members table links users to their respective inboxes, with foreign keys referencing the users and inboxes tables. The inboxes table stores information about each inbox, including the inbox ID, channel ID, account ID, name, creation and update timestamps, channel type, and enable auto assignment, with a foreign key referencing the accounts table. The messages table stores information about messages, including the message ID, content, account ID, inbox ID, conversation ID, message type, creation and update timestamps, private, user ID, status, source ID, content type, content attributes, and contact ID, with foreign keys referencing the contacts, inboxes, conversations, accounts, and users tables. The notification_settings table stores information about notification settings, including the setting ID, account ID, user ID, email flags, creation and update timestamps, with foreign keys referencing the users and accounts tables. The subscriptions table stores information about subscriptions, including the subscription ID, pricing version, account ID, expiry, billing plan, Stripe customer ID, creation and update timestamps, state, and payment source added, with a foreign key referencing the accounts table. The taggings table stores information about tags, including the tagging ID, tag ID, taggable type, taggable ID, tagger type, tagger ID, context, and creation timestamp, with a foreign key referencing the tags table. The tags table stores information about each tag, including the tag ID, name, and taggings count. The telegram_bots table stores information about Telegram bots, including the bot ID, name, auth key, account ID, creation and update timestamps, with a foreign key referencing the accounts table. The users table stores information about each user, including the user ID, provider, user ID, inviter, encrypted password, reset password token, reset password sent at, remember created at, sign in count, current sign in at, last sign in at, current sign in IP, last sign in IP, confirmation token, confirmed at, confirmation sent at, unconfirmed email, name, nickname, email, tokens, creation and update timestamps, and pubsub token, with a foreign key referencing the users table. The webhooks table stores information about webhooks, including the webhook ID, account ID, inbox ID, URL, creation and update timestamps, and webhook type, with foreign keys referencing the inboxes and accounts tables.
