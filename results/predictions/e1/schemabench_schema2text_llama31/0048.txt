The schemabench_0048 database is designed to manage user accounts and their associated information. The account table stores details about each account, with a unique identifier, email address, and date of creation, as well as optional fields for a Stripe customer ID, subscription ID, plan, referrer, and active status. The account ID is the primary key, ensuring each account has a distinct and unique identifier. The invite table tracks invitations sent to users, with a unique ID, optional invite ID, email address, account ID, date sent, and a flag indicating whether the invitation has been used. The account ID in the invite table references the account ID in the account table, establishing a relationship between the two, and the foreign key constraint is set to cascade updates and deletes, meaning that if an account is deleted, any associated invitations will also be deleted. The user table stores information about individual users, with a unique identifier, name, email address, password, date of creation, last login date, permission level, and push token, as well as an account ID that references the account ID in the account table, establishing a one-to-one relationship between users and accounts.
