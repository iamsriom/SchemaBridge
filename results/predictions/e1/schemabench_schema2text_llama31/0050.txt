The schemabench_0050 database is designed to manage various aspects of a business, including customer interactions, team management, and task assignments. The database consists of 22 tables that work together to store and retrieve data. The attachments table stores files associated with various entities, with each attachment having a unique ID, path, and reference to the entity it belongs to. The comments table contains customer feedback and comments on tickets, with each comment linked to a specific ticket and user. The failed jobs table tracks any errors that occur during the execution of background tasks. The ideas table stores suggestions and ideas submitted by customers, with each idea linked to a requester and having various attributes such as status, title, and due date. The kpis table tracks key performance indicators, with each indicator having a date, type, and relation ID. The lead status updates table stores updates made to customer leads, with each update linked to a lead and user. The leads table contains information about customer leads, including their email, status, and team assignment. The memberships table tracks team membership, with each member linked to a user and team. The merged tickets table stores information about merged tickets, with each merged ticket linked to the original ticket and the merged ticket. The migrations table tracks database migrations, with each migration having a unique ID and batch number. The password resets table stores reset tokens for user passwords. The requesters table contains information about customers who have submitted ideas, with each requester having a unique ID, name, and email. The settings table stores global settings for the application, including the default team ID and Slack webhook URL. The taggables table links tags to leads and tickets, with each taggable item having a unique ID and type. The tags table stores tags used to categorize leads and tickets, with each tag having a unique ID and name. The tasks table contains tasks assigned to users, with each task linked to a lead and user. The teams table stores information about teams, including their name, email, and Slack webhook URL. The ticket events table stores events related to tickets, with each event linked to a ticket and user. The ticket types table stores types of tickets, with each type having a unique ID, name, and color. The tickets table contains information about tickets, including their title, body, and status. The user settings table stores user-specific settings, including notification preferences and signature. The users table contains information about users, including their name, email, and password.
