The schemabench_0064 database is used to track various aspects of user interactions with a system, including the devices they use, the paths they take, and the queries they execute. The tracker_agents table stores information about the browsers and their versions used by users, while the tracker_devices table contains details about the devices themselves, including their kind, model, platform, and platform version. The tracker_sessions table links these devices to user sessions, which are identified by a unique UUID and can be associated with a user ID, a device ID, an agent ID, a client IP address, a referer ID, a cookie ID, a geoip ID, and a language ID. The tracker_sessions table also includes information about whether the session is from a robot. The tracker_log table stores information about each log entry, including the session ID, path ID, query ID, method, route path ID, and error ID, as well as whether the request was made via AJAX, was secure, was JSON, or wanted JSON. The tracker_referers table contains information about the domains and URLs that refer users to the system, including the domain ID, URL, host, medium, source, and search terms hash. The tracker_referers_search_terms table stores individual search terms used by users. The tracker_route_paths table links route IDs to path IDs, while the tracker_route_path_parameters table stores the parameters and values for each route path. The tracker_routes table contains information about the routes themselves, including the name and action. The tracker_sql_queries table stores information about SQL queries executed by the system, including the SHA1 hash, statement, time taken, and connection ID. The tracker_sql_queries_log table links log entries to SQL queries, while the tracker_sql_query_bindings table stores serialized bindings for SQL queries. The tracker_sql_query_bindings_parameters table stores the parameters and values for each SQL query binding. The tracker_system_classes table contains information about system classes, including the name. The tracker_errors table stores information about errors that occur, including the code and message. The tracker_events table stores information about events, including the name. The tracker_events_log table links events to log entries and classes. The tracker_geoip table stores information about the geographic location of users, including latitude, longitude, country code, and city. The tracker_languages table stores information about user languages, including the preference and language range. The tracker_domains table stores information about domains, including the name. The tracker_connections table stores information about connections, including the name. The tracker_cookies table stores information about cookies, including the UUID. The tracker_paths table stores information about paths, including the path. The tracker_queries table stores information about queries, including the query.
