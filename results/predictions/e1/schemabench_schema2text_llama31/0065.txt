The schemabench_0065 database is used to manage various aspects of payment processing and billing. It contains 14 tables that store information about billing agreements, billing plans, payment definitions, charges, disputes, payers, payments, refunds, sales, and webhooks. The djpaypal_billingagreement table stores details about billing agreements, including the agreement's ID, name, state, description, and payer information. Each billing agreement is linked to a billing plan in the djpaypal_billingplan table, which contains information about the plan's ID, name, description, type, and state. The djpaypal_billingplan_payment_definitions table acts as a bridge between billing plans and payment definitions, linking a billing plan to a payment definition in the djpaypal_paymentdefinition table, which stores details about the payment definition's ID, name, type, frequency, and amount. The djpaypal_chargemodel table stores information about charge models, including the model's ID, type, and amount. The djpaypal_dispute table stores details about disputes, including the dispute's ID, reason, status, and disputed transactions. The djpaypal_payer table stores information about payers, including the payer's ID, first name, last name, email, and shipping address. The djpaypal_payment table stores details about payments, including the payment's ID, intent, cart, and transactions. The djpaypal_refund table stores information about refunds, including the refund's ID, amount, reason, and parent payment ID. The djpaypal_sale table stores details about sales, including the sale's ID, amount, payment mode, and state. The djpaypal_webhookevent table stores information about webhooks, including the event's ID, event type, and resource. The djpaypal_webhookeventtrigger table stores details about webhook triggers, including the trigger's ID, remote IP, headers, and body. The djpaypal_preparedbillingagreement table stores information about prepared billing agreements, including the agreement's ID, data, and executed agreement ID. The djpaypal_paymentdefinition_charge_models table stores a link between payment definitions and charge models. The djpaypal_paymentdefinition table has a foreign key referencing djpaypal_chargemodel, and djpaypal_billingagreement has a foreign key referencing djpaypal_billingplan. The djpaypal_refund table has foreign keys referencing djpaypal_payment and djpaypal_sale. The djpaypal_sale table has a foreign key referencing djpaypal_payment. The djpaypal_webhookeventtrigger table has a foreign key referencing djpaypal_webhookevent.
