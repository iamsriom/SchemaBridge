The schemabench_0076 database is designed to manage and track the status of checks and their associated hosts. The checks table stores information about each check, including its unique identifier, the host it belongs to, the type of check, its current status, whether it is enabled or not, and details about its last run, such as the message, output, and timestamp. The host_id field references the id field in the hosts table, establishing a relationship between the two tables. The hosts table contains information about each host, including its unique identifier, name, SSH user, port, IP address, and custom properties. The custom_properties field in both tables stores additional data in JSON format, allowing for flexible and dynamic storage of metadata. The created_at and updated_at fields in both tables track when each record was created and last updated, respectively. The checks table also includes a boolean field to indicate whether the check is enabled, and fields to track when it was last run and when it is scheduled to run again.
