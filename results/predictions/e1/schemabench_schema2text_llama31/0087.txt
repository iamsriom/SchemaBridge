The schemabench_0087 database is designed to manage customer information and their associated subscriptions, receipts, and billing details. At its core, the database contains a table called 'users/teams' which stores unique identifiers for users and teams, represented by a single column 'id' of type BIGINT UNSIGNED, which is the primary key and auto-increments for each new entry. The 'customers' table is linked to 'users/teams' through a foreign key 'billable_id', indicating that a customer is associated with a specific user or team. This table also includes columns for tracking trial end dates, last update and creation times, and 'billable_type' which specifies whether the customer is a user or a team. The 'subscriptions' table is another key component, storing details about the subscriptions of customers, including the 'billable_id' and 'billable_type' referencing the 'users/teams' table, as well as subscription name, Paddle ID, status, plan, quantity, trial end dates, and last update and creation times. The 'receipts' table is used to store payment information, with columns for the 'billable_id' and 'billable_type' referencing 'users/teams', Paddle subscription ID, checkout and order IDs, amount, tax, currency, quantity, receipt URL, and paid date, as well as last update and creation times. All tables have a foreign key 'billable_id' referencing 'users/teams', indicating that each customer, subscription, and receipt is associated with a specific user or team.
