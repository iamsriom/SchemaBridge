At its core, the database contains information about users, which are identified by a unique id and can be assigned a level, represented by the levels table, which stores the level number and the experience points required to advance to the next level. Users can earn experience points through various activities, which are tracked in the experiences table, which links users to levels and records the experience points earned. The streaks table keeps track of the number of consecutive days a user has performed a specific activity, while the streak histories table stores a record of all streaks a user has achieved. The streak activities table lists the different types of activities that can be tracked. The achievements table stores information about the different achievements that can be unlocked by users, and the achievement_user table links users to the achievements they have unlocked, along with their progress towards completing the achievement. The experience audits table records any changes to a user's experience points, including when they level up and why.
