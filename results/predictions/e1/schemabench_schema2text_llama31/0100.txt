The schemabench_0100 database is designed to store data related to household expenditures and demographics. The EXPENDITURES table contains information about specific expenditures, with each expenditure identified by a unique EXPENDITURE_ID, which is a 11-character string and the primary key of the table. Each expenditure is associated with a HOUSEHOLD_ID, a 10-character string that references the HOUSEHOLDS table, and is linked to a specific year and month. The table also includes the product code, cost, and whether the expenditure was a gift or not, with the latter being an integer value that defaults to 1 if not specified. The HOUSEHOLDS table stores information about households, with each household identified by a unique HOUSEHOLD_ID, a 10-character string and the primary key of the table. Each household is associated with a year, income rank, and various income ranks for different categories, as well as the age of the reference person. The HOUSEHOLD_MEMBERS table contains demographic information about the members of each household, with each member identified by a HOUSEHOLD_ID and year, and linked to the HOUSEHOLDS table through the HOUSEHOLD_ID. The table also includes the marital status, sex, age, and work status of each member, with the work status being optional and defaulting to null if not specified.
