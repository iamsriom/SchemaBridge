The schemabench_0101 database is a comprehensive data repository that stores information about countries and their indicators over time. The database consists of four main tables: Data, Metadata - Countries, Metadata - Indicators, and target. The Data table contains historical data for various indicators across different countries, with each row representing a specific country and indicator, and columns representing the years from 1960 to 2011. The Country Code and Indicator Code columns serve as the primary key, uniquely identifying each country and indicator combination. The Indicator Code column is also referenced in the Metadata - Indicators table, where each indicator is uniquely identified by its INDICATOR_CODE, and its name, source note, and source organization are stored. The Metadata - Countries table stores information about each country, including its code, name, region, income group, and special notes. The Country Code column in this table is referenced in the Data and target tables, which means that each country's data is linked to its corresponding country information. The target table contains data for the year 2012, with each row representing a country and its corresponding value for that year. The foreign key constraints ensure that data is deleted or updated consistently across the database, with the CASCADE rule applied to both the Data and target tables when a country or indicator is deleted or updated in the Metadata - Countries or Metadata - Indicators tables, respectively.
