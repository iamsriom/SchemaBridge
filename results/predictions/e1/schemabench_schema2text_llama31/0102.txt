The schemabench_0102 database is designed to store information about breweries and their beers. The breweries table contains details about each brewery, including its unique identifier, name, city, and state. The id column in the breweries table serves as the primary key, ensuring that each brewery is uniquely identified. The name, city, and state columns allow for a brief description of each brewery, and they can be left blank if not applicable. The beers table, on the other hand, stores information about individual beers, including their unique identifier, brewery identifier, alcohol by volume (abv), International Bitterness Unit (ibu), name, style, and ounces. The id column in the beers table is the primary key, uniquely identifying each beer. The brewery_id column references the id column in the breweries table, establishing a relationship between a beer and its brewery. The abv, ibu, and ounces columns allow for precise measurements, and the name and style columns provide a brief description of each beer. The name column in the beers table is required, while the abv, ibu, style, and ounces columns can be left blank if not applicable. The foreign key constraint on the brewery_id column in the beers table ensures that each beer is associated with an existing brewery, and the ON DELETE RESTRICT rule prevents the deletion of a brewery if it has associated beers.
