The schemabench_0106 database is designed to store information about Formula 1 racing, encompassing various aspects of the sport, including circuits, constructors, drivers, and races. The database contains 14 tables, each representing a distinct entity within the racing world. The circuits table stores information about the locations where the races take place, including their unique identifier, reference, name, location, country, latitude, longitude, altitude, and URL. The constructors table holds details about the teams that participate in the racing, such as their identifier, reference, name, nationality, and URL. The drivers table contains information about the drivers, including their identifier, reference, number, code, forename, surname, date of birth, nationality, and URL. The races table stores information about the individual races, including their identifier, year, round, circuit identifier, name, date, time, and URL. The seasons table contains a list of years for which racing data is available, with each year serving as a primary key. The status table stores a list of possible statuses that a race can have, such as "Finished" or "Not Started". The results table holds the outcome of each race, including the identifier, race identifier, driver identifier, constructor identifier, grid position, finishing position, points earned, and other relevant details. The constructorResults table stores the points earned by each constructor in each race, while the driverStandings table stores the points earned by each driver in each race. The constructorStandings table stores the points earned by each constructor in each race, as well as their position and wins. The qualifying table stores the results of each qualifying session, including the identifier, race identifier, driver identifier, constructor identifier, and position. The lapTimes table stores the lap times for each driver in each race, including the race identifier, driver identifier, lap number, position, time, and milliseconds. The pitStops table stores the pit stop data for each driver in each race, including the race identifier, driver identifier, stop number, lap number, time, duration, and milliseconds. The target table stores the target data for each driver in each race, including the target identifier, race identifier, driver identifier, and win count. The database also includes several foreign keys to establish relationships between the tables, ensuring data consistency and integrity. For example, the constructorResults table references the constructors and races tables, indicating that the points earned by a constructor in a race are linked to the constructor and the race in which they were earned. Similarly, the results table references the constructors, drivers, and races tables, indicating that the outcome of a race is linked to the constructor, driver, and race involved. The database also includes several indexes and constraints to ensure data consistency and integrity, such as primary keys, unique constraints, and foreign key constraints with ON DELETE and ON UPDATE rules.
