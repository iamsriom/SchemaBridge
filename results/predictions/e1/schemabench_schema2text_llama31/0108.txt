The schemabench_0108 database is designed to store information about genes and their interactions. The Classification table contains a list of unique gene identifiers, each associated with a specific localization, which serves as the primary key for the database. The Genes table holds detailed information about each gene, including its essentiality, class, complex, phenotype, motif, chromosome, function, and localization, with the GeneID from the Classification table serving as a foreign key that links each gene to its corresponding classification. The Interactions table stores information about the relationships between different genes, with each interaction represented by two GeneIDs from the Classification table, which are used as a composite primary key to uniquely identify each interaction, and a type and expression correlation value. The GeneIDs in the Interactions table are also foreign keys that reference the GeneID in the Classification table, with an ON DELETE CASCADE rule, meaning that if a gene is deleted from the Classification table, all interactions involving that gene will also be deleted.
