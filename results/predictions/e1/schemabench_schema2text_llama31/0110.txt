The schemabench_0110 database is designed to store information about awards, organizations, institutions, investigators, and programs. The awards table contains details about each award, including the title, effective and expiration dates, amount, instrument, and abstract narration, as well as the organization code and program officer. The organization table stores information about organizations, including their code, division, and directorate, while the institution table holds details about institutions, such as their name, city, zip code, contact, address, country, and state. The foa_info table lists FOA (Funding Opportunity Announcement) codes and names, and the foa_info_awards table links these codes to specific awards. The institution_awards table associates awards with institutions, and the investigator_awards table links awards to investigators, including their email, start and end dates, and role code. The program_element and program_reference tables store program codes and their corresponding texts, and the program_element_awards and program_reference_awards tables connect these codes to specific awards. Each award is uniquely identified by its award_id, which is a primary key in the awards table and referenced in several other tables, including foa_info_awards, institution_awards, investigator_awards, program_element_awards, and program_reference_awards. The organization code in the awards table references the code in the organization table, and the name and zip code in the institution_awards table reference the name and zip code in the institution table, ensuring data consistency and integrity across the database.
