The schemabench_0130 database is designed to store data related to online posts and user interactions. The database consists of eight tables: badges, comments, postHistory, postLinks, posts, tags, users, and votes. The badges table stores information about the badges earned by users, with each badge having a unique ID, a user ID referencing the user who earned it, a name, and a date. The comments table stores comments made on posts, with each comment having a unique ID, a post ID referencing the post it was made on, a score, text, creation date, user ID, and user display name. The postHistory table stores a history of changes made to posts, with each entry having a unique ID, a post ID referencing the post it was made on, a revision GUID, creation date, user ID, text, comment, and user display name. The postLinks table stores links between posts, with each link having a unique ID, creation date, post ID, related post ID, and link type ID. The posts table stores information about individual posts, with each post having a unique ID, post type ID, accepted answer ID, creation date, score, view count, body, owner user ID, last activity date, title, tags, answer count, comment count, favorite count, last editor user ID, last edit date, community owned date, parent post ID, closed date, owner display name, and last editor display name. The tags table stores information about tags used in posts, with each tag having a unique ID, tag name, count, excerpt post ID, and wiki post ID. The users table stores information about users, with each user having a unique ID, reputation, creation date, display name, last access date, website URL, location, about me, views, up votes, down votes, account ID, age, and profile image URL. The votes table stores votes cast on posts, with each vote having a unique ID, post ID, vote type ID, creation date, user ID, and bounty amount.
