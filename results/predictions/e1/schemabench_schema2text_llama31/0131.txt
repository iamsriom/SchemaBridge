The schemabench_0131 database is designed to manage a complex system for managing customers, orders, and inventory across multiple warehouses. At the core of this system is the C_Customer table, which stores information about individual customers, including their ID, district ID, warehouse ID, name, address, phone number, and credit information. The primary key for this table is a composite of the customer ID, district ID, and warehouse ID, ensuring that each customer is uniquely identified within their respective district and warehouse. The c_d_id column references the C_District table, which stores information about each district, including its ID, warehouse ID, name, and address. The district ID is used to link customers to their respective districts. The C_Warehouse table stores information about each warehouse, including its ID, name, address, and tax rate. The district ID in the C_District table references the warehouse ID in the C_Warehouse table, establishing a hierarchical relationship between districts and warehouses. The C_History table stores a record of all transactions, including the customer ID, district ID, warehouse ID, date, amount, and other relevant details. The C_Item table stores information about each item in stock, including its ID, name, price, and other details. The C_Order table stores information about each order, including the order ID, district ID, warehouse ID, customer ID, entry date, and other details. The C_Order_Line table stores information about each line item in an order, including the order ID, district ID, warehouse ID, item ID, quantity, and other details. The C_Stock table stores information about the current stock levels of each item in each warehouse, including the item ID, warehouse ID, quantity, and other details. The s_i_id column in the C_Stock table references the item ID in the C_Item table, establishing a link between the stock levels and the items themselves. The s_w_id column in the C_Stock table references the warehouse ID in the C_Warehouse table, establishing a link between the stock levels and the warehouses. The C_New_Order table is a redundant table that references the C_Order table, but is not used in the schema.
