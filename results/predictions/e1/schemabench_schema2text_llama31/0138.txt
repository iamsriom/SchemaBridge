The schemabench_0138 database is designed to manage information about courses and the people involved in teaching them. The database contains four main tables: advisedBy, course, person, and taughtBy. The advisedBy table tracks the relationships between people, where each pair of people is linked by a primary key composed of two columns, p_id and p_id_dummy, both of which reference the person table. The person table stores information about each individual, including their professor, student, and hasPosition status, with each of these fields having a default value of '0' if not specified. The course table holds details about the courses, with a unique course_id serving as the primary key and a courseLevel field that can be null if not provided. The taughtBy table links courses with the people who teach them, with a primary key composed of the course_id and p_id, and both of these fields referencing the course and person tables, respectively, with the relationships being set to cascade in case of updates or deletions.
