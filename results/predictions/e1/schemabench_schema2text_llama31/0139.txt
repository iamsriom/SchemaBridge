The schemabench_0139 database is a structured repository for storing and organizing image-based data, specifically designed to manage relationships between images, objects, and their attributes. At its core, the database consists of six tables: ATT_CLASSES, IMG_OBJ, IMG_OBJ_ATT, IMG_REL, OBJ_CLASSES, and PRED_CLASSES. The ATT_CLASSES table stores unique attribute classes with a unique identifier, ATT_CLASS_ID, and a descriptive name, ATT_CLASS. The OBJ_CLASSES table is a similar repository for object classes, containing an OBJ_CLASS_ID and a corresponding OBJ_CLASS name. In contrast, the PRED_CLASSES table holds a list of prediction classes, each with a unique PRED_CLASS_ID and a descriptive name, PRED_CLASS. The IMG_OBJ table is a central hub for image data, linking images to their respective object samples through the OBJ_SAMPLE_ID, and also referencing the object class they belong to via OBJ_CLASS_ID. The IMG_OBJ_ATT table bridges the gap between image objects and attribute classes, establishing a many-to-many relationship between them. The IMG_REL table, meanwhile, captures relationships between images, object samples, and prediction classes, with each relationship defined by a unique combination of image ID, prediction class ID, and object sample IDs.
