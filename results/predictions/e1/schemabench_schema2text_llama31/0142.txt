The schemabench_0142 database is designed to track citations between web pages, with the primary purpose of maintaining a record of which web pages reference other web pages. The database consists of three tables: webpage, content, and cites. The webpage table stores information about individual web pages, with each page identified by a unique webpage_id, which is a string of up to 255 characters. The class_label field, also a string of up to 255 characters, can be left blank if not specified. The content table links specific words to web pages, with each word identified by a unique word_cited_id, which is also a string of up to 255 characters, and the webpage to which it belongs, identified by webpage_id. The cites table, on the other hand, records the citations between web pages, with each citation referencing a cited paper, identified by cited_paper_id, and a citing paper, identified by citing_paper_id. Both cited_paper_id and citing_paper_id are strings of up to 255 characters and are the primary key for the cites table. The webpage_id in the cites table references the webpage table, ensuring that only valid webpage IDs can be used, and the relationships between citations are maintained through the use of foreign keys, which also enforce the rule that when a webpage is deleted, all its citations are automatically deleted, and when a citation is deleted, the webpage it references is also automatically deleted.
