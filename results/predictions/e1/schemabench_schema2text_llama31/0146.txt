The schemabench_0146 database is designed to manage various aspects of a booking and accommodation management system. At its core, it contains a table for payments, which stores information about financial transactions, including the reservation ID, user ID, amount, payment date, and status. Each payment is linked to a reservation through the reservation ID, and also to a user through the user ID. The database also includes a table for amenities, which lists the available amenities with a unique name. Users are stored in a separate table, which includes their name, email, password, and other details, with a unique email address and a timestamp for email verification. Promotions are stored in another table, which includes a unique code, discount percentage, start and end dates, and can be applied to reservations. User notifications are stored in a table that links to the users table, allowing for notifications to be sent to specific users. Reviews and their associated media are stored in separate tables, with reviews linked to reservations and media linked to the reviews. Reservations are stored in a table that links to users and rooms, with details such as start and end dates, price, and total. Wishlists are also stored in a table that links to users, allowing users to save rooms they are interested in. Room amenities are stored in a table that links rooms to amenities, and messages are stored in a table that links to users, reservations, and other users. Media is stored in a table that links to various models, and reviews are stored in a table that links to reservations. Finally, reservations can be associated with promotions, and users can save rooms in their wishlists.
