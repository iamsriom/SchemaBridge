The schemabench_0147 database is designed to manage user interactions and content within a social media platform. At its core, the User table stores information about each registered user, including their email address, username, and password, with a unique identifier for each user. The Profile table complements the User table by storing additional details such as the user's name, bio, profile picture, website, and date of birth, linked to the corresponding user through a unique foreign key. The Post table represents the content shared by users, including the post's content, the user who created it, and the parent post if it's a reply to another post. Users can also create Reposts, which are essentially copies of existing posts, and these reposts are linked to the original post through a foreign key. The Like table tracks which users have liked a particular post, and the Message table stores direct messages between users, with a foreign key referencing the user who sent the message. The Chat table represents group conversations, linking users who are participating in a chat. The UserFollows table allows users to follow other users, creating a many-to-many relationship between followers and followees. The Notification table sends notifications to users when they are mentioned or interact with content, with foreign keys referencing the sender and recipient of the notification. Finally, the Session table stores information about user sessions, including a unique refresh token, expiration time, and the user ID, ensuring secure and authenticated access to the platform.
