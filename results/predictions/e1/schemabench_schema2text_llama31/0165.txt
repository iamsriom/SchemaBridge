The schemabench_0165 database is designed to store information about athletes, coaches, events, and other related data. The athlete table contains detailed information about each athlete, including their code, name, function, country, height, weight, birth date, and other personal details. The coach table stores information about coaches, including their code, name, function, category, country, and disciplines they specialize in. The event table contains information about each event, including its name, tag, sport, and sport code. The medalist table stores information about medal winners, including the date they won the medal, the type of medal, their name, country, and event details. The medal table contains a summary of medals won by each country, including the type of medal, code, date, and event details. The medal_total table stores the total number of gold, silver, and bronze medals won by each country. The schedule table contains information about the schedule of events, including the start and end dates, status, discipline, and event details. The schedule_preliminary table stores preliminary information about the schedule, including the estimated start time, venue, and event details. The team table stores information about each team, including their code, name, country, discipline, and athletes and coaches associated with them. The torch_route table stores information about the torch relay route, including the title, city, start and end dates, and tag. The venue table contains information about each venue, including its name, sports, and start and end dates.
