The schemabench_0166 database is designed to manage various aspects of a retail business, including products, customers, employees, payments, and sales transactions. The database consists of 16 tables, each representing a distinct entity within the business. The BRAND table stores information about different brands, with a unique brand ID and name, as well as an optional email address. The COLOR table contains a list of available colors, identified by a six-character code and a descriptive name. The CATEGORY table categorizes products, with each category having a unique ID and name. The SIZE table lists available product sizes, with a two-character code and a description. The GENDER table stores information about product genders, with a unique ID and name. The TYPE table links products to categories, with a unique ID, name, and a foreign key referencing the CATEGORY table. The PRODUCT table stores detailed information about each product, including its ID, type, size, color, name, brand, gender, description, and prices. The EMPLOYEE and CUSTOMER tables store employee and customer information, respectively, with unique IDs, names, dates of birth, emails, and phone numbers. The CCPAYMENT_STATE table lists possible payment states, with a one-character code and description. The CCPAYMENT table manages payment transactions, with a unique ID, payment type, expected, approved, and actual amounts, as well as timestamps for creation, update, and expiration. The CCPAYMENT_TYPE table lists payment types, with a two-character code and description. The CCENTRY_METHOD table stores entry methods, with a one-character code and description. The CCPAYMENT_CARD table stores payment card information, with a unique payment ID, payment type, encryption status, card number, bank name, expiration date, and entry method. The TICKET table stores sales transactions, with a unique ID, timestamps, employee and customer IDs, total product, tax, and order amounts, as well as a foreign key referencing the CCPAYMENT table. The TICKET_ITEM table links sales transactions to products, with a unique ticket ID, sequence number, product ID, quantity, price, tax amount, and product amount.
