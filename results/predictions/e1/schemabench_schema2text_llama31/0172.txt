The schemabench_0172 database is designed to manage various social media features, including users, publishers, friendships, pages, groups, chats, multimedia content, activities, posts, comments, reactions, events, and event participants. The database consists of 17 tables, each representing a distinct entity. The Publisher table stores information about publishers, with a unique publisher ID and name, which is a required field. The User table represents individual users, with a unique user ID, phone number, gender, birth date, age, and address, with the age being at least 13 years old. The User table also has a unique constraint on the phone number and a foreign key referencing the Publisher table, indicating that a user can be a publisher. The Friendship table stores friendships between users, with a composite primary key of sender and receiver IDs, and foreign keys referencing the User table. The Page table represents social media pages, with a unique page ID, website, and an admin ID that references the User table. The PageFollower table stores followers of pages, with a composite primary key of follower and page IDs, and foreign keys referencing the User and Page tables. The Group table represents social media groups, with a unique group ID, name, and an admin ID that references the User table. The GroupMember table stores group members, with a composite primary key of member and group IDs, and foreign keys referencing the User and Group tables. The Chat table represents chat rooms, with a unique chat ID and name, and the ChatParticipant table stores participants in chats, with a composite primary key of participant and chat IDs, and foreign keys referencing the User and Chat tables. The Multimedia table stores multimedia content, with a unique multimedia ID, title, URI, size, format, and length, with constraints on the size and format. The Activity table represents activities, with a unique activity ID, activity text, and date, and the Message table stores messages, with a unique message ID, date sent, multimedia ID, author ID, and chat ID, with foreign keys referencing the Multimedia, User, and Chat tables. The Post table represents posts, with a unique post ID, publisher ID, multimedia ID, page ID, and group ID, with foreign keys referencing the Publisher, Multimedia, Page, and Group tables. The Comment table stores comments, with a unique comment ID, author ID, and post ID, with foreign keys referencing the User and Post tables. The Reaction table represents reactions, with a composite primary key of activity and user IDs, and foreign keys referencing the Activity and User tables. The Event table represents events, with a unique event ID, name, description, occurrence date, and creator ID, with a foreign key referencing the User table. Finally, the EventParticipant table stores event participants, with a composite primary key of participant and event IDs, and foreign keys referencing the User and Event tables.
