The schemabench_0174 database is designed to manage the operations and information of a hospital. It consists of 15 tables that store data about physicians, departments, medical procedures, patients, nurses, appointments, medications, and hospital rooms. The physician table contains information about each doctor, including their employee ID, name, position, and social security number. The department table stores details about each department, such as its ID, name, and head. The affiliated_with table links physicians to the departments they are affiliated with, while the trained_in table records the medical procedures each physician is certified in. The patient table holds information about each patient, including their social security number, name, address, phone number, insurance ID, and primary care physician ID. The nurse table stores details about each nurse, including their employee ID, name, position, registration status, and social security number. The appointments table schedules appointments for patients, including the patient's ID, nurse's ID, physician's ID, start and end times, and examination room. The medication table lists available medications, including their code, name, brand, and description. The prescribes table records the medications prescribed to patients, including the physician's ID, patient's ID, medication ID, date, appointment ID, and dose. The block table represents the hospital's layout, with each block consisting of a floor ID and a block code ID. The room table stores information about each room, including its number, type, block floor ID, block code ID, and availability status. The on_call table tracks which nurse is on call for each block and floor. The stay table records the duration of each patient's stay in the hospital, including their ID, patient ID, room ID, start and end times. The undergoes table tracks the medical procedures each patient undergoes, including their ID, patient ID, procedure ID, stay ID, date, physician ID, and assisting nurse ID.
