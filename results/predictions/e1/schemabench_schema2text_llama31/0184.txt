The schemabench_0184 database is designed to manage information about users, restaurants, food items, customer service interactions, and orders. The User table stores details about each individual, including their phone number, password, email, name, date of birth, and address. The Food table contains information about the various food items available, including their name, price, availability, rating, quantity, and description. The Restaurant table holds details about each restaurant, such as its name, founding date, address, rating, and description. The CustomerService table tracks customer inquiries, including the email and name of the customer, the inquiry itself, its status, and the date it was submitted. The OrderHistory table stores information about each order, including the user who made it, the total price, and the date it was placed, referencing the User table for the user's details. The Products table links users to the orders they have made, referencing both the User and OrderHistory tables. The Interacts table tracks interactions between customers and customer service, referencing both the CustomerService and User tables. The Buys table shows which users have purchased which food items, referencing both the User and Food tables. Finally, the Sells table tracks which restaurants sell which food items, referencing both the Restaurant and Food tables.
