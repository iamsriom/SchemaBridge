The schemabench_0190 database is designed to manage user interactions with online content. At its core, it contains a table for users, where each user is identified by a unique username, which must be between 1 and 25 characters long, and a timestamp of their last login. The topic table stores information about different topics, with each topic having a unique name, a brief description, and a timestamp of when it was created. The post table represents individual posts, which can have a title, a URL, and a text content, and are associated with a specific user and topic. Each post is also linked to a user through a foreign key that allows for null values in case the user is deleted, but will cascade delete the post if the user is removed. The comment table stores comments made by users on posts, with each comment having a text content, a timestamp, and links to the parent comment, the user who made the comment, and the post it was made on. The vote table tracks user votes on posts, with each vote being either 1 or -1, and is linked to the user who made the vote and the post being voted on, with the user foreign key allowing for null values in case the user is deleted, but the post will be deleted if the user is removed.
