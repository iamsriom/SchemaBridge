The schemabench_0195 database is a comprehensive system for managing orders and their associated data. At its core, the database contains information about runners, who are tracked through the 'runners' table, which stores each runner's unique identifier and their registration date. The 'customer_orders' table represents all orders placed by customers, including the order ID, customer ID, pizza ID, any exclusions from the order, any extras added to the order, and the time the order was placed. The 'runner_orders' table keeps track of the orders assigned to each runner, including the order ID, runner ID, pickup time, distance traveled, duration of the delivery, and any cancellation information. The 'pizza_recipes' table contains details about the ingredients used in each pizza, identified by a unique pizza ID and a string of toppings. The 'pizza_names' table provides a list of names for each pizza, linked to their respective pizza IDs, and the 'pizza_toppings' table lists the available toppings, each with a unique topping ID and name. The relationships between these tables are established through foreign keys: the 'customer_orders' table references the 'runners' table through the runner ID, the 'runner_orders' table references the 'customer_orders' table through the order ID and the 'runners' table through the runner ID, the 'pizza_recipes' table references the 'pizza_names' table through the pizza ID, and the 'pizza_names' table references the 'pizza_recipes' table through the pizza ID.
