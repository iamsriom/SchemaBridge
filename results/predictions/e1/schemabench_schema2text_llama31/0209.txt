The schemabench_0209 database is designed to manage information about students, courses, classes, teachers, and departments within an educational institution. The students table stores details about each student, including their ID, first name, middle name, last name, date of birth, email, phone number, address, and a description of the student. The courses table contains information about each course, such as its ID, name, code, creation date, credit hours, and a description. The enrollments table links students to courses they are enrolled in, with each enrollment having a unique ID, the student's ID, the course ID, the enrollment date, and a description. The classes table stores details about each class, including its ID, course ID, name, schedule, room, and a description. The attendance table tracks student attendance in classes, with each attendance record containing a unique ID, the class ID, the student ID, the attendance date, a status, and a description. The grades table stores the marks obtained by students in each course, with each grade record having a unique ID, the enrollment ID, the marks obtained, the total marks, the grade, and a description. The teachers table stores information about each teacher, including their ID, first name, middle name, last name, email, phone number, address, and a description. The teaching assignments table links teachers to classes they teach, with each assignment having a unique ID, the teacher ID, the class ID, and a description. The departments table stores information about each department, including its ID and name, along with a description. The student department table links students to the departments they belong to, with each record containing a description, the student ID, and the department ID. The relationships between these tables are established through foreign keys, ensuring that data integrity is maintained, for example, a student can only be enrolled in a course that exists in the courses table, and a teacher can only teach a class that exists in the classes table.
