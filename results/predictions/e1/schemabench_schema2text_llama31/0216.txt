The schemabench_0216 database is designed to store and analyze data about video game sales and user reviews. The game_sales table contains information about each game, including its title, the platform it was released on, its publisher and developer, the number of copies sold, and the year of release. The game title is the primary key, meaning each game can only be listed once in the database. The reviews table stores user and critic scores for each game, with the game title serving as the primary key. The top_critic_years table tracks the average critic score for each year, with the year being the primary key. The top_critic_years_more_than_four_games table is similar, but it only includes years where more than four games were reviewed, and it also stores the number of games reviewed in that year and the average critic score. The top_user_years_more_than_four_games table does the same for user scores, tracking the average user score for each year where more than four games were reviewed.
