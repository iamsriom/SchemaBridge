The schemabench_0217 database is designed to manage a library system, allowing administrators to manage users, schools, books, and their various relationships. The admin table stores information about the system administrators, with each admin having a unique username and password. The school table contains details about each school, including its name, email, principal's name, address, and phone number. The user table represents individual users, who can be students, teachers, or handlers, and each user has a unique username, password, and school affiliation. The book table stores information about each book, including its ISBN, title, summary, publisher, page count, language, and image. The category table contains a list of categories, and the book_category table links books to their respective categories. The author table stores information about authors, and the book_author table links books to their authors. The key_words table stores keywords associated with each book, and the stores table tracks the availability of books in each school. The applications table manages borrowing requests, tracking the status of each application, and the review table stores user reviews of books, including their evaluation, rating, and approval status. The database enforces various constraints to ensure data integrity, such as unique usernames and email addresses for admins and users, and constraints on the number of available copies of a book in a school.
