The schemabench_0223 database is designed to manage information about candidates, positions, users, and voters in an election process. The Candidate table stores details about each candidate, including their name, service ID, designation, workplace, mobile number, email, and photo path. The CandidatePosition table links candidates to specific positions, with each record referencing a candidate's ID and a position's ID. The Position table contains information about each position, including its name and the number of posts available. The Role table defines different roles, such as the type of role, and is linked to the User table, which stores details about each user, including their name, service ID, mobile number, email, password, and role ID. The VoteCastingInformation table tracks voting information, referencing the candidate's ID, the voter's ID, and the position ID. The Voter table stores details about each voter, including their name, service ID, mobile number, email, blood group, whether they have been selected, whether their vote has been committed, a unique identification number, and whether a mail has been sent to them. The database ensures data integrity through various constraints, such as primary keys in each table, unique constraints in the Voter table, and foreign keys that link tables together, with some referencing other tables with ON DELETE CASCADE rules to ensure that related records are deleted when necessary, while others have ON DELETE RESTRICT rules to prevent deletion of referenced records.
